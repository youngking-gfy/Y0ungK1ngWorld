`.htaccess` 文件是  Apache HTTP 服务器的目录级配置文件，它允许用户覆盖 Web 服务器的系统范围设置，而无需修改全局配置文件（例如 `httpd.conf` 或 `apache2.conf`）。

这里我们可以通过上传  `.htaccess` 文件，其内容设置如下：

```cobol
<FilesMatch ".jpg">
  SetHandler application/x-httpd-php
</FilesMatch>
```
