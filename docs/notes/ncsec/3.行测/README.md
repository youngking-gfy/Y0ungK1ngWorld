# 行测笔记

## 一、考试结构与模块简介

行测主要包括以下模块：

- 言语理解与表达
- 数量关系
- 判断推理
- 资料分析
- 常识判断

## 二、常见题型与解题思路

### 1. 言语理解与表达

- 题型：选词填空、片段阅读、语句排序等
- 技巧：抓主旨句、排除法、定位关键词

### 2. 数量关系

- 题型：数字推理、数学运算
- 技巧：特值法、代入法、公式法、排除法

### 3. 判断推理

- 题型：图形推理、定义判断、类比推理、逻辑判断
- 技巧：归纳法、演绎法、找规律、分类排除

### 4. 资料分析

- 题型：表格、图形、文字资料计算与分析
- 技巧：速算、估算、找突破口、关注单位

### 5. 常识判断

- 题型：法律、科技、人文、地理、时政等常识题
- 技巧：积累、排除、联想、热点关注

## 三、备考建议

- 先整体了解各模块内容，明确复习重点
- 多做真题，熟悉题型和命题规律
- 归纳总结常见解题方法和易错点
- 合理分配时间，注重查漏补缺
- 关注时政热点，积累常识知识

## 四、答题技巧

- 善用排除法、特值法、关键词定位等高效技巧
- 注意时间分配，先易后难，保证做题效率
- 规范书写，条理清晰，避免遗漏要点

## 五、常见问题与解决方法

- 分点不清晰：分类分条作答，层次分明
- 字数控制能力差：合理规划每点字数，精炼表达
- 找不准重点：抓主旨句、关键词，多练习阅读理解
