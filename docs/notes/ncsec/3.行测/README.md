## 二、**经验贴**



### **1.学习顺序**

一阶段：（知觉速度）、资料分析、判断推理

二阶段：言语理解、数量关系

三阶段：政治理论、常识判断（不建议太多时间学，学一些蒙题技巧即可）



### **2.网课名师**


#### **行测，实战80**

#### **行测**：资料是最重要的，也是最好提分的，开始会很煎熬。

高照资料打基础，p神、岳飞资料可提速。 

dy、b站都有很多资料大神，多去借鉴；也有很多人学花生，我觉得花生有点老了，现在像p神、岳飞的高手可能更能拔高

#### **行测**：

**图形推理**-超格刘义恒，真正的神，国考押题全中上热搜，真正的考官思维。（之前也有人学龙飞，但我还是一样的原因，觉得太老了）

**逻辑推理**-b站薛睿，真的很强，考研老师来公考降维打击，b站免费课。（我当时是超格程意打基础，薛睿拔高，可以提速）

**类比推理、定义判断**模块我跟的超格程意，这几个模块可以参考下其他师兄推荐，个人不是很强。

**言语理解**-超格老于，但不是我的强项，可以参考别人

**数量关系**-高照基础、p神拔高，性价比不是很高的模块，一定注意会的题一定要短时间做对

**政治理论、常识判断**-超格超哥，但不是我的强项，可以参考别人



申论和公专不是我强项。

公专可以跟波波，不要跟若冰，然后冲刺课可以跟桐哥冲刺和法师于哲的冲刺考点课，非常厉害。
