- 尾句分析
	- 新对象——解释/描述
	- 现象/论断——描述、分析产生原因
	- 问题——分析、解决问题
	- 隐含倾向——明确倾向
	- 错误认识——正确认识（澄清事实）
	- 一个做法——具体做法
	- 甲对乙的作用——具体作用

- 行文脉络
	- 总分

- 选项
	- 主题词
	- 本文信息不选
		- 原文
		- 逻辑前文
	- 下下文信息不选



**1、考查频次**：一般，考试中考察题目数量在1-2道题左右。
    
**2、题型特征**：根据已知文段推断下文内容。
    
**3、提问方式**：
    
（1）接下来最可能讲的是？

（2）这段文字之后作者最可能阐述/说明的是？

（3）接下来最可能讲的/讲述的是？

（4）根据这段文字，接下来会说明？

## 解题思路

**1、** 原文中论述过的内容，下文不会再出现。比如原文出现XXX的意义，则下文（答案）不会再谈论XXX的意义
    
**2、** 下文内容应与原文话题一致，不会突然跳跃到无关信息。
    
**3、下文推断常见结构**:
    
（1）上文文末给出一个新内容，下文很可能会解释这个新内容。
（2）上文文末给出一个现象，下文很可能围绕这个现象展开，或者解释“为什么”会产生这个现象。
（3）上文文末提出问题，下文很可能分析问题/解决问题。
（4）上文文末给出宏观对策，下文给出具体对策。


**4、下文推断不易识别结构**:
    
（1）时间对比：过去不行 → 现在有了新突破。

（2）总分：上文是总+分 → 下文补充另“分”。

（3）转折关系：然而、但是、尽管 → 下文可能提出相反观点。

（4）举例说明：例如、比如、以…为例 → 顺着观点往下说。

（5）总结结论 → 通常无需展开，下文可能结束(需结合选项判断)。

> 随着近年来题目的难度升级，也有少部分题目的陷阱设置较多一些，当文段尾句谈论的话题比较多难以判断落脚点时，就需要行文脉络找重点的方法，判断出文段尾句重点想要强调的话题。
