## **方法论**


### **位置规律**
#### **平移**

1. 直接向左向右
2. 跳着走
3. 循环左右移动
4. 方格题：移动步数等差数列
5. 相邻两两互换

::: tip
1. 除了小黑球、小方块等常规图形外，空白区域、线段、端点、交点等都可作为平移元素移动
2. 多个相同平移元素在宫格内移动时，由于移动规律不同，可能出现两元素重合
3. 当题干图形明显分为`内外/上下/左右`时，考虑`内外/上下/左右`分开看
4. 元素的移动轨迹有时会被隐藏或者元素只在宫格内局部移动
5. 按上述都没有平移规律时，考虑“相邻比较”小技巧，找相邻两幅图的相同或不同之处

:::

#### **旋转、翻转**

1. 常在九宫格中复合考查
2. 九宫格行没有思路就去看列

::: tip
1. 当元素组成相同，图形明显在原地打转时，考虑旋转
2. 当元素组成相同，两个图形明显关于竖轴（左右对称），横轴对称（上下翻转）

:::

### **样式规律**
#### **加减同异**


1. 结合“分开看”思维，图形外框线条求同，内部线条求异
2. 九宫格横着看找不到规律时，==记得“竖着看”=={.danger}


::: tip
1. 当图形的元素组成相似，且相同线条重复出现时，优先考虑加减同异，其中==求异考查频次最高==
2. 加减同异特征明显，单纯考虑无法解出时，考虑其与位置规律的复合考法
	- 先加减同异，后位置规律
	- 先位置规律，再加减同异

:::



#### **黑白运算**


1. 位置规律和黑白运算对应的图形特征要做好区分:
	- 各图中黑块(球数量相同，优先考虑位置规律;
	- 各图中黑块(球)数量不同，优先考虑黑白运算。
2. 黑白运算题目的计算公式的结果可能是不同的，注意一道题目中黑+白=?”和“白+黑=?”两个公式的结果也可能是不同的，需要具体题目具体分析。
3. 解黑白运算题目时，可能不需要得出全部黑白运算公式的结果，可直接对比选项找差异，根据差异回到题干去找对应位置的计算公式
4. 除了黑白块(球)外，阴影、空白、线段等元素也可以进行黑白运算。
5. 黑白运算题目中，有时会隐藏图形的部分外轮廓，且其内部多是三角形分割区域(如下图所示)，此时也可以优先考虑黑白运算

::: tip
1. 当题干图形轮廓和分割区域相同，但==黑块数量不成规律==时，优先考虑黑白运算。
2. 白白、黑黑、黑白、白黑

:::


#### **遍历**

遍历常见命题思路:
- 元素数量遍历
- 元素颜色遍历
- 元素位置遍历

::: tip
1. 当图形的元素组成相似，且相同元素重复出现时，优先考虑遍历
2. 遍历的解题方法为缺什么补什么。

:::

### **属性规律**

#### **对称性**

图形的对称性共有轴对称、中心对称、轴对称+中心对称三种类型
- 轴对称图形:一个图形如果沿一条直线对折后，直线两边的部分能够完全重合那么该图形是轴对称图形，一个轴对称图形可能有1条或多条对称轴。
- 中心对称图形:一个图形如果绕着某个点旋转 180°，旋转后的图形能与原来的图形完全重合，那么该图形是中心对称图形。
- 轴对称 +中心对称图形:一个图形如果存在两条相互垂直的对称轴，那么该图形是轴对称 + 中心对称图形。

::: tip
1. 当图形明显存在“等腰”特征时，优先考虑轴对称
2. 当图形明显出 现“S"“N”“Z”及其变形图，平行四边形，“大风车”,相同图形反着放等时，优先考虑中心对称
3. 当图形明显存在两条相互垂真的对称轴时，优先考虑轴对称+中心对称，如下图所示。
4. 轴对称的考查角度更多，有以下细化考法
	1. 若题干图形基本都有多条对称轴，优先考虑对称轴的数量
	2. 若题干图形都只有一条对称轴，优先考虑对称轴的方向
	3. 若题干图形都只有一条对称轴，且对称轴的方向无明显规律，可以考虑==对称轴和图形本身的线、点、面的关系==
	4. 若题干图形明显都由两个或三个对称图形组成，或明显可以分为内外/ 左右/上下两部分，优先考虑==分开看==组成图形的对称性

:::

::: warning

1. 黑白块(球)的题目也可以考虑看对称性，优先进行整体观察，整体观察没有对称性时，再考虑只看黑块(球)部分/白块(球)部分的对称性。

2. 九宫格形式的题目，除了可以横向或竖向观察找规律外，还可以按“米”字形观察找规律；且九宫格形式的题目涉及对称轴的数量规律时，若没有等差递增/递减的规律，则可以考虑数量之间能否进行运算，如同一行图 形对称轴的数量分别是1、3、4,可以按照1+3=4的规律选答案。

:::



#### **曲直性、开闭性** 

1. 曲直性：根据组成图形的线条是曲线还是直线，可将图形分为全曲线图形、全直线图形、既有曲线也有直线图形
2. 开闭性：根据图形本身有无封闭区域，可将图形分为全开放图形(图形没有任何封闭区域)、全封闭图形(整个图形是全封闭的)、 半开半闭图形(既有封闭区域，也有开放区域)三种。


::: tip

1. 当题干图形明显大部分存在圆、弧等全曲线图形时，优先考虑曲直性。

2. 当题干图形明显大部分存在生活化图形 (贴近日常生活中物品的图形)、粗线条图形时,可以考虑开闭性。

:::

::: warning

1. 近年来，曲直性和开闭性的考查难度有所增大，有时也可能会利用小元素进行考查。

2. 有些题目考查得没那么细致，全封闭图形和半开半闭图形也可以视为一类，都属于“存在封闭区域的图形”。

3. 曲直性和开闭性经常和其他规律(尤其是数量规律)复合进行考查。

:::

### **数量关系**

#### **点**

这里的“点” 一般指“交点”,可再细分为“切点”“曲直交点”“框上/框内交点”等。

::: tip
1. 当题干图形线条交叉明显、相切较多时，优先考虑数点。
2. 当题干绝大部分图形都存在相切时，可以直接考虑只数切点。
3. 当题干大部分图形均由曲线和直线构成，且曲线和直线交叉明显时，可以直接考虑只数曲直交点。
4. 当题干所有图形都有明显的外框(圆形居多),且框内线条与外框相交时，可以直接考虑只数框上/框内交点。
:::

::: warning

1. 切点，包括曲线与直线相切形成的点，也包括曲线与曲线相切形成的点。

2. 除了平面图形，立体图形也可能会考查数“交点”,即数立体图形的顶点。

3. 数交点的特征图与数笔画的特征图非常相似，若图形数笔画特征明显，但笔画数无规律，也可以考虑数交点。
4. 当单独看交点数不成规律时，可以考虑将框内外交点数做运算，即单看无规律，考虑运算。

:::


#### **线**

这里的“线”一般包括“直线”“曲线”“笔画”。

1. 直线数、曲线数就是构成一个图形的全部直线、曲线数量。

2. 在所经过线条不重复的情况下，一个图形最少可以几笔画成，该数值即该图形的笔画数。比如一笔画图形，指的是该图形在所经过线条不重复的情况下，可以一笔画成。

::: tip

1. 当题干图形出现多边形或单一直线时，优先考虑数直线。
2. 当题干图形出现全曲线图、单一曲线(圆、弧)时，优先考虑数曲线。
3. 当单独看直线数或者曲线数不成规律时，可以考虑将直线数和曲线数==做运算==，即单看无规律，考虑运算。
4. 当题干图形中横线或竖线较多，或作为数线特征图的单一直线为横线或竖线时，可以优先考虑数横线或竖线。
5. 当题干图形出现同一方向上成对的线，如“=”“Z”,或相同形状的图形规则摆放时，可以优先考虑数平行线。
6. 当题干图形出现五角星等明显能一笔画成的图形，“日”“田”及其变形图(框+内部简单线条),圆相切、相交及其变形图，多端点图时，优先考虑数笔画。
7. 对于简单图形，可直接看出其笔画数；而对于复杂的连通图形，需要借助奇点[+奇点]数来判断其笔画数。奇点[+奇点]是指发射出奇数条线的点。
8. 当题干图形均可看成一根线折来折去，类似“贪吃蛇”时，可以考虑看==首尾两段线==之间的关系(平行/垂直)


::: 


::: warning

1. 有的题目除了考查直线数、曲线数及将二者做运算外，还会考查拆分思维。当题干图形存在多个部分时，可以考虑按部分分开看，判断各部分的线数量是否存在规律，以及各部分的线数量做运算后是否存在规律。

2. 图形推理题目中出现汉字，优先将其视作图形，观察图形特征。若汉字图形中横竖线较多，可以考虑数横竖线；若题干图形多为“山”“大”等简单汉字，也可以考虑数汉字的笔画。

3. 在黑白块(球)题目中，若题干图形中 的黑块(球)/白块(球) 都连接在一起，构成粗线条图形，可以考虑数黑块(球)/白块(球)所构成粗线条的笔画数。

4. 笔画数为高频考点，解题没有思路时，可以考虑笔画数，记住“走投无路，试试笔画”。

:::
