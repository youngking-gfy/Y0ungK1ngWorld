### **基础概念**

| 概念   | 记号      | 定义                      | 记忆口诀   |
| ------ | --------- | ------------------------- | ---------- |
| 现期   | $A$       | 比较终点（“比”之前）      | 现在、终点 |
| 基期   | $B$       | 比较起点（“比”之后）      | 基准、起点 |
| 增长量 | $\Delta$  | $\Delta = A - B$          | “差”       |
| 增长率 | $r$       | $r = \Delta/ B = A/B − 1$ | “比”       |
| 倍数   | $N$       | $N = \frac{A}{B}$         |            |
| 比重   | $SG$      | $SG = \frac{A}{B}$        |            |
| 平均   | $\bar{x}$ | $\bar{x} = \frac{S}{n}$   |            |

### **基础增长**

| 求值  | 记号       | 公式 1            | 公式 2               | 公式 3                           |
| --- | -------- | --------------- | ------------------ | ------------------------------ |
| 现期  | $A$      | $B + \Delta$    | $B\cdot(1+r)$      | $\frac{\Delta}{r} \cdot (1+r)$ |
| 基期  | $B$      | $A - \Delta$    | $\frac{A}{1+r}$    | $\frac{\Delta}{r}$             |
| 增长量 | $\Delta$ | $A - B$         | $B \cdot r$        | $\frac{A}{1+r} \cdot r$        |
| 增长率 | $r$      | $\frac{A-B}{B}$ | $\frac{\Delta}{B}$ | $\frac{\Delta}{A-\Delta}$      |

::: tip

==本质==
$$\frac{A}{B}=1+r$$

:::

### **倍数**

| 倍数   |       |                         |
| ------ | ----- | ----------------------- |
| 是几倍 | $N$   | $N = \frac{A}{B}$       |
| 多几倍 | $N-1$ | $N-1 = \frac{A}{B} - 1$ |

### **比重**

| 比重         |                 |                                                         |
| ------------ | --------------- | ------------------------------------------------------- |
| 比重         | $SG$            | $SG = \frac{A}{B}$                                      |
| 基期比重     | $SG_{B}$        | $SG_{B} = \frac{a-\Delta{a}}{A-\Delta{A}}$              |
|              |                 | $SG_{B} = \frac{a}{A} \cdot \frac{1+r_{A}}{1+r_{a}}$    |
| 比重增长量   | $\Delta_{SG}$   | $\Delta_{SG} = \frac{a}{A} \cdot \frac{r_a-r_A}{1+r_a}$ |
| 比重变化依据 | $r_a-r_A$正负值 | ·正数：上升<br>·零数：相等<br>·负数：下降               |

### **平均数**

$\bar{x} = \frac{S}{n}$

| 平均         |                |                                                        |
| ------------ | -------------- | ------------------------------------------------------ |
| 平均         | $\bar{x}$      | $\bar{x} = \frac{S}{n}$                                |
| 基期平均数   | $\bar{B}$      | $\bar{B} = \frac{S}{n} \cdot \frac{1+r_B}{1+r_A}$      |
| 平均数增长量 | $\bar{\Delta}$ | $\bar{\Delta}=\frac{S}{n} \cdot \frac{r_S-r_n}{1+r_S}$ |
| 平均数增长率 | $\bar{r}$      | $\bar{r}=\frac{r_S-r_n}{1+r_n}$                        |

### **隔年增长率**

| 隔年增长率 |             |                                             |
| ---------- | ----------- | ------------------------------------------- |
| 隔年增长率 | $r_{n→n+2}$ | $r_{n→n+2}=r_1+r_2+r_1 \cdot r_2$           |
| 隔年基期   | $B_{1}$     | $B_{1}=\frac{A_2}{1+r_1+r_2+r_1 \cdot r_2}$ |
