# 速算技巧1

## 加、减法
- 尾数法
  - 何时用：加、减法，精算，尾数不同
  - 怎么用：尾数进行加减，观察选项
- 高位叠加
  - 何时用：多个数加和，精算、估算
  - 怎么用：从高位加起，精算，一加到底，估算，两加一估
- 划线减法
  - 临界值：插入临界值
  - 普通数值：划线，以好算、少借位为前提

## 乘法
- 高位乘法
  - 何时用：多位数 × 一位数
  - 怎么用：高位乘起，最后叠加
- 拆分法
  - 何时用：多位数 × 多位数，保留两位，且有一个数接近整十
  - 怎么用：先按整十计算，再分析误差
- 口诀法
  - 何时用：多位数 × 多位数，保留两位，不接近整十
  - 怎么用：前前后后，里里外外
- 特殊数字
  - 技巧1：一个数 × 1.5，等于这个数 + 本身的一半
  - 技巧2：一个数 × 1.1，等于这个数错位相加
  - 技巧3：一个数 × 0.9，等于这个数错位相减
  - 技巧4：百化分，CP法辅助记忆

# 速算技巧2

### 分数拆分
- 何时用：分数在1、50%左右
  - 怎么用：化1法、化半法

### 截位直除
- 何时用：除法估算
  - 怎么用：
    - 差距大，保留两位
      - 首位均不同
        - 首位相同，第二位不同，第二位差 > 首位
    - 差距小，保留三位
      - 首位均不同，但为临界值，例如：59 与 61
      - 首位相同，第二位不同，第二位差 ≤ 首位
    - 差距极小，保留四位
      - 前两位相同
  - 看选项
    - 一步除法，截分母，厂除
    - 多步除法，截分子、分母，约分
  - 看量级
    - 选项之间位数相同，无需考虑量级，计算有效数字即可
    - 选项之间存在约10、100倍的关系，先看量级，再计算

### 等比修正
- 何时用：复杂除法（主要用于基期差值、基期比例，选项差距小）
- 怎么用：
  - 估倍数：大致估算分子、分母间倍数
  - 同加减：分子、分母原来几倍，其加上或减去的数也为几倍

### 分数比较
- 何时用：分数比较
- 怎么用：
  - 先分析：分子大，分母小，分数大
  - 再比较：竖着直接除，横着看倍数

## **加、减法**

### **1. 尾数法**

- 适用条件：
    - 加减法精算
    - 精确度一致（如都是个位数）
    - 选项尾数不同
- 操作步骤：直接计算尾数后对比选项
:::warning
小数点看清，位数对应

减法先判正负，大减小
:::

### **2. 高位叠加法**

- 核心思想：数据的有效性原则（高位数字更重要）
- 适用场景：多个数加和（精算/估算均可）
- 操作方法：
    - 精算：从高位到低位逐位相加
    - 估算："两加一估"（前两位精算+第三位估算）


### **3. 划线减法**


#### **1）临界值减法**

- 临界值法：插入整百数计算，如714-688= (714-700)+(700-688)=14+12=26

#### **2）普通数值减法**

﻿
- 普通数值法：
	- 划线原则：避免借位，按位数对齐
	- 示例：816-634可分解为(81-63)=18和(6-4)=2→182
	- 补零规则：56-47=09需补零，防止位数错位（如756-347=409）


## **乘法技巧**

﻿

#### **1.高位乘法**

- 适用场景：多位数×一位数的快速口算
- 核心原理：从高位向低位逐位计算，最后叠加结果
- 优势：避免传统竖式计算中容易遗忘进位的问题，保证计算准确性

| A   | B   | A×B |
| --- | --- | --- |
| 84  | 5   |     |
| 75  | 6   |     |
| 65  | 7   |     |


- 计算步骤：
	- $84×5：80×5=400，4×5=20 → 400+20=420$
	- $75×6：70×6=420，5×6=30 → 420+30=450$
	- $65×7：60×7=420，5×7=35 → 420+35=455$
- 注意事项：建议从高位开始计算，因为高位数字对结果影响更大

### **2.拆分法乘法**


- 适用条件：多位数×多位数，保留两位有效数字，且有一个乘数接近整十数
- 操作方法：
    - 将接近整十的数拆分为整十数±差额
    - 先计算整十数乘法，再调整差额部分
- 典型例题：
    - $53×21=53×20+53×1=1060+53=1113$
    - $53×19=53×20-53×1=1060-53=1007$
- 优势：简化计算过程，减少心算负担

### **3.口诀法乘法**

﻿
- 口诀法介绍与何时使用
    - 适用场景：两位数×两位数，且数字不接近整十的情况
    - 核心口诀：=="前前后后，里里外外"==
        - 前前：十位×十位（千位百位）
        - 后后：个位×个位（十位个位）
        - 里里：第一个数的个位×第二个数的十位
        - 外外：第一个数的十位×第二个数的个位
- 例题1：56×36的计算
    - 计算过程：
        - 前前：50×30=1500
        - 后后：6×6=36
        - 里里：6×30=180
        - 外外：50×6=300
        - 叠加：1500+300+180+36=2016
- 例题2：47×36的计算
    - 计算过程：
        - 前前：40×30=1200
        - 后后：7×6=42
        - 里里：7×3=21（实际为70×3=210）
        - 外外：40×6=240
        - 叠加：1200+240+210+42=1692


### **4.特殊数字乘法**
﻿
- 一个数乘以1.5的算法
    
    - 计算原理：
        
       $﻿a×1.5 = a + \frac{a}{2}$
        
    - 示例：
        - 120×1.5=120+60=180
        - 124×1.5=124+62=186
- 一个数乘以1.1与0.9的算法
    
    - 1.1计算原理：
        
        ﻿$a×1.1 = a + \frac{a}{10}$
        ﻿（错位相加）
        - 120×1.1=120+12=132
        - 124×1.1=124+12.4=136.4
        - 135×1.1=135+13.5=148.5
    - 0.9计算原理：
        
        ﻿$a×0.9 = a - \frac{a}{10}$﻿
        （错位相减）
        - 120×0.9=120-12=108
        - 124×0.9=124-12.4=111.6
    - 注意事项：划线减法时要注意位数对齐，避免计算错误

#### **7）百化分应用**


##### 1）例题:乘法运算

﻿
- 解题技巧：当遇到$134249 \times (1+10.2\%)$时，可转化为﻿$134249 \times 1.102$计算
- 速算方法：一个数乘以1.1可采用错位相加法，即原数+原数前移一位（如$134249+13424.9$）
- 结果验证：通过速算得到约147000的结果，对应选项C（147942）
- 记忆要点：百分数转换为小数计算时，注意小数点位置（10.2%→0.102）

##### 2）例题:除法运算

﻿
- 近似转换：
    
    ﻿$\frac{23.2}{24.8\%}$中，24.8%可近似为25%（即1/4）
- 运算简化：除以1/4等价于乘以4，因此
    
    ﻿$23.2 \times 4=92.8$﻿
    
- 选项分析：计算结果92.8最接近选项D（93.5）
- 误差控制：实际值24.8%小于25%，故计算结果应略小于92.8
- 核心口诀："除以百分数≈乘以倒数"，需熟记常见百分数分数对应关系

##### 3）例题:百分数转换

﻿
- 基准选择：12.6%接近12.5%（即1/8），因此
    
    ﻿$\frac{65391}{12.6\%}≈65391 \times 8$
    
- 计算过程：
    - ﻿$60000 \times 8=480000$
    - ﻿$5000 \times 8=40000$
    - ﻿$300 \times 8=2400$
    - ﻿$90 \times 8=720$
    - $﻿1 \times 8=8$﻿
    - 合计：523,128→约52.3万
- 误差分析：
    - 实际分母12.6% > 基准12.5%，故计算结果偏大
    - 排除大于52.3万的选项（C、E）
- 选项验证：最接近正确值的选项是D（51.9万）

##### 4）例题:分数运算

- 分数转换：66.7%对应2/3，即1.5分之1
- 运算技巧：
    
    $\frac{262}{66.7\%}=262 \times 1.5$
    
- 速算方法：一个数乘1.5等于该数加其一半（262+131=393）
- 记忆要点：关键百分数对应关系：
    - 66.7%→2/3
    - 14.3%→1/7
    - 16.6%→1/6
