# 平均数
## 识别
- 关键字：平均、每
- 特殊表述：单价、亩产量、单位企业实现利润
## 现期平均数
### 列式方法
- 方法一：后 ÷ 前
- 方法二：单位做分子
- 方法三：再后做分母
### 双重平均数
出现月均、日均的双重平均数，均谁除谁，谁归算，先除谁
### 算总数
总数 = 平均数 × 个数
### 特定平均数
- 判断平均约大于某一数值的有几个
- 注意单位
### 多个数求平均
- 数据相差小，削峰填谷，分析选项
- 数据相差大，凑整加和或截位相加，再直除
### 平均数比例类比
给分子，不给分母，求平均数
  - 第一步：找到分母相同的另一平均数
  - 第二步：类比，分子是几倍，平均数是几倍
## 基期平均数
### 给现期、增长量
基期平均数 = $\frac{分子 - 分子增长量}{分母 - 分母增长量}$
### 给现期、增长率
基期平均数 = $\frac{A}{B} \times \frac{1 + b}{1 + a}$
  - 分析：算前看后
  - 计算：
    - 差距大，两位约分
    - 差距小，三位化 1
## 两期平均数
### 比较
问法一：判断平均的升降
  - $a > b$ → 平均数上升
  - $a < b$ → 平均数下降
### 计算
- 平均数增长量 = $\frac{A}{B} \times \frac{a - b}{1 + a}$
  - 优化列式，重在分析，注意量级
  - $a > b$ → 平均数上升
  - $a < b$ → 平均数下降
- 问法二：连续年份平均比较
  - 给增长率：不给增长率，先看比例，再看增速
- 平均数增长率 = $\frac{a - b}{1 + b}$
  - 优化式，重在分析
