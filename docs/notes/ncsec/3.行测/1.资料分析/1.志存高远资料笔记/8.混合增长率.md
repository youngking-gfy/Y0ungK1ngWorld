# 混合增长率
## 识别
计算增长率，数据不全，主体可转化为加和或差值
## 常规考法
### 第一步：找关系
总体 = 部分1 + 部分2
### 第二步：定位置
总体在中间，部分在两边
### 第三步：先口诀，后线段
#### 口诀法
混合增长率居中；偏向基期量（一般参考现期）大的一方
#### 线段法
距离与量成反比
- 距离：部分增长率与总体增长率的差值
- 量：部分的基期（一般参考现期）
#### 反例
现期接近或部分增长率相差较大时，口诀法、线段法中均用基期，不能用现期参考
## 累计增速
- 当月增速 > 累计增速，就找累计增速上升
- 当月增速 < 累计增速，就找累计增速下降
## 多者混合
- 居中，偏向
- 拆分成多个两两混合，优先找等量混合
## 固定搭配与转化
### 固定搭配
- 进出口 = 进口 + 出口
- 全国 = 城镇 + 农村
- 邮电 = 邮政 + 电信
- 本外币 = 人民币 + 外币
- 全年 = 1 - 11月 + 12月
- 一季度 = 1 - 2月 + 3月
### 差值转化
- 出口 - 进口 = 顺差
- 进口 - 出口 = 逆差
- 收入 - 支出 = 盈余
### 矛盾关系
- 总体 = A + 非A
