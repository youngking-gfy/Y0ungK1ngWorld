# 一般增长率
## 计算（识别：问增长的比例（百分数、倍数）为多少？）
### 给现期增长率、百分点
- 第一步：看加减，高减低加
- 第二步：看规则
	- 增速、增幅上升或下降，有负号，带符号
	- 降幅扩大或收窄，带绝对值算降幅，再转化增长率
### 给现期、基期、增长量任意两个
- 增长率 = 增长量 ÷ 基期
- 优化习惯，口算加减，直接厂除
### 特定增长率
#### 给现期、基期
- 方法一：转化倍数
  - 增长率 ＞ 10% → 现期 ＞ 1.1 × 基期 （错位相加）
  - 增长率 ＞ 50% → 现期 ＞ 1.5 × 基期 （本身 + 一半）
- 方法二：看前三位，口算增长量，计算增长率
#### 给现期、增长量
- 增长率 ＞ 100% → 2 × 增长量 ＞ 现期
- 增长率 ＞ 1% → 101 × 增长量 ＞ 现期
## 比较（识别：问谁增长的最快或最慢？）
### 给现期、基期
- 倍数差异明显，比较倍数，倍数大，增长率大
- 倍数差异不明显，比增长率，看前三位，口算增长量
	- 先分析：增长量大，基期小，增长率大
    - 再比较：增长量 ÷ 基期
- 技巧：材料为柱状图，高度差占柱子比例越大，当年增长率越大
### 给现期、增长量
- 比较“增长量 ÷ 现期”，结果越大，增长率越大，只能比效用，计算不可行
## 易错点
### 增幅、降幅、变化幅度
- 增幅（增长率、增速）可表示上升、下降，比较时，增长率带正、负号比较
- 降幅只表示下降，比较时，比较增长率的绝对值
- 变化幅度可表示上升、下降，比较时，比较增长率的绝对值
### 增长率与倍数的转化
- 增长几倍 = 增长率
  - 增长 1 倍 → 增长 100%
  - 增长 1.2 倍 → 增长 120%
- 是几倍 = 增长率 + 1
  - 增长 1 倍 → 是 2 倍
  - 增长 20% → 是 1.2 倍
- 增长率 = 是几倍 - 1
  - 是 2 倍 → 增长 100%
  - 是 1.2 倍 → 增长 20%
