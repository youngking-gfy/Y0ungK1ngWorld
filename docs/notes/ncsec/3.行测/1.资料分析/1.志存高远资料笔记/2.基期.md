# 基期

### 计算
- 识别：向过去的量是多少？
  - 给现期、变化量，高减低加
    - 基期 = 现期 - 增长量
    - 基期 = 现期 + 减少量
    - 基期 = 增长量 ÷ 增长率
  - 给增长量、增长率
    - 考的少，棉花种植类材料可能考
  - 基期 = 现期 ÷ 1+增长率
    - 差距大，广除两位
    - 差距小，广除三位，|r| ≤ 5%时，可化除为乘
    - 差距极小（前两位相同），广除四位
  - 基期和差 = A ÷ 1+a - B ÷ 1+b
    - 方法一：算一半，看一半
    - 方法二：能瞪则瞪，不列式广除，或者等比修正，分母化同
  - 复杂类
    - 识别：算基期，数不够，存在总分结构，给比重
    - 情况一：给所求主体的增长率
      - 基期 = 现期 ÷ 1+增长率
      - 分子需要转化：部分 = 总体 × 比重
    - 情况二：不给所求主体的增长率
      - 部分基期 = 总体基期 ÷ 基期比重
      - 总体基期 = 部分基期 × 基期比重

### 比较
- 识别：向过去的量谁大谁小？
- 给现期、变化量，高减低加，对比排除
- 基期 = 现期 ÷ 1+增长率
  - 先分析：现期大，增长率小，基期大
  - 再比较：分数比较
