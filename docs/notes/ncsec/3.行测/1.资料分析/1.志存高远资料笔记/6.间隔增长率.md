# 间隔增长率
## 间隔增长率
- 识别: 隔一期, 问增长的比例为多少?
- 公式: 间隔增长率$r = r_1 + r_2 + r_1r_2$，简称: 和 + 积 
## 间隔倍数
- 识别: 隔一期, 问是几倍或多几倍?
- 第一步: 估算间隔增长率
  - 是几倍 = 间隔增长率 + 1
  - 多几倍 = 间隔增长率 
## 间隔基期
- 识别: 隔一期, 问过去的量为多少?
- 第一步: 估算间隔增长率
  - 差大, 估算至十位
  - 差小, 估算至个位 
- 第二步: 厂除, 算基期 
## 间隔现期
- 识别: 保持增长率不变, 隔一期, 问期本值为多少?
- 第一步: 估算间隔增长率 
- 第二步: 间隔现期 = 基期 × (1 + 间隔增长率) 
## 间隔增长量
- 识别: 隔一期, 问增长的具体值为多少?
- 第一步: 估算间隔增长率 
- 第二步: 百化分, 算增长量 
## 逆运用: 求基期增长率
- 同比与环比
  - 给$r_1$、间隔增长率, 求$r_2$，$r_2 = \frac{间隔增长率 - r_1}{1 + r_1}$ 
  - 给$r_1$、两年平均增长率$r$, 求$r_2$ 
    - 第一步 间隔增长率 = $r + r + r×r$ 
    - 第二步 $r_2 = \frac{间隔增长率 - r_1}{1 + r_1}$ 
- 同比套环比、同比套年差
  - 方法一: 转化成间隔增长率 
  - 方法二: 按本质, 先算基期、现期, 再算增长率 
## 间隔多年增长率(西瓜 + 芝麻)
- 间隔增长率 ≈ 年均增长率 × 年份差 
- 各年增长率 > 0 时, 间隔增长率 > $r_1 + r_2 + r_3 + \cdots\cdots$
