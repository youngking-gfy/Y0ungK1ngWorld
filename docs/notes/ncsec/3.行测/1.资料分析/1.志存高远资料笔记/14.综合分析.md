# 综合分析
## 找分析
分析性选项优先看
- 两期比例比较
- 混合增长率，看范围
- 当月与前几月均值比较
## 看表述
### 绝对的容易错
均、都、同一个、逐年上升或下降、首超
### 委婉的容易对
约
## 避陷阱：典型陷阱，绕道而行
- 多几倍，常混淆“是几倍”
- 日均、月均，忘记除以天数、月份，或算错量级
- 单位不同，转化麻烦，容易失误
## 易到难
直接找数 → 加减 → 一步除法 → 增长量 → 增长率 → 基期或两期比例计算
## 敢常识
材料为真实统计，具有客观性
- 常见人口、经济等常识
- 正能量：好的越来越好，坏的越来越少
