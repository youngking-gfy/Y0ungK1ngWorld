# A与非A
## A与非A的值
- A + 非A = 总体
## A与非A的增长量
- A的增长量 + 非A的增长量 = 总体的增长量
## A与非A的增长率
- 混合增长率
  - 居中、偏向
  - 线段法：量之比为比例的分母（基期）之比
## A与非A的比重
- 混合比重
  - 居中、偏向
  - 线段法：量之比为比例的分母（总体）之比
- 给倍数，问比重，转化倍数
  - A的占比为50% → A = 非A
  - A的占比为66.7% → A ≈ 2 × 非A
  - A的占比为75% → A = 3 × 非A
- A与非A的倍数越大，A的占比越大
## A与非A的平均数
- 混合平均数
  - 居中、偏向
  - 线段法：量之比为平均数的分母之比
## A与非A的倍数
- 混合增长率：居中、偏向
- 给比重，问倍数，转化比重
  - A是非A的2倍 → A的占比约为66.7%
  - A是非A的3倍 → A的占比为75%
