# 中国古代文化成就

### 诸子百家
- 儒家
  - 孔子
    - 儒家学派创始人，被后世尊为“万世师表”“至圣”
    - “礼”与“仁”
    - “为政以德”
    - “有教无类”，“因材施教”
    - 编订六经《诗》《书》《礼》《易》《乐》《春秋》
    - 《论语》是孔子弟子及再传弟子记录孔子及其弟子言行而编成的语录集
  - 孟子
    - “亚圣”
    - 性善论
    - “仁政” — “民为贵，社稷次之，君为轻”
    - 著作《孟子》
  - 荀子
    - “性恶论”
    - 主张礼法并用
    - 著作《荀子》（首篇《劝学》）
- 道家
  - 老子
    - 道家学派创始人
    - 主张“道” — 道法自然、无为而治
    - 著作《老子》/《道德经》
  - 庄子
    - 著作《庄子》/《南华经》
    - 主张相对主义和绝对的精神自由
- 墨家
  - 墨子
    - 墨家学派创始人
    - 著作《墨子》
- 法家
  - 韩非
    - 主张法术势兼用
    - 著作《韩非子》
- 兵家
  - 春秋-孙武-《孙子兵法》（世界上最早的兵书）
  - 战国-孙膑-《孙膑兵法》
