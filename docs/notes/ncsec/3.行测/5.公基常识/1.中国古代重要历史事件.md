# 中国古代重要历史事件

### 夏朝
- 大禹建立夏朝
- 王位世袭制取代禅让制
  - 禹死启继
- 鸣条之战
	- 夏桀VS商汤

### 商朝
- 盘庚迁殷
- 武丁中兴
- 牧野之战
	- 商王VS周武王
	  - 典故：阵前倒戈

### 周朝
- 分封制
- 周幽王烽火戏诸侯
- 平王东迁
  - 进入东周时期
- 三家分晋
  - 春秋之终、战国之始的分水岭
- 长平之战
	- 秦国VS赵国
- 百家争鸣

### 秦朝
- 建立于BC221年，嬴政称帝
- 大泽乡起义


### 汉朝
- 楚汉之争
  - 以项羽败亡、刘邦称帝告终
- 文景之治
- 汉武帝时期：开通丝绸之路
  - 张骞出使西域
- 封狼居胥
	- 霍去病
- 王莽篡汉
  - 建立新朝
- 光武中兴
	- 东汉光武帝刘秀
- 黄巾起义


### 三国两晋南北朝
- 官渡之战
	- 曹操VS袁绍
- 赤壁之战
    - 孙刘联军以少胜多
- 三国鼎立
  - 曹丕、刘备、孙权先后称帝
- 夷陵之战
  - 孙吴败蜀军
- 司马炎
  - 西晋建立
- 八王之乱
- 永嘉南渡与东晋建立
  - 司马睿
- 淝水之战
  - 东晋VS前秦
- 北魏孝文帝改革
  - 主要内容是汉化运动

### 隋朝
- 开皇之治
  - 隋文帝
- 科举制
- 扩建京杭大运河
	- 隋炀帝

### 唐朝
 - 贞观之治
    - 唐太宗

- 开元之治     
    - 唐玄宗

- 安史之乱
  - 安禄山、史思明发动的叛乱，使唐朝由盛转衰

- 黄巢起义
    - 一场农民起义


### 宋朝

- 陈桥兵变
  - 赵匡胤；又称黄袍加身
- 澶渊之盟
  - 宋辽在澶州订立的盟约
- 王安石变法
  - 宋神宗熙宁年间
- 靖康之难
  - 金灭北宋
- 崖山海战
    - 南宋与蒙古的最后一次大决战


### 元朝
- 李儿只斤·铁木真
  - “尊号”成吉思汗
- 元朝建立
  - 忽必烈公布《建国号诏》
- 行省制
  - 西藏地区正式成为我国中央政府直接管辖的一个宣政院地方行政区域
- 澎湖巡检司
  - 中央政权最早管理台、澎的行政机构


### 明朝
- 洪武之治
  - 朱元璋
- 建设故宫
  - 永乐年间
- 成立内阁
  - 成立于明成祖时
- 郑和下西洋
 - 明成祖以来郑和率船队7次远航
- 土木之变
  - 亲征蒙古瓦刺部的明英宗兵败被俘于土木堡
- 戚继光抗倭
  - 嘉靖年间
- 一条鞭法
  - 张居正改革
- 李自成起义
  - 崇祯年间

### 清朝
- 清顺治年；吴三桂
  - 清军入关
- 郑成功收复台湾
- 康乾盛世
  - 康熙、雍正、乾隆
- 军机处
  - 清雍正以来直接协助皇帝处理军政机要的中枢机构
