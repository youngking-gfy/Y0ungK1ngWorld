### **例题：音乐系美术系总人数比**

:::: card-grid
::: card title="例题 1：音乐系与美术系总人数比求解" icon="svg-spinners:blocks-shuffle-3"

<Badge type="warning" text="比例计算" />十字交叉法应用

某高校艺术学院分音乐系和美术系两个系别，已知学院男生人数占总人数的 30%，且音乐系男女生人数之比为 1:3，美术系男女生人数之比为 2:3。问音乐系和美术系的总人数之比为多少？

**选项**：

A: 2:1 B: 3:1 C: 5:1 D: 5:2

**答案**：!!A!!

::: collapse

- **解析**：
  - **已知条件**：
    - 学院男生占总人数比为 3/10
    - 音乐系男生占本系总人数比为 1/4（因男女生比\(1:3\) ）
    - 美术系男生占本系总人数比为 2/5（因男女生比\(2:3\) ）
  - **解题关键**： 用十字交叉法时，分母对应总人数，需统一比例分母。将\(1/4\)、\(2/5\)、3/10\)通分为 5/20\)、\(8/20\)、\(6/20\) 。
  - **计算过程**：
    - 音乐系与整体男生占比差：\(6 - 5 = 1\)
    - 美术系与整体男生占比差：\(8 - 6 = 2\)
    - 音乐系和美术系总人数比为差的反比，即\(2:1\) 。
  - **验证方法**： 改用女生占比计算（音乐系女生占\(3/4\)、美术系女生占\(3/5}\)、整体女生占\(7/10\) ），通分后重复计算，结果仍为\(2:1\) 。
  - **易错点**： 直接用原始比例（男女生比）代入十字交叉，未统一分母对应总人数，会导致错误。

:::

::: card title="例题 2：音乐系与美术系女生人数比求解" icon="svg-spinners:blocks-shuffle-3"

<Badge type="warning" text="比例计算" />分母锁定原则

某高校艺术学院分音乐系和美术系，已知学院男生占 30%，音乐系男女生比\(1:3\)，美术系男女生比\(2:3\)。求音乐系和美术系女生人数之比？

**答案**：!!（5:2）!!

::: collapse

- **解析**：
  - **方法选择**： 求女生人数比，需将 “女生” 置于分母，可通过 “女：总” 或 “男：女” 比例推导。
  - **计算过程**：
    - 音乐系女：总 = 3/4，美术系女：总 = 3/5，整体女：总 = 7/10 。
    - 通分统一分母（如 21/28、21/35)、21/30 ），计算差值得女生人数比为\(5:2\) 。
  - **易错点**： 直接用原始男女生比（\(1:3\)、\(2:3\) ）计算，未转换为 “女：总” 或对应分母，会得出错误结果。

:::

::: card title="例题 3：音乐系与美术系男生人数比求解" icon="svg-spinners:blocks-shuffle-3"

<Badge type="warning" text="比例计算" />分母灵活转换

某高校艺术学院分音乐系和美术系，已知学院男生占 30%，音乐系男女生比\(1:3\)，美术系男女生比\(2:3\)。求音乐系和美术系男生人数之比？（题目隐含，需推导）

**答案**：!!5:4!!

::: collapse

- **解析**：
  - **方法选择**： 求男生人数比，需将 “男生” 置于分母，可通过 “男：总” 或 “女：男” 比例推导。
  - **计算过程**：
    - 音乐系女：男 = \(3:1\)，美术系女：男 = \(3:2\)，整体女：男 = \(7:3\) 。
    - 通分统一分母（如 18/6、14/6、9/6），计算差值得男生人数比为 5:4 。
  - **验证方法**： 改用 “总：男” 比例（音乐系\(4:1\)、美术系\(5:2\) ），通分后重复计算，结果仍为\(5:4\) 。
  - **易错点**： 混淆 “男生比” 与 “总人数比” 的分母逻辑，误将总人数比分母代入男生比计算。

:::
