### **一、数量**

#### **1. 数量学习的方法**

##### **1）学习策略**

- 作用比例：听课仅占学习效果的**10%-20%**，**80%-90%** 需要通过课后练习完成
- 双重目标：
    - 提高数学思维能力（需长期积累）
    - 记忆固定套路题型（考场快速解题关键）
- 时间特性：行测数量关系平均每题仅有1-1.5分钟解题时间

##### **2）备考建议**

- 难度应对：
    - 考试难度存在波动，近年整体呈下降趋势
    - 不能因某次考试难而放弃学习，2023国考数量较简单
- 时间分配：
    - 政治理论+常识共35题，做题快会挤出更多数量时间
    - 建议基础差者定"10分钟做5道"目标，剩余题目按选项分布蒙答

##### **3）考场技巧**

- 做题顺序：
    - 先做固定套路题（30秒/题）
    - 再做简单基础题
    - 最后攻克难题
- 正确率控制：
    - 做出5道+蒙对2道≈7道正确
    - 举例：2025国考15题用时15分钟，其中4分钟浪费在列错方程
