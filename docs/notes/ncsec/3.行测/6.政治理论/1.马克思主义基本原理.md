## **一、导论**

**马克思主义的科学内涵**：马克思主义是由==马克思==和==恩格斯==创立并为后继者所不断发展的科学理论体系(==A=={.info}),是关于自然、社会和人类思维发展一般规律的学说，是关于社会主义必然代替资本主义、最终实现共产主义的学说，是关于无产阶级解放、全人类解放和每个人自由而全面发展的学说，是指引人民创造美好生活的行动指南。

**马克思主义理论体系**（==考对应关系=={.info}）：由三个基本组成部分包括

- **马克思主义哲学**
	- 直接理论来源：**德国古典哲学**

- **马克思主义政治经济学**
	- 直接理论来源：**英国古典政治经济学**

- **科学社会主义**
	- 直接理论来源：**英法空想社会主义**

**马克思主义诞生的标志**：

- ==1848年2月==发表的马克思和恩格斯合写的《共产党宣言》，标志着科学社会主义的诞生和马克思主义的公开问世。

- ==1920年8月==，《共产党宣言》中译本问世，**译者陈望道**（==B==）

**马克思两大发现**：

- 唯物史观
- 剩余价值学说

**马克思主义的鲜明特征**（==考对应关系=={.info}）：

1. 科学性——马克思主义是对自然、社会和人类思维发展本质和规律的==正确==反映。

2. 革命性——集中表现为它的彻底的批判精神和鲜明的==无产阶级立场==。

3. 实践性——实践观点是其==首要的==和==基本的==观点（==C==）。

4. 人民性——坚持人民立场是马克思主义最鲜明的==政治立场==。

5. 发展性——马克思主义具有==与时俱进==的理论品质。

## 二、哲学概论

### **1、哲学的概念**

> 哲学是==理论化、系统化的世界观==，是==世界观和方法论的统一==，是==有关自然、社会、人类思维知识==的概括和总结。


#### **哲学与世界观和方法论的关系**

- **世界观** 世界观是人们对于生活在其中的现实世界以及人与现实世界关系的总体看法和根本观点
- **方法论** 方法论是人们观察问题和处理问题的根本方法

==世界观决定方法论，方法论体现世界观=={.danger}

- **哲学** 哲学是关于世界观的系统化和理论化，是以总体方式把握人与世界的理论体系

#### **哲学与具体科学的关系**：


| 区别/联系    | 哲学                                       | 具体科学                            |
| -------- | ---------------------------------------- | ------------------------------- |
| **研究对象** | 以包括自然、社会和人类思维在内的整个世界的最一般规律为研究对象          | 以世界某一特殊领域的具体规律为研究对象             |
| **理论特征** | 一般性、普遍性、抽象的                              | 个别性、特殊性、具体的                     |
| **联系**   | 以具体科学为基础，没有具体科学的发展，哲学既不可能产生，也不可能发展。      | 以哲学为指导，哲学为具体科学的研究提供的世界观和方法论的指导。 |
| **总述**   | 哲学与具体科学是==共性与个性、一般与特殊==（普遍与特殊、一般与个别）的关系。 | 哲学是具体科学的基础，哲学给具体科学以世界观和方法论的指导。  |

### **2、哲学的基本问题（1个）**

**哲学的基本问题是，思维和存在的关系问题，即意识与物质的关系问题**，这个问题包括以下两个方面：

- **思维和存在**何者为==第一性==：思维和存在、精神和物质，谁是本原，谁是派生的问题。对这方面问题的不同回答，是划分哲学党性即==唯物主义和唯心主义=={.danger}两大派别的唯一标准。

- **思维和存在**是否具有==同一性==：思维能否认识现实世界或世界是否可知的问题。对这个问题的不同回答，把哲学区分为==可知论和不可知论=={.danger}。可知论认为思维和存在具有同一性， 世界是可以被认识的；不可知论认为思维和存在不具有同一性，世界是无法被认识的。

 **唯物主义和唯心主义的对立**：

- 唯物主义主张存在是世界的本原，先有物质后有意识，物质决定意识。
- 唯心主义主张思维是世界的本原，先有意识后有物质，意识决定物质。

### **3、唯物主义和唯心主义**

**古代朴素唯物主义**：认为某种物质的具体形态`金、木、水、火、土、阴阳、天地`是世界的本原，其否认了神创造世界，坚持了唯物主义的方向，但这是一种可贵的猜测，没有科学依据，把复杂的问题简单化了。例如“世界是一团活火”、“天地合而万物生，阴阳接而变化起”等。

**近代形而上学唯物主义（机械唯物主义）**：基本特征是把基本粒子的构成、物质结构、物质结构的某种属性即原子作为世界的本原；其具有了一定的科学依据，但用==孤立的、静止的、片面的==观点看问题，把复杂的问题简单化了，具有形而上学性。例如“生命是架化学机器”、“世界的本原是原子”等。

**辩证唯物主义和历史唯物主义**：不仅承认世界的本原是物质、物质决定意识，而且承认意识对物质具有反作用，认为人类社会在本质上也是物质的。例如“物质决定意识，意识对物质有能动的反作用”。==客观实在性是物质的本质属性==。

**唯心主义**：唯心主义根据精神的不同又可以分为主观唯心主义与客观唯心主义，二者的区别在于对 “精神” 的不同规定，但它们的实质都是一样的，都是把精神作为世界的本原。

- **主观唯心主义**：主张==人的精神=={.info}是世界的本源（人、我、心）

- **客观唯心主义**：人之外的精神“客观精神”是世界的本源

|        | 世界的本原                                                  | 代表人物及观点                                                                                        |
| ------ | ------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| 主观唯心主义 | 把人的主观精神`人的目的、心灵、经验、感觉、意志等`夸大为唯一的实在，当成本原的东西，夸大了人的主观能动性。 | 孟子：万物皆备于我  <br>庄子：万物与我唯一  <br>王阳明：心外无物  <br>笛卡尔：我思故我在  <br>贝克莱：存在就是被感知物是观念的集合                  |
| 客观唯心主义 | 把客观精神`道、理、绝对观念、理念、上帝等`看作世界的主宰和本原，夸大了客观精神的作用。           | 老子：道是天地之根，万物之母  <br>朱熹：理在物先，理在事先。  <br>黑格尔：绝对理念是万事万物的本源  <br>柏拉图：现实世界是理念世界的影子  <br>孔子：生死由命富贵在天 |

## 四、辩证法

联系和发展的观点是唯物辩证法的总观点和总特征

### **（一）唯物辩证法的总特征**

#### **1.事物的普遍联系**

**联系的含义及特征**
    
- **含义** ：联系是指事物内部各要素之间和事物之间相互影响、相互制约、相互作用的关系。
	
- **特征** ：联系的特征包括客观性、普遍性、多样性、条件性、==系统性=={.info}。


 **联系的客观性**
    
- 世界上没有孤立存在的事物，**每一种事物都是在与其他事物的联系之中存在的**。事物的联系是事物本身所固有的，不是主观臆想的。
	
- 联系的客观性要求我们**从客观事物本身固有的联系出发去认识事物**。坚持联系的客观性，就是在联系的观点上坚持了唯物论。
        
 **联系的普遍性**
    
- 任何事物内部的不同部分和要素之间都是相互联系的。任何事物都不能孤立存在，都同其他事物处于一定的联系之中。整个世界是相互联系的统一整体。
	
- **事物的普遍联系都是通过 “中介” 实现的。**中介就是事物之间或事物内部要素之间相互联系的媒介、环节或桥梁，其本质在于它是相互作用的传递者。
        
**联系的多样性**
    
- 物质世界是多样性的统一，因而事物之间的联系也是多样的。
        
**联系的条件性**
    
- 任何联系总是在==一定条件下==的联系，条件是对事物存在和发展发生作用的诸要素的总和。一切事物的生长灭亡都需要一定的条件。

**联系的系统性**


#### **2.事物的永恒发展**

**发展的含义及实质**

- 发展是==前进的、上升的运动==。发展≠变化，运动、变化比发展范围广泛，而发展则比运动更深刻，它表明了事物运动变化的总方向和总趋势。发展的实质是新事物的产生和旧事物的不断灭亡。
	
- 新事物是合乎历史前进方向、具有远大前途的东西，旧事物是指丧失历史必然性、日趋灭亡的东西。新旧事物区分的标志是是否同事物发展的必然趋势相符合。
        
**用发展的眼光看待问题**
    
- 要如实地把事物看成是一个变化发展的过程。
	
- 明确事物在发展变化过程中所处的阶段和地位。
	
- 要坚持与时俱进，培养创新精神，促进新事物的成长。
	

### **（二）唯物辩证法的基本规律**

包括==对立统一规律、量变质变规律、否定之否定规律==

#### **1.对立统一规律：事物发展的源泉和动力**

**对立统一规律的含义及地位**
    
- 对立统一规律又称矛盾规律，矛盾是反映客观事物内部或不同事物之间对立统一关系的哲学范畴。
	
- 对立统一规律在唯物辩证法体系中处于核心地位，是唯物辩证法的实质和核心。
	
- 对立统一规律揭示了事物普遍联系的根本内容和永恒发展的内在源泉与动力。
	
- 对立统一规律为人们提供了认识世界和改造世界的最根本的方法，即矛盾分析法。在唯物辩证法体系中，矛盾分析方法居于核心地位，是根本的认识方法。
        
**矛盾的基本属性**
    
- 矛盾的同一性和斗争性是矛盾的两种基本属性。
	
	- **矛盾的同一性** ：
		- ==相互依存、互为条件==
			- “江碧鸟逾白，山青花欲燃”
			- “天下之理，有张必有弓，有强必有弱，有兴必有废，有与必有取”
			- “有无相生，难易相成，长短相形，高下相倾，音声相和，前后相随”
		- ==相互渗透、相互转化==
			- “塞翁失马，焉知非福”
			- “贾人旱则资舟，水则资车，以待乏也”
			- “安而不忘危，存而不忘亡，治而不忘乱”。
		
	- **矛盾的斗争性** ：矛盾双方相互排斥、相互分离。
		- “本是同根生，相煎何太急”
		- “煮豆燃豆萁，豆在釜中泣”。
            
**矛盾的普遍性和特殊性**
    
- **矛盾的普遍性** ：矛盾无处不在、无时不有。矛盾存在于一切事物的发展过程中，==处处有矛盾==；每一事物的发展过程自始至终存在着矛盾，==时时有矛盾==。矛盾的普遍性原理要求我们树立矛盾的观点，敢于承认矛盾，正确分析矛盾，坚持矛盾分析法，全面的看问题，一分为二的看问题。`金无足赤、人无完人`
	
- **矛盾的特殊性** ：规定了一事物区别于其他事物的特殊本质。
	- 不同事物的矛盾各有其特点；
	- 同一事物的矛盾在不同发展过程和发展阶段各有不同的特点；
	- 构成事物的诸多矛盾以及每一矛盾的不同方面各有不同的性质、地位和作用。
	
	矛盾的特殊性原理要求我们在分析事物时要做到具体问题具体分析。==具体问题具体分析（矛盾的特殊性）是正确认识事物的基础和正确解决矛盾的关键==。例如：
	- “梅须逊雪三分白，雪却输梅一段香”
	- “人间四月芳菲尽，山寺桃花始盛开”
	- “骏马能历险，力田不如牛；坚车能载重，渡河不如舟”。
	
- **矛盾的普遍性和特殊性的辩证关系** ：
	- 矛盾的普遍性即矛盾的共性，矛盾的特殊性即矛盾的个性。矛盾的共性是无条件的、绝对的，矛盾的个性是有条件的、相对的。
 
	- 矛盾的普遍性和特殊性的关系，也就是共性与个性、一般与个别的关系，它们是辩证统一的。任何现实存在的事物都是普遍性与特殊性的有机统一。
	
	- **普遍性寓于特殊性之中**，普遍性是许许多多不同的特殊事物包含的共性，只能存在于各种特殊事物之中。特殊性又都是包含着普遍性的特殊性。普遍性和特殊性的区分是相对的，二者在一定条件下可以相互转化。矛盾的普遍性和特殊性辩证关系的原理，不仅是马克思主义的普遍真理同各国的具体实际相结合的哲学基础，也是中国特色社会主义的哲学依据。`白马非马`
        
**矛盾发展的不平衡性原理**（==理解==）
    
- 矛盾发展的不平衡性是矛盾特殊性的重要表现。它主要表现为两种情形：一种是主要矛盾和次要矛盾的不平衡；另一种是矛盾的主要方面和次要方面的不平衡。
	
	- **主要矛盾和次要矛盾**
		
		- **主要矛盾** ：居于支配地位、对事物的发展过程起着决定作用的矛盾。
		- **次要矛盾** ：处于从属地位、对事物的发展过程不起决定作用的矛盾。
		- **二者关系** ：主要矛盾在矛盾体系中起主导作用，它制约着次要矛盾。次要矛盾影响主要矛盾，次要矛盾解决得好，有利于主要矛盾的解决。主要矛盾和次要矛盾在一定条件下可以相互转化。一旦出现转化，我们工作的重点也相应地转移。例如：
			- “打蛇先打七寸”
			- “牵牛要牵牛鼻子”
			- “射人先射马，擒贼先擒王”
			- “挽弓当挽强，用箭当用长”
			- “重心、核心、中心、突破口、牛鼻子”
			
	- **矛盾的主要方面和次要方面**
		
		- **矛盾的主要方面** ：居于支配地位、起着主导作用。
		- **矛盾的次要方面** ：处于被支配地位。
		- **二者关系** ：矛盾的主要方面支配次要方面，事物的性质由主要矛盾的主要方面决定。矛盾的次要方面也影响、制约矛盾的主要方面。矛盾的主、次双方在一定条件下可以相互转化，在这种情况下，事物的性质会发生变化。
			
	- **坚持两点论与重点论的统一**
		
		- 主、次矛盾及矛盾主、次方面原理，要求我们坚持唯物辩证法的两点论和重点论的统一。
			
			- **两点论** ：“两点论” 就是全面论。要求在研究复杂事物的发展过程时，既要看到主要矛盾，又要看到次要矛盾；在研究某一种矛盾时，既要看到矛盾的主要方面，又要看到矛盾的次要方面。例如：
				- “学会弹钢琴的手法”
				- “反腐败既要‘打老虎’，又要‘拍苍蝇’”。
				
			- **重点论** ：“重点论” 就是分清矛盾主次抓重点。要求在研究复杂事物的发展过程时，要着重地把握它的主要矛盾；在分析某一矛盾时，要着重地把握它的主要方面。
                    
**内因和外因**
    
- **内因** ：内部矛盾是事物发展的动力和源泉，是第一位的原因。
	
- **外因** ：外部矛盾是事物发展变化的条件，是第二位的原因。外因通过内因而起作用。例如：“师傅领进门，修行靠个人”（内因），“蓬生麻中，不扶自直”（外因），“实行独立自主、自力更生为主和争取外援为辅的方针”（内外因相结合）。
        

#### **2.量变质变规律：事物发展的形式和状态**

 **质、量、度的含义**
    
- **质** ：是使一个事物成为它自身并区别于其他事物的内在规定性。`本质`
- **量** ：是事物存在和发展的规模、程度和速度以及它的构成成分在空间上的排列组合等可以用数量表示的规定性。`数量、场所、排序`
- **度** ：是事物保持其质的存在的量的限度、幅度和范围。`范围`
        
**量变与质变及其辩证关系**
    
- **量变的含义** ：量变是事物量的规定性的变化，是事物在原有性质的基础上，在度的范围内发生的不显著的变化，体现了事物发展渐进过程的连续性，呈现出相对稳定、静止的状态。
	
- **质变的含义** ：质变是事物质的规定性的变化，是事物根本性质的变化，是事物由一种质态向另一种质态的飞跃。质变表现为根本性的、显著的变化，体现了事物发展渐进过程和连续性的中断。质变有两种取向，即前进的质变与倒退的质变。区分量变和质变的根本标志是事物变化是否超出度的范围。
	
- **量变和质变的辩证关系**
	
	- **量变是质变的必要准备**。任何事物的变化都有一个量变的积累过程，没有量变的积累，质变就不会发生。
	- **质变是量变的必然结果**，量变达到==一定程度==必然引起质变。事物的发展最终是通过质变来实现的，没有质变就没有发展。
	- **量变和质变是相互渗透的**。在总的量变过程中有阶段性和局部性的部分质变；在质变过程中也有旧质在量上的收缩和新质在量上的扩张。量变和质变是相互依存、相互贯通的，量变引起质变，在新质的基础上，事物又开始新的量变，如此交替循环，构成了事物的发展过程。量变质变规律体现了事物发展的渐进性和飞跃性的统一。
            
**方法论意义**
    
- 重视量的积累。
- 不失时机地促成事物的飞跃。
- ==坚持适度原则==。例如：
	- “治大国如烹小鲜”
	- “增之一分则太长，减之一分则太短，着粉则太白，施朱则太赤”
	

#### **3.否定之否定规律：事物发展的方向和道路**

**肯定和否定**
    
- 任何事物内部都包含着肯定和否定两个方面。肯定方面是事物中维持其存在的方面，否定方面是事物中促使其灭亡的方面。
        
**辩证的否定观**
    
- 辩证的否定是事物的自我否定，是事物内部矛盾运动的结果。
- 辩证的否定是事物发展的环节。
- 辩证的否定是事物联系的环节。
- 辩证的否定的实质是 “扬弃”，即既克服又保留。`去粗取精`
        
**否定之否定**
    
- 否定之否定规律的基本内容是：事物的发展经过两次辩证的否定，由肯定阶段到否定阶段，再到否定之否定阶段，从而使事物的发展表现为螺旋式上升和波浪式前进的过程。
	
- 否定之否定规律表明：事物发展的总方向、总趋势是前进的、上升的，事物发展的具体道路又是曲折的、迂回的。即事物的发展过程是前进性和曲折性的统一。
        
**方法论意义**
    
- 要从事物存在的总体出发，辩证地把握肯定和否定。
	
- 要从事物发展的全过程出发，正确地对待前进和曲折。
	
- 要具体分析事物的发展过程，合理地运用否定之否定。
	

### **（三）唯物辩证法的基本范畴（联系和发展的基本环节）**

#### **1.偶然性与必然性**

**定义** ：揭示和反映事物变化发展的确定趋势和不确定趋势之间关系的一对范畴。
    
**内涵** ：偶然性是客观事物联系和发展过程中不一定要发生、可以这样出现也可以那样出现的不确定的趋势。必然性是客观事物联系和发展过程中合乎规律的、一定要发生的、确定不移的趋势。
    
**二者关系** ：必然性存在于偶然性之中，通过大量的偶然性表现出来并为自己开辟道路；偶然性背后隐藏着必然性，受必然性支配，偶然性是必然性的形式和补充；偶然性和必然性在一定条件下可以相互转化。
    
**方法论意义** ：重视偶然性，利用有利的偶然性、机遇，避免不利的偶然性，通过偶然性掌握必然性。宣称 “偶然性是科学的敌人” 是形而上学的观点。
    

#### **2.现象与本质**

**定义** ：揭示客观事物的外部表现和内在联系之间相互关系的一对范畴。
    
**内涵** ：现象是事物的外部联系和表面特征。本质是事物的根本性质和事物基本要素的内在联系。
    
- **真象和假象** ：现象中有真象和假象，==真象和假象都能够反映事物的本质=={.danger}。真象是从正面表现本质的现象，假象是从反而歪曲表现事物本质的现象。
	
- **假象和错觉** ：假象和错觉不能等同，错觉是由于人的感觉上的错误造成的，属于==主观==的范畴；假象则是由客观存在的种种条件造成的，它是现象的一种，属于==客观==的范畴。
        
**二者关系** ：任何本质都会通过现象表现出来，任何现象都表示本质。假象作为现象也是表示本质的。
    
**方法论意义** ：现象和本质存在着对立，这使科学研究成为必要；现象和本质存在着统一，这使科学研究成为可能。要善于透过现象把握本质。
    

#### **3.原因与结果**

**定义** ：揭示事物的前后相继、彼此制约关系的一对范畴。
    
**内涵** ：原因是引起一定现象的现象。结果是由于原因作用而被引起的现象。
    
**二者关系** ：原因就是原因，结果就是结果，二者不能混淆。原因和结果相互依存，世界上既没有无因之果，也没有无果之因。原因和结果在一定条件下相互转化。
    
**方法论意义** ：原因和结果构成因果联系，因果关系具有时间顺序性，即原因在前，结果在后；原因和结果之间存在引起和被引起的关系。把握事物的因果关系，可以帮助我们增强行动的自觉性和预见性。
    

#### **4.可能性与现实性**

**定义** ：揭示客观事物由可能向现实转化过程的一对范畴。
    
**内涵** ：可能性是包含在现实事物之中的、预示着事物发展前途的种种趋势，是潜在的尚未实现的东西。现实性是包含内在根据的、合乎必然性的存在，是客观事物和现象种种联系的综合。
    
**二者关系** ：可能性是尚未实现的现实，而现实性则是已经实现了的可能，二者不能混淆。可能性离不开现实性，可能性的根据存在于现实性之中；现实性也离不开可能性，现实性是由可能性发展而来的。可能性和现实性在一定条件下可以相互转化。
    

#### **5.内容与形式**

**定义** ：揭示事物内在要素及其结构和表现方法的一对范畴。
    
**内涵** ：内容是构成事物的一切内在要素的总和。形式是事物的各种内在要素的结构或表现方式。
    
**二者关系** ：内容决定形式，形式对内容有重大的反作用。当形式适合内容时，对内容起积极的推动作用；当形式不适合内容时，就会阻碍内容的发展。

## 五、**认识论**（实践与认识及其发展规律）


### **（一）实践和认识**

#### **1.实践**

**实践的含义**

实践是人类能动地改造世界的物质活动，具有客观物质性、主观能动性和社会历史性。是主观见之于客观的活动，是沟通主观和客观的桥梁。

**实践的特征**
 * **客观物质性** ：实践的构成要素（主体、对象、手段）都是客观的，其过程及其结果也受到客观事物及其规律的制约。
 * **主观能动性** ：实践是人有意识、有目的地改造客观世界的活动，体现了人的主观创造性。
 * **社会历史性** ：实践不是孤立的个人活动，而是处于一定社会关系中，并受社会发展阶段的制约。

**实践的基本形式**
 * **生产实践** ：人类最基本的实践活动，是人们为了获取物质生活资料而进行的生产活动。
 * **处理社会关系的实践** ：包括阶级斗争、社会革命、改革等，推动着社会关系的变迁和社会的进步。
 * **科学实验** ：是探索自然规律和社会规律的有目的、有计划的实践。

#### **2.认识**

**认识的本质**

认识是在实践基础上主体对客体的能动反映，具有摹写性和创造性。

**认识的属性**
 * **客观性** ：认识是以客观事物为对象，是对客观事物的反映。
 * **主体性** ：认识受到主体的立场、观点、方法、知识水平等因素的影响，表现出主体的特征。

#### **3.实践和认识的辩证关系**

**实践对认识的决定作用**
 * **实践是认识的来源** ：人们只有通过实践，才能获得对客观事物的认识。
 * **实践是认识发展的动力** ：实践中不断出现的新问题，推动人们去进行新的探索和研究。
 * **实践是检验认识真理性的唯一标准** ：只有通过实践，才能检验认识是否正确地反映了客观事物。
 * **实践是认识的目的** ：认识从实践中来，最终还要回到实践中去，为实践服务。

**认识对实践的反作用**
正确的认识对实践具有积极的推动作用，错误的认识则会对实践产生消极的影响甚至导致实践的失败。

### **（二）认识过程的基本规律**

#### **1.认识的辩证过程**

**从感性认识到理性认识**
 * **感性认识** ：人们在实践过程中，通过感觉器官对客观事物的外部现象、个别属性的直接反映，具有直接性和形象性。包括感觉、知觉和表象三种形式。
 * **理性认识** ：人们借助抽象思维，对感性认识材料进行加工制作，达到对事物的本质、全体和内部联系的认识，具有间接性和抽象性。包括概念、判断和推理三种形式。
 * **感性认识和理性认识的辩证关系** ：二者相互联系、相互渗透。感性认识是理性认识的基础，理性认识是感性认识的升华。二者在一定条件下可以相互转化。

**从理性认识到实践**
实现认识过程的第二次能动飞跃，即将理性认识应用于实践，指导实践，是认识过程的更重要的阶段。实践是检验认识真理性的唯一标准，也是认识发展的动力。

#### **2.认识发展的总规律**

认识运动是从实践到认识、再从认识到实践的循环往复、不断深化的上升过程。实践、认识、再实践、再认识，循环往复以至无穷，使认识不断由低级向高级发展。


### **（三）真理与谬误**

#### **1.真理的含义及属性**

**真理的含义** 真理是标志主观与客观相符合的哲学范畴，是对客观事物及其规律的正确认识。
    
**真理的属性**
    
- **客观性** ：真理的内容是客观的，是对客观事物的本质和规律的正确反映。真理的客观性还体现在检验真理的标准是客观的，即实践。
	
- **绝对性和相对性** ：真理的绝对性是指任何真理都包含着不依赖于人的客观内容，是绝对的；真理的相对性则表明任何真理都是对客观事物一定方面、一定层次和一定程度的正确认识，有待于扩展和深化。
        

#### **2.谬误的含义及与真理的关系**

**谬误的含义** 谬误是同客观事物及其发展规律相违背的认识，是对客观事物本来面目的歪曲反映。
    
**真理与谬误的辩证关系** 真理和谬误是对立的，二者存在原则区别，有着明确的界限。同时，真理和谬误又是相互依存、相互转化的。在一定条件下，真理可以转化为谬误，谬误也可以转化为真理。

## **六、唯物史观**


### **（一）社会存在与社会意识**

#### **1.社会存在**

社会存在也称社会物质生活条件，是社会生活的物质方面，主要包括==自然地理环境、人口因素和物质生产方式==。

| 自然地理环境<br>`资源` | 自然地理环境是指人类生存和发展所依赖的诸种自然条件的总和。自然地理环境是人类社会生存和发展的永恒的、必要的条件，是人们生活和生产的自然基础。                           |
| -------------- | ------------------------------------------------------------------------------------------------ |
| 人口因素<br>`人`    | 人口因素是社会物质生活的必要条件之一，对社会发展起着制约和影响作用。主要表现在：第一，一定数量的人口是社会物质生产的必要前提。第二，人口状况能加速或延缓社会的发展。               |
| 物质生产方式         | 物质生产方式简称生产方式，指的是人们为获得物质生活资料而进行的生产活动的方式，是一定历史时期生产力和生产关系的统一体。物质生产方式是社会存在和发展的基础及决定力量，集中体现了人类社会的物质性。 |


#### **2.社会意识**

社会意识是社会生活的精神方面，本质上是社会物质生活在人们头脑中的反映，根源于人的劳动过程，特别是物质劳动和精神劳动的分离。

| 意识形态  | 意识形态是指反映并服务于经济基础的社会意识，具体包括政治法律思想、道德、艺术、宗教、哲学和大部分社会科学。在阶级社会中，它具有鲜明的阶级性。             |
| ----- | ---------------------------------------------------------------------------------- |
| 非意识形态 | 非意识形态是指反映自然现象和不属于特定经济基础的某些社会现象的社会意识形式，主要包括自然科学、一部分社会科学和思维科学，如语言学、逻辑学、心理学等。它不具有阶级性。 |

#### **3.社会存在与社会意识的辩证关系**

**社会存在决定社会意识**
 * 社会存在是社会意识内容的客观来源，社会意识是社会物质生活过程及其条件的主观反映。
 * 社会意识是人们进行社会物质交往的产物。
 * 随着社会存在的发展，社会意识也相应地或早或晚地发生变化和发展。

**社会意识反作用于社会存在**
 * 先进的或正确的社会意识对社会存在的发展起积极的推动作用，促进社会向前发展。
 * 落后的或错误的社会意识对社会存在的发展起消极的阻碍作用，延缓社会的发展进程。

**社会意识的相对独立性**
 * 社会意识在根本上受到社会存在决定的同时，还具有自己特有的发展形式和规律。主要表现如下：
   * 社会意识与社会存在变化发展的不完全同步性和不平衡性。`超前或落后`
   * 社会意识内部各种形式之间的相互影响及各自具有的历史继承性。
   * 社会意识对社会存在的能动反作用，这是社会意识相对独立性的突出表现。

### （**二）社会历史发展的基本规律**

#### **1.生产力与生产关系的矛盾运动及其规律**

**生产力**
生产力指人类在物质生产过程中形成的改造和影响自然以使其适合自身需要的物质力量。生产力表现的是==人与自然==的关系。**生产力是人类社会的最终决定力量**，衡量社会进步的最高、最根本的标准是社会生产力发展水平。

| 劳动资料<br>`工具` | 劳动资料是人们劳动过程中所运用的物质资料或物质条件，其中最重要的是生产工具。==生产工具是区分社会经济时代的客观依据==。     |
| ------------ | ----------------------------------------------------------------- |
| 劳动对象<br>`棉花` | 一切自然物质都是可能的劳动对象，其中引入生产过程的部分则是现实劳动对象。劳动对象和劳动资料合称生产资料。              |
| 劳动者<br>`主导`  | 劳动者是具有一定生产经验、劳动技能和知识，能够运用一定劳动资料作用于劳动对象，从事生产实践活动的人。劳动者是生产力中最活跃的因素。 |

**生产关系**
生产关系是指人们在物质生产过程中形成的不以人的意志为转移的经济关系，即人与人之间的关系。
- 生产资料的所有制形式
- 人们在生产中的地位和相互关系
- 产品分配形式

**生产力与生产关系的辩证关系及其矛盾运动**
 * 生产力决定生产关系。
 * 生产关系对生产力具有能动的反作用。
 * 生产力与生产关系的矛盾运动推动社会生产发展

#### **2.经济基础与上层建筑的矛盾运动及其规律**

**经济基础**
经济基础是指由社会一定发展阶段的生产力所决定的生产关系的总和。经济基础中具有决定意义的是生产资料所有制。

**上层建筑**
上层建筑是建立在一定经济基础之上的意识形态以及与之相应的制度、组织和设施。它由意识形态以及政治法律制度及设施和政治组织两部分组成。

| 观念上层建筑 | 观念上层建筑包括政治法律思想、道德、艺术、宗教、哲学等思想观点。                                                                      |
| ------ | ----------------------------------------------------------------------------------------------------- |
| 政治上层建筑 | 政治上层建筑包括国家政治制度、立法司法制度和行政制度，以及国家政权机构、政党、军队、警察、法庭、监狱等政治组织形态和设施。在上层建筑中，政治上层建筑居主导地位，==国家政权是核心=={.danger}。 |

**经济基础和上层建筑的辩证关系及其矛盾运动**
 * 经济基础决定上层建筑。
 * 上层建筑反作用于经济基础。上层建筑对经济基础的反作用集中表现在为自己的经济基础服务。当它为适合生产力发展要求的经济基础服务时，就会成为推动社会发展的进步力量；反之，就会成为阻碍社会发展的消极力量。
 * 经济基础与上层建筑的矛盾运动推动社会生产发展。

#### **3.社会基本矛盾的关系**

社会基本矛盾中生产力和生产关系的矛盾是更根本的，它决定上层建筑和经济基础的矛盾；而生产力和生产关系矛盾的解决又依赖于经济基础和上层建筑矛盾的解决。

### **（三）社会历史发展的动力系统**

#### **1.社会基本矛盾是社会历史发展的根本动力**

生产力和生产关系、经济基础和上层建筑的矛盾是社会基本矛盾。社会基本矛盾是社会历史发展的根本动力。其中，生产力是社会基本矛盾运动中最基本的动力因素，是人类社会发展和进步的最终决定力量。

#### **2.阶级斗争、社会革命和改革在社会历史发展中的作用**

**阶级斗争** ：是社会基本矛盾在阶级社会中的直接表现，是阶级社会发展的直接动力。

**社会革命** ：既是社会基本矛盾运动的结果，又是推动社会发展特别是社会形态更替的重要动力。社会革命是阶级斗争的最高形式。

**改革** ：是同一种社会形态发展过程中的量变和部分质变，是推动社会发展的又一重要动力。

#### **3.科学技术是推动社会发展的强大杠杆**

马克思认为科学是 “历史的有力的杠杆”，是 “最高意义上的革命力量”。每一次科技革命，都不同程度地引起了生产方式、生活方式和思维方式的深刻变化和社会的巨大进步。

### **（四）人民群众在历史发展中的作用**

人民群众是社会历史的主体，是历史的创造者。在社会历史发展过程中，人民群众起着决定性的作用。但人民群众创造历史的活动要受一定社会历史条件的制约，其中首要的制约因素是社会经济条件。

| 人民群众是历史的 “剧中人” 和 “剧作人” | 人民群众对推动历史发展的重要作用主要表现如下：人民群众是社会物质财富的创造者。人民群众是社会精神财富的创造者。人民群众是社会变革的决定力量。 |
| --- | --- |
| 英雄史观与群众史观的对立 | 英雄史观无视或否认人民群众的历史作用，把历史发展的原因归于少数统治者或社会精英的创造。群众史观认为对历史发展起决定作用的是人民群众，但承认个人尤其是少数历史人物的作用。 |

### **（五）人的本质和人的价值**

#### **1.人的本质**

人的属性分为自然属性和社会属性。社会属性表现了人的本质。人的本质在于人的社会性质。从人与动物相区别的层次上说，人的本质在于社会劳动；从人与人相区别的层次上说，==人的本质在于社会关系==。`非社会地位`

#### **2.人的价值**

人的价值分为社会价值和个人价值两个方面。

| 社会价值 | 人对社会的积极的、肯定性的作用和奉献，就是个人的创造活动对社会需要的满足。 |
| --- | --- |
| 个人价值 | 个人存在和行为对于自身的价值，就是人通过自己的活动满足自己的需要。 |
| 两者关系 | 人的价值是社会价值和个人价值的统一。二者是相互统一，不可分割的。马克思主义认为人应在对社会的奉献中实现和表现自己的价值。唯物史观在二者的关系问题上强调个人对社会、对他人的贡献，即人的社会价值是第一位的。 |
