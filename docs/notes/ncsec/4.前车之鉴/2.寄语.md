::: tip 徐铖（20经侦一，总分第一、行测第一、专业第一）

1. 暑假打牢基础后，重点补薄弱点。然后分模块刷题。最后每天一套（定模块时间）。
2. 行测参加粉笔放出的模考。

高度重视行测,分模块补短板强弱项。

:::

::: tip 全洋威（19 法制二；行测 78.40 分，单科第 3 名）

  

1. 行测到后期要边看课边刷题，一定要多练习。
2. 要抓住联考的题型（个人是粉笔打基础、专门针对警校生的机考更合适）。
3. 不要想着捷径，要自己思考自己的薄弱项。
4. 个人日常尝试乱序的试卷，帮助稳心态。
5. 个人习惯过于难的题目不会纠结太久。

  

行测的不同板块也尽量不要偏科，否则会很影响情绪，始终觉得心里没底。  
:::

  

::: tip 高深（19 法制一；行测 82.00 分，单科第 1 名；合成成绩 74.95 分，全校第 2 名）

  

1. 今年行测比较难。
2. 我个人的复习计划是抓好基本题，能做一道就做一道。
3. 我个人买了 “粉笔 980”，感觉还是蛮有成效的。
4. 日常刷题主要看质量，刷完题后一定要复盘，特别是做错的题。
5. 我把国考和浙江省省考的真题是放到后期才来做的，这样感觉比较有临考的氛围。
6. 常识一定要关注党史、领导讲话等。

  

行测每个人的基本情况差异很大，所以复习要根据个人状况来设定策略。复习中遇到瓶颈很正常，一定要保持良好的心态，心态真的很重要。  
:::

  

::: tip 金卓辰（20 网安四，行测全校第二）

  

1. 行测要强调底线思维。
2. 后期为了锻炼自己的心态，专门做难的卷子，给自己极限施压。

  

行测的任何一个模块都不能放弃。  
:::

  

::: tip 邱添（20 治三，申论全校第一）

  

1. 小题多关心国省考的真题，要反复看、反复做。概括题最有效；公文题每种要注意标准答案。
2. 大题素材积累更在于质量，在模考中反复应用。要注意积累公安的例子（崔道植、阮林根）。
3. 要注意论证方法。
4. 形成套路，最后要内化。

  

千万不能以为申论靠着辅导机构就行了，辅导机构的作用在于解题思路，是打底，而要想获得高分，一定要自己加压。  
:::

  

::: tip 林宣彤（20 涉外一，申论全校第一）

  

1. 申论一定要复盘，练习要计时。练习后要感受答案（囊中对比）。模考的解析视频（要从头到尾看下来，反复看）。要整理模版。
2. 后期四天一道真题。

  

在套路中有自己的观点很重要。  
:::

  

::: tip 王倩宇（19 经侦二；申论 82.00 分，单科第 1 名；合成成绩 75.10 分，全校第 1 名）

  

1. 8 月份返校后申论跟着机构学习，9-10 月自己学习，在 B 站找资源针对性补弱点。
2. 9-10 月练真题，每天练一道题，但是不断回顾。
3. 后期申论每天练一道小题，保持敏感度，还整理了答题模板、大作文素材、大作文的立论。
4. 一定要关注时事，我是保持看人民日报的社论的。

  

考试当天心态一定要好，遇到难题的冷静力来源于日常刷难题，考试时千万不要为难自己，我是要求自己先写完。  
:::

  

::: tip 滕晓珺（19 经侦一；申论 78.50 分；合成成绩 73.23 分，全校第 5 名）

  

1. 申论要学会思考，要体悟，要一遍遍看行文结构、逻辑。
2. 审题非常重要（比如考的如何改善电子烟），要站在题目的角度看逻辑结构和应证性，不要漏点。
3. 申论的大作文相对难度反而低，我是用公考小马哥等 B 站资源，不要听不同的人，要找适合自己的老师。

  

华图的辅导解决基本入门，但是提高要靠自己。  
:::

  

::: tip 曾亦圆（19 法制一；申论 76.50 分，单科第 3 名）

  

1. 申论大三下学粉笔的网课，大四上跟学校机构课，个人还报了个批改班。
2. 申论答题尽量选择原词，内容上按文章的层次和逻辑来写，形式上标序和有前置词，一定要把字写清楚。
3. 练习时要重视审题（形成答题思路），写作的最关键是立意立准（总分论点），写完后复盘很重要（追求质量而非数量）。

  

参加国省考，体验真题。区队内实力相近的同学抱团在一起，相互帮助。  
:::

  

::: tip 郑凯伦（20 公情一，专业第一）

  

1. 学习要有计划，目标要有区分（长期 -- 月 - 模糊；短期 - 周 - 明确）。
2. 找对自己的老师。个人觉得 “老六讲公专” 等公众号挺好。要高度重视新修订的法条，题目表象背后还是法条在支撑。
3. 2-3 人的小组学习成效好。公众号关注一些解题诀窍。
4. 法律很重要。
5. 实习中积累的实战经验对公专还是很有帮助的。

  

公基的状况是学了不一定考好，但考好必须要学习，特别是要打好法律知识的基础，弄通行政、刑事案件办理程序。  
:::

  

::: tip 徐铖（20 经侦一，总分第一、行测第一、专业第一）

  

1. 重视学校的模考。
2. 复习要全面。

  

考试时题目的阅读量很大，要求做题有一定的速度，日常训练要有强度。  
:::

  

::: tip 李泽星（19 法制一，业务 85.00 分，单科第 1 名）

  

1. 3 月份实习期间看校外机构网课，要扎实理解掌握每个知识点，要掌握法条的立法意图。
2. 要做好知识点串联，个人习惯做思维导图。
3. 要联系公安实践，在实习时多看案卷，结合实际来理解公基的题目，回校学习公基时要回忆实习的警务实践。
4. 要学好法律课程，要从法条的记忆来推导实务工作。
5. 公基前 50 题难度低，多选题难度大，情境题极难。所以前面该拿的分要拿到。情境题阅读量极大，图表的复杂度极高，平时一定要注意做题的速度和时间控制，否则正式考试时容易心态崩。
6. 学校组织的战术与时政的专题辅导帮助比较大，要重视。

  

很多难题没有法条的对应性，考的更多的是公安思维。要树立公安思维，就要高度重视实习、重视法律课，要关注国家时事，特别要重点关注公安部、两高的意见。  
:::

  

::: tip 吴孟哲（19 侦查四；业务 83.00 分，单科并列第 2 名）

  

1. 公基知识点庞杂，跟机构跟着一个就好。
2. 个人习惯做思维导图，感觉很有帮助，复习中期骆冰的思维导图做了几万字。
3. 公基刷题求精不求多，自己建立了错题本，通过错题去拓展。

  

要摆正心态，大一大二的课程都是有用的，实习期间师傅让我办了一次案件，也很有帮助。复习前一定要了解公基的大纲，要安排好节奏，营造好小生态。  
:::
