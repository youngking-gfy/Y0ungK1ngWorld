::: card title="错题1" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选"/>行政复议法规定判定  
为防止和纠正违法的或者不当的行政行为，保护公民、法人和其他组织的合法权益，监督和保障行政机关依法行使职权，发挥行政复议化解行政争议的主渠道作用，推进法治政府建设，根据宪法，制定《行政复议法》。根据该法律，下列表述正确的是（ ）。(3.1分)  

**选项**：  
A、行政复议机关办理行政复议案件，应当进行调解。调解应当遵循合法、自愿的原则，不得损害国家利益、社会公共利益和他人合法权益，不得违反法律法规的强制性规定  
B、公民、法人或者其他组织认为行政机关的行政行为所依据的规范性文件不合法，在对行政行为申请行政复议时，可以一并向行政复议机关提出对该规范性文件的附带审查申请，附带审查的规范性文件包含规章  
C、对公安部作出的行政复议决定不服的，可以向人民法院提起行政诉讼；也可以向国务院申请裁决，国务院依照本法的规定作出最终裁决  
D、适用普通程序审理的行政复议案件，行政复议机构既可以当面或者通过互联网、电话等方式听取当事人的意见，并将听取的意见记录在案；也可以书面审理  

**答案**：!!C!!  

::: collapse  
- **解析**  
    - A 是“可以”调解，非“应当”；B 附带审查规范性文件不含规章；D 书面审理是因当事人原因不能听取意见时才可；C 符合规定，选C 。  
:::

::: card title="错题2" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选"/>民警盘查操作合规性判定  
五一小长假期间，洛阳市公安局老城分局南关派出所民警小王、小李在洛邑古城巡逻过程中，在拥挤的人群中发现一男一女神色可疑，女方携带的挎包异常。遂对二人展开盘查。根据法律规定，以下操作不正确的是：（ ）。(3.1分)  

**选项**：  
A、出示证件后将二人带至保安亭处进行盘查  
B、在保安亭对二人进行盘问  
C、要求二人将挎包打开并拿出包内物品  
D、小王盘问，小李在旁戒备  

**答案**：!!C!!  

::: collapse  
- **解析**  
    - 依《公安机关人民警察盘查规范》，不能让被盘查人自行翻拿物品，C 错误，选C 。  
:::

::: card title="错题3" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选"/>行政强制法规定判定  
《行政强制法》是为规范行政强制的设定和实施，保障和监督行政机关依法履行职责，维护公共利益和社会秩序，保护公民、法人和其他组织的合法权益，根据宪法而制定的法律。下列符合该法律规定的是（ ）。(3.1分)  

**选项**：  
A、公安机关在查处治安案件时，发现某KTV擅自从事经营活动，遂查封该KTV，属于行政强制措施  
B、某县公安局交警大队以赵某违章停车为由，决定暂扣赵某1个月的驾驶执照，属于行政强制执行  
C、公安机关对人民法院不予受理强制执行申请的裁定有异议的，可以在10日内向上一级法院申请复议  
D、在公安机关强制执行程序中，如果执行标的灭失的，应中止执行  

**答案**：!!A!!  

::: collapse  
- **解析**  
    - B 暂扣驾驶证是行政处罚；C 应15日内申请复议；D 标的灭失应终结执行；A 查封属行政强制措施，选A 。  
:::

::: card title="错题4" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选"/>刑事案件和解及处理判定  
某县村民张某和李某因矛盾发生纠纷，争执中张某将李某鼻梁骨打断，李某报警，经鉴定为轻伤。公安机关在查清事实并征得当事人双方同意的基础上，组织双方达成了和解协议，当事人双方提请公安机关就此结案。下列关于公安机关处理该案表述正确的是：（ ）。(3.1分)  

**选项**：  
A、灵活运用法律让当事人双方都满意  
B、程序违法刑事案件不能和解  
C、可以和解但需将案件移送检察院  
D、不能和解也不能结案  

**答案**：!!C!!  

::: collapse  
- **解析**  
    - 依《刑事诉讼法》，因民间纠纷引起轻罪案件可和解，和解后移送检察院，检察院可作不起诉等决定，C 正确，选C 。  
:::

::: card title="错题5" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选"/>民警休假期间涉事责任判定  
县公安局治安大队民警荀某在郊区休假期间，驾驶的机动车发生故障，找当地乡人大代表曲某帮忙修车。曲某赶来，将自己的机动车停在旁边商店门口。商店老板储某要求将汽车挪离，曲某拒绝，两人争吵并厮打。荀某上前将2人拉开，便同曲某修车。一会儿，储某和曲某再次厮打在一起，荀某喊了一声别打了，又埋头修车。后储某被曲某推倒，太阳穴正好撞至路旁隔离带上，当场死亡。下列说法正确的是（ ）。(3.1分)  

**选项**：  
A、荀某涉嫌玩忽职守罪  
B、储某的死亡属于意外事件  
C、公安机关如果决定对曲某采取刑事拘留措施，需报请曲某所属的人民代表大会许可  
D、如荀某涉嫌职务犯罪，由人民检察院立案侦查  

**答案**：!!A!!  

::: collapse  
- **解析**  
    - 荀某作为国家机关工作人员，对工作严重不负责任致储某死亡，构成玩忽职守罪；B 荀某有过失，不属意外；C 曲某是乡人大代表，刑拘只需向乡人大报告；D 职务犯罪由监察委立案，选A 。  
:::

::: card title="错题6" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="多选"/>人民警察核心价值观体现判定  
犯罪分子劫持群众，要求用民警交换，并高声叫嚣“哪个敢过来？”面对危情，公安局副局长常某挺身而出“我是公安局负责人，有事冲我来，不要伤害群众！”该副局长的行为体现的人民警察核心价值观有：（ ）。(3.5分)  

**选项**：  
A、忠诚  
B、为民  
C、正直  
D、奉献  

**答案**：!!AB!!  

::: collapse  
- **解析**  
    - 人民警察核心价值观是忠诚、为民、公正、廉洁。副局长行为体现对党、人民忠诚及为人民着想，选AB 。  
:::

::: card title="错题7" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="多选"/>公安机关窗口单位判定  
2016年，公安部出台《关于加强公安机关窗口单位规范化建设的指导意见》，要求进一步提升窗口单位管理服务水平，着力实现场所设置合理化、内部管理制度化、办事流程规范化、管理服务精细化、工作方法多样化。下列属于河东县公安机关“窗口单位”的是：（ ）。(3.5分)  

**选项**：  
A、某县公安局法制大队  
B、某县公安局值班室  
C、某县公安局巡警队  
D、某县公安局交警大队  

**答案**：!!BCD!!  

::: collapse  
- **解析**  
    - 依《公安机关窗口单位服务规定》，值班室、巡警队、交警大队属窗口单位，法制大队不直接面向社会服务，选BCD 。  
:::

::: card title="错题8" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="多选"/>许可证获取及相关责任判定  
王某欲申请爆破作业单位许可证，但其不具备申请资格。为此，其先后4次向当地公安局局长贾某赠送红包，总计2万余元。数日后，王某顺利取得了该许可证。下列说法正确的是（ ）。(3.5分)  

**选项**：  
A、应当撤销王某取得的许可证  
B、王某3年内不得再申请该许可  
C、贾某构成受贿罪（立案标准3万以上，本题2万不构成 ）  
D、对贾某应当予以处分  

**答案**：!!ABD!!  

::: collapse  
- **解析**  
    - 王某通过行贿取得许可证应撤销，3年内禁申；贾某受贿2万未达立案标准（3万以上），不构成受贿罪，但应处分，选ABD 。  
:::

::: card title="错题9" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="多选"/>违规使用公安信息网政务处分判定  
某公安局民警赵某应朋友之托，使用内部网络查询了该朋友债务关系人的个人信息，私下发送给该朋友。根据赵某行为的情节，对其可给予的政务处分有：（ ）。(3.5分)  

**选项**：  
A、警告  
B、记过  
C、降职  
D、严重警告（属党纪处分，非政务处分 ）  

**答案**：!!AB!!  

::: collapse  
- **解析**  
    - 依《公安机关人民警察纪律条令》，违规用公安信息网，可给警告、记过等处分，降职表述不准确，严重警告是党纪处分，选AB 。  
:::

::: card title="错题10" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="多选"/>涉外行政案件办理规定判定  
在涉外行政案件办理中，根据《公安机关办理行政案件程序规定》，下列说法错误的是（ ）。(3.5分)  

**选项**：  
A、若沙希里享有外交特权，办案公安机关应将其身份、证件及违法行为等基本情况记录在案，保存有关证据，并尽快将有关情况层报公安部，由公安部商情同级人民政府外事部门通过外交途径解决  
B、外国人查理因从事与居留事由不相符的活动，被县公安局处以限期出境的处罚，对此，查理无权申请复议  
C、外国人布莱恩因殴打他人被决定行政拘留后，书面请求不通知其所属国家的使馆、领馆的，可以不通知  
D、外国人戴维因非法持有毒品被行政拘留15日，如其在拘留期间死亡，要报告省级公安机关并通报同级外事部门  

**答案**：!!ABCD!!  

::: collapse  
- **解析**  
    - A 应层报省级公安；B 外国人对限期出境等措施不服可申请复议；C 我国与当事人国籍国未签双边协议规定必须通知的，可书面要求不通知，但需当事人提出；D 应通知所属国家驻华使馆领馆并报告公安部、通报同级政府外事部门，ABCD 均错误，选ABCD 。
