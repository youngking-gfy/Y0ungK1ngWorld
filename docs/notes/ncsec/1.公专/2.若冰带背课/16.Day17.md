### **错题难题回顾**



:::: card-grid  
::: card title="错题1" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选"/>妨害公共安全行为判定  
下列不属于妨害公共安全行为的是（ ）。(4分)  

**选项**：  
A、某路边仓库管理部门未经批准安装了防盗电网  
B、李某盗窃正在使用的铁路信号灯  
C、张某为练习枪法，用气枪射击街边的路灯  
D、程某为发泄不满，纠集多人到马路上堵塞交通  

**答案**：!!D!!  

::: collapse  
- **解析**  
    - 程某纠集多人堵塞交通，是扰乱公共场所秩序行为，属扰乱公共秩序类，非妨害公共安全；A、B、C 均妨害公共安全，选D 。  
:::

::: card title="错题2" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选"/>情报信息收集工作判定  
凌晨发现路口黑色轿车，车内有血迹、皮包及物品，最需开展情报信息收集的工作是（ ）。(4分)  

**选项**：  
A、固定和提取车内物品  
B、加强市区道路交通管理  
C、通过户籍查询车主的个人信息  
D、调阅周边路段卡口的监控信息  

**答案**：!!D!!  

::: collapse  
- **解析**  
    - 监控图像可“历史重现”，反映现场及周边情况，助于锁定嫌疑人，D 最关键；A、B、C 非最急需，选D 。  
:::

::: card title="错题3" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选"/>卖淫嫖娼案件处罚及程序判定  
田某介绍卖淫，县公安局对其及相关人员处罚，说法正确的是（ ）。(4分)  

**选项**：  
A、田某逾期不缴罚款，县公安局经催告后仍不缴纳，可以加处罚款  
B、县公安局如果没有告知其对拟处罚的5000元罚款可以申请听证，那么之后作出的处罚决定无效  
C、对于田某的违法行为，违法行为地和田某的居住地均有管辖权  
D、对于田某涉嫌的违法案件，征得田某书面同意的前提下，可以适用快速办理制度  

**答案**：!!B!!  

::: collapse  
- **解析**  
    - A 加处罚款前需催告；B 未告知听证属重大程序违法，处罚无效，正确；C 卖淫嫖娼案由违法行为地专属管辖；D 可能处10日以上拘留或需听证的，不适用快速办理，选B 。  
:::

::: card title="错题4" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选"/>人身检查防护目的判定  
吸毒人员黄某贩卖毒品被抓，民警陈某人身检查时用手套，目的是（ ）。(4分)  

**选项**：  
A、防止证据灭失  
B、保证证据不被毁损  
C、预防受伤和感染疾病  
D、避免事后被诬告  

**答案**：!!C!!  

::: collapse  
- **解析**  
    - 民警检查涉毒人员，用手套可防接触针筒、刀片等受伤或感染疾病，C 正确；A、B、D 非主要目的，选C 。  
:::

::: card title="错题5" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选"/>现场制止违法犯罪手段判定  
根据法律规定，属于公安机关现场制止违法犯罪的手段是（ ）。(4分)  

**选项**：  
A、限制活动犯罪  
B、徒手制止  
C、拘留审查  
D、人身约束  

**答案**：!!B!!  

::: collapse  
- **解析**  
    - 依《公安机关人民警察现场制止违法犯罪行为操作规程》，处置措施含徒手制止等，B 正确；A、C、D 不符规定，选B 。
