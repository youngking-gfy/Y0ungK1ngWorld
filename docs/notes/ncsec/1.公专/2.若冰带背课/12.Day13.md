### **错题难题回顾**

:::: card-grid  
::: card title="错题 1" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="单选"/>涉恐案件辩护律师会见规定判定  
谢某因涉恐犯罪被指定居所监视居住，侦查期间聘请初某为辩护律师，正确说法是（ ）。(3.34 分)  

  

**选项**：  
A、初某会见谢某应当经县级以上公安机关负责人许可  
B、初某会见谢某无需经县级以上公安机关负责人许可  
C、初某会见谢某时，侦查人员可进行监听  
D、侦查期间初某不可以了解案件有关情况

  

**答案**：!!A!!

  

::: collapse

  

- **解析**
    - 涉恐案件，辩护律师会见需经县级以上公安机关负责人批准；不得监听；侦查期间律师有权了解案件情况，所以选 A 。  

:::  
::: card title="错题 2" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="单选"/>勘验检查规定判定  
关于勘验检查，正确说法是（ ）。(3.34 分)

  

**选项**：  
A、办理刑事案件，对案发现场应当进行勘验  
B、办理刑事案件，对人身进行检查应当经县级以上公安机关负责人批准  
C、办理行政案件，检查对象范围等于刑事案件中检查对象加上搜查对象  
D、办理刑事案件，检查不需要见证人

  

**答案**：!!C!!

  

::: collapse

  

- **解析**
    - A 案发现场必要时勘验；B 对人身检查无需县级以上公安负责人批准；D 刑事案件检查应有见证人；C 表述正确，选 C 。  
:::  
::: card title="错题 3" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="单选"/>传唤和询问规定判定  
根据《治安管理处罚法》和《公安机关办理行政案件程序规定》，关于传唤和询问正确的是（ ）。(3.34 分)

  

**选项**：  
A、传唤是询问的前置条件，即必须先传唤，后询问  
B、办案民警应当异地执行传唤，不能异地传唤  
C、张三涉嫌饲养动物干扰他人正常生活，公安机关可以对其进行不超过 24 小时的传唤  
D、对旅馆业不制止的违法行为，公安机关对涉嫌违法的工作人员的传唤不得超过 8 小时

  

**答案**：!!B!!

  

::: collapse

  

- **解析**
    - A 传唤不是询问前置条件；C 饲养动物干扰他人正常生活传唤不超 8 小时；D 旅馆业相关违法，若有拘留处罚，传唤可超 8 小时；B 办案民警应异地执行传唤，正确，选 B 。  

:::  
::: card title="错题 4" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="单选"/>刑事案件询问证人规定判定  
办理刑事案件中，询问证人正确说法是（ ）。(3.34 分)

  

**选项**：  
A、无论在哪里询问证人，均应当制作《询问通知书》  
B、制作《询问通知书》，需要经过县级以上公安机关负责人批准  
C、如果需要通知证人到公安机关提供证言，应当制作《询问通知书》  
D、在现场询问证人，出示人民警察证就可

  

**答案**：!!D!!

  

::: collapse

  

- **解析**
    - A 现场询问证人无需《询问通知书》；B 制作《询问通知书》经办案部门负责人批准即可；C 通知证人到公安提供证言，可用《询问通知书》或其他方式；D 现场询问出示人民警察证即可，正确，选 D 。  
:::
