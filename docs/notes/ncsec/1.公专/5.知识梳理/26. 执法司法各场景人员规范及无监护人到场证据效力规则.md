### **一、处警人员要求**

- **允许人员构成**：民警、辅警
    

### **二、身体检查规范（分案件类型）**

#### （一）刑事案件

- **女性身体检查**：执行人员为 **女工作人员 或 医师**（二选一即可，无见证人额外要求）
    

#### （二）行政案件（2024年新规）

- **女性身体检查**：执行人员需同时满足两项要求
    
    - 必须是 **女民警 或 女医师**（限定性别+身份，无其他替代人员）
        
    - 需有 **女性见证人** 在场（见证人性别与被检查人一致，强化程序合规性）
        

#### （三）趋势预测

- 刑事案件未来可能同步采用行政案件的严格标准（即要求“女民警/女医师+女性见证人”）
    

### **三、未成年人询问/讯问规范**

#### （一）通用基本要求（适用于所有未成年人）

1. **记录要求**：应当同步录音录像（全程留存证据，避免程序争议）
    
2. **效率要求**：尽量一次完成询问（减少对未成年人的反复干扰）
    
3. 讯问未成年人无大人（法定代理人 / 合适成年人），未成年犯罪嫌疑人的供述绝对排除，不得作为定案根据，不适用补正规则；
    
4. 询问无大人（法定代理人 / 合适成年人）到场的证据效力：属于证据瑕疵，可通过补正（如补充通知、说明未到场合理原因）或作出合理解释后使用；无法补正或解释的，不得作为定案根据。
    

#### （二）特殊情形（女性未成年人）

|   |   |   |
|---|---|---|
|场景|核心要求|执行人员范围|
|询问女性未成年被害人/证人|由女性工作人员专属执行|女民警、女辅警（均可）|
|讯问女性未成年犯罪嫌疑人|必须有女性工作人员在场（陪同）|女民警、女辅警（均可，需在场）|

### **五、辅警参与询问的权限与限制**

- **核心原则**：辅警无独立执法权，不得单独参与任何正式询问（含刑事、行政案件），仅能在具备执法资格的民警指导、监督下开展辅助工作。
    
- **刑事程序中的参与边界**：
    
- 协助性工作：可协助记录询问笔录、维护现场秩序等，但询问主体必须是侦查人员（正式民警），且需满足“不少于2名侦查人员”的法定要求；
    
- 特殊情形例外：询问女性未成年被害人/证人时，女辅警可作为“女性工作人员”专属执行询问，但仍需有正式民警在场监督，且需同步录音录像。（法律来源：1. 《中华人民共和国未成年人保护法》第112条，明确询问女性未成年被害人、证人应当由女性工作人员进行，未限定“女性工作人员”仅为民警，为女辅警参与提供依据；2. 《公安机关办理刑事案件程序规定》相关要求，明确询问需在侦查人员主导或监督下进行，故需正式民警在场；3. 同步录音录像要求源自未成年人保护法及办理性侵害未成年人刑事案件相关意见，强化对未成年人的程序保护。）
    
- **行政程序中的参与边界**：
    
- 辅助记录：在正式民警带领下，可协助记录询问笔录，最终由民警对笔录真实性、合法性负责；
    
- 严格限制：询问笔录制作、核心提问等关键环节，需由正式民警主导，辅警不得独立开展；仅在接报案、信息采集等非核心环节可辅助参与。
    
- **证据效力风险**：若辅警单独参与询问并制作笔录，或无民警事后确认，该笔录因程序违法可能被认定为无效证据，不得作为定案或处罚依据。
