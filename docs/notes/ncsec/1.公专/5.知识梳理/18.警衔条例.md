# 《中华人民共和国人民警察警衔条例（2009 修正）》考试速记笔记

## 一、总则（核心考点：目的、警衔性质、管理主体）

1. **立法目的**：加强人民警察队伍 “革命化、现代化、正规化” 建设，增强责任心、荣誉感、组织纪律性，保障指挥、管理和执行职务（关键词：“三化”+“三感”+ 履职保障）
2. **制度核心**：人民警察实行警衔制度，警衔是 “区分等级、表明身份的称号 / 标志、国家荣誉”（3 重属性：等级区分 + 身份证明 + 荣誉象征）
3. **上下级认定**：
    - 一般规则：警衔高者为上级
    - 特殊规则：警衔高者职务隶属于警衔低者时，**职务高者为上级**（职务优先于警衔）
4. **主管机关**：公安部主管警衔工作

## 二、警衔等级设置（必考：五等十三级 + 专业技术警衔）

### （一）通用警衔等级（五等十三级）

|等级|具体层级|
|---|---|
|第一等|总警监、副总警监（2 级）|
|第二等|警监（一级、二级、三级，3 级）|
|第三等|警督（一级、二级、三级，3 级）|
|第四等|警司（一级、二级、三级，3 级）|
|第五等|警员（一级、二级，2 级）|

### （二）专业技术警衔

- 规则：在对应警衔前冠以 “专业技术”（如 “专业技术一级警监”）

## 三、职务与警衔编制对应（高频考点：行政 / 专业技术职务匹配范围）

### （一）行政职务与警衔对应

| 行政职务     | 对应警衔范围    |
| -------- | --------- |
| 部级正职     | 总警监       |
| 部级副职     | 副总警监      |
| 厅（局）级正职  | 一级警监至二级警监 |
| 厅（局）级副职  | 二级警监至三级警监 |
| 处（局）级正职  | 三级警监至二级警督 |
| 处（局）级副职  | 一级警督至三级警督 |
| 科（局）级正职  | 一级警督至一级警司 |
| 科（局）级副职  | 二级警督至二级警司 |
| 科员（警长）职  | 三级警督至三级警司 |
| 办事员（警员）职 | 一级警司至二级警员 |

### （二）专业技术职务与警衔对应

|专业技术职务|对应警衔范围|
|---|---|
|高级|一级警监至二级警督|
|中级|一级警督至二级警司|
|初级|三级警督至一级警员|

## 四、警衔首次授予（关键：依据 + 批准权限）

1. **授予依据**：以 “现任职务、德才表现、现职时间、工作年限” 为依据（4 项依据，缺一不可）
2. **特殊情形**：毕业 / 招考录用 / 调任人民警察的，按确定职务授予对应警衔
3. **批准权限（分级别）**：
    - 总警监、副总警监、一级警监、二级警监：**国务院总理**批准
    - 三级警监、警督：**公安部部长**批准
    - 警司：
        - 地方：省 / 自治区 / 直辖市公安厅（局）厅（局）长批准
        - 公安部机关及直属机构：公安部政治部主任批准
    - 警员：
        - 地方：省 / 自治区 / 直辖市公安厅（局）政治部主任批准
        - 公安部机关及直属机构：公安部政治部主任批准

## 五、警衔晋级（核心：期限 + 条件 + 批准权限）

### （一）分级晋级规则

|晋级范围|晋级期限|晋级要求|
|---|---|---|
|二级警员→一级警司|每晋升一级 3 年|1. 守法 + 执行法规政策；2. 胜任本职；3. 廉洁奉公、联系群众、作风正派（3 项条件）|
|一级警司→一级警督|每晋升一级 4 年|同上|
|一级警督以上|无固定期限，按 “德才表现 + 工作实绩” 选升|无固定期限，选升制|

### （二）特殊晋级情形

1. **职务提升触发**：警衔低于新任职务编制警衔最低警衔的，**晋升至该最低警衔**（必升）
2. **培训要求**：警司晋警督、警督晋警监，需经 “相应人民警察院校培训合格”（前置条件）
3. **提前晋升**：工作有突出功绩的，可提前晋升；批准权限：警司 / 警员提前晋升由**公安部政治部主任**批准

### （三）晋级结果

- 考核合格：逐级晋升
- 考核不合格：延期晋升

## 六、警衔的保留、降级、取消（重点：不同情形处理规则）

|情形|处理方式|特殊说明|
|---|---|---|
|离休 / 退休|警衔保留，不得佩带标志|-|
|调离警察岗位 / 辞职 / 退职|警衔不予保留|-|
|不胜任现任职务调任下级职务|警衔高于新任职务编制警衔最高警衔的，**调整至该最高警衔**|批准权限与原警衔批准权限相同|
|违犯警纪|可给予警衔降级处分|1. 批准权限与原警衔批准权限相同；2. 降级后晋级期限重新计算；3. 不适用于二级警员（底线）|
|被开除公职|警衔相应取消|-|
|犯罪（判剥夺政治权利 / 有期徒刑以上）|警衔相应取消|离休 / 退休人民警察犯罪，同样适用|

## 七、附则（适用范围）

1. **适用主体**：
    - 国家安全部门、劳动改造劳动教养管理部门的人民警察
    - 人民法院、人民检察院的司法警察
2. **批准权限特殊规定**：
    - 国安、劳改劳教部门警衔授予 / 晋级：国务院规定
    - 司法警察警衔授予 / 晋级：最高法、最高检参照本条例规定
3. **排除适用**：公安、国安、劳改劳教部门中 “不担任人民警察职务的人员”，不实行警衔制度

## 八、关键时间与效力

- 公布 / 施行日期：2009 年 8 月 27 日（修正后同步生效）
- 时效性：现行有效
- 效力位阶：法律（全国人大常委会制定）
