| 部门法     | 近亲属范围                                              | 法律依据                         | 关键差异点                                         |
| :------ | :------------------------------------------------- | :--------------------------- | :-------------------------------------------- |
| **民法**  | 配偶、父母、子女、兄弟姐妹（包括婚生非婚生，同父异母，同母异父）、祖父母、外祖父母、孙子女、外孙子女 | 《民法典》第 1045 条第 2 款           | 含三代直系血亲与二代旁系血亲，不含其他扶养 / 赡养关系亲属                |
| **刑法**  | 配偶、父母、子女、同胞兄弟姐妹                                    | 《刑事诉讼法》第 108 条第（六）项          | 仅含核心家庭成员 + 同父同母兄弟姐妹，不含祖父母 / 外祖父母 / 孙子女 / 外孙子女 |
| **行政法** | 配偶、父母、子女、兄弟姐妹、祖父母、外祖父母、孙子女、外孙子女 + 其他具有扶养、赡养关系的亲属   | 《最高人民法院关于适用〈行政诉讼法〉的解释》第 14 条 |                                               |
