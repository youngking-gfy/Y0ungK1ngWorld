| 案件类别   | 回避对象及对应决定机关                                                                                                                                                        |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 治安行政案件 | 1. 办案民警回避：由所属公安机关决定（派出所民警回避由派出所决定，因派出所属于公安机关）<br><br>2. 公安机关负责人回避：由县级以上公安机关决定（派出所所长、教导员、副所长属于此范畴）<br><br>3. 无独立执法主体资格部门民警（如分局治安 / 网安 / 刑侦大队）回避：由所属分局决定（大队不能称为公安机关） |
| 刑事案件   | 1. 侦查人员回避：由县级以上公安机关负责人（局领导班子 / 县级以上公安负责人）决定<br><br>2. 县级以上公安机关负责人（局领导班子 / 县级以上公安负责人）回避：由同级人民检察院检察委员会决定                                                             |
