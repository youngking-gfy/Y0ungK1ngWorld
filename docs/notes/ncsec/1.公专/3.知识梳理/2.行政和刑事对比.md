## **一、立案**

:::: card-grid



::: card title="行政案件立案" icon="typcn:tick-outline"

  

- 填表
    - 填写《行政立案登记表》
- 上网
    - 需要
- 询问笔录
    - 民警自由裁量
- 受案回执
    - 不需要
- 接受证据
    - 使用《接受证据清单》
- 立案审批
    - 办案部门负责人审批
- 审查立案时间
    - 最多 3 日
- 不立案的救济
    - 行政复议前置  
:::

  

::: card title="刑事案件立案" icon="typcn:tick-outline"

  

- 填表
    - 填写《受案登记表》
- 上网
    - 需要
- 询问笔录
    - 应当作
- 受案回执
    - 应当作
- 接受证据
    - 使用《接受证据材料清单》
- 立案审批
    - 县级以上公安机关负责人审批
- 审查立案时间
    - 普通刑事案件最多 30 日；经济犯罪最多 60 日
- 不立案的救济
    - 控告人：`3-7-30+30-7-30+30`
    - 行政机关：`3-3-3`  
:::

## **二、管辖 - 横向管辖**

:::: card-grid



::: card title="行政案件横向管辖" icon="typcn:tick-outline"

  
- 行为地
    - 违法行为地（含发生地、结果地）
    - 卖淫嫖娼毒品赌博案件为专属案件（吸毒发现地也有管辖权）
- 居住地
    - 违法行为人居住地（含户籍所在地、经常居住地）
- 备注
    - 无特殊限制  
:::

  

::: card title="刑事案件横向管辖" icon="typcn:tick-outline"

  

- 行为地
    - 犯罪行为地（含发生地、结果地）
    - 卖淫嫖娼毒品赌博案件为专属案件（吸毒发现地也有管辖权）
- 居住地
    - 犯罪行为人居住地（含户籍所在地、经常居住地）
- 备注
    - 无管辖权限制  
:::  
::::


## **二、管辖 - 纵向管辖**


:::: card-grid



::: card title="行政案件纵向管辖" icon="typcn:tick-outline"

  

- 派出所
    - 可办理：警告、1000 元以下罚款（单一违法行为）
- 交警队
    - 可办理：警告、罚款、暂扣驾驶证（单一违法行为）
- 出入境管理部门
    - 可办理：警告、5000 元以下罚款（单一违法行为）
- 公安部
    - 可办理：驱逐出境  
:::

  

::: card title="刑事案件纵向管辖" icon="typcn:tick-outline"

- 派出所
    - 可办理：较为简单的刑事案件
- 交警队
    - 无对应刑事案件管辖权限
- 出入境管理部门
    - 无对应刑事案件管辖权限
- 设区的市一级以上公安机关
    - 负责侦查：重大的国、恐、外、经、集、跨区域犯罪案件
- 公安部
    - 无特殊对应刑事案件管辖表述  
:::  
::::

  
## **二、管辖 - 特殊案件管辖**

:::: card-grid



::: card title="行政案件特殊管辖" icon="typcn:tick-outline"

  

- 网络案件
    - 派出所可以办理较为简单的案件
- 行驶中的客车
    - 管辖地：最初停靠地、始发地、途径地、到达地
- 倒卖、伪造、变造火车票案件
    - 管辖地：最初受理地 / 主要违法行为地的铁路公安或地方公安机关
- 铁路施工工地上发生的案件
    - 未规定明确管辖主体
- 列车上发生的案件
    - 管辖地：铁路公安  
:::

  

::: card title="刑事案件特殊管辖" icon="typcn:tick-outline"

  

- 网络案件
    - 派出所可以办理较为简单的案件
- 行驶中的客车
    - 管辖地：最初停靠地、始发地、途径地、到达地
- 倒卖、伪造、变造火车票案件
    - 管辖地：最初受理地 / 主要违法行为地的铁路公安或地方公安机关
- 铁路施工工地上发生的案件
    - 管辖地：地方公安机关
- 列车上发生的案件
    - 抓获场景 1（火车上抓住）：前方停靠站、始发站、终点站
    - 抓获场景 2（车站里抓住）：车站所在地的铁路公安、负责该列车乘务的铁路公安
    - 抓获场景 3（未抓住）：负责该列车乘务的铁路公安  
:::  
::::

  
## 二、管辖 - 共同管辖与管辖争议

:::: card-grid



::: card title="共同管辖（行政 + 刑事通用）" icon="typcn:tick-outline"

  

- 行政案件
    - 几个公安机关都有管辖权时，由最初受理地公安机关管辖；必要时，可由主要违法地公安机关管辖
- 刑事案件
    - 未单独明确表述，可参考行政案件 “最初受理地优先，必要时主要犯罪地管辖” 原则  
:::

  

::: card title="管辖争议（行政 + 刑事通用）" icon="typcn:tick-outline"

  

- 处理流程
    1. 第一步：先协商管辖
    2. 第二步：协商不成，报请共同的上级公安机关指定管辖
- 行政与刑事案件差异
    - 无额外差异表述，处理流程一致  
:::

## **三、回避**

:::: card-grid


::: card title="行政案件回避" icon="typcn:tick-outline"

  

- 回避主体
    - 公安机关负责人、办案民警、翻译人、鉴定人
- 回避理由
    - 近亲属关系、利害关系、其他关系 + 可能影响公正处理
- 回避方式
    - 自行回避、申请回避、指令回避
- 回避审批
    - 所属公安机关或上一级公安机关审批；无救济路径
- 审批时限
    - 2 日内
- 驳回救济
    - 无救济路径
- 决定前状态
    - 不停止工作
- 决定后状态
    - 不参与处罚决定作出前的工作，可参加后期执行工作
- 效力
    - 回避决定前开展的工作可能有效，也可能无效  
:::

  

::: card title="刑事案件回避" icon="typcn:tick-outline"

  

- 回避主体
    - 公安机关负责人、办案民警、翻译人、鉴定人、记录人
- 回避理由
    - 近亲属关系、利害关系、其他关系 + 可能影响公正处理；担任过本案证人、鉴定人、辩护人、诉讼代理人
- 回避方式
    - 自行回避、申请回避、指令回避
- 回避审批
    - 侦查人员、翻译人、鉴定人、记录人：局长审批；重大复杂案件需同级检察院检委会审议
- 审批时限
    - 一般==2日==内；情况复杂，经县级以上公安机关负责人批准可延长至 5 日内
- 驳回救济
    - 5 日内可申请复议，复议机关 5 日内作出决定
- 决定前状态
    - 不停止工作
- 决定后状态
    - 不参与处罚决定作出前的工作，可参加后期执行工作
- 效力
    - 回避决定前开展的工作可能有效，也可能无效  
:::  
::::

## **四、调查 / 侦查一般规定**

:::: card-grid



::: card title="行政案件调查规定" icon="typcn:tick-outline"

  

- 调查主体
    - 一般情况：两名以上人民警察
    - 例外情况：1 名民警 + 辅警 + 全程录音录像，可办理特定 6 类事项
- 强制措施
    - 人身强制：强制传唤、继续盘问、强制检测保护性约束措施、拘留审查、限制活动范围、人身约束措施
    - 财产强制：查封、扣押、扣留、冻结、先行登记保存、抽样取证、封存文件资料  
:::

  

::: card title="刑事案件侦查规定" icon="typcn:tick-outline"

  

- 侦查主体
    - 必须为两名以上侦查人员
    - 无 “民警 + 辅警” 例外情形
- 强制措施
    - 人身强制：拘传、取保候审、监视居住、拘留、逮捕
    - 财产强制：查封、扣押、冻结（无 “先行登记保存、抽样取证” 表述）  
:::  
::::

  
## **五、行政案件五大调查手段**

:::: card-grid



::: card title="行政案件调查手段详情" icon="typcn:tick-outline"

  

- 传唤
    - 审批：口头无需审批，书面需办案部门负责人审批
    - 时限：一般 8-24 小时；治安案件 8-12-24 小时
    - 地点：公安局、村委会、居委会等
    - 见证人：不需要
    - 备注：口头传唤需在询问笔录注明，书面传唤需在传唤证注明；应当异地执行传唤；行政有强制传唤，回单位找办案部门负责人补批手续
- 询问
    - 审批：无需审批
    - 时限：参考传唤时间
    - 地点：询问违法嫌疑人，原则上不在现场和其提出的地点进行
    - 见证人：不需要
    - 备注：家庭成员必要时询问；无关问题有权拒绝回答；需签名或捺指印；按 “人身安全检查 - 采集信息 - 询问” 流程进行
- 勘验检查
    - 审批：勘验无需审批，检查需县级以上公安机关负责人批准
    - 时限：无法定时间限制
    - 地点：勘验在案发现场，检查在场所、物品、人身
    - 见证人：应当有
    - 备注：勘验视情况必要时开展；无证检查：商家需 “必要时”，住所需 “重大案事件”
- 鉴定
    - 审批：办案部门负责人审批
    - 时限：无法定时间限制
    - 地点：无法定地点限制
    - 见证人：不需要
    - 备注：多人意见不同时，应当注明
- 辨认
    - 审批：无需审批
    - 时限：无法定时间限制
    - 地点：无法定地点限制
    - 见证人：不需要
    - 备注：需按 “混杂辨认” 规则，对应数量为 6、7、10（特定情形下）  
:::

  

::: card title="刑事案件对应侦查手段（参考行政）" icon="typcn:tick-outline"

  

- 传唤（对应行政传唤）
    - 审批：口头无需审批，书面需办案部门负责人审批
    - 时限：12-24 小时
    - 地点：侦查机关办案场所等
    - 见证人：不需要
    - 备注：无 “异地执行” 特殊表述
- 讯问（对应行政询问）
    - 审批：无需审批
    - 时限：参考传唤时间，复杂案件可延长
    - 地点：看守所（羁押后）或侦查机关办案场所（未羁押时）
    - 见证人：不需要
    - 备注：需全程录音录像（重大案件）；需签名且捺指印；无关问题有权拒绝回答
- 勘验检查（与行政类似）
    - 审批：勘验无需审批，检查需县级以上公安机关负责人批准
    - 时限：无法定限制
    - 地点：案发现场（勘验）、场所 / 物品 / 人身（检查）
    - 见证人：应当有
    - 备注：人身检查需符合法定程序，女性身体检查需女性工作人员进行
- 鉴定（与行政类似）
    - 审批：办案部门负责人审批
    - 时限：无法定限制，需及时出具鉴定意见
    - 地点：法定鉴定机构
    - 见证人：不需要
    - 备注：鉴定意见需告知犯罪嫌疑人、被害人
- 辨认（与行政类似）
    - 审批：无需审批
    - 时限：无法定限制
    - 地点：法定辨认场所
    - 见证人：不需要
    - 备注：混杂辨认规则，人数 / 物品数需符合法定要求（如犯罪嫌疑人辨认 7 人，物品辨认 10 件）  
:::  
::::


## **六、行政 / 刑事传唤措施对比**

:::: card-grid



::: card title="行政案件传唤" icon="typcn:tick-outline"

  

- 种类
    - 口头传唤、书面传唤、强制传唤
- 审批
    - 口头传唤：无需审批
    - 书面传唤：办案部门负责人审批
    - 强制传唤：办案部门负责人审批
- 期限
    - 一般案件：8-24 小时
    - 治安案件：8-12-24 小时（特殊情况可延长至 24 小时）
- 见证人
    - 不需要  
:::

  

::: card title="刑事案件传唤" icon="typcn:tick-outline"

  

- 种类
    - 口头传唤、书面传唤（无 “强制传唤” 表述，对应 “拘传” 强制措施）
- 审批
    - 口头传唤：无需审批
    - 书面传唤：办案部门负责人审批
- 期限
    - 一般案件：12 小时
    - 案情特别重大、复杂，需要采取拘留、逮捕措施的：24 小时
- 见证人
    - 不需要  
:::  
::::

  
## **七、行政 / 刑事扣押措施对比**

:::: card-grid



::: card title="行政案件扣押" icon="typcn:tick-outline"

  

- 对象
    - 普通动产（涉案件的违法财物、证据等）
- 审批
    - 公安机关负责人审批
- 期限
    - 一般 30 日；情况复杂可延长 30 日（总计最长 60 日）
- 其他
    - 需出具《扣押清单》，由办案人员、持有人、见证人签名  
:::

  

::: card title="刑事案件扣押" icon="typcn:tick-outline"

  

- 对象
    - 普通动产（涉案件的犯罪所得、作案工具、证据等）
- 审批
    - 一般案件：办案部门负责人审批
    - 现场紧急情况：现场指挥人员审批
    - 重大复杂案件：县级以上公安机关负责人审批
- 期限
    - 无明确法定时间限制（需随案移送或依法处理）
- 其他
    - 需出具《扣押清单》，一式三份，由侦查人员、持有人、见证人签名  
:::  
::::



## **八、行政/刑事查询、冻结措施对比**



:::: card-grid

::: card title="行政" icon="typcn:tick-outline"

- 对象
	- 涉恐人员的财产
- 查询审批
	- 县级以上公安机关负责人
- 冻结审批
	- 县级以上公安机关负责人
- 冻结财产的出售
	- 无规定

:::

::: card title="刑事" icon="typcn:tick-outline"

- 对象
	- 涉恐人员的财产
- 查询审批
	- 县级以上公安机关负责人 
- 冻结审批
	- 一般案件：县级以上公安机关负责人
	- 股权、保单权益：==设区的市一级以上公安机关负责人==
	- 上市公司的股权：==省级以上公安机关负责人==
- 冻结财产的出售
	- 权利告知
	- 持有人申请
	- 审批
		- 本票支票：两不影响+期满即将届满
		- 股票基金：两不影响[+两不影响]

:::


::::



 [+应当作1]:
	如果是行政执法机关移送的案件，不需要制作《受案回执》，在《移送案件通知书》上签字即可。


 [+审查立案时间]:
	 如果是行政机关移送的案件，公安机关应当自接受案件之日起==三日==内进行审查并书面告知结果。


 [+卖淫等]:
	 注意：卖淫、嫖娼包含四类案件，分别是卖淫、嫖娼、在公共场所拉客招嫖以及引诱、容留、介绍他人卖淫


[+混杂辨认]:
	辨认违法嫌疑人时，被辨认的人数不得少于七人；对违法嫌疑人照片进行辨认的，不得少于十人照片。辨认每一件物品时，混杂的同类物品不得少于五件



[+两不影响]:
	- 不影响国家、被害人、其他权利人权益
	- 不影响诉讼正常进行
