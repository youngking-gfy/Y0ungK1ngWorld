# 涉案财物的管理


### **一、涉案财物的来源**  
 
#### **1. 扣押扣留**：
- **审批**：公安机关负责人批准`30日`	
- **延长**：县级以上公安机关负责人批准延长到`60日`
- **地点**：转移占有，需移交专门保管部门；特殊情况下可委托第三方保管（如需特定保存条件）。 

#### **2. 查封**
- **审批**：公安机关负责人批准`30日`	
- **延长**：县级以上公安机关负责人批准延长到`60日`
- **地点**：不转移占有

#### **3. 冻结**
- **审批**：县级以上公安机关批准`2个月`	
- **延长**：上一级公安机关批准延长到`3个月`
- **地点**：金融系统——针对涉恐人员

#### **4. 抽样取证**
- **审批**：行政机关负责人
- **地点**：原则上公安机关

#### **5. 先行登记保存**
- **审批**：行政机关负责人
- **期限**：`7日内`
- **地点**：持有人所在地或公安机关或其他地方


#### **6. 追缴**
- **审批**：
	- 县级以上公安机关决定
	- 但是需要==退还被侵害人==的，公安派出所也可以追缴
- **范围**：==违法所得==应当追缴。违法所得包括赃款赃物和非法利益

#### **7. 收缴**
- **审批**：
	- 县级以上公安机关决定；
	- 但是违禁品、管制器具、吸食注射毒品的工具，500元以下非法财物且当事人无异议的，派出所可直接收缴。  
- **范围**：
	- 毒品、淫秽物品等违禁品
	- 赌具和赌资（==本金+赢钱==）
	- 吸食、注射毒品的用具
	- 伪造、变造的公文、证件、印章、证明文件、票证等
	- 倒卖的车船票、文艺演出票、体育比赛入场券等有价票证
	- 主要用于实施违法行为本人所有工具以及直接用于实施毒品违法行为的资金
	- 法律法规规定的可收缴的其他非法财物
	- ==注意=={.danger}：对明显无价值的物品，可以==不作出收缴决定=={.info}，在证据保全文书中注明处理情况

#### **表格梳理**

| 措施     | 审批人                        | 审批时间         |
| ------ | -------------------------- | ------------ |
| 扣押扣留   | 公安机关负责人（延长需县级以上公安机关负责人批准）  | 30日（可延长至60日） |
| 查封     | 公安机关负责人（延长需县级以上公安机关负责人批准）  | 30日（可延长至60日） |
| 冻结     | 县级以上公安机关（延长需上一级公安机关批准）     | 2个月（可延长至3个月） |
| 抽样取证   | 行政机关负责人                    | /            |
| 先行登记保存 | 行政机关负责人                    | 7日内          |
| 追缴     | 县级以上公安机关（退还被侵害人的，公安派出所也可）  | /            |
| 收缴     | 县级以上公安机关（违禁品等特定情况派出所可直接收缴） | /            |

### **二、涉案财物的移交**  

- **时限**：
	- 提取涉案财物后`24小时内`将财物移交涉案财物管理人员，并办理移交手续
	- 对查封、冻结、先行登记保存的涉案财物，在采取措施后`24小时`，将法律文书复印件及涉案财物情况送交涉案财物管理人员予以登记
	- 异地、偏远、交通不便提取涉案财物，办案人民警察回单位后`24小时`移交
	- 情况紧急需要鉴定、辨认、检验、检查等工作的，经办案部门责任人批准，可以完成上述工作后`24小时`上交
	- 在提取涉案财物后`24小时`已处理完毕的，不再移交，但应将处理涉案财物的相关手续附卷保存

### **三、涉案财物的保管**  

#### **地点**
- 县级以上公安机关指定内设部门
- 办案部门设置专门场所保管
- 委托第三人保管

#### **电子台账**



#### **特殊涉案财物保管要求**

- 易腐、不易保管物品，经==公安机关负责人==批准，在==拍照或者录像后=={.important}依法==变卖==或者==拍卖==，变卖或拍卖所得价款暂予保存
- ==易燃、易爆、毒害性、放射性==等危险物品应当存放在符合危险物品存放条件的专门场所
- 对属于被侵害人或者善意第三人合法占有的财物，应当在登记、拍照或者录像、评估后及时==返还==
- 不宜入卷物证，应当==拍照入卷==

#### **保管费用**

公安机关==承担=={.danger}

### **四、涉案财物的调用**  
### 调用权限与程序  
- **调用条件**：办案需要（如==询问、鉴定、辨认、检查==等）。  
- **审批流程**：需经==办案部门负责人==批准，使用后及时归还保管部门。  

---

### **五、涉案财物的处理**  
#### **处理原则与方式**  
- **基本原则**：作出行政处理决定时，应当对涉案财物一并作出处理 
#### **处理方式分类**  
- **返还**
	- 属于被侵害人或者善意第三人的合法财务，及时**返还**：  
	  - **期限**：通知原主或者当事人在`6个月`内来领取，特殊情况酌情延期处理，最多不超过`3个月`
	  - 原主不明确的：采取==公告=={.info}方式，`6个月`后无人认领，上缴国库或者依法变卖或者拍卖将所得款项上缴国库
- **上缴国库**：  
  - 无主财物或无法返还的违法所得（如黄赌毒相关资金）。  
- **拍卖/变卖**：  
  - 无主或需处置的作案工具（如刀具、赌具），所得款项上缴国库。  
- **销毁**：  
  - 无价值或危险物品（如违禁品、毒品），或无法销毁的返厂处理。  

---


### **六、易错点辨析**  
- **查封 vs 扣押**：查封不转移占有（如查封商铺），扣押需转移至公安机关或第三方。  
- **追缴 vs 收缴**：追缴针对违法所得及衍生利益；收缴针对违禁品、赌具等直接非法财物。
