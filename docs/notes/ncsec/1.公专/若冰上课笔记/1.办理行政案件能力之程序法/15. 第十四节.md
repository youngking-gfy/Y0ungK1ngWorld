# 行政处理决定课程笔记


### **一、行政处理决定的审核审批**
1. **审核与审批的区别**  
   - **审核**：中间环节，由专业人员[+审核人]进行法律专业把关，确保程序合法性。  
     - 审核人需具备法律专业能力，新任审核人需通过法考（老人老政策，新人新政策）。  
     - 审核人对审核意见负责，但不最终决定案件结果（如==派出所所长审核拘留建议，但需局长最终审批=={.info}）。  
     
   - **审批**：最终决定环节，由有权机关负责人（如公安局局长）签字确认，结束案件流程。  
	 - ==办案部门负责人=={.info}审批（如==警告==、==500元以下罚款==由派出所所长审批）
     - ==县级以上公安机关负责人=={.info}审批
     - 重大、复杂、疑难案件，由==公安机关领导=={.info}集体讨论决定

2. **执法过错责任划分**  
   - ==谁错谁担责=={.important}：  
     - 办案人员：对送审材料的真实性、准确性、完整性负责（如隐瞒关键证据导致处罚错误，由办案人员担责）。  
     - 审核人：对审核意见负责（如明知证据不足仍同意处罚，审核人担责）。  
     - 审批人：对最终审批决定负责（如超出审核建议加重处罚，审批人担责）。

### **二、行政处罚的适用**

#### 1. **适用原则与影响因素**  
   - **时间因素**：追究时效制度（消灭时效）。  
   - **对象因素**：是否属于从轻、减轻或不予处罚主体（如盲聋哑人、未成年人、初次违法且危害轻微并及时改正者）。  
   - **情节与结果因素**：是否存在从重、从轻情节（如配合查处、主动消除危害后果）。  
   - **违法状态纠正**：处罚目的是教育与预防，而非单纯罚款。例如：  
     - 电动车未戴头盔罚款后必须要求佩戴；  
     - 货车超载需卸货后放行（消除违法状态）。  

#### 2. **时间影响——追究时效**  
   - **时效类型**：  
     - **消灭时效**：经过一定时间后失去追责权利（如治安案件6个月）。  
     - **取得时效**：经过时间后获得某项权利（如旧婚姻法中婚前财产转化，现已取消）。  
   - **追究时效规则**：  
     - **治安管理**：违法行为在==6个月内==未被发现的，不再处罚
     - 其他违法行为—==2年内==
     - 涉及人身安全、金融安全且有危害后果——==5年内==）。  
     - **起点**
       - 违法行为==发生之日==起
       - 违法行为有==连续、继续或者持续状态==的，从行为终了之日起计算
       - 被侵害人在追究时效内向公安机关控告，公安机关应当受理而不受理的，不受追究时效的限制
     - **中断与延长**：  
       - **中断**：在时效内再次违法，前行为时效重新计算。  
       - **延长**：特殊情况（如嫌疑人逃匿）可暂停时效计算。
     - **处理超过追究时效案件**
       - 不立案;
       - 立案后：
	       - 经调查发现超过追究时效，终止案件调查。==但如果有违禁品，应当依法予以收缴=={.danger}
	       - 违法行为因超过追究时效，由于没有启动调查程序，违法行为没有查证属实，==不应算作前科=={.danger}
	   - 超过追究时效，并不影响有关当事人依法要求追究违法行为人的==民事责任=={.info}

#### 3. **对象影响**  
- **年龄**
   - ==不满14周岁==的人违法行为
	   - ==不予行政处罚=={.info}——制作不予行政处罚决定书
	   - 责令其监护人严加管教，并在决定书中载明
	   - 对违法所得和非法财物可以追缴或者收缴，但==不得适用没收=={.info}等行政处罚
	   - 违法行为有==连续继续状态=={.info}，只对已满14周岁之后的违法行为承担责任
- **精神状态**
	- **完全**正常
		- 应当给予处罚
	- **完全**不正常
		- ==不予行政处罚=={.info}+制作不予行政处罚决定书
		- 责令其监护人严加看管和治疗，并在不予行政处罚决定书中载明
		- 对精神病人不予处罚，但对他人造成损害的，其监护人应当承担民事责任；有违法所得和非法财物，应当予以追缴或者收缴
	- **半**正常
		- 应当予以行政处罚
		- 但可以==从轻==或==减轻==处罚

- **盲人、又聋又哑**可以从轻、减轻或不予处罚
	- 盲人:双目失明；聋哑人：==又聋又哑==的人
	- 关键看生理缺陷和违反治安管理行为之间因果关系的关联强弱
	- 是==可以==，而不是==应当==：防止不法分子钻空子

#### 4. **情节影响**
- **应当从轻、减轻或者不予处罚的情形**
	- 主动消除或减轻违法行为危害后果，并取得被侵害人谅解的
	- 受他人胁迫或诱骗的
	- 有立功表现的
	- 主动投案，向公安机关如实陈述自己的违法行为
	- 其他
- **应当从重处罚的情形**
	- 有较严重后果的
	- 教唆、胁迫、诱骗他人实施违法行为
	- 对报案人、控告人、举报人、证人等打击报复的
	- ==六个月内==曾收到治安管理处罚或者一年内因同类违法行为受到两次以上公安行政处罚的
	- 刑罚执行完毕三年内，或者缓刑期限，违反治安管理的
- **时间形态**
	- **预备**：应当==不予处罚==
	- **中止**：未造成损害，不予处罚，造成损害，应当减轻处罚
	- **未遂**：应当从轻、减轻或者不予处罚

#### 5. **结果影响**

- **罚款**
	- 1. **并科原则**
	    - **定义**：对同一主体的==多个违法行为==，罚款金额直接==相加==。
	    - **适用场景**：
	        - 例：A行为罚款500元，B行为罚款500元 → 总罚款1000元。
	        - **注意**：仅限于多个==独立=={.danger}违法行为，非同一行为触犯多法。
	- 2. **一事不再罚（罚款）原则**
	    - **定义**：==同一==违法行为不得被多个行政机关==重复=={.danger}罚款，但可给予其他处罚（如拘留）。
	    - **核心规定**：
	        - **内外有别**：
	            - ==外部单位==（如税务局、卫健委）已罚款 → 公安机关不可再罚款，但可采取其他处罚（如警告、拘留）。
	            - ==公安机关内部==：同一行为若涉及多个法律规范，需按优先级选择处罚依据。
	        - **法律规范优先级**：
	            - **上位法优先**：若上位法（如法律）与下位法（如规章）冲突，适用上位法。
	            - **罚款数额高者优先**：
		            - 若未接相同，比较罚款上限 → 上限高者优先；
		            - 上限相同则比较下限 → 下限高者优先。

    - **案例解析**：
        - 大妈无证摆早餐摊 → 卫生局、市监局、税务局、交警均可能处罚，但罚款只能由一家单位执行，其他单位可采取警告、没收等非罚款处罚。

- **拘留**
	- **拘留合并**
	    - **最长时限**：合并执行拘留不得超过20日。
	    - **操作流程**：
	        - **分别决定，合并执行**：对多个违法行为分别作出拘留决定，但总时长不超过20日。
	        - **案例**：
	            - 张三甲行为拘留15日 + 乙行为拘留15日 → 合并执行不超过20日。
	            - 若分阶段处罚（如甲行为执行完后处罚乙行为），则总时长可能超过20日，但需分次执行。
    - **作出拘留决定但不执行拘留**
	    - 已满14周岁不满16周岁
	    - 已满16周岁不满18周岁，==初次==违反治安管理或者其他公安行政管理的。==但是=={.danger}曾被收容教养、被行政拘留依法不执行行政拘留或者曾因实施扰乱公共秩序、妨害公共安全、侵犯人身、财产权利、妨害社会管理的行为被人民法院判决有罪的==除外=={.danger}。
	    - 已满==70周岁==以上的
		- 孕妇或者正在哺乳自己婴儿的妇女
	- **折抵行政拘留问题**
		- 刑事案件转成行政案件，被处以行政拘留的。
		- 刑事拘留和逮捕一日折抵行政拘留一日；指定居所监视居住两日折抵行政拘留一日。询问查证、继续盘问和采取约束措施的时间不予折抵。
		- 被采取上述刑事强制措施限制人身自由的时间超过决定的行政拘留期限，行政拘留决定==不再执行==。
	- **处罚决定书**
		- 一人多行为，==分别决定、合并执行==
		- 一案有多人，==分别决定==，==可以=={.info}制作一式多份
