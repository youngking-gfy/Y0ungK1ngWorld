## 课程笔记：公安机关五大调查手段之询问、检查


## 询问

### **一、询问的基本规范**
1. **询问主体**  
   - 必须由**两名以上具有执法资格的民警**共同执行，符合一般程序要求。

2. **询问对象**  
   - **被侵害人（好人）**：指案件中的受害者，需制作询问笔录。  
   - **违法嫌疑人（坏人）**：行政案件中使用“询问笔录”，刑事案件中则为“讯问笔录”。  
   - **证人**：提供案件相关信息的第三方，同样使用询问笔录。

3. **询问地点**  
   - **违法嫌疑人**：  
     - **安全原则**：需确保对民警和嫌疑人双方的安全。  
     - **地点选择**：  
       - 可在嫌疑人住处、单位或所在市县内的指定地点（如公安机关、居委会、村委会等）。  
       - **不得在现场询问**：避免群众围观或同案犯干扰，除非紧急情况（如嫌疑人生命危险、需立即获取关键证据）。  
     - **地点提出权**：嫌疑人无权指定询问地点，民警可根据安全考虑拒绝其提出的地点。  
   - **被侵害人和证人**：  
     - 灵活选择地点（如家中、医院、公共场所等），无特殊限制，以方便其配合为原则。

4. **询问时间**  
   - **传唤后询问**：  
     - 传唤后询问、鉴定、辨认等总时长不超过**24小时**（一般不超过8小时）。  
     - 符合条件（如案情复杂）可延长至24小时。  
   - **非传唤询问**：  
     - 未使用传唤直接询问时，时间参照传唤标准（8-24小时）。  
   - **被侵害人与证人**：无明确时间限制，但需兼顾效率与合法性。


### **二、询问笔录的制作流程**
1. **询问前的程序**  
   - **人身安全检查**：  
     - **强制性步骤**：将嫌疑人带至办案区后，**必须首先进行人身安全检查**。  
     - **目的**：排除危险物品（如凶器、违禁品），保障民警和嫌疑人安全。  
     - **无需检查证或笔录**：属于安全措施，非取证行为。  
   - **信息采集**：包括身份信息、生物特征等，为后续程序做准备。

2. **询问中的规范**  
   - **笔录内容**：如实记录嫌疑人陈述、辩解及被侵害人、证人证言。 认为记录有误或遗漏，应当允许被询问人更正或补充，并在修改处==捺指印=={.info}(==只捺指印，不签名==)，认为无误后，在询问笔录==逐页签名或捺指印=={.info},笔录末页注明：“以上笔录我看过，与我说的相符”
   - **询问要求**：应当个别进行，可以全程录音录像。
   - **重点对象**：对违法嫌疑人的询问是考试核心，需注意流程与法律依据。  
   - **顺序要求**：人身安全检查→信息采集→询问笔录，不可颠倒。

3. **询问后的处理**  
   - **证据固定**：对查获的危险物品需依法扣押、登记，并规范保管。（==不用收缴=={.danger}）  
   - **退还流程**：合法物品在程序结束后应退还，并做好记录。


### 三、刑事案件与行政案件的区别

| **项目**    | **行政案件**    | **刑事案件**           |     |
| --------- | ----------- | ------------------ | --- |
| **嫌疑人陈述** | 询问笔录        | 讯问笔录               |     |
| **询问地点**  | 灵活（但需安全）    | 严格限制（不得在现场询问）      |     |
| **程序处理**  | 传唤时间不超过24小时 | 讯问可延长至24小时（特殊案件更长） |     |

### **四、其他关键点**
1. **危险物品处理**：  
   - 检查中发现危险物品，需依法扣押并登记，妥善保管，避免二次风险。

2. **证人与被侵害人的保护**：  
   - 询问时需注意隐私保护，地点选择需兼顾安全与便利。

3. **自由裁量权**：  
   - 民警需根据实际情况判断嫌疑人是否“拒不配合”，合理使用强制措施。

## 勘验检查


### **一、勘验**
- 必要时**勘验**
	- 违法行为人实施违法行为
	- 遗留与违法行为有关痕迹

### **二、检查**
- **目的**：查获嫌疑人和违法证据
- **检查主体**：
	- 两名以上警察
	- 检查妇女身体：应当由女性工作人员（指==公安机关内部工作的女户籍民警、女内勤以及女辅警==，不包括保洁、保安、厨师、司机等）
- **审批主体**
	- 县级以上公安机关负责人批准后制作《检查证》
- **检查对象**
	- 1.**场所**
		- 原则上两警两证（==警察证=={.info}、==检查证=={.info}）,两警单证（==警察证=={.info}）例外可以，事后无需补办检查证
		- **商用场所**：必要时没有检查证也可当场检查。==不立即检查导致证据灭失和违法人逃脱=={.danger}
		- **住宅场所**：住宅必须出示警察证+检查证。必须==有证据表明==或者==有群众报警==公民住所正在发生==危害公共安全==或者==公民人身安全==或者==违法存放危险物质==
		- **商住两用场所**（居住场所与市场监督管理局注册登记的经营场所合一的）：经营时-检查经营场所；非经营时间-检查公民住所
	- 2.**物品**
		- 用于实施违法行为的工具、赃物、现场遗留物、随身携带的物品；==避免对物品造成不必要损坏==
	- 3.**人身**
		- **体外**：查违禁品、枪支、凶器、赃款、赃物以及作案工具等。
		- **体表**：违法行为相关身体特征、伤害情况、生理状态
		- **体内**：依法提取收集人体生物识别信息和生物样本
	==无证检查在紧急情况下适用于场所、物品、人身=={.danger}
	
- 应当有**见证人**。检查人、被检查人、见证人签字或盖章，被检查人不在场或拒绝，笔录==注明=={.info}
- **强制检查无需审批**：违法嫌疑人无正当理由无权拒绝检查
- **检查记录**
	- **笔录**：检查人员、被检查人和见证人签名或盖章
	- **全程录音录像**可以代替书面检查笔录

| 检查场所类型 | 检查条件                                      | 检查目的与限制                    |
| ------ | ----------------------------------------- | -------------------------- |
| 商用场所   | 两警两证, 两警单证（警察证）事后无需补办检查证                  | 必要时无证，不立即检查可能导致证据灭失和违法人逃脱  |
| 住宅场所   | 两警两证。有证据表明或者有群众报警，危害公共安全、公民人身安全或者违法存放危险物质 | 严格限制,如果发生的是危害到公共安全或者公民人身安全 |
| 商住两用场所 | 经营时间检查经营场所；非经营时间检查公民住所                    | 根据使用性质和时间来确定检查方式           |
|        |                                           |                            |
