# 刑事案件管辖课程笔记


### **一、外部管辖：谁有权管哪类案件？**

#### **1.1 人民检察院直接受理案件（14+转）**

| 范围                | 法条依据       | 课堂逐字稿要点                                                                                    |
| ----------------- | ---------- | ------------------------------------------------------------------------------------------ |
| **14类罪名**         | 《刑诉规则》第13条 | ==司法工作人员利用职权侵犯人权==：非法拘禁、非法搜查、刑讯逼供、暴力取证、虐待被监管人、滥用职权、玩忽职守、徇私枉法、民事行政枉法裁判、执行判决裁定失职、执行判决裁定滥用职权等 |
| **管辖转移**          | 《刑诉规则》第17条 | 原为公安机关管辖的国家机关工作人员重大犯罪，经**省级以上人民检察院**决定，可转由检察院立案侦查（示例：省厅领导故意杀人→省检决定→检察院立案）                  |
| **三要件缺一不可**       | 课堂强调       | ①司法工作人员（侦查、检察、审判、监管职责）②利用职权③侵犯人权→同时满足才归检察院，缺一则归公安或监委                                       |
| **公安与检察交叉案件**<br> | /          | 看主罪确定主侦查                                                                                   |

> 举例：  
> • 警察王水因私债拘禁张三 → **缺“利用职权”→公安管辖**  
> • 警察王水传唤李四超时拘禁 → **三要件齐全→检察院管辖**

---

#### **1.2 人民法院直接受理案件（5+8+转）**

| 类型            | 罪名/情形                                                                      | 告诉才处理例外                 | 课堂逐字稿要点                                                                  |
| ------------- | -------------------------------------------------------------------------- | ----------------------- | ------------------------------------------------------------------------ |
| **告诉才处理（5）**  | 侮辱、诽谤、暴力干涉婚姻自由（==致死除外==）、虐待（==重伤、死亡、无能力告诉，受强制威胁==）、侵占（==绝对的告诉才处理=={.info}） | 危害社会秩序、国家利益或致重伤死亡除外     | • 个人/家庭法益→被害人意志优先<br>• 进入公共法益→公安主动介入                                     |
| **轻微刑事案件（8）** | 轻伤害、非法侵入住宅、重婚、遗弃、生产销售伪劣商品、侵犯知识产权、三年以下刑罚案件                                  | 公安、法院**均有管辖权**          | • 口诀：**“通侵重伪弃 3”**（通信自由、侵入住宅、重婚、伪劣商品、遗弃、三年以下）<br>• 公安不得推法院；法院缺证据或不轻微可推公安 |
| **公诉转自诉**     | 公安/检察院不追究且限人身、财产权                                                          | 需同时满足：①有证据证明侵权②曾控告而被不追究 | 案件类型仅限人身权、财产权，不含民主权                                                      |



---

#### **1.3 监察委员会管辖**

| 范围              | 程序规则                 | 课堂逐字稿要点                              |
| --------------- | -------------------- | ------------------------------------ |
| **职务违法/犯罪108种** | 监察法第11条              | 贪污贿赂、滥用职权、玩忽职守、权力寻租、利益输送、徇私舞弊、浪费国家资财 |
| **互涉案件**        | 监委为主调查，公安、检察协助       | • 监委用“调查”而非“侦查”<br>• 监委侦查手段不受刑诉法严格约束 |
| **线索移送**        | 法院、检察、公安、审计发现线索→先送监委 | “先找钱，再找人”——查清职务犯罪后，再处理其他犯罪           |

### **二、内部管辖：公安内部如何分工？**

#### **2.1 地域管辖**
- **原则**：犯罪地公安机关管辖  
- **例外**：居住地更适宜（流窜作案、民愤极大、缓刑监管地）

#### **2.2 级别管辖**

| 级别          | 可办案件                                      | 不可办案件（派出所禁止清单）                                                                    |
| ----------- | ----------------------------------------- | --------------------------------------------------------------------------------- |
| **派出所**     | 因果关系明显、案情简单、无需跨县侦查：①当场抓获②自首③扭送④直接破案⑤其他简单案 | **“十一不办”**：故意杀人、重伤、强奸、抢劫、绑架、贩毒、放火、爆炸、投放危险物质、入室/汽车/系列/团伙/跨区盗窃、需专业侦查案件              |
| **县级公安**    | 本辖区内一般刑事案件                                | /                                                                                 |
| **设区市以上公安** | 重大国恐外经跨区案件                                | • 涉外犯罪：普通外国人犯罪**县局**即可立案侦查（程序规定第363条）<br>• 普遍管辖：外国人在外国犯罪后入境→**市局**立案侦查（程序规定第364条） |

---

#### **2.3 管辖争议与并案**

| 情形 | 操作规则 | 课堂口诀 |
|---|---|---|
| **共同管辖** | 最初受理为主；必要时主要犯罪地 | 与行政案件逻辑一致 |
| **并案侦查** | ①一人犯数罪②共同犯罪③节外生枝④上下游关联 | **“一人数、数人一、节外枝、上下游”** |
| **指定管辖** | 协商不成由共同上级书面指定 | 决定书抄送同级法检 |

### **三、特殊案件管辖**

| 场景           | 管辖机关                                               | 案例         |
| ------------ | -------------------------------------------------- | ---------- |
| **网络犯罪**     | 行为地、居住地公安均可                                        | 远程盗刷银行卡    |
| **铁路**       | • 运行途中抓获→前方停靠站铁路公安<br>• 非运行→乘务公安<br>• 车站被抓→车站或乘务公安 | 列车上盗窃      |
| **国际列车**     | 有协定按协定；无协定→中国始发/前方停靠站铁路公安                          | 莫斯科-北京列车诈骗 |
| **境外中国航空器**  | 中国最初降落地公安                                          | 万米高空打架     |
| **驻外使领馆**    | 主管单位/原户籍地公安                                        | 使馆内盗窃      |
| **境外中国公民犯罪** | 入境地/离境前或现居地；被害人也可                                  | 境外赌博回国被捕   |

### **四、立案衔接与文书**

| 文书 | 发送对象 | 课堂提醒 |
|---|---|---|
| **不予立案通知书** | 仅**控告人** | 举报人、报案人无 |
| **受案登记表** | 一式两份，一份附卷，一份交移送单位 | 环保局移送案件须当场制作 |
| **并案/指定管辖决定书** | 抄送被指定机关+同级法检 | 书面决定，口头无效 |

### **五、真题回顾**

:::: card-grid

::: card title="真题1" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="多选" />下列案件中，公安机关应当将案件材料和有关证据移交有管辖权的人民法院，并告知当事人有权向人民法院起诉的有：（ ）（2017年公安联考第54题）

A. 李某将张某委托自己代为保管的价值十万元的汽车据为己有  
B. 王某多次暴力虐待养女，导致其身受重伤  
C. 赵某因邻里矛盾，多次散布谣言，诽谤邻居  
D. 孙某因琐事将周某打致轻伤  

**答案：!!AC!!**  

::: collapse 
- **解析**
	- A侵占、C诽谤属告诉才处理；
	- B虐待致人重伤已非“轻微”，应公诉；
	- D轻伤属于“8类轻微刑案”，公安法院均可管辖，无须移交。
:::

::: card title="真题2" icon="svg-spinners:blocks-shuffle-3"
<Badge type="warning" text="单选" />甲县市场监督管理局局长陈某受贿并庇护“黑龙帮”，管辖正确的是（2020年公安联考第73题）  
A. 仅移送检察机关  
B. 检、公分别管辖  
C. 公安可并案管辖  
D. 监委为主调查，公安协助  

**答案：!!D!!**  

::: collapse 
- **解析**
	- 涉职务犯罪，监委优先；
	- 涉黑犯罪公安配合，体现“监委为主、其他协助”原则。
:::
