# 公安机关刑事诉讼职权与原则 · 速记笔记  
（依据 2025 公安联考资料整理）

---

## 一、公安机关在刑事诉讼中的 **六大基本职权**

| 分类              | 具体权能                                                                                                                                 | 高频考点 / 易错提示                       |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------- |
| 1️⃣ 立案权         | 对属于自己管辖的刑事案件审查后决定是否立案                                                                                                                | 对“属于自己管辖”的范围要熟记（地域+级别+专门管辖）       |
| 2️⃣ 侦查权         | **十大侦查手段**：讯问；询问；勘验、检查；搜查；查封、扣押；查询、冻结；鉴定；辨认；技术侦查；通缉                                                                                  | 注意“通缉”只能由县级以上公安机关负责人批准            |
| 3️⃣ 预审权         | 对证据的 **客观性**、**关联性**、**合法性** 及 **证明力大小** 进行审查                                                                                        | 预审 ≠ 起诉审查，是侦查终结前的内部把关             |
| 4️⃣ 强制措施        | **决定 + 执行**：拘传、取保候审、监视居住、拘留；<br>**执行权**：对检察院批准/决定的逮捕、取保、监居；法院决定的取保、监居、逮捕                                                             | 只有 **逮捕** 必须经检察院批准或法院决定           |
| 5️⃣ 不予立案 / 撤销案件 | 依据《刑诉法》第 16 条 & GA 规则第 186 条，共 **6 类不追究** 情形：<br>1. 显著轻微不认为是犯罪<br>2. 已过追诉时效<br>3. 特赦<br>4. 告诉才处理的案件无告诉或撤回<br>5. 嫌疑人死亡<br>6. 其他法律规定免责 | 追诉时效口诀：5-10-15-20（无期/死刑最高检核准可超20） |
| 6️⃣ 移送审查起诉      | 侦查终结 → 制作《起诉意见书》→ 连同案卷、证据 **一并移送同级人民检察院**                                                                                            | “同级”是地域同级，非级别同级                   |
| 7️⃣ 行政处理权       | 对 **不够刑事处罚** 的嫌疑人，可依法予以行政处罚或移送行政部门                                                                                                   | 常见：赌博、吸毒、故意伤害（轻伤以下）               |
| 8️⃣ 部分刑罚执行权     | 1. **拘役**、**剥夺政治权利**、**驱逐出境** 由公安机关执行；<br>2. 有期徒刑余刑 **≤ 3 个月** 的，由看守所代为执行                                                            | 注意与“监狱执行”区分                       |

## 二、公安机关办理刑事案件的 **四大原则**

| 原则 | 核心要义 | 实务提示 |
|---|---|---|
| 1️⃣ 接受检察监督 | 立案、侦查、强制措施、移送起诉等各环节 **依法接受人民检察院法律监督** | 检察院可发出《纠正违法通知书》 |
| 2️⃣ 内部执法监督 | 建立 **办案责任制** + **执法过错责任追究制**；<br>**上级可撤销 / 变更下级决定**，也可指令纠正；<br>下级必须执行上级决定，如有异议可 **边执行边报告** | 考试中常考“指令纠正”与“自行纠正”并用 |
| 3️⃣ 同级移送 | 向 **同级人民检察院** 提请批准逮捕、移送审查起诉 | 地域同级，非级别同级 |
| 4️⃣ 语言文字保障 | 1. 为不通晓 **当地通用语言文字** 的诉讼参与人提供翻译；<br>2. 少数民族聚居或多民族杂居地区：<br>讯问使用 **当地通用语言**，<br>外发文书使用 **当地通用文字** | 注意“当地通用”≠“普通话” |
