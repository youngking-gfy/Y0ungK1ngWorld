# 行政处罚告知与听证程序课程笔记


### **一、行政处罚告知程序**

#### **1. 定义与目的**  
行政处罚告知是公安机关在作出行政处罚决定前，依法向当事人告知拟处罚的事实、理由、依据及权利义务的程序，是保障当事人陈述权和申辩权的重要环节。

#### **2. 告知方式**  
- **简易程序**：口头告知
- **快速办理制度**：可以口头，也可以书面告知
- **普通程序**：应当书面告知；因违法行为人逃跑等原因无法履行告知义务的，公安机关可以采取==公告==方式送达，期限为==7日==

#### **3. 关键内容**  
- **告知内容**：  
  - **事实**：具体违法行为的时间、地点、行为人及行为内容（例：2025年3月某日，在某地与他人赌博）。  
  - **理由**：证据支持（例：“有证人证言、监控录像等证据为证”）。  
  - **依据**：具体法律条款（例：根据《治安管理处罚法》第70条）。  
  - **处罚种类与幅度**：需明确具体处罚（如“拟处行政拘留5日并罚款500元”），不得笼统表述（如“将进行处罚”）。  

- **权利告知**：  
  - 当事人享有陈述权和申辩权。  
  - 对陈述和申辩内容，公安机关需记录或附书面材料，并进行复核。

- **违法嫌疑人的陈述权和申辩权**
	- 这是一项基本程序权利
	- 对违法嫌疑人提出新的事实、理由和依据，公安机关应当复核
	- 公安机关不得因违法嫌疑人的申辩而加重处罚
 

**4. 注意事项**  
- **明确处罚内容**：避免模糊表述，否则可能被认定为程序违法。  
- **签字确认**：当事人需对告知内容签字确认，拒签时应注明“拒签”。

### **二、听证程序**

#### **1. 启动条件**  
听证程序适用于以下情形（根据《行政处罚法》第63条）：  
- **资格罚** 降低资质登记、吊销许可证件（==暂扣驾驶证不听证，轻微！=={.danger}）；
- **行为罚** 责令停产停业、责令关闭、限制从业；
- **财产罚** 较大数额罚款；没收较大数额违法所得、没收较大价值非法财物；
	- 拟对个人作出==2000元以上罚款==；  
	- 拟对单位作出==1万元以上罚款==；  
	- 出入境个人==6000元以上罚款==；
	- ==注意：较大数额罚款只适用于一个处罚，而不适用“分别处罚、合并执行”的情形=={.danger}

#### **2. 听证组织机构**  
- 法制部门
- 依法具有独立执法主体资格的公安机关业务部门以及出入境边防检查站依法作出行政处罚决定的，由其非本案调查人员组织听证。

#### **3. 流程步骤**  (告知-申请==5=={.info}-受理==2=={.info}-举办==7、10=={.info}-听证笔录-听证报告书)
##### **(1) 听证告知**  
- 办案民警告知违法嫌疑人  
- 告知当事人有权申请听证，并明确申请期限（==5日==，注意新法修改！原为3日）。  

##### **(2) 申请与受理**  
- 当事人应在告知后==5日内==提出听证申请。  
	- 此**5日**内允许反复：违法嫌疑人放弃听证或者撤回听证要求后，处罚决定作出前，又提出听证要求的，只要在听证申请有效期内，应当允许。
- 法制部门在收到申请后==2日内==决定是否受理：  
  - 符合条件：受理并出具《举行听证通知书》。  
	  - 应当在举行听证==7日==前将《举行听证通知书》送达听证申请人
  - 不符合条件：出具《不予受理听证通知书》（例：案件不属于听证范围）。  

##### **(3) 听证会组织**  
- **时间**：收到听证申请==10日内==举行听证。  
- **参与人员**：  
  - **听证主持人**：由非本案调查人员担任。  
  - **听证员**：协助主持人。  
  - **记录员**：负责听证笔录。  
  - **当事人及其代理人**：办案警察；证人鉴定人和翻译人员；其他有关人员（第三者[+第三者]）。

- **听证形式**：  
  - **公开听证**：原则公开进行（涉及国家秘密、商业秘密、个人隐私除外）。  

- **听证笔录**：听证申请人、证人签名或捺指印；主持人、听证员和记录员签名[+签名]

##### **(4) 听证结果**  
- **听证报告书**：听证主持人根据笔录撰写报告，连同听证笔录一并提交行政机关负责人。  这其中包含处理意见和建议，属于==内部工作文书==，不属于法律文书，当事人==无权查阅=={.important}

##### **(5) 听证时间线**
::: timeline horizontal

- 民警告知
  time=null

  
- 当事人申请听证
  time=5日内 type=success

  收到告知后

- 法制部门决定是否受理
  time=2日内 type=important

  收到申请后

  time=7日内 type=danger

  举行听证前


- 举办听证
  time=10日内 type=warning

  收到申请后
  :::


##### **(6) 其他**  
- **合并听证**：
	- 两个以上违法嫌疑人分别对同一行政案件提出听证要求的，可以合并举行（==可选择=={.info}）
- **部分**违法嫌疑人申请听证
	- 同一行政案件中有两个以上违法嫌疑人，其中部分嫌疑人提出听证申请的，应当在听证举行后一并作出处理决定。
- **中止听证**
	- **3新+1回避**：新证人、新证据，重新鉴定勘验证据，因回避中止
- **终止听证**：  
  - 听证申请人==撤回==听证申请
  - 听证申请人及其代理人==不正当理由拒不出席==或者未经听证主持人许可中途推出听证
  - 人死财散
  - 扰乱听证秩序

```markmap

---
markmap:

# 听证

## 案件范围
- 严重罚：警告、通报批评 → 排除
- 财产罚：罚款、没收违法所得、没收非法财物 → 附加：较大数额价值
- 资格罚：暂扣许可证（排除）、降低资质等级、吊销许可证
- 行为罚：限制经营范围（排除）、责令停产停业、责令关闭、限制从业
- 自由罚：拘留 → 排除

## 听证组织机构
- 公安机关法制部门
  - 如果没有法制部门，由非本案调查人员组织

## 基本原则
- 不得加重：公安机关不得因违法嫌疑人提出听证要求而加重处罚
- 合并听证：多人一案，均要求听证
- 一并听证：多人一案，部分人申请，一并听证审查
- 全面听证：对于大案要，小案据，给合均要审查

## 听证参加人
1. 听证人员：主持人、记录员、听证员
2. 办案的警察
3. 当事人及其代理人、证人、鉴定人、翻译人
4. 第三人依申请参加或者依职权通知参加

## 听证程序
### 1. 告知
- 告知主体：办案部门
- 告知时间：处罚决定作出前
- 告知内容：拟作出处罚的事实、理由和依据，以及听证的权利

### 2. 申请
- 5日内公安机关决定是否举行 → 可反复

### 3. 受理
- 2日内
  - 制作《举行听证通知书》或《不予受理听证通知书》
  - 逾期不通知的，视为受理

### 4. 举行
- 7日前 → 举行听证7日前 → 举行听证通知书 → 听证申请人 → 口头或其他方式 → 其他人
  - 原则：公开听证
  - 例外：三密除外
- 10日内 → 收到听证申请之日起10日内举行
  1. 主持人宣布听证开始
  2. 调查阶段
  3. 辩论阶段
  4. 最后陈述阶段
  5. 核对听证笔录 → 听证申请人 → 证人 → 听证人员
- 制作听证报告书
  1. 制作主体：主持人
  2. 制作内容：听证过程的简要描述 + 自己的处理意见和建议
  3. 制作目的：呈报领导

## 中止听证
1. 通知听证的证人到会：主持人当场决定
2. 调取新的证据：主持人当场决定
3. 需要重新鉴定或检验：县级以上公安机关负责人决定
4. 申请回避：所属公安机关决定

## 终止听证
1. 撤申请
2. 不出席
3. 中途走
4. 人死财绝
5. 刑拘
```
