# 报案、移送、举报、控告的区别（2025 国考考点）

| 类别  | 核心要点                                                    |
| --- | ------------------------------------------------------- |
| 报案  | 机关 / 团体 / 公民（含被害人）向司法机关报告违法犯罪事实 / 嫌疑人，但**被害人不确定嫌疑人**。   |
| 移送  | 公安机关对不属于本单位管辖的案子，先行处理后移交有管辖权的机关的流程。                     |
| 举报  | 发现他人违法违规，**举报人一般不是当事人**（如路人），向相关机关反映。                   |
| 控告  | 机关 / 团体 / 个人向公安 / 司法机关揭露违法犯罪事实 / 嫌疑人，要求惩处，**被害人已知嫌疑人**。 |
