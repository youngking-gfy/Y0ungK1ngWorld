| 行为类型       | 法律   | 行政法规              | 地方性法规                                              | 规章                 |
| ---------- | ---- | ----------------- | -------------------------------------------------- | ------------------ |
| **行政处罚**   | 所有种类 | 可设定除限制人身自由外的处罚    | 可设定警告、罚款、没收、责令停产停业、暂扣 / 吊销许可证（==吊销企业营业执照、限制从业除外==） | 可设定警告、通报批评和一定数额的罚款 |
| **行政许可**   | 所有种类 | 经常性行政许可           | 本地经常性行政许可                                          | 省级规则可设定 1 年内临时性许可  |
| **行政强制措施** | 所有种类 | 可设定除限制人身自由、冻结外的措施 | 可以设定查封、扣押                                          | 不得设定               |
| **行政强制执行** | 所有种类 | 不得设定              | 不得设定                                               | 不得设定               |


::: note


根据 2021 年最新修订的《行政处罚法》，行政处罚的种类包括：

1. **警告、通报批评**（声誉罚）
2. **罚款、没收违法所得、没收非法财物**（财产罚）
3. **暂扣许可证件、降低资质等级、吊销许可证件**（资格罚）
4. **限制开展生产经营活动、责令停产停业、责令关闭、限制从业**（行为罚）
5. **行政拘留**（人身自由罚，仅法律可设定）
6. **法律、行政法规规定的其他行政处罚**

:::
