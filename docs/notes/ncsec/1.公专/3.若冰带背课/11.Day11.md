# 初阶带背 Day11

## **一、法理学**

### **（一）法的本质**

由浅到深表现为国家意志→统治阶级意志→物质制约性

### **（二）法的规范功能**

指引、预测、评价、强制、教育作用

### **（三）法律规则构成**

前提条件 + 行为模式 + 法律后果

### **（四）法律规则的分类**

1. 根据规则的行为模式不同：授权性规则和义务性规则（包括命令性规则和禁止性规则）
2. 根据规则内容的确定性程度不同：确定性规则、委任性规则（指向其他机关）、准用性规则（指向其他规则）
3. 根据行为限定的范围或程度不同：强行性规则、任意性规则

### **（五）交叉位阶冲突处理**

1. 同一机关制定的新的一般规定和旧的特别规定不一致时，由制定机关裁决；
2. 部门规章之间、部门规章和地方政府规章之间对同一事项的规定不一致时，由国务院裁决；
3. 地方性法规和部门规章之间对同一事项作出不同规定的，由国务院提出意见，国务院认为应当适用地方性法规的，应当决定在该地方适用地方性法规；认为应当适用部门规章的，应当提请全国人大常委会裁决。

### **（六）法律部门**

1. 划分标准：以调整对象为主，调整方法为辅。
2. 公法和私法的划分：古罗马法学家乌尔・比安。
3. 当代中国有七个法律部门：宪法及宪法相关法、民商法、行政法、经济法、社会法、刑法、诉讼与非诉讼程序法。

### **（七）法律关系**

1. 基于合法还是违法行为产生的不同：调整性法律关系和保护性法律关系
    - 调整性法律关系：如合同法律关系
    - 保护性法律关系：如刑事法律关系、行政法律关系
2. 基于法律关系主体之间的地位是否平等：平权（横向）法律关系和隶属（纵向）法律关系
    - 平权法律关系：民商事法律关系
    - 隶属法律关系：主要是行政法律关系、刑事法律关系、亲权法律关系。

### **（八）法律关系产生、变更和消灭的条件**

1. 法律规范的立、改、废。
2. 法律事实。包括法律行为和法律事件，
	- 法律事件分为社会事件和自然事件，
		- 社会事件包括战争、出生、死亡；
		- 自然事件火山、地震、泥石流等。

### **（九）法律关系和法律制裁之间的关系**

有法律责任不一定有法律制裁；有法律制裁一定有法律责任。

### **（十）法律解释**

1. 根据解释的主体：
    - 正式解释：立法解释（全人常）、司法解释（最高司法机关）、行政解释（国务院及其主管部门）；
    - 非正式解释：学理解释（专家学者）、任意解释（一般人）
2. 根据解释的尺度：
    - 字面解释：严格按照法条语言的通常含义解释；
    - 限制解释：作出比字面含义窄的解释；
    - 扩充解释：作出比字面含义广的解释。
3. 根据解释的方法：
    - 文义解释：解释的焦点集中在条文语言上。
    - 体系解释：将被解释的法条放在整部法律中乃至整个法律体系中进行解释。
    - 目的解释：解释立法者的意图。
    - 历史解释：依据历史事实或某现象有史以来的情况对正在讨论的法律问题进行解释。
    - 比较解释：根据外国的判例和判例学说对某个法律规定进行解释。
    - 客观目的解释：根据社会共同伦理道德的需要对某个法律规定进行解释。

### **（十一）法与道德**

1. 法律是最低的道德
2. 自然法学派主张 “恶法非法”，实证法学派认为 “恶法亦法”
3. 法律、道德都具有强制性，但强制力不同
4. 法律具有可诉性，道德不具有可诉性。

## **二、宪法**

1. 制宪主体：人民；
2. 制宪机关：第一届全国人大代表大会第一次会议；
3. 修宪主体：全国人民代表大会；
4. 监督宪法实施的机关：全国人大及其常委会；
5. 解释宪法的机关：全国人大常委会
6. 人民行使国家权力的机关：全国人民代表大会和地方各级人民代表大会。
7. 属于国家所有的：城市的土地、矿藏、水流；属于集体所有的：宅基地、自留山、自留地。
8. 国有经济 -- 保障；集体经济 -- 鼓励、指导和帮助；非公经济 -- 鼓励、支持和引导。
9. 劳动和受教育 --- 既是权利也是义务。
10. 除因国家安全或者追查刑事犯罪的需要，由公安机关或者检察机关依照法律规定的程序对通信进行检查外，任何组织或者个人不得以任何理由侵犯公民的通信自由和通信秘密。
11. 物质帮助权：中华人民共和国公民在年老、疾病或者丧失劳动能力的情况下，有从国家和社会获得物质帮助的权利
12. 宪法的修改，由全国人民代表大会常务委员会或者五分之一以上的全国人民代表大会代表提议，并由全国人民代表大会以全体代表的三分之二以上的多数通过。
13. 非正常状态决定权
    - 全国人大：决定战争与和平；
    - 全国人大常委会：决定战争状态的宣布；决定全国总动员或者局部动员；决定全国或者个别省、自治区、直辖市进入紧急状态；
    - 国务院：决定省、自治区、直辖市的范围内部分地区进入紧急状态。
14. 民族自治地方的自治机关：人民代表大会和人民政府。
15. 民族自治地区：自治区、自治州、自治县。
16. 监察委员会依照法律规定独立行使监察权，不受行政机关、社会团体和个人的干涉。监察机关办理职务违法和职务犯罪案件，应当与审判机关、检察机关、执法部门互相配合，互相制约。

## **三、行政处罚法**

### **（一）行政处罚的种类**

1. 声誉罚：警告、通报批评；
2. 财产罚：罚款、没收违法所得、没收非法财物；
3. 资格法：暂扣许可证件、降低资质等级、吊销许可证件；
4. 行为罚：限制开展生产经营活动、责令停产停业、责令关闭、限制从业；
5. 自由罚：行政拘留；
6. 兜底：法律、行政法规规定的其他行政处罚。

### **（二）行政处罚的设定**

1. 限制人身自由的行政处罚，只能由法律设定。（法律：13 种）
2. 行政法规可以设定除限制人身自由以外的行政处罚。（行政法规：12 种）
3. 地方性法规可以设定除限制人身自由、吊销营业执照以外的行政处罚。（地方性法规：11 种）
4. 规章。尚未制定法律、行政法规的，国务院部门规章对违反行政管理秩序的行为，可以设定警告、通报批评或者一定数额罚款的行政处罚，罚款的限额由国务院规定。尚未制定法律、法规的，地方政府规章对违反行政管理秩序的行为，可以设定警告、通报批评或者一定数额罚款的行政处罚。罚款的限额由省、自治区、直辖市人民代表大会常务委员会规定。（规章：3 种）

### **（三）行政处罚权的承接**

1. 审批：省、自治区、直辖市；
2. 下放谁的权力：县级人民政府部门的行政处罚权；
3. 下放给谁：基层管理迫切需要，并且能够有效承接的乡镇政府、街道办事处。

  
::: tip
参考法条：省、自治区、直辖市根据当地实际情况，可以决定将基层管理迫切需要的县级人民政府部门的行政处罚权交由能够有效承接的乡镇人民政府、街道办事处行使，并定期组织评估。决定应当公布。
:::
### **（四）综合执法权**

国务院或者省、自治区、直辖市人民政府可以决定一个行政机关行使有关行政机关的行政处罚权。（但拘留不可以被综合到其他部门）

### **（五）不予行政处罚的情形**

1. 初次违法且危害后果轻微并及时改正的，可以不予行政处罚。
2. 当事人有证据足以证明没有主观过错的，不予行政处罚。
