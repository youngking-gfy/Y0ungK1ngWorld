# **公安机关办理刑事案件程序规定**

### **重点一：立案**

#### **一、应当受理**

1. 应当立即接受，并制作《询问笔录》；（注意：这里的笔录指的是《询问笔录》，行政案件没有要求受理案件的时候必须制作《询问笔录》）
2. 制作《受案登记表》；
3. 制作《受案回执》；
4. 制作《接受证据材料清单》；（注意：行政案件是《接受证据清单》）
5. 进行网上登记；
6. 遇到紧急情况，要及时处置。

| 内容   | 刑事案件             | 行政案件       |
| ---- | ---------------- | ---------- |
| 笔录要求 | 必须制作询问笔录（包括自首人员） | 无强制要求      |
| 文书名称 | 受案登记表            | 立案登记表      |
| 受案回执 | 对非行政单元应当出具受案回执   | 无需回执       |
| 证据   | 制作《接受证据材料清单》     | 制作《接受证据清单》 |
| 法律依据 | 《公安机关办理刑事案件程序规定》 | 《行政处罚法》    |

#### **二、进行审查**

是否符合立案条件。（认为有犯罪事实，需要追究刑事责任，且属于管辖范围，即事实条件 + 法律条件 + 管辖条件）

#### **三、审查结果**

1. 立案：==县级以上公安机关负责人==批准；
2. 不予立案：==县级以上公安机关负责人==批准。

#### **四、救济**

1. **控告人**：`3日`内告知 --`7日`内申请复议 --`30+30`出复议决定 -- 仍然不服，`7日`内申请复核 --`30+30`出复核结果。（`3—7—30+30—7—30+30`）
2. **行政机关**：`3日`内告知 --`3日`申请复议 --`3日`内复议决定。

#### **五、调查核实**

1. 审批：经==办案部门负责人==批准；
2. 措施：柔性措施。

#### **六、检察院对公安机关不立案的监督**

1. 公安机关 `7日`内说理；
2. 公安机关 `15日`内立案。

  

关联法条：《公安机关办理刑事案件程序规定》第一百八十二条：对人民检察院要求说明不立案理由的案件，公安机关应当在收到通知书后七日以内，对不立案的情况、依据和理由作出书面说明，回复人民检察院。公安机关作出立案决定的，应当将立案决定书复印件送达人民检察院。

  

人民检察院通知公安机关立案的，公安机关应当在收到通知书后`十五日`以内立案，并将立案决定书复印件送达人民检察院。

### **重点二：撤案和终止侦查**

#### **一、审批**

==县级以上公安机关负责==人。

#### **二、撤案的法定情形**

（1）没有犯罪事实的；  
（2）情节显著轻微，危害不大，不认为是犯罪的；  
（3）犯罪已过追诉时效期限的；  
（4）经特赦令免除刑罚的；  
（5）犯罪嫌疑人死亡的；  
（6）其他依法不追究刑事责任的。

#### **三、终止侦查的法定情形**

1. 对于经过侦查，发现有犯罪事实需要追究刑事责任，但不是被立案侦查的犯罪嫌疑人实施的；（抓错人）
2. 共同犯罪中，部分犯罪嫌疑人不够刑事处罚的；（共同犯罪中的小坏人）
3. 结果：对有关犯罪嫌疑人终止侦查，并对该案件继续侦查。

#### **四、告知时间**

1. 公安机关作出撤销案件决定后，应当在三日以内告知原犯罪嫌疑人、被害人或者其近亲属、法定代理人以及案件移送机关。
2. 公安机关作出终止侦查决定后，应当在三日以内告知原犯罪嫌疑人。

### **重点三：管辖**

#### **一、外部管辖**

1. 检察院：`14+转`。14 指的是司法工作人员利用职权侵人权。
2. 法院：`5+8+转`。5 指的是：侮辱罪、诽谤罪、暴力干涉婚姻自由罪、虐待罪、侵占罪；8 指的是有证据证明的轻微刑事案件（通知轻重，住伪弃 3）；转指的是公诉转自诉。

#### **二、内部管辖**

1. 地域管辖：犯罪地 + 居住地。
2. 级别管辖：设区的市一级以上公安机关负责重大的危害国家安全犯罪、恐怖活动犯罪、涉外犯罪、经济犯罪、集团犯罪、划区域犯罪的侦查。

#### **三、特殊案件管辖**

1. 网络犯罪：和犯罪行为沾边的地方。
2. 行驶中的交通工具上发生的刑事案件：由交通工具最初停靠地公安机关管辖，必要时，交通工具始发地、途经地、目的地公安机关也可以管辖。
3. 铁路建设工地上发生的刑事案件：由地方公安机关管辖。
4. 在列车上发生的刑事案件（==3-2-1=={.warning}）
    - 犯罪嫌疑人在列车运行途中被抓获的，由前方停靠站所在地的铁路公安机关管辖；必要时，也可以由列车始发站、终点站所在地的铁路公安机关管辖。
    - 在列车运行途经的车站被抓的，可以由该车站所在地的铁路公安机关管辖，也可以由负责该列车乘务的铁路公安机关管辖。
    - 犯罪嫌疑人在列车运行途中未被抓获的，由负责该列车乘务的铁路公安机关管辖；

### **重点四：回避**

#### **一、适用主体**

公安机关负责人、侦查人员、记录人、翻译人员和鉴定人。（行政案件的回避主体没有记录人）

#### **二、决定主体**

1. 侦查人员 -- 由==县级以上公安机关负责人==决定；
2. 县级以上公安机关负责人 -- 由==同级人民检察院检察委员会==决定；
3. 记录人、翻译人、鉴定人 -- 由==县级以上公安机关负责人==决定。

#### **三、批准时间（2—5 日）**

1. 公安机关应当在收到回避申请后`二日`以内作出决定并通知申请人；
2. 情况复杂的，经==县级以上公安机关负责人==批准，可以在收到回避申请后`五日`以内作出决定。

#### **四、救济**

当事人不服 --5 日内提出复议申请 --5 日内作出复议决定。  
（行政案件中的回避，当事人不服，无救济路径）

### **重点五：传唤**

#### **一、传唤的审批**

**办案部门负责人**

#### **二、传唤的方式**

1. 书面传唤：出示传唤证和警察证－到案后，责令犯罪嫌疑人在传唤证上填写到案时间，结束时，应当由其在传唤证上填写传唤结束时间。拒绝填写的，侦查人员应当在传唤证上注明。
2. 口头传唤：现场发现－出示警察证－在讯问笔录中应当注明犯罪嫌疑人到案方式，并由犯罪嫌疑人注明到案时间和传唤结束时间。
3. 注意：对自动投案或群众扭送到公安机关的犯罪嫌疑人，可以依法传唤。

#### **三、传唤时间**

1. 传唤持续时间不得超过`12小时`。
2. 延长传唤至 `24小时`：案件特别重大、复杂，需要采取拘留、逮捕措施的，经办案部门负责人批准。

  

注意：第一、无强制传唤；第二、刑事传唤可以不通知家属。

### **重点六：讯问**

#### **一、讯问地点**

1. 羁押期间：看守所－讯问室；拘留所、强戒所、监狱－执行场所；
2. 非羁押期间：  
    原则上在公安机关办案场所的讯问室  
    特殊情况：现场（情况紧急）、医院和住处（伤病、残疾、怀孕）

#### **二、讯问女性未成年犯罪嫌疑人**

应当有女工作人员在场。

#### **三、可能判无期、死刑或者其他重大犯罪案件**

应当录音录像。

#### **四、顺序**

人身安全检查 -- 信息采集 -- 进行讯问。

#### **五、讯问结束后**

1. 如果核对有误 -- 应当允许其补充或更正，并让其捺指印。
2. 如果核对无误 -- 让其逐页签名且捺指印。

### **重点七：询问证人、被害人的地点**

1. 现场询问－应当出示人民警察证；
2. 出示询问通知书
    - 审批：应当经过办案部门负责人批准；
    - 场合：非现场，非公安局

  

注意：可以书面、电话或当场通知证人、被害人到公安机关提供证言。

### **重点八：人身检查**

#### **一、审批**

无需审批。

  

对比：行政案件中需要县级以上公安机关负责人审批。

#### **二、强制检查的对象和审批**

1. 针对犯罪嫌疑人；
2. 办案部门负责人批准。

  

对比：行政案件中强制检查无需审批。

#### **三、检查妇女的身体**

应当由女工作人员或者医师进行。

  

对比：行政案件由女性工作人员进行。

#### **四、必须有见证人**

（行政案件中也必须有见证人）

#### **五、制作检查笔录**

由参加检查的侦查人员、检查人员、被检查人员和见证人签名。被检查人拒绝签名的，侦查人员应当在笔录中注明。

### **重点九：尸体解剖**

#### **一、批准**

县级以上公安机关负责人批准；

#### **二、通知**

应当通知死者的家属到场；

#### **三、主持**

侦查人员主持；

#### **四、解剖地点**

应当在尸体解剖室进行。确因情况紧急，或者受条件限制，需要在现场附近解剖的，应当采取隔离、遮挡措施。

#### **五、尸体处理**

对已经查明死因，没有继续保存必要的尸体，应当通知家属领回处理；对于无法通知或者通知后家属拒绝领回的，经县级以上公安机关负责人批准，可以及时处理。

### **重点十：侦查实验**

#### **一、批准**

==县级以上公安机关负责人==

#### **二、主持人**

侦查人员

#### **三、地点**

一般在案发地点进行；燃烧、爆炸等危险性实验，应当在其他能够确保安全的地点进行；

#### **四、禁止**

足以造成危险、侮辱人格、有伤风化的行为。

#### **五、制作侦查实验笔录**

由参加实验的人签名。

#### **六、应当全程录音录像。**

### **重点十一：现场勘查**

#### **一、现场勘查的人员构成**

指挥人员（队员、队长、局长）、勘查人员（刑事犯罪现场勘查证）、见证人（如果找不到，可以全程录音录像替代）、法医（如果有尸体的情形）

#### **二、确定见证人**

由现场勘查指挥人员确定。

#### **三、串并案件**

由现场勘查人员确定。

#### **四、现场勘验、检查工作的步骤**

1. 巡视现场，划定勘验、检查范围；（划范围）
2. 按照 “先静后动，先下后上，先重点后一般，先固定后提取” 的原则，根据现场实际情况确定勘验、检查流程；（定流程）
3. 初步勘验、检查现场，固定和记录现场原始状况；
4. 详细勘验、检查现场，发现、固定、记录和提取痕迹、物证；
5. 记录现场勘验、检查情况。

#### **五、现场和尸体是否保留的决定**

现场勘验、检查结束后，由现场勘验、检查指挥员决定是否保留现场。

#### **六、现场的复验、复查**

人民检察院审查案件时认为需要复验、复查的，应当对现场进行复验、复查，并可以通知检察院派员参加。

### **重点十二：搜查**

#### **一、审批**

经==县级以上公安机关负责人==批准，制作搜查证。

#### **二、对象**

与案件有关的场所、物品和人身（体外）

#### **三、执行拘留、逮捕的时候，遇到下列紧急情况之一，不用搜查证也可以进行搜查：（有刀有枪有人有证据）**

1. 可能随身携带凶器的；
2. 可以隐藏爆炸、剧毒等危险物品的；
3. 可能隐匿、毁弃、转移犯罪证据的；
4. 可能隐匿其他犯罪嫌疑人的；
5. 其他突然发生的紧急情况。

#### **四、搜查笔录的制作**

搜查的情况应当制作搜查笔录，由侦查人员和被搜查人或者他的家属，邻居或者其他见证人签名。

#### **错题难题回顾**

::: card title="错题 1" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="单选"/>办理刑事案件现场询问证人的证件出示  
在办理刑事案件过程中，现场询问证人时，应当出示（ ）。(4 分)

  

**选项**：  
A、传唤证  
B、搜查证  
C、人民警察证  
D、询问通知书

  

**答案**：!!C!!

  

::: collapse

  

- **解析**
    - 依据《公安机关办理刑事案件程序规定》第 210 条第 3 款，在现场询问证人、被害人，侦查人员应当出示人民警察证，所以选 C 。  

:::  


::: card title="错题 2" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="单选"/>行政机关移送刑事案件的受案回执与告知期限  
某县市场监督管理局办理案件中认为需追刑责移送公安，公安机关（ ）受案回执；对不符合刑事立案条件的，应在（ ）日内告知移送行政机关。(4 分)

  

**选项**：  
A、应当出具，3  
B、应当出具，5  
C、不应当出具，3  
D、不应当出具，5

  

**答案**：!!C!!

  

::: collapse

  

- **解析**
    - 对于行政机关移送案件，公安机关无需出具受案回执，在移送案件通知书签字即可；经审查不符合立案条件的，应在 3 日内告知移送行政机关，所以选 C 。  
:::  
::: card title="错题 3" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="多选"/>刑事案件现场勘查的法定要求  
某日下午，张某发现家门口价值 3000 元自行车被盗报警，技术民警勘查盗窃现场，应当（ ）。(4 分)

  

**选项**：  
A、拍摄现场照片  
B、绘制现场图  
C、制作笔录  
D、录音录像

  

**答案**：!!ABC!!

  

::: collapse


- **解析**
     - 依据《公安机关办理刑事案件程序规定》第二百一十六条，勘查现场应拍摄照片、绘制现场图、制作笔录，由勘查人和见证人签名；==重大案件勘查==才应当录音录像，本题非重大案件，所以选 ABC 。  
:::  

::: card title="错题 4" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="判断"/>传唤等保障犯罪嫌疑人饮食休息要求  
传唤、拘传、讯问犯罪嫌疑人，应当保证犯罪嫌疑人的饮食和充足的休息时间，并记录在案。(3 分)

  

**选项**：  
A、正确  
B、错误

  

**答案**：!!B!!

  

::: collapse

  

- **解析**
    - 依据《公安机关办理刑事案件程序规定》201 条，是保证饮食和 “必要的” 休息时间，并非 “充足的”，所以该说法错误，选 B 。  
:::  
::: card title="错题 5" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="判断"/>犯罪嫌疑人供述涉重大利益撤案的审批层级  
犯罪嫌疑人自愿如实供述涉嫌犯罪事实，有重大立功或案件涉国家重大利益需撤案的，应层报省级公安，由省级公安商请最高检核准后撤案，且通报同级检察院。(3 分)

  

**选项**：  
A、正确  
B、错误

  

**答案**：!!B!!

  

::: collapse

  

- **解析**
    - 依据《公安机关办理刑事案件程序规定》第一百八十八条，应层报公安部，由公安部商请最高检核准后撤案，并非省级公安，所以该说法错误，选 B 。  
:::  
::: card title="错题 6" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="判断"/>撤销案件或终止侦查时对被逮捕嫌疑人的处理  
公安机关决定撤销案件或对犯罪嫌疑人终止侦查，原犯罪嫌疑人在押的应立即释放发释放证；原被逮捕的，需经原批准逮捕的检察院批准。(3 分)

  

**选项**：  
A、正确  
B、错误

  

**答案**：!!B!!

犯罪嫌疑人在列车运行途中被抓获的，只有前方停靠站所在地铁路公安机关有管辖权。(3 分)

  

**选项**：  
A、正确  
B、错误

  

**答案**：!!B!!

  

::: collapse

  

- **解析**
    - 依据相关规定，犯罪嫌疑人在列车运行途中被抓获的，由前方停靠站所在地铁路公安机关管辖；必要时，也可由列车始发站、终点站所在地铁路公安机关管辖，并非只有前方停靠站所在地有管辖权，所以该说法错误，选 B 。
