# 初阶带背 Day6：公安机关办理刑事案件程序规定

## **重点十三：查封、扣押**

1. **查封审批**：==县级以上公安机关负责人==批准。
2. **查封对象**：不动产和特殊动产，包括涉案的土地、房屋等不动产，以及船舶、航空器、其他不宜移动的大型机器、设备等特定动产。
3. **与行政案件对比**：

| 对比项  | 行政案件                              | 刑事案件        |
| ---- | --------------------------------- | ----------- |
| 批准主体 | 公安机关负责人                           | 县级以上公安机关负责人 |
| 查封对象 | 专门用于无证经营活动的场所、设施和物品               | 不动产和特殊动产    |
| 期限   | 30 日，情况复杂的，经县级以上公安机关负责人批准可延长 30 日 | /           |



4. **扣押审批**：
    - 侦查过程中：办案部门负责人批准。
    - 现场勘验或搜查中：现场指挥人员决定。
    - 价值较高或可能严重影响正常生产经营的：县级以上公安机关负责人批准。
    - 扣押犯罪嫌疑人的邮件、电子邮件、电报：县级以上公安机关负责人批准。
5. **与行政案件扣押对比**：
    - 行政案件扣押由公安机关负责人批准。
    - 行政案件扣押期限是 30+30 日。
6. **解除查封、扣押**：经查明与案件无关的，应当在`3日`内解除，`6个月`内无人认领，按无主财物处理，上缴国库。
7. **特殊物品处理**：在侦查期间，对于易损毁、灭失、腐烂、变质而不宜长期保存，或者难以保管的物品，经==县级以上公安机关主要负责人==批准，可在拍照或者录音录像后委托有关部门变卖、拍卖，价款暂予保存，待诉讼终结后一并处理。

## **重点十四：查询、冻结**

1. **查询审批**：==县级以上公安机关负责人==批准。
2. **冻结审批**：
    - 一般的冻结：县级公安机关负责人批准。
    - 冻结股权、保单权益的：设区的市一级以上公安机关负责人批准。
    - 冻结上市公司股权的：省级以上公安机关负责人批准。
3. **冻结的期限**：
    - 两款两金（存款、汇款、证券交易结算资金、期货保证金）：一般案件 `6个月`；重大复杂案件 `1年`（需经设区的市一级以上公安机关负责人批准）。
    - 权益类（股权、保单权益或者投资权益）：`6个月`。
    - 证券类（债券股票基金份额等证券）：`2年`。
4. **对冻结财产的出售**：
    - 告知：公安机关应告知当事人或其法定代理人、委托代理人有权申请出售。
    - 申请：权利人提出书面申请，公安机关不得自行决定。
    - 审批：县级以上公安机关负责人批准。符合以下情况可批准：
        - 出售不影响国家、被害人、其他权利人利益且不影响诉讼正常进行（债券、股票、基金份额）。
        - 出售不影响国家、被害人、其他权利人利益且不影响诉讼正常进行，且冻结的汇票本票支票的有效期即将届满。
    - 保管：出售或变现所得款项应继续冻结在银行账户中，并及时告知当事人及其近亲属；无对应银行账户的，所得价款由公安机关在银行指定专门账户保管，并及时告知当事人或者其近亲属。
::: warning **与行政案件冻结对比**


行政案件冻结审批是县级以上公安机关负责人审批，期限是 `2个月`，经上一级公安机关负责人批准，可以再延长`1个月`，适用对象是涉恐嫌疑人的财产。

:::
## **重点十五：鉴定**

1. **鉴定主体**：指派或聘请具有鉴定资质的人员。
2. **审批**：经==县级以上公安机关负责人==批准，对内委托对外聘请鉴定人。
3. **与行政案件对比**：行政案件中的对外聘请鉴定人由办案部门负责人批准。
4. **多人鉴定意见处理**：多人参加鉴定的，鉴定人有不同意见的，应当注明。
5. **补充鉴定**：在正确的基础上，经县级以上公安机关负责人批准，适用于 “两新”（对鉴定物证有新的鉴定要求；发现新的有鉴定意义的证物）和 “两漏”（鉴定内容有明显遗漏；鉴定意见不完整导致委托事项无法确定）情况。
::: warning **与行政案件对比**

行政案件没有补充鉴定。

:::
6. **重新鉴定**：在错误的基础上，经==县级以上公安机关负责人==批准，应当另行指派或聘请鉴定人，适用于以下情况：
    - 主体问题：鉴定机构和鉴定人不具备鉴定资质和条件；故意作虚假鉴定或者违反回避规定。
    - 程序问题：鉴定程序违法或者违反相关专业技术要求。
    - 检材问题：检材虚假或者被损坏。
    - 依据问题：鉴定意见依据明显不足。
7. **公安机关鉴定人出庭作证的条件**：
    - 公诉人、当事人或者辩护人、诉讼代理人对鉴定意见有异议。
    - 人民法院通知。
8. **鉴定时间计入办案期限规定**：对犯罪嫌疑人作精神病鉴定的时间不计入办案期限，其他鉴定时间都应当计入办案期限。
::: warning **与行政案件对比**

所有鉴定时间都不计入办案期限

:::
## **重点十六：辨认**

1. **辨认审批**：提解在押嫌疑人出所辨认需经县级以上公安机关主要负责人批准。
2. **主持人**：主持辨认的侦查人员不得少于`二人`。
3. **辨认人**：被害人、证人、犯罪嫌疑人。
4. **辨认对象**：犯罪嫌疑人、与犯罪有关的物品、文件、尸体、场所。
5. **辨认前**：不得在辨认前向辨认人展示辨认对象及其影像资料。
6. **辨认中**：
    - 个别辨认：几名辨认人对同一辨认对象进行辨认时，应当由辨认人个别进行。
    - 混杂辨认：
        - 质上：应当将辨认对象混杂在特征相类似的其他对象中，不得在辨认前向辨认人展示辨认对象及其影像资料，不得给辨认人任何暗示。
        - 量上：人不少于`7人`；物品不少于`6件`；照片不少于`10张`；质上特征要类似。
7. **关联法条**：《公安机关办理刑事案件程序规定》第二百六十条规定，辨认犯罪嫌疑人时，被辨认的人数不得少于`七人`；对犯罪嫌疑人照片进行辨认的，不得少于`十人`的照片。辨认物品时，混杂的同类物品不得少于五件；对物品的照片进行辨认的，不得少于十个物品的照片。对场所、尸体等特定辨认对象进行辨认，或者辨认人能够准确描述物品独有特征的，陪衬物不受数量的限制。
8. **辨认后**：制作辨认笔录，由侦查人员、辨认人、见证人签名。

## **重点十七：技术侦查措施**

1. **审批主体**：==设区的市一级以上公安机关负责人==批准。
2. **适用对象**：犯罪嫌疑人、被告人以及与犯罪活动直接关联的人员。
3. **实施主体**：由设区的市一级以上公安机关负责技术侦查的部门实施。
4. **期限**：3 个月 + 3 个月 +……
5. **适用范围**：国恐黑毒严逃。
6. **在有效期内解除技侦措施的程序规定**：
    - 办案部门应当立即书面通知技侦部门解除。
    - 负责技术侦查的部门认为需要解除技术侦查措施的，报批准机关负责人批准，制作解除技术侦查措施决定书，并及时通知办案部门。
7. **采用技术侦查措施收集材料的使用与管理**：
    - 用途特定：只能用于对犯罪的侦查、起诉和审判。
    - 管理：无关要销毁；涉及三密要保密。
8. **采取技术侦查措施收集的材料在刑事诉讼中作为证据使用规定**：
    - 直接使用。
    - 决定书要附卷。
    - 采取保护措施（人身＋设备＋方法）。

## **重点十八：隐匿身份侦查**

1. **审批**：必要时，==县级以上公安机关负责人==决定。
2. **侦查人员**：侦查人员、公安机关指定的其他人员。
3. **方法底线**：不得进行犯意诱发、危害公共安全、造成重大人身危险。
4. **证据使用**：收集的材料在刑事诉讼中可以作为证据使用。如果可能产生危及人身安全，应当采取不暴露有关人员身份等保护措施。

## **重点十九：控制下交付**

1. **审批**：==县级以上公安机关负责人==。
2. **案件范围**：涉及给付毒品等违禁品或者给付财物的犯罪活动。
3. **证据使用**：收集的材料在刑事诉讼中可以作为证据使用。如果可能产生危及人身安全，应当采取不暴露有关人员身份等保护措施。

## **重点二十：通缉**

1. **通缉的对象**：
    - 应当逮捕而在逃的。
    - 越狱逃跑的犯罪嫌疑人、被告人或罪犯。
2. **通缉令的发布权限和范围**：
    - 县级以上公安机关在自己管辖的范围内，可以直接发布。
    - 超过管辖范围，应当报请有权决定的上级公安机关发布。
3. **通缉令的补发**：通缉令发出后，如果发现新的重要情况可以补发通报。通报必须注明原通缉令的编号和日期。
4. **通缉令的效力和执行**：
    - 及时布置查缉：公安机关接到通缉令后，应当及时布置查缉。
    - 抓获后依法羁押：抓获犯罪嫌疑人后，报经县级以上公安机关负责人批准，凭通缉令或者相关法律手续羁押。
    - 通知发布机关核实，办理交接手续。
5. **悬赏通告**：县级以上公安机关负责人批准，可以发布悬赏通告。悬赏通告应当写明悬赏对象的基本情况和赏金的具体数额。(`可人可物`)
6. **边控措施**：县级以上公安机关负责人审核－层报省级公安机关批准，办理全国范围内的边控措施。

## **重点二十一：拘传**

1. **审批主体**：县级以上公安机关负责人。
2. **拘传地点**：犯罪嫌疑人所在市、县公安机关执法办案场所进行讯问。
3. **适用前提**：
    - 对象：已立案侦查的犯罪嫌疑人、被告人但未被羁押。
    - 方式：
        - 间接拘传：对经传唤无正当理由拒不到案的犯罪嫌疑人。
        - 直接拘传：根据案件情况直接拘传犯罪嫌疑人。
4. **拘传时间**：不得超过`12小时`；案情特别重大、复杂，需要采取拘留、逮捕措施的，传唤、拘传持续的时间不得超过`24小时`。
5. **注意**：拘传必须是书面的；可以不通知家属。

## **重点二十二：取保候审**

1. **审批**：经县级以上公安机关负责人批准。
2. **期限**：在公安机关侦查阶段不得超过`12个月`。
3. **对象（本质是轻）**：
    - 可能判处管制、拘役或者独立适用附加刑的。
    - 可能判处有期徒刑以上刑罚，采取取保候审不致发生社会危险性的。
    - 患有严重疾病、生活不能自理，怀孕或者正在哺乳自己婴儿的妇女，采取取保候审不致发生社会危险性的。
    - 羁押期限届满，案件尚未办结，需要采取取保候审的。
    - 对拘留的犯罪嫌疑人，证据不符合逮捕条件，以及提请逮捕后，人民检察机关不批准逮捕，需要继续侦查的，并且符合取保候审条件的，可以依法取保候审。
4. **保证人的条件**：
    - 与本案无牵连。
    - 有能力履行保证义务。
    - 享有政治权利，人身自由未受到限制。
    - 有固定的住处和收入。
5. **注意**：对未成年人，优先适用保证人保证。
6. **保证人的义务**：监督 + 报告。
7. **保证人的责任**：`1千-2万元`罚款；救济：`3-57-57` [+3-57-57]。
8. **保证金保证**：未成年人起点数额为 `500元`；成年人起点数额为`1000元`。
9. **没收保证金**：`5万元`以上，由设区的市一级以上公安机关负责人批准；救济：`3-57-57` [+3-57-57]。
10. **负责执行的单位**：应当由被取保候审人居住地的派出所执行；==同时交付相关法律文书及相关材料。必要时，办案部门可以协助执行=={.info}。
11. **重新犯罪处理**：在取保候审期间涉嫌重新故意犯罪被立案侦查的，负责执行的公安机关应当暂扣其交纳的保证金，待人民法院判决生效后，根据有关判决作出处理。

## **重点二十三：监视居住**

1. **审批**：经==县级以上公安机关负责人==批准。
2. **期限**：在公安机关侦查阶段不得超过`6个月`。
3. **对象**：
    - 患有严重疾病、生活不能自理的（前提：符合逮捕条件）。
    - 怀孕或者正在哺乳自己婴儿的妇女（前提：符合逮捕条件）。
    - ==系生活不能自理的人的唯一扶养人=={.warning}（前提：符合逮捕条件）。
    - ==因案件的特殊情况或者办理案件的需要，采取监视居住措施更为适宜的=={.warning}（前提：符合逮捕条件）。
    - 羁押期限届满，案件尚未办结，需要采取监视居住措施的（前提：符合逮捕条件）。
    - 对人民检察院决定不批准逮捕的犯罪嫌疑人，需要继续侦查，并且符合监视居住条件的，可以监视居住（前提：不批准逮捕）。
    - 对于符合取保候审条件，但犯罪嫌疑人==不能==提出保证人，也==不交纳==保证金的，可以监视居住（前提：符合取保候审）。
    - 对于取保候审人违反取保候审期间应该遵守的规定，可以监视居住（前提：符合取保候审）。
::: warning
自残自伤加严重不去报候审

:::
4. **被监视居住人义务**：
    - 未经执行机关批准不得离开处所。
    - 未经执行机关批准不得会见或通信。
    - 传讯时及时到案。
    - 不得干扰证人作证。
    - 不得毁灭伪造证据、串供。
    - 护照、身份证件、驾驶证等证件交执行机关保存。
5. **注意**：行政案件中公安机关对于涉恐嫌疑人采取的人身约束措施中，也可将其身份证件予以保存。
6. **指定居所监视居住**：
    - 两种情形：
        - 无固定住处进行指定居所监视居住（无家找家）。
        - 国、恐 + 在住处执行有碍侦查 + 上一级公安机关批准，在指定的居所执行（有家找家）。
    - 通知义务：`24小时`以内通知家属，无法通知的除外。
    - 折抵刑期：被判管制的，一日折抵刑期一日；被判处拘役、有期徒刑的，二日折抵刑期一日。可以折抵行政拘留，二日折抵一日。
7. **执行机关**：公安机关决定监视居住的，由被监视居住人住处或者指定居所所在地的派出所执行，办案部门可以协助执行。==必要时，也可以由办案部门负责执行，派出所或者其他部门协助执行==。

## **重点二十四：拘留**

1. **审批程序**：==县级以上公安机关负责人==批准。
2. **先行拘留情形**：
    - 正在预备犯罪、实行犯罪或者在犯罪后即时被发觉的。
    - 被害人或者在场亲眼看见的人指认他犯罪的。
    - 在身边或者住处发现有犯罪证据的。
    - 犯罪后企图自杀、逃跑或者在逃的。
    - 有毁灭、伪造证据或者串供可能的。
    - 不讲真实姓名、住址，身份不明的。
    - 有流窜作案、多次作案、结伙作案重大嫌疑的。
3. **3 个 24 小时**：
    - 立即送看，至迟不得超过`24小时`（异地执行拘留的情形，无法及时押解回管辖地的，宣布拘留后立即送抓获地看守所，至迟不得超过`二十四小时`。到达管辖地后，应当立即送看守所羁押）。
    - `24小时`内通知家属（国恐 + 有碍侦查、无法通知的情形除外，没有在二十四小时以内通知家属的，应当在拘留通知书中注明原因）。
    - `24小时`内讯问。
4. **期限**：
    - 公安拘留时间：3 天（一般情况）；4-7 天（特殊情况的，可延长 1－4 天）；30 天（流窜作案、多次作案、结伙作案）。
    - 检察院审查批准逮捕的时间：7 天。
5. **身份不明的处理**：对其进行调查，符合逮捕条件的，可以按照其自报的姓名提请批准逮捕。

## **重点二十五：逮捕**

1. **逮捕的种类**：
    - 一般逮捕：证据条件 + 徒刑条件 + 危险性条件。
    - 径行逮捕：证据条件 + 10 年以上有期徒刑；证据条件 + 徒刑条件 + 曾经故意犯罪 / 身份不明。
    - 转化逮捕：严重违反取保候审 / 监视居住的规定转化而来。
2. **决定、批准与执行机关**：决定机关为检、法；批准机关为检察院；执行机关为公安机关。
3. **审批程序**：县级以上公安机关负责人批准，制作提请批准逮捕书，连同案卷材料、证据，一并移送检察院审查批准，犯罪嫌疑人自愿认罪认罚的，应当记录在案，并在提请批准逮捕书中写明有关情况。
4. **不批准逮捕的救济**：5 日内复议（向同级检察院）—7 日内答复 —5 日内复核（向上一级检察院）—15 日内答复（口诀：`5，7`→`5，15`）。
5. **逮捕后三件事**：
    - 立即送看守所羁押。
    - 除了无法通知外，`24小时`以内，通知被逮捕人的家属。
    - `24小时以内`讯问。-`24小时笔录`
6. **逮捕后羁押**：
    - 羁押期限：2+1（上一级检察院）+2（省检批 -- 交集流广）+2（省检批 --10 年以上）+X（最高检报全人常）。
    - 期间重新计算：发现另有重要罪行。
    - 期限的开始计算：查清身份之日起。
7. **逮捕措施的变更**：公安机关释放被逮捕的人或者变更逮捕措施的，应当通知批准逮捕的人民检察院。
8. **羁押必要性审查**：犯罪嫌疑人被逮捕后，人民检察院经审查认为不需要继续羁押，建议予以释放或者变更强制措施的，公安机关应当予以调查核实。认为不需要继续羁押的，应当予以释放或者变更强制措施；认为需要继续羁押的，应当说明理由。公安机关应当在`十日`以内将处理情况通知人民检察院。
9. **申请变更强制措施的规定**：犯罪嫌疑人及其法定代理人、近亲属或者辩护人有权申请变更强制措施。公安机关应当在收到申请后`三日`以内作出决定；不同意变更强制措施的，应当告知申请人，并说明理由。
10. **强制措施变更手续**：
    - 同一阶段内部轻变重，轻的不办解除手续。
    - 换阶段不办解除手续。
    - 取保候审变更为监视居住的，取保候审、监视居住变更为拘留、逮捕的，对原强制措施不再办理解除法律手续。
    - 案件在取保候审、监视居住期间移送审查起诉后，人民检察院决定重新取保候审、监视居住或者变更强制措施的，对原强制措施不再办理解除法律手续。

张三户籍所在地为 A，经常居住地为 B，在 C 地实施犯罪被 C 地公安机关立案，办理监视居住时，负责执行的是（ ）。(3 分)

  

**选项**：  
A、A 地公安机关派出所  
B、B 地公安机关派出所  
C、C 地公安机关派出所  
D、A 地、B 地、C 地派出所都可执行

  

**答案**：!!C!!

  

::: collapse

  

- **解析**
    - 执行监视居住的地址是办案机关所在地派出所，并非犯罪嫌疑人居住地派出所，所以由立案的 C 地公安机关派出所执行，选 C 。
