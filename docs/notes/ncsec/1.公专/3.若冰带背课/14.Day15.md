::: card title="错题 1" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="单选"/>我国根本政治制度判定  
我国宪法规定，（ ）是我国的根本政治制度。(2 分)  

  

**选项**：  
A、社会主义制度  
B、人民民主专政制度  
C、人民代表大会制度  
D、民族区域自治制度

  

**答案**：!!C!!

  

::: collapse

  

- **解析**
    - 人民代表大会制度是我国根本政治制度，选 C 。  
:::
