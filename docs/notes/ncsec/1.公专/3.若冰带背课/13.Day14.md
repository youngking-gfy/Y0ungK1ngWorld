### **错题难题回顾**

:::: card-grid  
::: card title="错题 1" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="单选"/>行政案件中手机处置判定  
张某（高中生）因座位纠纷用家长买的手机砸伤同学脸部，对该手机处置正确的是（ ）。(3.3 分)  

  

**选项**：  
A、扣押后转收缴  
B、扣押后转追缴  
C、扣押后退还张某  
D、扣押后上缴国库

  

**答案**：!!C!!

  

::: collapse

  

- **解析**
    - 手机主要用于查阅资料，非主要用于实施违法行为的工具，不能收缴，应退还，选 C 。  

:::  
::: card title="错题 2" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="单选"/>行政案件送达和期间规定判定  
办理行政案件中，关于送达和期间说法错误的是（ ）。(3.3 分)

  

**选项**：  
A、公告送达期限不得少于 60 日  
B、电子送达必须经受送达人同意  
C、期间以时、日、月、年计算，期间开始之时或者日不计算在内  
D、无法当场送达的，治安管理处罚决定应当在七日内送达

  

**答案**：!!D!!

  

::: collapse

  

- **解析**
    - 无法当场送达的，治安管理处罚决定应在二日内送达，D 错误，选 D 。  
:::  
::: card title="错题 3" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="多选"/>警务督察错误做法判定  
关于警务督察，做法错误的是（ ）。(4.3 分)

  

**选项**：  
A、民警小刘着常服值班站岗换普通领带，督查人员可要求纠正并扣留普通领带作依据  
B、督察机构对本级及下级公安不执行决定、命令的，可责令执行；对错误决定、命令，可决定撤销或变更，报本级公安督察长批准后执行  
C、民警因履职、用权被不实举报，督察机构应立即变更或撤销决定并全市澄清  
D、督察机构发现民警涉嫌犯罪，移交所属机关依法处理

  

**答案**：!!ABCD!!

  

::: collapse

  

- **解析**
    - A 督查人员无权扣留普通领带；B 应报本级公安机关行政首长批准；C 不实举报需经调查核实后处理，非立即变更撤销；D 应移交司法机关，所以 ABCD 均错误，选 ABCD 。
