# 初阶带背 Day8

## **刑法**

### **重点一：空间效力和时间效力**

1. **属地管辖**：我的地盘我做主。
2. **属人管辖**：我的公民我做主。
3. **保护管辖**：我的利益我做主。
4. **普遍管辖**：我是人类我做主。
5. **对外国刑事判决的消极承认**：在外国已经受过刑罚处罚的，可以免除或者减轻处罚。
6. **刑法溯及力**：从旧兼从轻。

### **重点二：犯罪论**

1. **已满十二周岁不满十四周岁的人**，犯故意杀人、故意伤害罪，致人死亡或者以特别残忍手段致人重伤造成严重残疾，情节恶劣，经最高人民检察院核准追诉的，应当负刑事责任。
2. **已满十四周岁不满十六周岁的人**，犯故意杀人、故意伤害致人重伤或者死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质罪的，应当负刑事责任。`8种`
3. **因不满十六周岁不予刑事处罚的**，责令其父母或者其他监护人加以管教；在必要的时候，依法进行==专门矫治教育==。
4. **已满七十五周岁的人故意犯罪的**，可以从轻或者减轻处罚；过失犯罪的，应当从轻或者减轻处罚。
5. **未遂和中止的区分**：核心是能不能。

### **重点三：刑罚论**

1. **管制**：
    - 未经执行机关批准，不得行使言论、出版、集会、结社、游行、示威自由的权利；
    - 对于被判处管制的犯罪分子，在劳动中==应当同工同酬==；
    - 对判处管制的犯罪分子，依法==实行社区矫正==。
2. **拘役**：
    - 在执行期间，被判处拘役的犯罪分子每月可以回家一天至两天；
    - 参加劳动的，可以==酌量发给报酬==。
3. **死刑**：
    - 犯罪时不满`18周岁`的；
    - 审判的时候怀孕的妇女；
    - 审判的时候已满`七十五周岁`的，不适用死刑，但以特别残忍手段致人死亡的除外。
4. **减刑条件与限度**：
    - **对象**：被判处管制、拘役、有期徒刑、无期徒刑的犯罪分子。
    - **限度**：
        - 判处管制、拘役、有期徒刑的，不能少于原判刑期的`二分之一`；
        - 判处无期徒刑的，不能少于`十三年`。
5. **假释**：
    - **适用对象**：有期徒刑和无期徒刑。
    - **适用条件**：被判处有期徒刑的犯罪分子，执行原判刑期`二分之一以上`，被判处无期徒刑的犯罪分子，实际执行`十三年`以上。
    - **考验期限**：有期徒刑的假释考验期限，为没有执行完毕的刑期；无期徒刑的假释考验期限为`十年`。

## **群众工作能力**

### **重点一 ：群众工作能力**

#### **一、社区警务**

1. **社区民警主要职责**：信息收集，人口管理，场所管理，危险物品管理，组织群防群治，为民服务。
2. **巡警**：无办案权。
3. **社区警务中的社会力量**：
    - 公安机关和保安服务公司是领导和被领导的关系；
    - 公安机关和治安联防队、机关和企事业单位保卫组织治安保卫委员会、群众自治组织是指导与被指导关系。

#### **二、群众工作能力的体现**

1. **宣传教育**：公安说群众听。
2. **组织动员**：由公安机关组织的社区中的非警务力量，以防范、协助打击、协助管理为主要任务。
3. **服务群众**：
    - 社区民警每周在社区工作的时间不少于 20 小时；
    - 设立警民联系箱，联系簿，发放警民联系卡，公布联系电话；
    - 帮助联系解决群众求助事宜；
    - 代办户口、公民身份证事宜，对有特殊困难的群众实行上门服务；
    - 参与社会公益活动。
    - **本质**：让群众第一时间找到民警；帮助群众解决实际难题；参加公益活动。
4. **沟通协调**：情商的表现。`方言工作法`

### **重点二：高风险场所管理能力**

#### **一、旅馆业管理**

1. 公安机关与旅馆业的关系是==指导与监督关系==。
2. 旅馆工作人员发现违禁物品和可疑物品，违法犯罪分子，形迹可疑的人员和被公安机关通缉的罪犯==应当及时报告==。
3. 接待境外旅客住宿，还应当在`24小时`内向当地公安机关==报送住宿登记表==。
4. 旅馆对旅客遗留的物品，应当妥为保管，设法归还原主或揭示招领；经招领`3个月`后无人认领的，要登记造册，送当地公安机关按拾遗物品处理。
5. 港澳台居民和外国人未携带证件的处理：由==住宿地公安机关出入境管理部门核实其身份==，并**出具证明**后可以办理住宿登记。

#### **二、高风险活动管理**

1. **游行示威**：
    
    - 主管单位为举行地的县市、区分局，跨区的呈报共同上级公安机关；
    - 必须有负责人，无人限人和身上有事的人不得担任。身上有事指的是被判处刑罚尚未执行完毕的或者正在被依法采取刑事强制措施或者法律规定的其他限制人身自由措施的；
    - 为了保障依法举行的游行的行进，负责维持交通秩序的人民警察可以临时变通执行交通规则的有关规定；
    - 游行在行进中遇有不可预料的情况，不能按照许可的路线行进时，人民警察现场负责人有权改变游行队伍的行进路线；
    - 未申请或者申请未获许可的，未按照主管机关许可的目的、方式、标语、口号、起止时间、地点、路线进行的，在进行中出现危害公共安全或者严重破坏社会秩序情况的，民警应当予以制止，不听制止的，人民警察现场负责人有权命令解散；拒不解散的，人民警察现场负责人有权决定采取必要措施强行驱散，并对拒不服从的人员强行带离现场或者立即予以拘留。
2. **大型群众性活动**：
    
    - 主管机关为==县级以上公安机关==；
    - 大型群众性活动，是指法人或者其他组织面向社会公众举办的每场次预计参加人数达到`1000人以上`的活动；
    - 参加人数为`1000—5000人`，由==县公安局==批，`5000以上`==地级市或直辖市公安局批，跨省公安部批==；
    - 承办者变更大型群众性活动==时间==的，应当在原定举办活动时间之前向做出许可决定的公安机关申请变更，经公安机关同意方可变更；
    - 承办者变更大型群众性活动==地点==、内容以及扩大大型群众性活动举办规模的，应当依照本条例的规定重新申请安全许可；
    - 承办者取消举办大型群众性活动的，应当在原定举办活动时间之前==书面告知=={.danger}做出安全许可决定的公安机关，并==交回==公安机关颁发的准予举办大型群众性活动的安全许可证件。

### **重点三：舆情防控能力**

#### **现场处警人员强化舆情意识**

1. 未经授权，不得接受媒体采访，公开发布有关案（事）件文字、图片、视音频信息，现场处警人员应当以正在执行公务为由婉拒记者、群众的询问；`双向授权`
2. 现场有媒体记者采访或者群众拍摄执法活动的，应当请其在警戒区外采访拍摄；
3. 对设立专门采访区域的，可以告知媒体记者到指定区域；对未设立专门采访区域的，可以告知媒体人员向公安机关新闻宣传部门提出采访申请；
4. 现场媒体记者较多、案（事）件可能引发社会广泛关注或有境外媒体记者的，及时向指挥中心报告；
5. 禁止拍摄：对涉及国家秘密、警务工作秘密、他人隐私、未成年人保护、人员死亡、场面血腥的，应当通过口头、广播、举牌等适当方式明示禁止采访、拍摄，==必要时可以设围挡=={.warning}。

::: card title="错题 1" icon="svg-spinners:blocks-shuffle-3"  
<Badge type="warning" text="单选"/>娱乐场所监督检查合规项目识别  
民警小马负责辖区娱乐场所监督检查，下列检查项目符合规定的是（ ）。(4.5 分)

  

**选项**：  
A、应当配备专业或兼职的保安人员  
B、应当建立营业日志并留存 30 日  
C、应当安装展现室内整体环境的透明门窗  
D、应当留存闭路电视监控录像原始资料 60 日

  

**答案**：!!C!!

  

::: collapse

  

- **解析**
    - 依据娱乐场所管理相关规定：
        - A 错误，应配备专业保安人员；
        - B 错误，营业日志应留存 60 日；
        - D 错误，监控录像原始资料应留存 30 日；
        - C 符合规定，所以选 C 。  
    
:::

**选项**：  
A、间接故意  
B、疏忽大意的过失  
C、过于自信的过失

- **解析**
