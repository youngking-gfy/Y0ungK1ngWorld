## **调查取证核心内容**

- **调查取证**
	- 回避
		- 目的：确保公平
		- 具体手段：申请回避、自行回避、指令回避
	- 五大调查手段
		- 目的：全面及时客观获取有无过错以及过错轻重的证据
		- 具体手段：传唤、询问、勘验检查、鉴定、辨认
	- 两大行政强制措施
		- 目的：预防危险，保全证据
		- 具体手段：人身强制和财产强制
	- 三大办案协作制度
		- 目的：跨地区作案增多，强化协作，抓获违法人，保全证据
		- 具体手段：人到、眼到、心到

## **回避**

### **一、回避的情形**

#### （一）应回避的主体是本案的当事人或者是当事人近亲属的；

近亲属：夫妻、父母、子女、祖父母、外祖父母、子女、孙子女、外孙子女、兄弟姐妹

#### （二）应回避主体本人或者其近亲属与本案有利害关系的；

利害关系：本案的处理会涉及他们的利益，从而可能影响案件的公正处理

#### （三）与本案当事人有其他关系，可能影响案件公正处理的。

其他关系：非近亲属关系。在题目中==必须出现关系特别好或者特别差的描述=={.danger}，才属于回避情形

### **二、回避的方式**


#### **1.自行回避**

（1）主体：公安机关负责人、办案人员、鉴定人员、翻译人员（自然人，不包括单位）；

（2）方式：==口头或者书面==提出回避申请；

（3）应当说理：即应当说明自己属于回避的哪种情形。

#### **2.申请回避**

（1）主体：当事人及其法定代理人的法定权利；

::: warning
==无行为能力人和限制行为人==是由申请回避的权利能力的
:::

（2）方式：==书面或口头==均可。口头申请的，公安机关应当==记录==在案；

（3）应当说理：提出回避申请要==说明理由==；

（4）==2日内==作出决定：公安机关应当在收到申请之日起二日内作出决定并通知申请人，如果成立，作出回避的决定，不成立的，作出驳回申请的决定，对此决定无救济路径。

::: warning

该回避不回避，会导致处罚决定的无效

:::

#### **3.指令回避**

（1）前提：符合回避情形的，但无人申请回避。

（2）主体：有权决定他们回避的公安机关知悉后，应当及时审查，确认具有回避情形之一的，可以指令他们回避。

### **三、回避的审批**

（一）**办案人员**：有所属的公安机关批准。

（二）**公安机关负责人**：由上一级公安机关批准。


（三）**鉴定人员和翻译人员**：由指派或聘请的公安机关决定。


::: tip
1. 派出所民警的回避由谁决定？
	- 有所属公安的派出所
2. 所长回避谁决定
	- 县级公安机关决定

:::

::: note 小测

【判断】 某县公安局治安大队张某在办案过程中自行回避，由治安大队决定

【答案】 !!错误，由某县公安局决定。（只有派出所、交警队、出入境）!!

【判断】 某县公安局派出所聘请的鉴定人员的回避，由派出所所长决定。

【答案】 !!错误，由派出所决定。（机关而不是某人）!!


:::


### **四、回避决定前是否停止工作**

==不停止=={.important}。因为公安办理行政案件具有连续性和紧迫性，如果办案工作不能及时进行，可能会给案件带来不必要的损失。



### **五、回避决定后之前的工作是否有效**

==可能有效，也有可能无效=={.important}

由作出回避决定的公安机关决定根据是否影响案件依法公正处理等情况决定。


### **六、回避决定做出后不得开展的工作**

回避人员不得再进行调查、审核、审批、鉴定、翻译工作。


::: note 小测

【判断】 回避决定作出后，回避的民警可以参与后期的执行工作

【答案】 !!正确。因为回避制度是为了保证案件的公平公正处理，因此不能参与处罚决定做出前的执法活动，但可以参加处罚决定作出后的执行工作。!!


:::

### **七、常见错误**

1. 我国法律未规定单位整体回避；
2. 办案民警不能担任鉴定人、翻译人员。
