# **课程笔记——执行**


### **一、处罚决定执行方式**
1. **主动履行**  
   - 违法行为人自觉在规定期限内到银行缴纳罚款或履行处罚决定。
   - **优点**：省时省力，无需后续强制措施。

2. **强制执行**  
   - 代履行：普通代履行和立即代履行
   - 拍卖[+拍卖]变卖[+变卖]查封扣押的财物
   - 加处罚款

3. **公安机关申请人民法院强制执行**

---

### **二、强制执行前的催告程序**
- **催告前提**：公安机关在依法作出==强制执行决定==或者==申请人民法院强制执行==之前；
	- ==注意=={.danger}：==加处罚款==和==立即实施代履行==之前，不需要催告
- **催告形式**：书面形式——《催告书》
- **催告书内容**：
	- 履行行政处理决定的期限和方式
	- 涉及金钱给付的，应当有明确的金额和给付方式
	- 被处理人依法享有陈述权和申辩权
- **送达**：直接送达
	- 如果拒绝接受或者无法直接直送，通过留置送达、邮寄送达、代为送达、电子送达、最后公告送达兜底
- **听取陈述和申辩**
	- ==注意=={.danger}：对于催告，不可==行政复议==或==行政诉讼==
- **催告期**
	- 公安机关强制执行前催告，时间有办案民警自由裁量。==特殊情况=={.important}下,对有证据证明有转移或隐匿财物迹象的，催告期不满，也可以强制执行。
	- 公安机关申请人民法院强制执行前，公安机关催告被处理人履行义务，送达`10日`内被处理人仍未履行义务的，公安机关可以向人民法院申请强制执行。
- **强制执行决定**
	- 经催告，被处理人无正当理由逾期仍不履行行政处理决定，法律规定公安机关强制执行的，公安机关可以依法执行强制执行决定

### **三、公安机关强制执行的方式**
1. **代履行**  
   - **适用前提**：危害交通安全、造成环境污染或者破坏自然资源 
   - **代履行主体**：==公安机关==、==公安机关委托没有利害关系的第三人==  
   - **费用承担**：按照成本合理确定，由当事人承担
   - **方式**：不得采用暴力、胁迫以及其他方式
   - **规定**：
	   - 代履行前送达决定书
	   - 代履行==三日==前，催告当事人履行，当事人履行的，停止代履行
	   - 代履行时，作出决定的公安机关应当派员当场监督
	   - 代履行完毕，公安机关到场监督人员、代履行人和当事人或者见证人应当在执行文书上签名或者盖章
   - **例外**：可立即实施代履行（无需催告）——情况紧急，需要立即清理道路障碍物等

2. **拍卖、变卖查封/扣押的财物**  
   - **前提**：公安机关已对违法行为人财物采取查封、扣押措施。  
   - **方式**：  
     - **拍卖**：委托拍卖行竞价出售，价高者得。  
     - **变卖**：按市场价直接出售。  
   - **用途**：所得款项用于抵缴罚款。多出部分及时退还被处罚人

3. **加处罚款**  
   - **适用条件**：拍卖、变卖财物后罚款仍不足。  
   - **计算规则**：  
     - 每日按罚款本金的`3%`加处，最多不超过本金。  
     - 例：本金100元，加处上限为99元（共199元）。  
   - **后续处理**：若仍未履行，公安机关需申请法院强制执行。

4. **申请法院强制执行**  
   - **情形**：加处罚款后仍不履行，或无可供执行的财物。  
   - **条件**：
	   - ==6个月==：不复议+不诉讼+不履行
	   - ==3个月==：公安机关催告当事人==10日=={.info}仍不履行+向法院申请强制执行
   - **申请对象**：
	   - 普通财物：基层人民法院
	   - 不动产：不动产所在地法院
   - **强制执行费用**：当事人承担
   - **救济手段**：人民法院不予受理强制执行申请、不予强制执行，公安机关有异议，==15日==内向上一级人民法院申请复议
   - **法院措施**：可划拨银行账户资金、强制执行剩余款项。

### **五、强制执行中止、终结、回转制度**

#### **中止**
- 情形
	- 当事人暂无履行能力
	- 第三人对执行标的[+执行标的]主张权利，确有理由
	- 执行可能对他人或公共利益造成==难以弥补的重大损失==的
- 恢复执行：中止情形消失
- 不再执行（==两无+3年==）：
	- 无明显社会危害
	- 无能力履行
	- 中止执行后满==3年==未恢复履行

#### **执行终结**(==人死财散，后继无人=={.important})
- 公民死亡，无遗产可供执行，有无义务承受人
- 法人或者其他组织终止，无财产可供执行，又无义务承受人
- 执行标的[+执行标的]灭失
- 据以执行的行政处理决定被撤销的
- 其他

#### **执行回转**
- 在==执行中==或者==执行完毕==后
- 据以执行的行政处理决定被撤销、变更，或者执行错误
- **法律后果**
	- 应当恢复原状或者退还财物
	- 不能恢复原状或者退还财物的，依法给予赔偿




 [+拍卖]:
	 价高者得

 [+变卖]:
	 直接以市场价出售

 [+执行标的]:
	 **执行标的**是指在执行程序中，法院为履行生效判决、仲裁裁决或其他有强制执行力的法律文件而针对债务人采取措施的对象
