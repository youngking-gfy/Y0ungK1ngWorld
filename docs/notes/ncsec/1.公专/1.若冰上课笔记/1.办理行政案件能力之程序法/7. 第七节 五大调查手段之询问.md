# 课程笔记：公安机关五大调查手段之询问



## 询问

### **一、询问主体**

   - 必须由**两名以上具有执法资格的民警**共同执行，符合一般程序要求。

### **二、询问对象**

   - **违法嫌疑人（坏人）**：行政案件中使用“询问笔录”，刑事案件中则为“讯问笔录”。 
   - **被侵害人（好人）**：指案件中的受害者，需制作询问笔录。   
   - **证人**：提供案件相关信息的第三方，同样使用询问笔录。

::: warning

在行政案件中不存在讯问。

:::

### **三、询问地点**  

#### **（一）违法嫌疑人**

1. 可以到其==住处==或==单位==。

::: note 住处

是指违法嫌疑人居住的地点，既包括其长期居住的地方，也包括临时居住的地方。

:::

2. 可以将其传唤到其所在市、县内的指定地点。

::: note 指定地点

所谓违法嫌疑人所在县、市内的指定地点：核心是==规避异地传唤==。指定地点可以是公安机关的办案场所，也可以是==居委会、村委会==等地方。

:::


::: warning

不得在现场讯问违法嫌疑人；【避免群众围观或同案犯干扰，除非紧急情况（如嫌疑人生命危险、需立即获取关键证据）】

违法嫌疑人==无权=={.danger}提出询问的地点。

:::

#### **（二）被侵害人和证人**

::: note  
灵活选择地点（如家中、医院、公共场所等），无特殊限制，以方便其配合为原则。
:::

1. 可以在**现场**进行，应当出示人民警察证；
2. 可以到单位、学校、住所、居委会、村委会；
3. 可以到被侵害人、证人**提出的地点**；
4. 必要时，也可以书面、电话或者当场通知起到公安机关提供证言。

::: note 必要时

**必要时**，应当是公安机关在办理重大、复杂行政案件时，为防止出现因到侵害人或者其他证人所在的单位、学校、住所或者其居住地居（村）民委员会进行询问，可能发生==干扰或者泄露案情以及其他不利于保护被侵害人或者其他证人的安全等情况==，才可以通知其到公安机关提供证言。

:::



###  **四、询问时间**  


参考传唤的时间。

   - **传唤后询问**：  
     - 传唤后询问、鉴定、辨认等总时长一般不超过`8小时`。 
     - ==新法=={.danger}：涉案人数众多、违反治安管理行为人身份不明的。询问查证时间不得超过`12小时`
     - 符合条件（如案情复杂）可延长至`24小时`。  
   - **非传唤询问**：  
     - 未使用传唤直接询问时，时间参照传唤标准（8-12-24小时）。  
   - **被侵害人与证人**：无明确时间限制，但需兼顾效率与合法性，参照传唤时间。


### **五、询问笔录**
#### （一）**询问前**（人身安全检查——采集信息——询问笔录）  
##### **1、对违法嫌疑人进行人身安全检查**

（1）目的

主要是考虑到安全（不在于取证），**无需**开具《检查证》，**无需**制作安全检查笔录。

（2）查谁

对==查获==或者==到案==的违法嫌疑人应当进行人身安全检查。

::: tip


此处==查获==或者==到案==隐含着实力控制含义。

对当场盘问、检查的对象进行检查时，适用“人身安全检查的规定”。

:::


::: note 小测

【判断】 对于现场发现的违法嫌疑人员，应当进行人身安全检查。

【答案】 !!错误，“发现”不等于“实力控制”，人身安全检查的前提是已经对违法嫌疑人实施了有效的实力控制。!!


【判断】 人身安全检查的地点只能在公安机关执法办案场所。

【答案】 !!错误，人身安全检查的地点可能在现场、公安机关或者其他地方。!!

:::


（3）查什么

- **对象**：违法嫌疑人的身体及其随身携带的物品
- **扣押**：发现违禁品或者管制器具、武器、易燃易爆等危险品以及与案件有关的需要作为证据的物品，应当立即扣押。

::: warning

不用收缴。（法条原话）

:::

- **登记-保管-退还**：对违法嫌疑人随时携带与案件无关的物品，应当按照有关规定予以登记、保管、退还。


##### **2、采集信息**

进行安全检查后，应当根据办案需要，按照操作规范对**违法嫌疑人员**进行信息采集。对采集的信息应当及时录入信息库进行核查、比对，并按照规定妥善保管。

- **人像**: 拍摄正面免冠照一张，左右侧面照各一张;
- **笔迹**: 由被采集人使用钢笔或者签字笔按要求填写笔迹信息采集卡:
- **指纹**: 采集十指指纹(三面捺印和平面捺印):
- **血样**: 由采样员使用采血针提取血样涂至采样卡上，晾干封存;
- 其他: 身高、体重、外貌特征、口音等其他办案需要的信息。

##### **3、询问特殊群体前的相关准备工作**

（1）未成年人（包括好人、坏人、证人）

- 应当通知其==父母或其他监护人==到场。


::: note 监护人

《民法典》第27条：

【未成年人的监护人】父母是未成年人子女的监护人。
- 未成年人的父母**已经死亡**或者**没有监护能力**的，由下列有监护能力的人按顺序担任监护人：
	- （一）祖父母、外祖父母；
	- （二）兄、姐；
	- （三）其他愿意担任监护人的个人或者组织，但是须经未成年人住所地的居民委员会、村民委员会或者民政部门同意。

:::

- 通知上述人员无法到场，也可以通知其他成年家属，所在学校、单位、居住地基层组织或者未成年人保护组织的代表到场。
- 确实无法通知或者通知后未到场，应当==在询问笔录中注明==。

::: warning

合适成年人未到场，==不影响询问笔录的效力==。

:::


（2）为**聋哑人**和**不通晓当地语言的人**聘请翻译

- **聋哑人**：包括聋人、哑人、聋哑人。
- **费用**：找翻译的费用原则上公安出。
- **翻译**：首先应当从公安机关内部具备翻译能力的人员中确定，如果在公安机关内部找不到合适人选，也可以从当地的语言学校或者其他能够承担翻译任务的人员中聘请。

::: note 小测

【判断】 证人小张是个聋人，公安机关在办案过程中，不需要为其提供翻译人员。

【答案】 !!错误，公安机关应当为小张提供翻译人员，否则该证人证言将会被排除。!!


:::

##### **4、了解背景情况**

讯问前，应当了解被询问人的身份以及其与被侵害人、其他证人、违法嫌疑人之间的关系。



#### （二）**询问中**


##### 1、**应当==个别==进行**

可以全程录音录像，并保持录音、录像资料的完整性。

::: warning

如果询问的时候未个别进行，笔录要排除。

:::

##### 2、**问明个人基本情况**

违法嫌疑人：个人信息+特殊身份（人大代表）+前科情况（仅针对坏人）+**必要时**问明家庭成员的相关情况。

::: warning

刑事案件是==应当==问明家庭成员。

:::

##### 3、**告知权利义务和责任**


- 权利：**申请回避的权利**、陈述权、申辩权、与案件**无关的问题**拒绝回答的权利；
- 义务：如实提供证据、证言；
- 责任：故意作伪证或者隐匿证据应负的法律责任。


##### 4、**询问违法事实**

询问违法嫌疑人时，**应当首先询问其有无违法行为**，让其陈述违法行为的情节和无违法行为的辩解，然后就其陈述不清的地方或者矛盾疑点等进一步追问，搞清楚事情的经过和违法行为的具体情节，包括违法事实、动机、目的、手段，与违法行为有关的时间、地点、涉及的人、物、事等内容。

##### 5、**听取陈述和申辩**

询问时，应当听取违法嫌疑人的陈述和申辩。对违法嫌疑人的陈述和申辩，应当核查，对有关证据，无论是否采信，都应当如实记录、妥善保管，并连同==核查==情况附卷。

::: warning

办案人民警察不得因违法嫌疑人的**申辩**而加重对其的处罚

:::

##### 6、**严禁刑讯逼供**

严禁刑讯逼供。严禁刑讯逼供和以威胁、引诱、欺骗等非法方式进行询问，以非法方式收集的言词证据不得作为处罚的根据

::: warning
 
询问查证期间应当保证违法嫌疑人的饮食和**必要**的休息时间（非==充足==），并在询问笔录中注明。在询问查证的间隙期间，可以将违法嫌疑人送入候问室，并按照候问室的管理规定执行。

:::

::: tip

为嫌疑人提供饮食时，应当提供安全餐具和不含骨、刺等有安全隐患的食品; 不得允许嫌疑人食用自带、亲属提供或者其他来源不明的食物。嫌疑人如厕时，办案民警应当在其往返途中以及如厕时进行监管，防止发生安全事故。

:::


##### 7、**保密**

询问违法嫌疑人时，需要运用证据证实违法嫌疑人违法行为，应当防止泄露调查工作秘密，对涉及的==国家秘密、商业秘密、个人隐私==，应当**保密**，并在笔录中注明。


#### （三）**询问后**

##### 1、**询问过程应当制作《询问笔录》**。


##### 2、**核对：询问笔录应当交给被询问人核对，对没有阅读能力的，应当对其==宣读==**。

##### 3、**核对结果**

- 认为记录有误或者遗漏，应当允许被询问人更正或者补充，并要求其在修改处**捺指印**(==只捺指印，不签名==)。
- 认为无误，应当在询问笔录==逐页签名或捺指印==，并在笔录末页注明：“以上笔录我看过（或已向我宣读过），与我说的相符”。
- 拒绝签名或捺指印，办案人民警察应当在询问笔录中注明。

##### 4、**需要在询问笔录上签名的人**

- 询问的警察和记录的警察、被询问人、翻译人员等。
	- 警察在笔录中的指定位置填写姓名；
	- 翻译人员应当在笔录结尾处==签名==(==不用捺指印=={.warning})

### **五、接受书面材料**

#### （一）自行提供书面材料

违法嫌疑人、被侵害人或者其他证人请求自行提供书面材料的，**应当**准许。

#### （二）要求自行书写

必要时，办案人民警察也可要求违法嫌疑人、被侵害人或者其他证人自行书写。

#### （三）自行书写材料的签字要求

- 手写的，**尾部**签名或捺指印
- 打印的，**逐页**签名或捺指印
- 警察收到后，应当在**首页**注明收到日期，并签名。

## 对象
- 好人、坏人、证人

- 坏人
  - 公安机关、居委会、村委会、住所、单位等

- 人身安全检查
  - 对象：查获或到案的违法嫌疑人

  - 物品

    - 登记、保管、退还：无关的物品

- 根据法律规定采集坏人信息

- 未成年人
  - 父母—其他监护人—成年亲属—相关单位组织推荐的人

- 语言不通—翻译

- 必要时，录音录像
  - 刑事案件：应当录像——可能被判处死刑、无期或者其他重大犯罪案件

- 个人情况—必须问
  - 个人基本信息、人大代表、前科
  - 必要时：家庭成员情况

- 告知权利义务，对于无关的问题有拒绝回答的权利

- 是否有违法行为

- 要核对，没有阅读能力，向其宣读

  - 有误或者有漏—纠正或补充——在修改处捺印

- 翻译人员—应当在笔录尾部签名

## 自行书写
- 形式：自己提要求—应当允许；警察也可要求其自行书写
- 打印版本：逐页签名或捺指印
- 手写版本：在末页签名或捺指印
- 交给警察：在首页签名确认收到
