## **刑事强制措施总图**

- **比例原则**：根据犯罪嫌疑人、被告人的人身危险性高低，选择相应的强制措施。危险性低则适用较轻的措施，危险性高则适用较重的措施。
- **变更原则**：随着人身危险性的变化，可以变更强制措施。如被取保候审人违反规定，可转为监视居住或逮捕；反之，如危险性降低，可从逮捕变更为取保候审或监视居住。

```markmap
- **执行**：拘传，剩下的都找公安机关执行
```

## **一、拘传**

### **（一）目的与参与人员**
- **目的**：为了查明案情，适用于刑事诉讼中，对未被羁押的犯罪嫌疑人、被告人。
- **主持人**：由公安机关、检察院、法院决定并执行（`互相单独对应`）。

### **（二）适用对象与审批**
- **适用对象**：未被羁押的犯罪嫌疑人、被告人。
- **审批**：需经==县级以上公安机关负责人==批准。

### **（三）拘传地点与适用前提**
- **拘传地点**：犯罪嫌疑人所在市、县公安机关执法办案场所。
- **适用前提**：
  - 已立案侦查的犯罪嫌疑人、被告人。
  - 经传唤无正当理由不到案的犯罪嫌疑人。

### **（四）适用程序与期限**
- **适用程序**：
  - 执行人员不得少于`2人`。
  - ==必须出示拘传证=={.danger}，书面形式，无例外。
- **期限**：一般不超过`12小时`，案情重大复杂可延长至`24小时`。

```markmap
# 拘传

  - 无正当理由拒绝公安机关传唤的→间接拘传

## 执行主体
- 公、检、法
- 必须出具拘传证

## 地点
- 犯罪嫌疑人所在市、县公安机关执法办案场所

## 签名
- 由犯罪嫌疑人在拘传证上填写到案时间、结束时间，并签名捺指印

## 时限
- 12小时
- 重大复杂+可能拘留逮捕的，24小时
- 从到案时间开始计算（次时）
- 拘传之间间隔不少于12小时（高检规则）
```
