### **一、适用对象**
- **可以适用的情形**：
  - 可能判处管制、拘役或独立适用附加刑的。
  - 可能判处有期徒刑以上刑罚，采取取保候审不致发生社会危险性的。
  - 患有严重疾病、生活不能自理，怀孕或正在哺乳自己婴儿的妇女，==采取取保候审不致发生社会危险性的==。
  - 羁押期限届满，案件尚未办结，需要采取取保候审的。
  - 对拘留的犯罪嫌疑人，证据不符合逮捕条件或检察院不批准逮捕，需继续侦查的。
- **不得适用的情形**：
  - 累犯。
  - 犯罪集团的主犯。
  - 以自伤、自残方法逃避侦查的犯罪嫌疑人。
  - 严重暴力犯罪以及其他严重犯罪的犯罪嫌疑人。

::: warning 例外适用
1. 患有严重疾病、生活不能自理，怀孕或者正在哺乳自己婴儿的妇女，采取取保候审不致发生社会危险性的
2. 羁押期限届满，案件尚未办结，需要采取取保候审

:::

### **二、审批与期限**
- **依职权**：公、检、法根据案件具体情况，可以直接主动地决定取保候审
- **依申请**：被羁押地犯罪嫌疑人、被告人及其法定代理人、近亲属、辩护人、值班律师有权申请取保候审，公检法收到申请后，`3日`内作出决定。
	- **审批**：由==县级以上公安机关负责人==批准。
	- **期限**：在公安机关侦查阶段最长不得超过`12个月`，其他阶段重新计算，但每个阶段均不得超过`12个月`。

::: tip 
在同一诉讼阶段，多次适用取保候审的，应当连续计算取保候审期限；但是，从一个阶段进入到后一个阶段，应当重新计算取保候审的期限。简言之，同一阶段连续计算，不同阶段重新计算。
:::

### **三、提供保证人保证**`清白+好人+3有`
- **优先保证人保证的情形**
	- 对==未成年人==
	- ==年满75周岁==的人
- **保证人的条件**：
  - 与本案无牵连。
  - 有能力履行保证义务。
  - 享有政治权利，人身自由未受到限制。
  - 有固定的==住处和收入==。
	::: warning
	暂缓行政拘留保证人：
	本地有==常住户口==和==固定住所==
	:::
- **保证人的数量**：
  - `1-2名`。
  - 《取保候审保证书》==签名+捺指印==
- **保证人的义务**：
  - 监督被保证人遵守规定。
  - 发现被保证人可能发生或已经发生违反规定的行为，及时向执行机关报告。
- **保证人违规处理**：
  - 责令重新提出保证人或缴纳保证金。
  - 作出变更强制措施的决定。
- **对保证人违规行为的处罚与救济**：
  - ==县级以上公安机关负责人批准==处以罚款：1000元-2万元。
  - 构成犯罪的，依法追究刑事责任。
  - 救济：对罚款不服可复议复核。`3-57-57`[+3-57-57]

### **四、提供保证金保证**
- **保证金数额**：犯罪嫌疑人保证金起点为1000元，未成年人为500元。
- **保证金交纳**：==一次性==存入公安机关指定账户，以==人民币==交纳。
- **保证金没收**：报==县级以上公安机关负责==人批准，没收`5万`元以上需经==设区的市一级公安机关负责人==批准。
- **保证金退还**：
  - 未违反规定且未重新犯罪的。
  - 具备撤销案件情形的。
  - 制作退还保证金决定书，通知银行如数退还保证金。
- **保证金的救济**
	- 可以复议复核`3-57-57`[+3-57-57]
- **涉嫌重新犯罪保证金的处理**
	- 在取保候审期间重新实施故意犯罪
	- 负责执行的公安机关应当暂扣其交纳保证金
	- 待法院判决生效后，如果是故意犯罪，就没收保证金；如果是过失犯罪或不构成犯罪，退还保证金

::: warning
取保候审保证金由县级以上执行机关统一收取和管理。提供保证金的人应当将保证金存入执行机关制定银行的专门账户。保证金的没收、退还决定，应当由执行机关作出。

:::
### **五、取保候审执行过程中的相关事项**
- **被取保候审人应遵守的义务**：
  - 一般义务：
    ::: tip
	应当制作《被取保候审人义务告知书》，一式三份，一份附卷，一份交给被取保候审人，一份交执行机关
	:::
	  - 未经批准不得离开居住的市、县；
	  - 住址、工作单位和联系方式变动的，`24小时`内向执行机关报告；
	  - 在传讯的时候及时到案；
	  - 不得以任何刑事干扰证人作证；
	  - 不得毁灭、伪造证据或串供。
  - 特殊义务：
	  - 不得进入==与其犯罪活动等相关联==的特定场所；
	  - 不得与==证人、被害人及其近亲属、同案犯以及与案件有关联的其他==特定人员会见或通信；
	  - 不得从事==与其犯罪行为等相关联==的特定活动；
	  - 将==护照等出入境证件、驾驶证件==交执行机关保存。
	::: warning
	- **监视居住**：
		- 出入境证件、==身份证件=={.danger}、驾驶证件交执行机关保存。
	- **暂缓规定**：
	    - 未经决定机关批准不得离开所居住的市、县
	    - 住址、工作单位和联系方式发生变动的，`24小时`内向决定机关报告
	    - 在行政复议和行政诉讼中不得干扰证人作证、伪造证据或串供
	:::

- **执行机关**
	- 公安机关决定取保候审的，应当及时通知被取保候审人居住地的派出所执行；同时交付相关法律文书及相关材料。必要时，办案部门可以协助执行。
	- 人民法院、人民检察院决定取保候审的，负责执行的县级公安机关应当在收到法律文书和有关材料后`24小时`以内，指定被取保候审人居住地派出所核实情况后执行

- **执行取保候审的派出所职责**：
  - 告知被取保候审人必须遵守的规定，以及违反规定或者在取保候审期间重新犯罪应当承担的法律后果。
  - 监督、考察被取保候审人有关规定，及时掌握其==活动、住址、工作单位、联系方式及变动情况==。	
  - 监督保证人履行义务。
  - 被取保候审人违反应当遵守的规定以及保证人未履行保证义务的，应当及时制止、采取紧急措施，同时告知决定机关。
::: warning
执行取保候审的派出所应当定期了解被取保候审人遵守取保候审规定的有关情况，并制作笔录。
:::

- **被取保候审人离开居住地的审批程序**
	- 被取保候审人有正当理由需要离开所居住的市、县的，应当经负责==执行的派出所负责人==批准
	- 人民法院、检察院决定取保候审的，==负责执行的派出所==所在批准被取保候审人离开所居住的市、县前，应当征得==决定==取保候审的机关同意
- **对违规的被取保候审人的处理**
	- 交纳保证金的，根据情节，决定没收部分或全部保证金
	- 情节较轻，不需要变更强制措施，允许再次取保候审的，责令其具结悔过、重新交纳保证金或者提出保证人；或者对其进行治安管理处罚。
	::: tip
	应当制作《\*\*\*公安局责令具结悔过决定书》，由正本、副本、存根三联组成。
	:::
	- 情节较重，不能继续适用取保候审，将其强制措施变更为监视居住或逮捕；对需要予以逮捕的，可以对其先行拘留。
	
### **六、取保候审的解除程序**
- **公安机关决定的取保候审**：办案部门呈请，经==县级以上公安机关负责人==批准，制作解除取保候审决定书，通知书，并及时通知负责执行的机关、被取保候审人、保证人和有关单位。
- **检察院、法院决定的取保候审**：负责执行的公安机关根据决定书及时解除，并通知被取保候审人、保证人和有关单位。
- **不再办理解除手续的情形**：
  - 变更取保候审为监视居住、拘留、逮捕的。
  - 移送审查起诉后继续取保候审或变更保证方式的。
  - 公安机关告知保证人解除保证义务或退还保证金的。

# 取保候审

## 决定机关与执行机关
- **决定机关**：公、检、法
- **执行机关**：公安机关

## 不需要通知家属

## 对象
- **可以取保候审的对象**：
  - 可能判处管制、拘役或独立适用附加刑的
  - 可能判处有期徒刑以上，采取取保候审不致发生社会危险性的
  - 患有严重疾病生活不能自理、怀孕或正在哺乳自己婴儿的妇女，采取取保候审不致发生社会危险性的
  - 羁押期限届满，案件尚未办结，需要继续侦查、审查起诉或审判的
  - 不能逮捕：证据不符合，以及检察院不批捕
- **不能取保候审的对象**：
  - 累犯
  - 犯罪集团的主犯
  - 以自伤、自残办法逃避侦查的犯罪嫌疑人
  - 严重暴力犯罪以及其他严重犯罪

## 程序
- **申请**：
  - 犯罪嫌疑人、被告人及其法定代理人、近亲属和辩护人可以向公安机关、检察院或法院提出申请
  - 公安机关应当在收到申请后的3日内作出决定
- **审批**：
  - 县级以上公安机关负责人批准
- **期限**
  - 无次数限制
  - 在公安机关侦查阶段，不得超过12个月，在此期间不得中断对案件的侦查
  - 同一阶段连续计算，不同阶段重新计算

## 保证
- **保证人**：
  - 人数：1-2人
  - 条件：有固定住处和收入、享有政治权利、与本案无牵连、有能力履行保证义务
  - 责任：监督被保证人遵守规定，及时报告执行机关
  - 处罚：违反规定需承担法律责任，可能被罚款、拘留，构成犯罪的追究刑事责任
- **保证金**：
  - 金额：成年人1000元以上，未成年人500元以上
  - 管理：由县级以上执行机关（公安）统一收取、管理
  - 没收：违反规定，经告知后仍不改正的，没收保证金
  - 退还：遵守规定，取保候审期满后退还

## 遵守规定

- **一般性义务**
	- 未经批准不得离开市、县（擅自离开，逮捕，双批）
	- 住址、单位、联系方式变动，24小时内向执行机关报告
	- 传讯时及时到岸，情节严重或两次传讯不到，逮捕
	- 不得干扰证人作证
	- 不得毁灭、伪造证据或串供
- **特殊义务**
	- 场所
	- 活动
	- 人
	- 交证件（出入境证件、驾驶证）
- **离开居住地**
	- 公安决定：正当理由+执行机关及派出所负责人批准
	- 法检决定：正当理由+法/检同意+执行机关及派出所负责人批准


## 解除
- **撤销取保候审的情形**：
  - 不构成犯罪
  - 撤回起诉
  - 不起诉
  - 取保候审期限届满
  - 变更为监视居住、拘留、逮捕
- **程序**：法定情形出现后，执行机关应当及时解除取保候审，退还保证金，解除保证人义务，并通知被取保候审人

## 执行机关职责
- **执行机关**
	- 被取保候审人的居住地派出所
- **职责**
	- **告知规定**：告知被取保候审人应遵守的规定和违反规定的后果
	- **监督考察**：监督被取保候审人遵守规定，监督保证人履行保证义务
	- **制止违法行为**：发现被取保候审人或保证人违反规定，及时制止并处理
	- **定期了解**：定期了解被取保候审人的生活、工作等情况，并制作笔录
