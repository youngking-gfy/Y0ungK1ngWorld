# 刑事强制措施课程笔记

## **一、监视居住**

### **（一）适用对象**

监视居住适用于符合逮捕条件但具有以下特殊情形的犯罪嫌疑人或被告人：

- 患有严重疾病，生活不能自理。
- 怀孕或者正在哺乳自己婴儿的妇女。
- 系生活不能自理的人的唯一扶养人。
- 因案件的特殊情况或者侦查工作的需要，采取监视居住措施更为适宜。
- 羁押期限届满，案件尚未办结，需要采取监视居住措施。
- 符合取保候审条件，但犯罪嫌疑人不能提出保证人，也不交纳保证金。

### **（二）审批程序**

- **审批主体**：由==县级以上公安机关负责人==批准。
- **期限规定**：公安机关侦查阶段不得超过`6个月`，检察院、法院阶段重新计算，每个阶段均不得超过`6个月`。

### **（三）执行程序**

- **执行部门**：
  - 公安机关决定的监视居住，由被监视居住人住处或指定居所所在地派出所执行，办案部门可协助；必要时，也可以由办案部门负责执行，派出所或者其他部门协助执行
  - 法院、检察院决定的监视居住，负责执行的县级公安机关应当在收到法律文书和有关材料后`24小时`，通知被监视居住人住所。必要时，可以由法、检协助执行。

- **被监视居住人义务**：
  - 未经批准不得离开执行场所。
	  - **公安机关决定**：应当经负责执行的派出所或者办案部门负责人批准
	  - **法、检决定**：负责执行的派出所在批准前，应当征得决定监视居住的机关同意
  - 不得会见他人或通信。
	  - **公安机关决定**：应当经负责执行的派出所或者办案部门负责人批准
	  - **法、检决定**：负责执行的派出所在批准前，应当征得决定监视居住的机关同意
  - 传讯时及时到案。
  - 不得以任何形式干扰证人作证
  - 不得毁灭、伪造证据或者串供。
  - 上交护照等==出入境证件、身份证件、驾驶证件==等证件。
	::: warning
	- **取保候审**：
		- 护照等出入境证件、驾驶证件交执行机关保存。
	:::
- **执行场所**：
  - 住处执行：在犯罪嫌疑人、被告人的住处（办案地的固定住处）。
  - 指定居所执行：
	  - 无固定住处
	  - 涉及国家安全、恐怖活动案件，在住处执行可能有碍侦查[+有碍侦查]的，需经==上级公安机关==批准。

::: warning
- **固定住处**：这里所谓固定住所是指被监视居住人在办案机关所在的市、县内工作、生活的合法住处。
- **通知义务**：指定居所监视居住的，除无法通知[+无法通知]的以外，应当在执行监视居住后二十四小时以内，通知被监视居住人的家属。
- **折抵刑期**：被判处管制的，指监居一日折抵刑期一日；被判处拘役、有期徒刑的，指监居二日折抵刑期一日。指监居二日折抵行政拘留一日。
- **指定居所的条件**：
	- 第一、具备正常的生活、休息条件
	- 第二、便于监视、管理；
	- 第三、保证安全；
	- 第四、不得在羁押场所、专门的办案场所或者办公场所执行
- 指定居所监视居住的，不得要求被监视居住人支付费用
:::


### **（四）监管要求与监控方式**

- **监管要求**：保障人身安全和证据安全。
- **监控方式**：
	- 电子监控
	- 不定期检查
	- 在侦查期间，可以对其通信进行监控。范围包括监控电话、传真、信函、邮件、网络等。

### **（五）违规处理与解除程序**

- **违规处理**：
  - 情节较轻：责令被监视居住人具结悔过或者给予治安管理处罚。
  - 情节严重：可以予以逮捕，需要予以逮捕，可以对其先行拘留。
  - 法、检决定监视居住的，被监视居住人违反应当遵守的规定，负责执行的派出所应当及时通知决定监视居住的机关，

- **解除程序**：
	- 制作解除监视居住决定书。

## **二、拘留**

### **（一）适用对象**

公安机关对现行犯或重大嫌疑分子，符合以下情形之一的，可以先行拘留`口头`：

- 正在预备犯罪、实行犯罪或犯罪后即时被发觉。
- 被害人或在场亲眼看见的人指认其犯罪。
- 在身边或住处发现有犯罪证据。
- 犯罪后企图自杀、逃跑或在逃。
- 有毁灭、伪造证据或串供可能。
- 不讲真实姓名、住址、身份不明。
- 有流窜作案、多次作案、结伙作案重大嫌疑。

::: tip 关联法条

- 《刑事诉讼法》第71条第4款：对违反取保候审规定，需要予以逮捕的，可以对犯罪嫌疑人、被告人==先行拘留==。
- 《刑事诉讼法》第77条第2款：对违反监视居住的犯罪嫌疑人、被告人违反前款规定，情节严重，可以予以逮捕的；需要予以逮捕的，可以对犯罪嫌疑人、被告人==先行拘留==。
- 《高检规则》第142条：对于监察机关移送起诉的已采取留置措施的案件，人民检察院应当在受理案件后，及时对犯罪嫌疑人作出拘留决定，交公安机关执行。执行拘留后，留置措施自动解除。

:::


### **（二）审批程序**

- 拘留犯罪嫌疑人，应当填写呈请拘留报告书，经==县级以上公安机关负责人==批准，制作拘留证。
- **紧急情况**：符合上述先行拘留的情形之一的，经出示人民警察证，可以将犯罪嫌疑人口头传唤至公安机关后立即审查，办理法律手续。

### **（三）执行程序**

- **三个24小时规定**：
  - ==立即送看==：拘留后，应当立即将被拘留人送看守所羁押，至迟不得超过`24小时`。
	  - 异地执行拘留的情形，无法及时押解回管辖地的，宣布拘留后立即送抓获地看守所，至迟不得超过`二十四小时`。到达管辖地后，应当立即送看守所羁押。
  - ==通知家属==：除非无法通知或涉嫌国家安全犯罪、恐怖活动犯罪通知可能有碍侦查的情形意外,应当在拘留后`24小时`内制作拘留通知书，通知被拘留人家属。拘留通知书要写明拘留原因和羁押处所。有碍侦查的情形消失以后，应当立即通知被拘留人的家属。对于没有在`二十四小时`以内通知家属的，应当在拘留通知书中注明原因。
  - ==讯问==：公安机关对被拘留的人，应当在拘留后`24小时`内进行讯问。发现不应当拘留的，应当经==县级以上公安机关负责人==批准，制作释放通知书，看守所凭释放通知书发给被拘留人释放证明书，将其立即释放。

- **特殊情形处理**：
  - 异地拘留：宣布拘留后24小时内押解至抓获地看守所。
  - ==身份不明者：调查身份，但不影响程序推进=={.warning}。

- **羁押期限** `公安拘留时间+检察院审查逮捕的时间`
	- **公安拘留时间**
		- `3天`：一般情况
		- `4-7天`：特殊情况的，可延长`1-4天`
		- `30天`：流窜作案、多次作案、结伙作案
	- **检察院审查批准逮捕的时间**
		- `7天`

- **身份不明**
	- 犯罪人不讲真实姓名、住址，身份不明的，应当对其身份进行调查。对符合逮捕条件的犯罪嫌疑人，也可以按照其自报姓名提请批准逮捕。

- **作为执行机关公安机关**
	- 人民检察院决定拘留犯罪嫌疑人的，由==县级以上公安机关==凭人民检察院送达的决定拘留的法律文书制作==拘留证==（无论公、检、法决定，拘留证==盖公安局的章=={.warning}）并立即执行

### **（五）对被拘留的犯罪嫌疑人的审查处理程序**

对被拘留的犯罪嫌疑人审查后，根据案件情况报经==县级以上公安机关负责人==批准，分别作出以下**处理方式**：
- 批准逮捕：在拘留期限内，依法办理提请批准逮捕手续；
- 直接起诉：应当追究刑事责任，但不需要逮捕的，依法直接向人民检察院移送给审查起诉，或者依法办理取保候审或者监视居住手续后，向人民检察院移送审查起诉；
- 转取保候审或监视居住：拘留期限届满，案件尚未办结，需要继续侦查的，依法办理取保候审或者监视居住手续；
- 撤案：具有撤案情形之一的，释放被拘留人，发给释放证明书；需要行政处理的，依法予以处理或者移送有关部门



[+有碍侦查]:
	1. 可能毁灭、伪造证据，干扰证人作证或者串供的；
	2. 可能引起犯罪嫌疑人自残、自杀或者逃跑的；
	3. 可能引起同案犯逃避、妨碍侦查的；
	4. 犯罪嫌疑人、被告人在住处执行监视居住有人身危险的；
	5. 犯罪嫌疑人、被告人的家属或者所在单位与犯罪有牵连的。


[+无法通知]:
	1. 不讲真实姓名、住址、身份不明的；
	2. 没有家属的；
	3. 提供的家属联系方式无法取得联系的；
	4. 因自然灾害等不可抗力导致无法通知的。
	
	无法通知的情形消失后，应当立即通知被监视居住人的家属，无法通知家属的，应当在监视居住通知书中注明原因。
