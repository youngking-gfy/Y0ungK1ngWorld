## 一、决定、批准与执行机关

| 机关类型 | 具体职责                                                                       |
| ---- | -------------------------------------------------------------------------- |
| 检察院  | 批准机关（审查公安机关提请的逮捕申请）、决定机关（可直接决定逮捕）                                          |
| 人民法院 | 决定机关（对符合条件的案件直接决定逮捕）（==5+8+转==）<br>  ·告诉才处理（5）<br>  ·轻微刑事案件（8）<br>  ·公诉转自诉 |
| 公安机关 | 执行机关（负责执行检察院批准或法院决定的逮捕程序）                                                  |

## 二、适用对象

### （一）一般逮捕

1. **核心条件**：有证据证明==有犯罪事实== + 可能判处==徒刑以上==（有期以上）刑罚 + 采取取保候审尚不足以防止社会危险性。
2. **社会危险性情形**：
    - 可能实施新的犯罪；
    - 有危害国家安全、公共安全或者社会秩序的现实危险；
    - 可能毁灭、伪造证据，干扰证人作证或者串供；
    - 可能对被害人、举报人、控告人实施打击报复；
    - 企图自杀或者逃跑。


::: tip
**“有证据证明有犯罪事实” 的认定**：需同时满足以下 3 点：
- 有证据证明发生了犯罪事实；
- 有证据证明该犯罪事实是犯罪嫌疑人实施的；
- 证明犯罪嫌疑人实施犯罪行为的证据已有查证属实的。
- 注：“犯罪事实” 可是单一犯罪行为事实，也可是数个犯罪行为中任一犯罪行为事实。
:::
### （二）径行逮捕

无需考量取保候审的社会危险性预防效果，直接适用逮捕，具体情形：

1. 有证据证明==有犯罪事实==，可能判处==十年有期徒刑以上==刑罚；
2. 有证据证明==有犯罪事实==，可能判处==徒刑以上==刑罚，且曾经故意犯罪或身份不明。

### （三）转化逮捕

因被取保候审、监视居住的犯罪嫌疑人、被告人违反相关规定，情节严重而转化为逮捕，具体情形如下：

  

| 强制措施类型 | 违反规定转化逮捕的情形                                                                                                                                                                                                                                                        |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 取保候审   | 1. 涉嫌故意实施新的犯罪行为；  <br>2. 有危害国家安全、公共安全或者社会秩序的现实危险；  <br>3. 实施毁灭、伪造证据或干扰证人作证、串供行为，足以影响侦查工作正常进行；  <br>4. 对被害人、举报人、控告人实施打击报复；  <br>5. 企图自杀、逃跑，逃避侦查；  <br>6. 未经批准擅自离开所居住的==市、县==（情节严重或两次以上）；  <br>7. 经传讯无正当理由不到案（情节严重或两次以上）；  <br>8. 违反规定进入特定场所、从事特定活动或与特定人员会见、通信（两次以上） |
| 监视居住   | 1. 涉嫌故意实施新的犯罪行为；  <br>2. 实施毁灭、伪造证据或干扰证人作证、串供行为，足以影响侦查工作正常进行；  <br>3. 对被害人、举报人、控告人实施打击报复；  <br>4. 企图自杀、逃跑，逃避侦查；  <br>5. 未经批准擅自离开执行监视居住的住所（情节严重或两次以上）；  <br>6. 未经批准擅自会见他人或通信（情节严重或两次以上）；  <br>7. 经传讯无正当理由不到案（情节严重或两次以上）                                              |

## 三、审批程序

### （一）提请逮捕

1. 审批权限：经==县级以上公安机关负责==人批准；
2. 材料准备：制作《提请批准逮捕书》，连同案卷材料、证据一并移送==检察院审查批准==；
3. 特殊要求：犯罪嫌疑人自愿认罪认罚的，需记录在案，并在《提请批准逮捕书》中写明相关情况。

### （二）检察院审查批准（审查期限：==7 日==内）

#### 1. 不批准逮捕的处理

| 处理环节            | 具体要求                                                                                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 补充侦查            | 检察院通知补充侦查的，公安机关需按补查提纲补充侦查；补充侦查完毕且符合逮捕条件的，重新提请批准逮捕                                                                                                             |
| 要求说明理由          | 检察院不批准逮捕但未说明理由的，公安机关可要求其说明理由（不批准理由通常包括：==不构成犯罪、依法不应追究刑事责任、不可能判处徒刑以上刑罚、取保候审 / 监视居住更合适、证据不足==）                                                                  |
| 释放被拘留人          | 公安机关收到不批准逮捕决定书后，若犯罪嫌疑人已被拘留，需立即释放并发给《释放证明书》，执行完毕后==3 日==内将执行回执送达检察院                                                                                            |
| 复议与复核(5-7,5-15) | - 复议：收到不批准决定书后 5 日内制作《要求复议意见书》，经县级以上公安机关负责人批准，送交同级检察院；检察院 7 日内作出是否变更的决定  <br>- 复核：收到复议决定书后 5 日内制作《提请复核意见书》，经县级公安机关负责人批准，连同复议决定书提请上一级检察院；上一级检察院 15 日内作出是否变更的决定 |

#### 2. 批准逮捕的执行

1. 签发与执行：==县级以上公安机关负责人==签发《逮捕证》，立即执行，执行完毕后 3 日内将执行回执送达检察院；若未能执行，需将回执送达并说明原因；
2. 执行要求：执行人员不得少于 2 人，必须出示《逮捕证》；
3. 逮捕后 “三件事”：


| 事项   | 责任主体           | 具体要求                                                |
| ---- | -------------- | --------------------------------------------------- |
| 送押羁押 | 执行机关（公安机关）     | 立即将被逮捕人送看守所羁押                                       |
| 通知家属 | 决定机关（检察院 / 法院） | 除无法通知的情况外（==国恐或有碍侦查=={.warning}），逮捕后 24 小时内通知被逮捕人家属 |
| 讯问   | 决定机关（检察院 / 法院） | 逮捕后 24 小时内进行讯问；发现不应当逮捕的，立即释放并发给《释放证明书》              |

::: warning

- 24小时笔录
	- 拘留审查
	- 拘留
	- 逮捕
- 拘留三个24小时
	- 送看
	- 通知家属
	- 讯问


:::

### （三）逮捕后的羁押期限（==2+1+2+2+X==）

| 审批主体    | 羁押期限       | 适用条件                                                                                      |
| ------- | ---------- | ----------------------------------------------------------------------------------------- |
| 同级检察院   | 一般不超过 2 个月 | 无特殊限制，常规案件适用                                                                              |
| 上一级检察院  | 延长 1 个月    | 案情重大复杂、期限届满不能侦查终结                                                                         |
| 省级检察院   | 延长 2 个月    | 1. 交通十分不便的边远地区的重大复杂案件；  <br>2. 重大的犯罪集团案件；  <br>3. 流窜作案的重大复杂案件；  <br>4. 犯罪涉及面广、取证困难的重大复杂案件 |
| 省级检察院   | 再延长 2 个月   | 可能判处十年以上有期徒刑刑罚                                                                            |
| 全国人大常委会 | 延长 X 个月    | 特殊案件，由最高检报请全人常批准延期审理                                                                      |

#### 羁押期限的特殊规定

1. **重新计算**：发现另有重要罪行的，制作《重新计算侦查羁押期限通知书》（“重要罪行” 指与逮捕时罪行不同种的重大犯罪，或同种犯罪中影响罪名认定、量刑档次的重大犯罪）；
2. **开始计算起点**：经县级以上公安机关负责人批准，从查清犯罪嫌疑人身份之日起计算；若犯罪事实清楚、证据确实充分但无法查清身份，按其自报姓名移送检察院审查起诉。

## 四、其他规定

### （一）强制措施不当的纠正程序

1. 公安机关发现对犯罪嫌疑人采取的强制措施不当，需及时撤销或变更；
2. 若犯罪嫌疑人在押，需==及时==释放；
3. 释放被逮捕人或变更逮捕措施的，需==通知==批准逮捕的检察院。

### （二）羁押必要性检察建议的处理

1. 检察院经审查认为被逮捕的犯罪嫌疑人无需继续羁押，建议释放或变更强制措施的，公安机关需调查核实；
2. 核实后认为无需继续羁押的，予以释放或变更强制措施；认为需要继续羁押的，需说明理由；
3. 公安机关需==在 10 日内将处理情况通知==检察院。

### （三）申请变更强制措施

1. 申请人：犯罪嫌疑人的法定代理人、近亲属或辩护人；
2. 公安机关处理要求：收到申请后==3日==内作出决定；不同意变更的，需告知申请人并说明理由。

### （四）强制措施变更的法律手续

1. 取保候审变更为监视居住，或取保候审、监视居住变更为拘留、逮捕的，对原强制措施不再办理解除法律手续；
2. 案件在取保候审、监视居住期间移送审查起诉后，检察院决定重新取保候审、监视居住或变更强制措施的，对原强制措施不再办理解除法律手续。
