## **第一节 审核审批**


::: tip

审核是中间环节，审批是最终环节。

:::

### **一、审核人**

1、办案部门兼职法制员审核；

2、办案部门负责人审核；

3、公安机关法制部门专职法制员审核；

初次从事审核的人员，应当通过国家统一法律职业资格考试取得法律职业资格。


### **二、审批人**

1、==办案部门负责人==审批（如警告、500元以下罚款由派出所所长审批）；

2、==县级以上公安机关负责人==审批；

3、重大、复杂、疑难案件，由公安机关领导集体讨论决定。


### **三、审核审批的内容**

1、违法嫌疑人的基本情况；

2、案件事实是否清楚，证据是否确定充分；

3、案件定性是否准确；

4、审查适用法律、法规和规章是否正确；

5、审查程序是否合法；

6、审查拟作出的处理决定是否适当。


### **四、办案人、审核人和审批人之间的执法过错划分**

> 谁错谁担责

1、办案人对送审材料的真实性、准确性、完整性负责；

2、审核人对审核意见负责；

3、审批人在审核时改变或不采纳办案人、审核人的正确意见造成执法过错的，由审批人承担责任。

4、办案人、审核人、审批人都有故意或者过失造成执法错误的，应当根据各自的执法过错所起的作用，分别承担相应责任。


## **第二节 行政处罚的适用理论梳理**

### **时间的影响**——追究时效


### **一、追究时效的意义**

超过追究时效，国家就不能再给予违法行为人行政处罚。

### **二、追究时效的期限**

（一）违法==治安==管理==行为=={.warning}——==六个月==内；

（二）其他违法==行为=={.warning}——==两年内==；

::: warning

是未发现行为而不是==未发现或抓获行为人==。

:::

（三）涉及人身安全、金融安全且有危害后果——==五年内==；


::: tip

这里的人身安全专指食品药品领域。

:::

（四）起点

1、违法行为发生之日起；

2、违法行为由连续、继续或者持续状态的，从行为终了之日起计算；


::: tip 连续、继续或者持续辨析

- **连续**：==本质上是多个违法行为==。比如1月1号偷东西，1月2号偷东西，1月3号偷东西，1月4号偷东西，有四个盗窃行为；今天吸毒，明天吸毒，后天吸毒，这个就叫连续状态；
- **继续或者持续**：==本质上只有一个行为==。比如非法拘禁只有一个行为，1月1号到1月2号，一个非法拘禁的一个行为。

:::

3、被侵害人在追究时效内向公安机关控告，公安机关应当受理而不受理的，不受追究时效的限制。

### **三、对超过追究时效的案件，公安机关应当如何处理？**

（一）不立案；

（二）立案后，经调查后发现超过追究时效，终止案件调查。但如果有违禁品，应当依法予以收缴；违法行为因超过追究时效，由于没有启动调查程序，违法行为没有查证属实，不应算作前科；

（三）超过追究失效，并不影响有关当事人依法要求追究违法行为人的民事责任。

### **对象影响**

### **一、年龄**

#### （一）**不满14周岁的人有违法行为**

1、不予行政处罚——制作==不予行政处罚决定书==；

2、应当责令其监护人严加管教，并在决定书中载明；

3、对于违法所得和非法财物可以追缴或者收缴，但不得适用没收等行政处罚；

4、违法行为有连续继续状态的，只对已满14周岁之后的违法行为承担责任。

::: tip 生日

对过生日当天的偷东西不予行政处罚，但过了生日以后的第一天偷东西给予处罚。

:::

#### **（二）已满14周岁不满18周岁——应当从轻或减轻处罚。**



### **二、精神状态**

> 实施违法行为时候的精神状态

#### （一）**完全正常**

应当给予处罚。

#### （二）**完全不正常**

1、不予行政处罚——制作不予行政处罚决定书；

2、应当责令其监护人严加看管和治疗，并在不予行政处罚决定书中载明；

3、对精神病人不予处罚，但对他人造成损害的，其监护人应当承担民事责任；有违法所得和非法财物，应当依法予以追缴或者收缴。


#### （三）**半正常**


1、应当予以行政处罚；

2、但可以从轻或减轻处罚。


::: info 补充知识点：精神判断

（一）调查该精神病人是否被人民法院宣告为无民事行为能力人或限制民事行为能力人；

（二）委托具有鉴定资格的人员进行精神疾病鉴定；

（三）医疗记录和其它有关检查结果；

（四）家属、邻居、同事、居民、村民委员会治保主任等的情况说明；

（五）实施违反治安管理行为当时的情况。

注意：鉴定意见只有经过公安民警审查确定，才可以作为认定行为人法律责任的根据。


:::

### **三、盲人和又聋又哑的人违反治安管理，可以从轻、减轻或不予处罚**

（一）**盲人**：==双目失明==的人；**聋哑人**：==又聋又哑==的人；

（二）到底是从轻、减轻或不予处罚？关键看生理缺陷和违反治安管理行为之间的==因果关系==的关联强弱。

（三）为什么是可以？而不是应当？为了防止一些不法分子钻法律空子，公安机关对那些依仗生理缺陷多次实施违反治安管理的盲人或者又聋又哑的人，要依法给予治安管理处罚。

### **情节影响**



### **一、应当从轻、减轻或者不予处罚的情形**


（一）==主动消除或减轻==违法行为危害后果，==并==取得被侵害人谅解的；

（二）受他人==胁迫或诱骗==的；`意思不自由`

（三）有==立功==表现的；

（四）==主动投案==，向公安机关如实陈述自己的违法行为；`自首`

（五）其他。


### **二、应当从重处罚的情形**


（一）有==较严重==后果的；

（二）==教唆、胁迫、诱骗==他人实施违法行为；

（三）对报案人、控告人、举报人、证人等==打击报复=={.warning}的；

（四）==一年内==<Badge type="danger" text="新法" />曾收到治安管理处罚或者==一年内==因同类违法行为（==大类=={.info}）受到==两次以上=={.info}公安行政处罚的；`屡教不改`

::: tip

调解无前科；

不予处罚决定书也不算前科。

:::

（五）刑罚执行完毕三年内，或者缓刑期限，==违反治安管理==的。`屡教不改`

::: tip

一定要违反治安管理，违反道交法不从重。

:::

::: warning 《公安机关执行治安管理处罚法有关问题的解释二》


1、**预备**——应当不予处罚。

2、**中止**——未造成损害，不予处罚，造成损害，应当减轻处罚。

3、**未遂**——应当从轻、减轻或者不予处罚。

:::





### **结果影响**

### **一、罚款**

（一）并科原则

一个人有两个行为，直接相加,钱数直接相加。

（二）一事不再罚原则

::: important 一事不再罚原则

对违法行为人的同一个违法行为，其他行政机关已给予罚款处罚的，==公安机关不得再给予罚款处罚==，但可以==依法给予其他种类==的行政处罚。

违法行为人的同一个违法行为同时违反多个公安法律规范，应当给予罚款处罚的，公安机关应当适用==效力高==的法律规范；相关法律规范效力相同的，应当适用==罚款数额高==的规定。

“罚款数额”,是指法律规范规定的罚款数额，而非实际作出的罚款处罚数额。法律规范规定罚款幅度的，适用==上限数额高==的规定；上限数额相同的，适用==下限数额高==的规定。

:::


### **二、拘留**

#### （一）行政拘留合并执行的，最长不超过==20日==。

#### （二）行政拘留==执行完毕前==，发现违法行为人有其他违法行为，公安机关依法作出行政拘留决定的，与正在执行的行政拘留==合并执行==。

#### （三）作出拘留决定但不执行拘留

::: warning

虽然没有执行但依然是算==前科==，因为已经作出处罚决定书。

:::

::: info 法条

**第二十三条**　违反治安管理行为人有下列情形之一，依照本法应当给予行政拘留处罚的，不执行行政拘留处罚：  
  
（一）已满十四周岁不满十六周岁的；  
  
（二）已满十六周岁不满十八周岁，初次违反治安管理的；  
  
（三）七十周岁以上的；  
  
（四）怀孕或者哺乳自己不满一周岁婴儿的。  
  
**前款第一项、第二项、第三项规定的行为人违反治安管理情节严重、影响恶劣的，或者第一项、第三项规定的行为人在一年以内二次以上违反治安管理的，不受前款规定的限制。**

:::

1、已满**14周岁**不满**16周岁**，；

2、已满**16周岁**不满**18周岁**，初次违法治安管理或者其他公安行政管理的。但是曾被收容教养、被行政拘留依法不执行行政拘留或者曾因实施扰乱公共秩序、妨害公共安全、侵犯人身、财产权利，妨害社会管理的行为被人民法院判决有罪的除外；

3、已满**70周岁**以上的；

4、**孕妇**或者正在哺乳**自己婴儿**的妇女。

**前款第一项、第二项、第三项规定的行为人违反治安管理情节严重、影响恶劣的，或者第一项、第三项规定的行为人在一年以内二次以上违反治安管理的，不受前款规定的限制。**

::: info 收容教养

收容教养制度是对实施了犯罪行为但不满16周岁不予刑事处罚的人，由政府进行收容进行集中教育管理的一种强制性的教育改造行政措施。2020年12月26日，《刑法修正案(十一)》和《预防未成年人犯罪法》通过，两部法律不再使用“收容教养”这一概念，将收容教养修改为专门矫治教育，收容教养制度退出历史舞台。

:::

::: warning

此处**自己婴儿**包括亲生包括收养。收养核心是要看有没有在民政局做登记。

:::

#### （四）折抵行政拘留问题

##### 1、刑事案件转成行政案件，被处以行政拘留的

之前因同一行为被刑事拘留、逮捕、指定居所监视居住的，可以折抵行政拘留

- 刑事拘留和逮捕==一日折抵行政拘留一日==；`全羁押`
- 指定居所监视居住==二日折抵行政拘留一日==。`半羁押`
- 询问查证、继续盘问和采取约束措施的时间==不予折抵==。

被采取上述刑事强制措施限制人身自由的时间超过决定的行政拘留期限的，行政拘留决定不再执行。

##### 2、行政案件转成刑事案件

行政拘留的日期不能折抵==刑事拘留或逮捕或指定居所监视居住==（==用于侦查的时间=={.info}）的时间，只能折抵刑期。


#### （五）处罚决定书的制作

1、**一人有两种以上违法行为，分别决定、合并执行**，可以制作一份决定书，分别写明对每种违法行为的处理内容和合并执行的内容。

2、**一个案件有多个违法行为人的，分别决定**，可以制作一式多份决定书，写明给予每个人的处理决定，分别送达每一个违法行为人。

::: warning

实施行政处罚时，应当责令违法行为人==当场或者现期改正==违法行为。

:::
