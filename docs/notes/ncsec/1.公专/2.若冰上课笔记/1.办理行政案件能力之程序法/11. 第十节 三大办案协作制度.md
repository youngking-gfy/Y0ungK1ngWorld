# **课程笔记：三大办案协作制度**



### **一、三种方式**


（一）**人到**：派员前往异地办理；

（二）**眼到**：通过视频远程合作办理；

（三）**心到**：委托异地办理。


### **二、办案协作的基本要求**

（一）办案部门**无条件**==通知==协作部门：办案部门应当制作==办案协作函件=={.warning}；

（二）协作部门**无条件**==提供帮助==：协作部门接到函件后，应当办理。


### **三、派员前往异地办理（人到）**  

#### （一）**异地执行传唤**

1、办案警察到达协作地。应当携带证件：==警察证+传唤证+办案协作函件==；

2、协作地公安机关应当协助；

::: tip

协作地公安机关只做形式审查，不做实质审查（==不要去判断别人的证据够还是不够=={.info}）

:::


3、地点：违法嫌疑人所在市、县内的指定地点或者到其住处、单位进行询问。

#### （二）**异地办理查扣冻、检查查询**

1、办案警察到达协作地。应当携带证件：==警察证+相关法律文书+办案协作函件==；

2、协作地公安机关应当协助；

3、情况危急下，可将办案协作函件和相关的法律文书通过==传真或者通过执法办案信息系统==发送至协作地公安机关，协作地公安机关应当及时采取措施，办案公安机关应当立即派员前往协作地。

#### （三）**办案地为主，协作地为辅**



### **四、 远程视频询问和处罚前告知（眼到）**  

#### （一）**程序**

1、**协作地公安机关**：警察在询问、处罚前核实被询问、告知人的身份；

2、**办案地公安机关**：应当制作询问笔录、处罚前告知笔录并传输至协作地公安机关；

3、**协作地公安机关**：将笔录交给被询问人、被告知人确认并逐页签名或捺指印后，由协作地公安机关协作人员==签名或盖章==；

4、**协作地公安机关**：将==笔录原件或者电子签名笔录==提供给办案地公安机关；

5、**办案地公安机关**：负责询问、告知的警察应当在首页注明收到日期，并签名或盖章；

6、**办案地公安机关**：负责询==问、告知全程录音==。


#### （二）**办案地为主，协作地为辅**


### **五、 委托异地办理（心到）**  

#### （一）**委托范围**

询问、向有关单位和个人调取电子数据，接受自行书写材料、进行辨认、履行处罚前告知程序、送达法律文书等工作；

#### （二）**委托代为询问、辨认、履行处罚前告知的**

委托代为询问、辨认、履行处罚前告知的，办案地应当列出明确的==询问、辨认、告知提纲==，==提供被辨认对象的照片和陪衬照片==；

#### （三）**委托代为向有关单位和个人调取电子数据的**

委托代为向有关单位和个人调取电子数据的，办案地协作函件和相关法律文书传真或者通过执法办案信息系统发送至协作地公安机关，由==协作地公安机关办案部门审核确认后办理=={.warning}。

#### （四）**协作地为主，办案地为辅**

### **六、依法协作的法律责任承担**

（一）==办案地承担==：依法履行办案协作职责所产生的法律责任，由办案地公安机关承担

（二）==协作地承担==：协作地公安机关在履行办案协作职责中超越委托权、或者因采取违法手段履行协作职责所产生的法律后果。

```markmap
# 办案协作制度

## 一般规定
- 携带证件：警察证+办案协作函件+相关法律文书
- 办案地：无条件通知协作地
- 协作地：无条件帮助办案地
- 责任承担：谁错谁担责

## 人到
- 异地执行传唤：警察证+办案协作函件+传唤证
- 异地办理检查、查询、扣押、冻结：同上
- 遇到紧急情况：文书先到，事先办，人后到

## 眼到
- 业务：远程视频询问、远程视频处罚前告知
- 程序
  1. 协作地：核实被询问人的身份
  2. 办案地：制作笔录+全程录音录像
  3. 办案地：把笔录传送给协作地
  4. 协作地：让被询问人核对笔录并签名
  5. 协作地：协作地警察签名或盖章
  6. 协作地：将笔录传送回办案地
  7. 办案地：办案地警察在首页注明收到日期，并签名或盖章

## 心到
- 业务：办案地全权委托协作地办理相关业务
- 手续：办案地公安机关提供相关法律文书、询问提纲、辨认的照片准备等。
```
