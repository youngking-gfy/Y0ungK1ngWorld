## **课程笔记：调查取证的一般规定**




### **（一）主体**

1. ==两名民警==以上，并表明执法身份
2. ==1警+警务辅助人员+全程录音录像==。
	- 仅限于接报案、立案登记、接受证据、信息采集、调解、送达文书等工作。


::: info

- **基本要求**：必须两名以上民警共同执法，且均需通过初级执法资格考试（2010年起全国推行执法资格等级考试）
- **资格分级**：
    - 基本级（初级）：通过考试才具备执法资格
    - 高级：通过后可获三等功奖励，具备进入法制部门工作资格
- **例外情形**：未通过初级考试的民警执法将导致：
    - 处罚决定无效（依据《行政处罚法》第38条）
    - 相关责任人受处分（依据《行政处罚法》第76条）
:::
### **（二）继续盘问**

#### **1. 对象**

（1）可以继续盘问的对象（一个前提+四种情形之一）：

- **一个前提**
	- 经过当场盘问、检查，仍不能排除或证实违法犯罪嫌疑的。
- **四种情形** 
	- 1.被害人、证人控告或者指认其有**犯罪行为**的；（==犯罪==）
	::: note 小测

	【判断】 被害人指认张三有违法行为的，符合继续盘问的情形。

	【答案】 !!错误，要求被害人指认张三有犯罪行为!!
	:::
	- 2.有正在实施违反治安管理或者犯罪行为嫌疑的；（==行为==）
	- 3.有违反治安管理或者犯罪嫌疑**且**身份不明的；（==身份==）
	::: note 小测

	【判断】 警察在盘查中，发现盘查对象身份不明，因此对其进行继续盘问。

	【答案】 !!错误，继续盘问的其中一种情形是“有违反治安管理或者犯罪嫌疑且身份不明的”，只是身份不明不可以继续盘问，缺乏了“有违反治安管理或者犯罪嫌疑”这一条件。!!
	:::
	- 4.携带的物品可能是违反治安管理或者犯罪的赃物；（==物品==）

（2）不可继续盘问的对象:

- 有违反治安管理或者犯罪嫌疑，但未经当场盘问、检查的；
- 经过当场盘问、检查，已经排除违反治安管理和犯罪嫌疑的；
- 嫌疑违反治安管理行为的法定最高处罚为警告、罚款或者其他==非限制人身自由=={.info}的行政处罚的。

::: tip 不得延长至24小时情形

- 一是，第42条: 擅自进入铁路防护网或者火车来临时在铁路线路上行走坐卧、抢越铁路，影响行车安全的，处警告或者**五百元**以下罚款;
- 二是，第67条: **从事旅馆业经营活动**不按规定登记**住宿人员**姓名、**有效**身份证件种类和号码等信息的，或者**为身份不明、拒绝登记身份信息的人提供住宿服务的**，**对其直接负责的主管人员和其他直接责任人员处五百元以上一千元以下罚款；情节较轻的，处警告或者五百元以下罚款。**;
- 三是，第68条: 房屋出租人将房屋出租给**身份不明、拒绝登记身份信息的人**的，或者不按规定登记承租人姓名、**有效**身份证件种类和号码**等信息**的，处**五**百元以上**一千元以下罚款**;
- 四是，第88条: 违反关于社会生活噪声污染防治的法律**法规**规定，**产生社会生活**噪声，经基层群众性自治组织、业主委员会、物业服务人、有关部门依法劝阻、调解和处理未能制止，继续**干扰他人正常生活**、工作和学习的，处五日以下拘留或者一千元以下罚款；情节严重的，处五日以上十日以下拘留，可以并处一千元以下罚款;
- 五是，第89条: 饲养动物，干扰他人正常生活的，处警告；警告后不改正的，或者放任动物恐吓他人的，处**一千**元以下罚款。

:::

- 从其住处、工作地点抓获以及其他应当依法直接使用传唤或者据传的；（==证实==）
- 已经到公安机关投案自首的；（==证实==）
- 明知其所涉案件已经作为治安案件受理或者已经立为刑事案件的；（==证实==）
- 不属于公安机关管辖的案件或者事件当事人的；
- 患有==精神病、急性传染病或者其他严重疾病==的；
- 其他不符合本规定第八条所列条件的。

#### **2. 地点**

- 派出所
- 出入境边防检查机关询问室

::: danger

==警务室==是不可以的！
:::

#### **3. 期限**

- 第一、==公安派出所负责人=={.important}批准，一般为==12h==；
- 第二、仍无法排除嫌疑，==县级以上公安机关值班负责人=={.important}批准，可延长==24h==；
- 第三、==不讲真实姓名、住址和身份=={.info}的，县级以上公安机关==主管负责人=={.important}（主管治安副局长）批准，可延长==48h==。（不能从一跳到三）

::: tip 

- 县级以上公安机关主管负责人：指的是主管治安的副局长。
- 县级以上公安机关主要负责人：指的是公安局的一把手。

:::

#### **4. 过程**

#### （1）【==四种人四小时，有接有送=={.important}】—— ==1670孕乳人员；2170有接有送=={.warning}
 - 必须在带至公安机关之时起==4小时==内盘问完毕，且==不得送入候问室==。 
	 - 对==怀孕=={.info}或者正在==哺乳=={.info}自己不满一周岁婴儿的妇女；
	 ::: warning
	 这里的婴儿不能是领养的。

	 在公安部的释义与实务指南当中，只有在==作出拘留决定但不执行==中包含亲生&领养，其余==统统特指亲身=={.warning}
	 :::
	- 不满==16周岁=={.info}的未成年人；
	- 已满==70周岁=={.info}的老年人；
- 有接有送
	- 如果在==21点到次日早上7点=={.info}之间释放的，应当通知其家属或者监护人领回，对于身份不明或者没有家属和监护人而无法通知的，应当护送至其住地。

#### （2）【==法定义务而非人文关怀=={.important}】

- 被盘问人的家属为老年人、残疾人、精神病人、不满16周岁的未成年人或者其他没有独立生活能力的人，因公安机关实施继续盘问而使被盘问人的家属无人照顾的，公安机关**应当通知**其亲友予以照顾或者采取其他适当办法妥善安排，并==将安排情况及时告知被盘问人==。

#### （3）【==全过程记录=={.important}】

- 第一、当场盘问、检查笔录：采取第二部动作的才需要制作。
	- 放行就不用；
	- 传唤/拘留+第一步补笔录；（==来源=={.important}）
	- 继续盘问+第一步补笔录；（==来源=={.important}）
- 第二、继续盘问审批表：回到单位后==立即找负责人审批==；
- 第三、继续盘问通知书：批准后填写，**送达**被盘问人，并**立即通知**其家属或单位；

#### （4）【==候问室=={.important}】

- 第一、在继续盘问间隙期间，应当将被盘问人送入**候问室**；
- 第二、未设置候问室的，应当由人民警察在**讯问室、办公室**看管，或者送入就近公安派出所的**候问室**；
- 第三、==禁止=={.danger}将被盘问人送入看守所、拘留所、强制戒毒所或者其他监管场所关押，以及将不同性别的被盘问人送入同一个候问室。

#### （5）结果

- 第一、【**放人**】
	- 已经排除嫌疑的，依法==应当立即释放==；
	- 嫌疑确定但==证据尚不充足==；
- 第二、【**关人**】
	- 证明确有嫌疑的，应当在继续盘问期间内依法变更，办理相关手续。

### **（三）对醉酒人的保护性约束**

#### **1、对象**

违法嫌疑人在醉酒状态中，对本人有危险或者对他人的人身、财产或者公共安全有威胁的。（==违法|醉酒|威胁=={.info}；三个条件同时具备）

::: warning

如果是犯罪|醉酒|威胁，就可以用手铐、脚镣等警械。

:::

#### **2、审批**

公安机关负责人；

#### **3、地点**

带至公安机关采取保护性措施约束之酒醒(专人严加看管)；通知其==家属、亲友或者所属单位=={.info}将其领回看管；==必要时应当送医院醒酒==；


#### **4、期限计算**

确认醉酒人酒醒后，应当立即解除约束，并进行询问，==约束事件不计算在询问查证时间内==。

#### **5、约束措施**

对行为举止失控的醉酒人，可以适用==约束带或者警绳==等进行约束，但是不得适用手铐、脚镣等警械。


### **（四）对恐怖活动嫌疑人实施约束措施**

#### **1、审批**

==县级以上公安机关负责人==批准

::: tip

涉恐涉外都要县级以上

:::

#### **2、约束措施**

公安机关调查恐怖活动嫌疑，经==县级以上公安机关负责人=={.warning}批准，可以根据其危险程度，责令恐怖活动嫌疑人员遵守下列==一项或者多项==约束措施；

- (1)未经公安机关批准不得离开所居住的市、县或者指定的处所；
- (2)不得参加大型群众性活动或者从事特定的活动；
- (3)未经公安机关批准不得乘坐公共交通工具或者进入特定的场所；
- (4)不得与特定的人员会见或者通信；
- (5)定期向公安机关报告活动情况；
- (6)将护照等出入境证件、**身份证件**、驾驶证件交公安机关保存。

::: tip 交身份证情节

- 涉恐人员约束措施
- 监视居住

:::

#### **3、期限**

不得超过==三个月==。

::: note 法条

①《反恐怖主义法》第53条:公安机关调查恐怖活动嫌疑，经县级以上公安机关负责人批准，可以根据其危险程度，责令恐怖活动嫌疑人员遵守下列一项或者多项约束措施:
- (一)未经公安机关批准不得离开所居住的市、县或者指定的处所;
- (二)不得参加大型群众性活动或者从事特定的活动;
- (三)未经公安机关批准不得乘坐公共交通工具或者进入特定的场所;
- (四)不得与特定的人员会见或者通信;
- (五)定期向公安机关报告活动情况;
- (六)将护照等出入境证件、身份证件、驾驶证件交公安机关保存。公安机关可以采取电子监控、不定期检查等力式对其遵守约束措施的情况进行监督。

采取前两款规定的约束措施的期限==不得超过三个月==。对不需要继续采取约束措施的，应当及时解除。

:::

#### **4、手段**

公安机关可以采取==电子监控、不定期检查==等方式对**被约束人遵守约束措施的情况**进行监督。

#### **5、违反约束措施的处罚**

《反恐怖主义法》第八十九条：“恐怖活动嫌疑人员违反公安机关责令其遵守的约束措施的，由公安机关给予警告，并责令改正；拒不改正的，处五日以上十五日以下拘留。”

::: tip
此处公安机关一定是县级以上
:::

#### **6、结果**

解除约束措施或者立为刑事案件侦办。

【拓展】

- 第一、认定主体：国家反恐怖主义工作==领导机构==；有管辖的中级以上人民法院。
- 第二、公告主体：由国家反恐怖主义工作领导机构的==办事机构==予以公告。

::: tip

设区的市以上，都必须要设立相应级别的反恐怖主义工作领导机构。

:::

- 第三、不服的救济：被认定的恐怖活动组织和人员对认定不服的，可以通过国家反恐怖主义领导机构的==办事机构==申请复核。国家反恐怖主义工作领导机构应当及时进行复核，作出维持或者撤销认定的决定。==复核决定为最终决定==。
