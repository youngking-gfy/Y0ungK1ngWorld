# 公安机关办理行政案件程序复盘


### **一、立案与管辖**
1. **立案目的**：确定案件由哪个公安机关管辖。
   - 全国公安机关近2500家，需明确管辖权。
2. **管辖原则**：
   - 根据案件性质、地域、级别等划分管辖权（如属地管辖、指定管辖等）。

---

### **二、回避制度**
1. **核心目的**：确保案件处理的公平公正。
2. **适用情形**：
   - 办案人与案件有利害关系或可能影响公正处理。
3. **程序**：
   - 当事人或其法定代理人可申请回避，由公安机关负责人决定。

---

### **三、调查取证工具**
1. **十大工具**：
   - **五大调查手段**：询问、勘验、检查、鉴定、调取证据。
   - **两大强制措施**：行政拘留、查封/扣押。
   - **三大办案协作制度**：异地办案协助、信息共享、联合行动。

---

### **四、案件处理路径**
1. **调解**：
   - 适用条件：熟人之间轻微治安案件。
   - 作用：促进社会和谐，简化程序。
2. **处罚**：
   - **程序选择**：
     - **简易程序**：当场处罚（事实清楚、证据确凿、情节简单）。
     - **一般程序**：常规流程，包含“快办制度”（对符合条件案件快速处理）。
   - **分流原则**：按案件难易程度选择“快车道（快办）”或“慢车道（一般程序）”。

---

### **五、处罚前告知**
1. **告知类型**：
   - **普通告知**：直接与违法嫌疑人沟通（适用于轻微案件）。
   - **听证告知**：涉及重大财产利益或当事人要求听证时，需中立听证人员参与。
2. **听证会特点**：
   - 三角结构（听证人员中立，类似法官角色）。

---

### **六、审核审批与处罚决定**
1. **审核审批流程**：
   - 审核：中间环节（如办案部门负责人审核）。
   - 审批：最终决定（如公安机关负责人审批）。
2. **处罚决定考量因素**：
   - **时效性**：是否超过追究时效。
   - **对象特殊性**：未成年人、精神病人等。
   - **情节与结果**：从轻/从重情节、数过并罚。
3. **治安管理处罚种类**：
   - 警告、罚款、拘留、收缴、限期出境、驱逐出境（针对外国人）。

---

### **七、处罚决定的执行**
1. **强制执行方式**：
   - **罚款执行**：
     - **主动缴纳**：
       1. 银行缴纳（15日内，罚缴分离原则）。
       2. 当场收缴（金额较小或当事人主动要求）。
       3. 缓缴/分期缴（经济困难且主动申请）。
     - **强制缴纳**：
       1. 催告后拍卖/变卖财产。
       2. 加处罚款（无需催告）。
       3. 申请法院强制执行（催告10日后仍不履行）。
   - **拘留执行**：
     - **本地执行**：在违法行为人所在地执行。
     - **异地执行**：需协调异地公安机关。
     - **暂缓执行**：
       - **条件**：同时满足五个条件（主体、时间、担保、救济、实质条件）。
       - **担保人要求**：需具备本地户籍、稳定收入、无违法犯罪记录等。
       - **担保金**：金额为拘留罚款的20%，符合条件退还，违约则没收。

---

### **八、结案与终止调查**
1. **结案情形**：
   - **调解/和解并履行**：双方达成协议且履行完毕。
   - **作出处罚决定**：已执行或因客观原因未执行。
2. **终止调查情形**：
   - **条件**：
     1. 追究时效已过。
     2. 无违法事实。
     3. 违法嫌疑人已死亡。
   - **程序**：需办案部门审批，出具终止调查决定书。

---

### **九、关键流程图**
1. **案件流程**：
   ```
   立案（管辖）→ 回避 → 调查取证 → 调解/处罚选择 → 程序选择（简易/一般） → 告知 → 审核审批 → 处罚决定 → 执行 → 结案/终止调查
   ```
2. **罚款执行流程**：
   ```
   主动缴纳（银行/当场/缓缴） → 强制缴纳（拍卖/加罚 → 法院强制执行）
   ```
3. **拘留暂缓执行流程**：
   ```
   申请暂缓 → 审查条件 → 确定担保人 → 履行担保义务 → 监督执行
   ```

---

### **十、重点知识点总结**
- **限期出境**：无再入境限制；**遣送出境/驱逐出境**：有明确限制。
- **快办制度**：对符合条件案件简化流程，缩短办案周期。
- **听证告知**：重大案件必经程序，确保程序正义。
- **担保人义务**：监督被暂缓执行人，确保其遵守规定（如不离开指定区域、随传随到）。

---

### **附：常见问题**
1. **限期出境与驱逐出境的区别**：
   - 限期出境：无再入境限制，适用于轻微违法外国人。
   - 驱逐出境：明确禁止再入境，适用于严重违法行为。
2. **暂缓执行拘留的担保条件**：
   - 担保人需无违法犯罪记录、本地固定住所、经济能力等。
3. **罚款加处罚款的计算**：
   - 每日按罚款数额3%加处，总额不超过原罚款。
