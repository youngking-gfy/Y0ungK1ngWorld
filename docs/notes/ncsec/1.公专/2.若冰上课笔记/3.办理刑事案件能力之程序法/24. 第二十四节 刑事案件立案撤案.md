## **第一节 立案**

### **一、案件来源**

（一）**主动发现**：巡逻、盘查中发现，以及在办理行政案件、刑事案件过程中发现的其他的刑事案件。

（二）**被动发现**：110指令、报案、控告、扭送、举报、有关机关移送的刑事案件、上级公安机关交办的刑事案件等。

::: note 保密的问题

 ==《公安机关办理行政案件程序规定》第63条==： 报案人不愿意公开自己的姓名和报案行为的，公安机关应当在受案登记时注明，并为其保密。


 ==《公安机关办理刑事案件程序规定》第173条第二款==： 扭送人、报案人、控告人、举报人如果不愿意公开自己的身份，应当为其保守秘密，并在材料中注明。

:::


**二、应当受理**

#### （一）**应当立即接受，问明情况，并制作询问笔录**。必要时，应当对接受过程录音录像。

::: note

和行政案件的受理阶段对比：多了两个程序，==一个是应当制作《询问笔录》；另一个是填写《受案回执》==。

行政中《询问笔录》可做可不做。

**原因**：因为此时还没有立案，应当制作询问笔录。

:::


::: warning

即使是坏人投案自首，也需要做《询问笔录》。

:::

#### （二）**制作《受案登记表》**

::: warning

行政案件是《立案登记表》。

:::

1、受案登记表一式两份， 一份留存、 一份附卷。无需给当事人。

2、受案登记表是刑事案件来源的重要证明。无论是否符合立案条件，也不论是否属于本单位管辖，都应该填写，妥善保管，留档备查。

#### （三）**制作《受案回执》**

1、**应当制作受案回执**：对扭送、报案、控告、举报的单位和个人；如果无法取得联系或者拒绝接收回执的，应当在回执中注明；

2、**不必制作受案回执**：对于==行政执法机关、其他公安机关以及司法机关==移送的涉嫌犯罪的案件，应当在**移送案件通知书**上签字即可，不必制作受案回执。

#### （四）**制作《接受证据材料清单》**

公安机关对扭送人、报案人、控告人、举报人、投案人提供的有关证据材料等应当登记，制作接受证据材料清单，由扭送人、报案人、控告人、举报人、投案人签名，并妥善保管。==必要时，应当拍照或录音录像==。

::: warning 与行政区分

刑事案件中为《接受证据材料清单》；行政案件中为《接受证据清单》，均为一式三份，一份交提交人、一份交保管人、一份附卷。

:::

#### （五）**进行网上登记**。


### **三、审查**

#### （一）**接报案件后，应当立即进行立案审查**。

1、认为**有犯罪事实**； (==事实条件==)

2、达到**刑事案件立案标准**，需要追究刑事责任；(==法律条件==)

3、符合案件管辖规定，**属于本单位管辖**。(==管辖条件==)

#### （二）**审查期限**

##### 1、**普通刑事案件**

（1）对于犯罪事实清楚的案件，应当==即受即立即办==，不得推诿拖延。

（2）刑事案件立案审查期限原则上不超过==3日==；

（3）涉嫌犯罪线索需要查证的，立案审查期限不超过==7日==；

（4）重大疑难复杂案件，经==县级以上公安机关负责人==批准，立案审查期限可以延长至==30日==；

::: warning

行政==3天==

:::

##### 2、**经济犯罪案件**

公安机关接受涉嫌经济犯罪线索的报案、控告、举报、自动投案后，应当立即进行审查，并在七日以内决定是否立案：重大、疑难、复杂线索，经==县级以上公安机关负责人==批准，立案审查期限可以==延长至三十日==：特别重大、疑难、复杂或者跨区域性的线索，经上一级公安机关负责人批准，立案审查期限可以==再延长三十日==。（30+30）



##### 3、**性侵未成年人刑事案件**

==《关于办理性侵害未成年人刑事案件的意见》第5条=={.info}：公安机关接到未成年人被性侵害的报案、控告、举报，应当及时受理，迅速审查。符合刑事立案条件的，应当立即立案侦查，重大、疑难、复杂案件立案审查期限==原则上不超过七日=={.danger}。具有下列情形之一，公安机关应当在受理后==直接立案侦查==；

（一）精神发育**明显迟滞**的未成年人或者**不满十四周岁**的未成年人怀孕、妊娠终止或者分娩的；

（二）未成年人的生殖器官或者隐私部位遭受==明显非正常损伤==的；

（三）未成年人被==组织、强迫、引诱、容留、介绍卖淫==的；

（四）其他有证据证明性侵害未成年人犯罪发生的。

### **四、结果**

#### （一）**立案** ——《立案决定书》

1、**审批**：==县级以上公安机关负责人==批准。

2、立案决定书有正本和存根两部分组成。正本附卷。


#### （二）**不予立案** ——《不予立案通知书》

1、**审批**：==县级以上公安机关负责人==

2、**制作的文书**：不予立案通知书，一存根，一副本，一正本，副本附卷。

3、**通知的对象**：控告人、移送案件的行政执法机关。

4、**通知的期限**：不予立案通知书在==3日以内==送达。

5、**不立案的救济**：

（1）**控告人**： ==7/30+30——7/30+30==

- **7** —— 控告人对不予立案决定不服的，可以在收到不予立案通知书后==7日内==向作出决定的公安机关==申请复议==；

- **30+30** —— 原决定公安机关应当在收到复议申请后==三十日以内==作出决定，并将决定书送达控告人；案情重大、复杂的，公安机关可以延长复议时限==30日==；

- **7** —— 控告人对不予立案的复议决定不服的，可以在收到复议决定书后==7日内==向上一级公安机关申请复核；

- **30+30** —— 上一级公安机关应当在收到复核申请后==三十日内==作出决定；案情重大、复杂的，公安机关可以延长复核时限==30日==。

（2）**行政机关**：==3—3—3==

- **3** —— 公安机关==3日内==审查出结果；

- **3** —— 行政机关对结果不服==3日内==向原决定机关申请复议；

- **3** —— 作出原决定公安机关==3日内==作出复议决定。

::: info **重点条文：**《程序规定》第180条——对行政执法机关移送案件的接受、审查

1、==3日内=={.warning}审查——公安机关应当自接受案件之日起3日内进行审查；

2、审查结果有四：

（1）**立案**：认为有犯罪事实，需要追究刑事责任，依法决定立案的，应当书面通知移送案件的行政执法机关；

（2）**不予立案**：认为没有犯罪事实，或者犯罪事实显著轻微，不需要追究刑事责任，依法不予立案的，应当说明理由，并将==不予立案通知书==送达移送案件的行政执法机关，相应退回案件材料；

（3）**补充材料**：公安机关认为行政执法机关移送的案件材料不全的，应当在接受案件后==24小时以内=={.warning}通知移送案件的行政执法机关在==三日内补正==，但不得以材料不全为由不接受移送案件。

（4）**不属于职责范围**：公安机关认为行政执法机关移送的案件不属于公安机关职责范围的，应当==书面通知=={.warning}移送案件的行政执法机关向其他主管机关移送案件，并说明理由。

:::


#### （三）**调查核实**

1、**前提**：发现案件事实或线索不明的；

2、**审批**：经==办案部门负责人==批准；

3、**可以采取的措施**：调查核实过程中，公安机关可以依照法律和规定采取询问、查询、勘验、鉴定和调取证据材料等不限制被调查对象人身、财产权利的措施。

4、**不得采取的措施**：不得对被调查对象采取强制措施，不得查封、扣押、冻结被调查对象的财产，不得采取技术侦查措施。

#### （四）**有犯罪事实，但不属于自己管辖，24小时内移送有管辖权的机关**


1、**有管辖权的机关**：既包括其他公安机关，也包括人民检察院、军队保卫部门、国家安全机关、监狱、海警机关等具有刑事侦查职权的机关，以及对公职人员犯罪具有调查权的监察机关。

2、**移送案件的审批**：应当立即报经县级以上公安机关负责人批准，制作移送案件 通知书，在24小时以内移送有管辖权的机关处理，并告知扭送人、报案人、控告人、举报人。

3、**需要紧急采取措施的，应该先紧急处置再移送**。

需要采取紧急措施的情形： 

（1）犯罪嫌疑人正在实施危害行为的；  

（2）犯罪嫌疑人正在逃跑的； 

（3）犯罪嫌疑人已经被抓获或者被发现的；  

（4）有人员伤亡，需要立即采取救治措施的；  

（5）国家、集体或者公民利益正在遭受重大损害的；  

（6）其他应当采取紧急措施的情形。

#### （五）**其他不归公安机关管辖**

对不属于公安机关职责范围的事项，在接报案时能够当场判断的，应当立即口头告知扭送人、报案人、控告人、举报人向其他主管机关报案。



::: info **立案程序差异（刑事 vs 行政案件）**  


| 内容   | 刑事案件             | 行政案件       |
| ---- | ---------------- | ---------- |
| 笔录要求 | 必须制作询问笔录（包括自首人员） | 无强制要求      |
| 文书名称 | 受案登记表            | 立案登记表      |
| 受案回执 | 对非行政单元应当出具受案回执   | 无需回执       |
| 证据   | 制作《接受证据材料清单》     | 制作《接受证据清单》 |
| 法律依据 | 《公安机关办理刑事案件程序规定》 | 《行政处罚法》    |

:::

## **第二节 撤案和终止侦查**




### （一）**撤案的法定情形**——针对案

1、没有犯罪事实的；

2、情节==显==著轻微，危害不大，不认为是犯罪的；

3、犯罪已过追诉==时==效期限的；

4、经==特赦令==免除刑罚的；

5、犯罪嫌疑人==死==亡的；

6、其他依法不追究刑事责任的。


::: important

==无犯罪事实，显时特死=={.warning}

:::

### （二）**终止侦查的法定情形**——针对人

1、虽然有犯罪事实需要追究刑事责任，但==不是被立案侦查的犯罪嫌疑人==实施的；

2、==共同犯罪中，部分犯罪嫌疑人==不够刑事处罚的。

3、**结果**：对有关犯罪嫌疑人终止侦查，并对该案件继续侦查。

### (三) **程序**


1、**呈批**：办案部门应当制作撤销案件或者终止侦查报告书；

2、**批准**：==县级以上公安机关负责人==批准；

3、**告知**：

（1）**撤案案件**——==三日以内告知==原犯罪嫌疑人、被害人或者其近亲属、法定代理人以及案件移送机关；

（2）**终止侦查**——==三日以内告知==原犯罪嫌疑人。

4、**结果**：

（1）**人**：原犯罪嫌疑人在押的，应当立即释放，发给释放证明书：原犯罪嫌疑人被逮捕的，应当通知==原批准逮捕的人民检察院==；对原犯罪嫌疑人采取其他强制措施的，应当立即解除强制措施；需要行政处理的，依法予以处理或者移交有关部门。

（2）**物**：除按照法律和有关规定另行处理的以外，应当在==3日内解除查封、扣押、冻结==，并及时返还或通知当事人。

::: important 拓展

特殊撤销案件：犯罪嫌疑人自愿如实供述涉嫌犯罪的事实，有重大立功或者案件涉及国家重大利益，需要撤销案件的，==应当层报公安部，由公安部商请最高人民检察院核准后撤销案件。报请撤销案件的公安机关应当同时将相关情况通报同级人民检察院==。

:::

# 刑事案件立案流程

## 案件来源
- 主动
- 被动
- 填写《受案登记表》
  - 一式两份：一份留存，一份附卷（无需给当事人）
- 上网登记
  - 涉密、重复、正在办理等不登记

## 受理
- 向控告人、举报人说明诬告应负的法律责任
- 保护扭送人、报案人、举报人、控告人及其近亲属的安全
- 制作《询问笔录》
  - 若要求保密，应在材料中注明
- 制作《受案回执》
  - 无法联系或拒绝接受回执的，应在回执中注明
- 行政机关、其他公安机关及司法机关移送的案件
  - 在移送案件通知书上签字即可
  - 不必制作《受案回执》
- 制作《接受证据材料清单》
  - 行政案件中为《接受证据清单》
- 紧急状态处理

## 立案的条件
- 有犯罪事实（事实条件）
- 需要追究刑事责任（法律条件）
- 归本单位管辖（管辖条件）

## 审查期限
- 原则：3日
- 普通案件
  - 线索需要查证的：不超过7日
  - 重大疑难复杂，经县级以上公安机关负责人批准：延长至30日
- 经济犯罪案件
  - 重大疑难复杂，经县级以上公安机关负责人批准：延长至30日
  - 特别重大疑难复杂，经上一级公安机关负责人批准：再延长30日

## 审查手段
- 询问、查询、勘验、鉴定、调取证据材料
- 办案部门负责人批准（事实条件不明朗）

## 立案决定书
- 审批：县级以上公安机关负责人

## 不予立案的救济途径
- 控告人
  - 制作《不予立案通知书》，并在三日内送达控告人
  - 7日内向原公安机关申请复议
    - 30+30复议决定
  - 7日内向上一级公安机关申请复核
    - 30+30复核决定
  - 找检察院申诉
    - 7日内通知公安机关说理
    - 15日内通知公安机关立案
  - 找法院起诉（公诉转自诉案件）
    - 有证据
    - 人身财产权利受损
    - 公检不管

## 行政机关移送案件的处理
- 书面通知不归公安机关
  - 公安机关3日内告知不立案决定
  - 不予立案书面通知+说理+退卷
  - 行政机关不服，3日内提起复议
    - 3日内审查
    - 复议机关3日内作出决定，书面通知
- 材料不全
  - 24小时内通知其3日内补正
- 不归公安管
  - 书面通知+说理+退卷
  - 审批：县级以上公安机关负责人
  - 时间：24小时内移送（紧急情况先处理后移送）
    - 移送案件通知书
    - 包括立案前和立案后移送
    - 移送内容：法律文书、证据、犯罪嫌疑人、财物及其孳息
- 口头告知
