### **一、适用主体**

公安机关负责人、侦查人员、==记录人=={.warning}、翻译人员和鉴定人。

::: warning

行政案件中的回避没有记录人。

:::

### **二、回避事由**

（一）是本案当事人或者是当事人的==近亲属=={.warning}的；

（二）本人或者他的近亲属和本案有利害关系的；

::: warning

近亲属，是指当事人的夫、妻、父、母、子、女、同胞兄弟姊妹。

:::
  
（三）担任过本案的证人、鉴定人、辩护人、诉讼代理人的；


（四）与本案当事人有其他关系，可能影响公正处理案件的。


### **三、回避种类**

（一）**自行回避**：公安机关负责人和侦查人员+口头或书面+==说明理由==

（二）**申请回避**:当事人及其法定代理人+口头或书面+==说明理由==

::: warning

申请回避的主体：==当事人及其法定代理人、辩护人、诉讼代理人==。

==八岁小孩能申请回避；精神病人能申请回避=={.danger}。

:::

（三）**指令回避**：公安机关负责人、侦查人员应当自行提出回避申请，没有自行提出回避申请的，应当责令其回避。

### **四、决定主体**

（一）侦查人员的回避，由==县级以上公安机关负责人==决定；

（二）县级以上公安机关负责人的回避，由==同级人民检察院检察委员会==决定；

（三）记录人、翻译人、鉴定人的回避，由==县级以上公安机关负责人==决定。

### **五、程序**

（一）**申请**：当事人及其法定代理人对侦查人员提出回避申请的；

（二）**答复**：==2日/5日==。公安机关应当在收到回避申请后==二日以内==作出决定并通知申请人；情况复杂的，经县级以上公安机关负责人批准，可以在收到回避申请后==五日以内==作出决定。

::: tip 行政中

==2日内==作出决定：公安机关应当在收到申请之日起二日内作出决定并通知申请人，如果成立，作出回避的决定，不成立的，作出驳回申请的决定，对此决定无救济路径。

:::

（三）当事人及其法定代理人对县级以上公安机关负责人提出回避申请的，公安机关应当及时将申请移送同级人民检察院。

### **六、救济**

::: tip

谁盖章就去找谁。

只有复议没有复核。

:::

（一）**当事人及其法定代理人不服**：==5日内提出复议申请==

当事人及其法定代理人对驳回申请回避的决定不服的，可以在收到驳回申请回避决定书后五日以内==向作出决定的公安机关申请复议==。

（二）**原公安机关作出决定**：==5日内作出复议决定==

公安机关应当在==收到复议申请后五日以内作出复议决定并书面通知==申请人。



### **七、效力**

（一）**回避前**：不停止

在作出回避决定前，申请或者被申请回避的公安机关负责人、侦查人员不得停止对案件的侦查。

（二）**回避后**：不参与

作出回避决定后，申请或者被申请回避的公安机关负责人、侦查人员不得再参与本案的侦查工作。

（三）**回避后之前的工作是否有效**：待定

被决定回避的公安机关负责人、侦查人员在回避决定作出以前所进行的诉讼活动是否有效，由作出决定的机关根据案件情况决定。


### **八、全景图**  

| 维度       | 行政案件                  | 刑事案件（本节重点）                                                      |
| -------- | --------------------- | --------------------------------------------------------------- |
| **适用主体** | 公安机关负责人、侦查人员、鉴定人、翻译人  | **增加“记录人”**                                                     |
| **决定主体** | 所属公安机关/上一级公安机关        | ①侦查/记录/翻译/鉴定人员→**县级以上公安机关负责人**<br>②公安机关负责人→**同级人民检察院检察委员会**     |
| **救济途径** | 无专门复议                 | **可向原机关申请复议一次**                                                 |
| **复议机关** | 同级政府（行政复议）            | **谁盖章找谁**（县公安局→县公安局；市局→市局）                                      |
| **批准时间** | 收到回避申请`二日`内作出决定并通知申请人 | • 收到回避申请`二日`内作出决定并通知申请人<br>• 情况特殊，县级以上公安机关负责人批准，收到回避申请后`五日`作出决定 |
| **复议期限** | 行政复议60日               | **5日内申请→5日内决定**                                                 |



### **九、思维导图**

```markmap

---
markmap:
  colorFreezeLevel: 2
---

# 刑事回避

## 回避主体
- 侦查人员
- 公安机关负责人
- 鉴定人
- 翻译人员
- 记录人员

## 回避情形
- 本人或近亲属是案件当事人
- 本人或近亲属与案件处理结果有利害关系
- 曾担任过本案的证人、鉴定人、辩护人、诉讼代理人
- 存在其他关系，可能影响案件公正处理

## 回避方式
- 自行回避
- 申请回避
- 指令回避

## 审批权限
- **侦查人员**
  - 县级以上公安机关负责人批准
- **县级以上公安机关负责人**
  - 同级人民检察院检察委员会批准
- **记录人、翻译人、鉴定人**
  - 县级以上公安机关负责人批准

## 回避决定的效力
- 作出决定前
  - 不停止工作
- 作出决定后
  - 之前工作是否有效，由作出决定的机关根据案件情况决定

## 救济程序
- 驳回回避申请
  - 原公安机关作出决定
    - 一般案件：2天内作出决定
    - 复杂案件：5天内作出决定（县级以上公安机关负责人批准）
- 不服决定
  - 5日内申请复议
  - 复议机关5日内作出复议决定

```
