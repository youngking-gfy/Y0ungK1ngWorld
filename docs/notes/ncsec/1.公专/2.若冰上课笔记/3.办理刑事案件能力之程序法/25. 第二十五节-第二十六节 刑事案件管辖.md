# 刑事案件管辖课程笔记




### **一、外部管辖**

#### （一）**人民检察院直接受理的案件范围（==14+转==）**

##### 1、**司法工作人员利用职权侵人权**

（1）**司法工作人员**：包括==侦查、检察、审判、监管职责的工作人员==。

（2）**案件范围**：侵犯公民权利，损害司法公正的犯罪。共14个具体罪名：非法拘禁罪，非法搜查罪，刑讯逼供罪，暴力取证罪，虐待被监管人罪，滥用职权罪，玩忽职守罪，徇私枉法罪，民事、行政枉法裁判罪，执行判决、裁定失职罪，执行、判决裁定滥用职权罪。

::: tip 三要件

司法工作人员（包括==侦查、检察、审判、监管职责的工作人员==）——利用职权——侵人权

:::

##### 2、对于公安机关管辖的国家机关工作人员利用职权实施的重大犯罪案件，**需要由人民检察院直接受理的时候，经省级以上人民检察院决定，可以由人民检察院立案侦查**。

##### 3、**公安和检察交叉案件管辖**：看==主罪确定主侦查==的原则

公安机关侦查的刑事案件涉及人民检察院管辖的案件时，应当将属于人民检察院管辖的刑事案件移送人民检察院。涉嫌==主罪=={.warning}属于公安机关管辖的，由公安机关为主侦查；涉嫌==主罪=={.warning}属于人民检察院管辖的，公安机关予以配合。


::: warning

如果和监委发生交叉不看案件轻重，不看主罪，一切以监委为主。

:::


> 举例：  
> • 警察王水因私债拘禁张三 → **缺“利用职权”→公安管辖**  
> • 警察王水传唤李四超时拘禁 → **三要件齐全→检察院管辖**


#### （二）**人民法院直接受理的案件范围（==5+8+转==）**

##### 1、**告诉才处理的案件**(法院专属管辖，除了括号里的特殊情况)

（1）侮辱案（严重危害社会秩序和国家利益的除外）`个人`

（2）诽谤案（严重危害社会秩序和国家利益的除外）`个人`

（3）暴力干涉婚姻自由案（==致使被害人死亡的除外=={.danger}）`家庭`

（4）虐待案（但==致使被害人重伤、死亡或被害人没有能力告诉或因受到强制、威吓无法告诉的==除外）`家庭`

（5）侵占案（==绝对的告诉才处理=={.warning}）

##### 2、**被害人==有证据证明==的==轻微刑事案件==**（==公安和法院都有管辖权=={.info}）

（1）故意伤害案（轻伤害）

（2）非法侵入住宅案

（3）侵犯通信自由案

（4）重婚案

（5）遗弃案

（6）生产、销售伪劣商品案，但==严重危害社会秩序和国家利益的==除外

（7）侵犯知识产权案，但==严重危害社会秩序和国家利益的==除外

（8）属于刑法分则第四章侵犯公民人身权利、民主权利罪和第五章侵犯财产罪规定的，对被告人可能判处==三年以下==刑罚的案件。


::: tip
==通知轻重、住伪弃3=={.warning}
:::


##### 3、**公诉转自诉的案件**（同时具备下列的两个条件）

（1）被害人==有证据证明==被告人侵犯了自己的==人身、财产权利==，应当追究被告人的刑事责任；

::: warning

只限于这两种，没有民主权利，选举权和被选举权受到侵犯无法公诉转自诉。

:::

（2）被害人有证据证明曾经提出控告，而公安机关或人民检察院不予追究被告人刑事责任 。

### **二、内部管辖**

#### （一）**地域管辖**

1、**一般情况**：由犯罪地的公安机关管辖；

2、**更为适宜时**：由犯罪嫌疑人居住地的公安机关管辖。

::: note “更为适宜的理解”

（1）犯罪嫌疑人流窜作案，主要犯罪地难以确定，而居住地群众更了解其犯罪情况的；

（2）犯罪嫌疑人在居住地民愤较大，当地群众强烈要求在居住地进行审判的；

（3）可能对犯罪嫌疑人判处管制或者适用缓刑，应当在犯罪嫌疑人居住地执行监督、考察的。

:::
#### （二）**级别管辖**

1、县级公安机关负责侦查发生在本辖区内的刑事案件。

::: warning

《关于建立派出所和刑警队办理刑事案件工作机制的意见》(公通字【2005】100号2005年12月31日): ……派出所负责办理辖区内发生的因果关系明显、案情简单、无需专业侦查手段和跨县、市进行侦查的刑事案件。

（1）犯罪嫌疑人被派出所民警当场抓获的；

（2）犯罪嫌疑人到派出所投案自首的；

（3）群众将犯罪嫌疑人扭送到派出所的；

（4）派出所民警获取线索可直接破案的；

（5）其他案情简单、派出所有能力侦办的刑事案件。

派出所在办理上述五类案件过程中，发现需要开展专门侦查工作的线索，应当及时将案件移交刑侦部门或其他专业部门办理。

派出所不办理发生在辖区内的下列刑事案件：

（1）故意杀人案；

（2）故意伤害致人重伤或者死亡案；

（3）强奸案；

（4）抢劫案；

:::

2、设区的市一级以上公安机关负责==重大的危害国家安全犯罪、恐怖活动犯罪、涉外犯罪、经济犯罪、集团犯罪、划区域犯罪==的侦查。



::: tip 

**涉外犯罪的理解**

《公安机关办理刑事案件程序规定》第363条：外国人犯罪案件，由==犯罪地的县级以上公安机关==立案侦查。

第364条：外国人犯中华人民共和国缔结或者参加的国际条约规定的罪行==后==进入我国领域内的，由该外国人被抓获地的==设区的市一级以上公安机关立案侦查==。

**跨区域犯罪的理解**

是指==跨省级==行政区域，或者==省级行政区域内跨不同地市==，且犯罪性质严重、具有较大社会影响，==区县==公安机关==难以侦办==的案件。

:::

3、上级公安机关认为有必要的，可以侦查下级公安机关管辖的刑事案件；下级公安机关认为案情重大需要上级公安机关侦查的刑事案件，可以请求上一级公安机关管辖。
#### （三）**管辖争议的解决**

1、**共同管辖**：几个公安机关都有权管辖的刑事案件，由最初受理的公安机关管辖。必要时，可以由主要犯罪地的公安机关管辖。

具有下列情形之一的，公安机关==可以==在职责范围内并案侦查：

（1）一人犯数罪的；

（2）共同犯罪的；

（3）共同犯罪中犯罪嫌疑人还实施其他犯罪的；

（4）多个犯罪嫌疑人实施的犯罪存在关联，并案处理有利于查明犯罪事实的。

2、**协商管辖**：对管辖不明确或者有争议的刑事案件，可以由有关公安机关协商。

3、**指定管辖**：协商不成的，由共同的上级公安机关指定管辖。

上级公安机关指定管辖的，应当将指定管辖决定书分别送达被指定管辖的公安机关和其他有关的公安机关，并根据办案需要抄送同级人民法院、人民检察院。

### **三、特殊案件管辖规定**

#### 1、**网络犯罪**

（1）网络犯罪：指的是针对或者利用计算机网络实施的犯罪；

（2）管辖权：==犯罪行为地和居住地都有管辖权==。

#### 2、**行驶中的交通工具上发生的犯罪**

由交通工具==最初停靠地公安机关==管辖；

必要时，交通工具==始发地、途经地、到达地公安机关也可以管辖==。

#### 3、**铁路系统发生的犯罪**：

（1）对倒卖、伪造、变造火车票的案件，由最初受理案件的铁路公安机关或者地方公安机关管辖。必要时，可以移送主要犯罪地的铁路公安机关或者地方公安机关管辖。

（2）==铁路建设施工工地发生的刑事案件由地方公安机关==管辖。

（3）在列车上发生的刑事案件，犯罪嫌疑人在列车运行途中被抓获的，由==前方停靠站所在地的铁路公安机关==管辖；必要时，也可以由==列车始发站、终点站所在地的铁路公安机关==管辖。

::: warning

客车案件有==最初停靠地，始发地，途经地，到达地=={.warning}，但火车案件没有途经地，只有==前方停靠站、始发站和终点站没有途经站=={.danger}。

:::

（4）犯罪嫌疑人不是在列车运行途中被抓获的，由==负责该列车乘务的铁路公安机关==管辖；

（5）在列车运行途经的车站被抓的，可以由==该车站所在地的铁路公安机关==管辖，也可以由==负责该列车乘务的铁路公安机关==管辖；

#### 4、**在中华人民共和国领域外的中国航空器内发生刑事案件，由该航空器在中国最初降落地的公安机关管辖**。


#### 5、**中国公民在中国驻外使、领馆内的犯罪，由其主管单位所在地或者原户籍所在地的公安机关管辖**。

中国公民在共和国领域外的犯罪，由==其入境地、离境前居住地或者现居住地的公安机关==管辖。被害人是中国公民的，也可由==被害人离境前居住地或者现居住地的公安机关==管辖。

#### 6、**在国际列车上发生的刑事案件，根据我国与相关国家签订的协定确定管辖；没有协定的，由该车始发或者前方停靠的中国车站所在地的铁路公安机关管辖**。

#### 7、**重大飞行事故刑事案件由犯罪结果发生地机场公安机关管辖**。

犯罪结果发生地未设机场公安或者不在机场公安机关管辖范围内的，由地方公安机关管辖，有关机场公安机关予以协助。
