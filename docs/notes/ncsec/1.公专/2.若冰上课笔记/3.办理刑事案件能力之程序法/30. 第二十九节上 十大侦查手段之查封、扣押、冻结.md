## **五、查封、扣押**

### （一）**查封、扣押的范围以及强制查封、扣押**

1、**范围**：在侦查活动中发现的可用以证明犯罪嫌疑人有罪或无罪的各种财物、文件，应当查封、扣押；但与案件无关的财物、文件，不得查封、扣押。

2、**强制查封扣押**：持有人拒绝交出应当查封、扣押的财物、文件的，公安机关可以强制查封、扣押。

### （二）**查封、扣押的对象和决定权**

1、**查封的对象**：不动产和特殊动产

不动产如==土地、房屋==等；

特殊动产如船舶、航空器以及其他不宜移动的大型机器、设备等。


::: note 行政查封对象

- **查封的对象**：专门用于无证经营活动的场所、设施、物品。包括：
    - 1. 擅自经营按照国家规定需要由公安机关==许可==的行业的；
    - 2. 依照《娱乐场所管理条例》可以由公安机关采取**取缔**措施的；
    - 3. 《反恐怖主义法》等法律、法规规定适用查封的其他公安行政案件。

:::

2、**查封的决定权**——==县级以上公安机关负责人==批准

3、**扣押的对象**：普通动产——财物、文件等。

4、**扣押的决定权**：

（1）侦查过程中 —— ==办案部门负责人==批准，制作扣押决定书。

（2）现场勘验或搜查中 —— ==现场指挥人员==决定，==不需要扣押决定书=={.warning}，开列扣押清单即可。

（3）价值较高或可能严重影响正常生产经营的 —— ==县级以上公安机关负责人==批准。

（4）扣押邮件、电子邮件、电报 —— ==县级以上公安机关负责人==批准。


::: note

我国《宪法》第40条：除因==国家安全或追查刑事犯罪==的需要，由公安机关或者检察机关依照法律规定的程序对通信进行检查外，任何组织或者个人不得以任何理由侵犯公民的通信自由和通信秘密。

:::

### （三）**查封、扣押过程注意事项**

1、**执行主体**：不少于2名侦查人员。

2、**查点和当场开具清单**：

（1）**查点人**：==侦查人员+持有人+见证人==；

（2）**当场开列清单**：不能事后补开，一式三份(持有人、公安机关保管人员、附卷),对于财物文件的持有人无法确定，以及持有人不在现场或者拒绝签名的，侦查人员应当在清单中注明；

3、**贵重财物**：依法扣押文物、贵金属、珠宝、字画等贵重财物的，应当拍照或者录音录像，并及时鉴定、估价。

4、**人道主义**：执行查封、扣押时，应当为犯罪嫌疑人及其所扶养的亲属==保留必需的生活费用和物品==。

5、**企业发展**：在能够保证侦查活动正常进行的前提下，可以允许有关当事人继续合理使用有关涉案财物，但应当采取必要的保值、保管措施。

6、**登记保存**：对作为犯罪证据但是不便提取或者没有必要提取的财物、文件，经登记、拍照或者录音录像、估计后，可以交财物、文件持有人保管或封存，并且开具登记保存清单一式两份，由侦查人员、持有人和见证人签名，一份交给财物、文件持有人，另一份连同照片或者录音录像资料附卷备查。财物、文件持有人应当妥善保管，不得转移、变卖、毁损。


::: note

不便提取的物品，主要是指大型物品或者数量较多的物品、文件；

没有必要提取的物品，如抢劫案件中因被害人反抗而未被抢走的手机等赃物、经济犯罪案件中涉案企业的印章等，属于其合法所有且需要继续使用的，公安机关没有必要提取。

:::

7、**制作笔录**：由侦查人员、持有人和见证人签名。

### （四）**查封扣押后的工作**

#### 1、**妥善保管、以供核查**。

（1）任何单位和个人==不得违规==使用、调换、损毁或自行处理。

（2）**保管地点**：==县级以上公安机关指定的内设部门==；==办案部门设置专门场所==。

::: note 专门场所

办案部门设置专门场所保管的物品是：价值较低、易于保管，或者需要作为证据继续使用，以及需要先行返还被害人的涉案财物。办案部门应当指定不承担办案工作的民警负责本部门涉案财物的接收、保管、移交等管理工作；严禁由侦查人员自行保管涉案财物。

:::

#### 2、**拍卖、变卖**。

对于易损毁、灭失、腐烂、变质而不宜长期保存，或者难以保管的物品，经==县级以上公安机关主要负责人==批准，可以在拍照或录音录像后委托有关部门变卖拍卖，所得价款暂予保存，待诉讼终结后一并处理。

::: note

行政案件当中，经过==公安机关负责人==批准，就可以进行拍卖变卖。

:::
#### 3、**查明无关，解除查封扣押**。

（1）经查明，确实与案件无关的，应当在==三日内==解除查封、扣押，退还原主或原邮电部门、网络服务单位；

（2）原主不明确的，应当采取==公告方式==告知原主认领。在通知原主或公告后==六个月==内，无人认领的，按照无主财物处理，登记后上缴国库。


::: note

行政中期限——==6个月+3个月==

:::



#### 4、**被害人合法财产返还**

（1）**同时符合三个条件**：

一是有关犯罪事实查证属实；

二是有证据证明相关财产权属明确且无争议；

三是属于被害人合法财产及其孳息。

（2）**程序**：

第一、==县级以上公安机关负责人==批准；

第二、返还之前，应当对财产进行登记、拍照或者录像、估价；

第三、开具发还清单，并在案卷材料中注明返还的理由，将原物照片、发还清单和被害人领取的手续存卷备查；

（3）**领取人**：

第一、涉案财物的合法权利人；

第二、合法权利人委托的人。委托他人代领的，应当出具委托书。==侦查人员或者公安机关的其他人员不得代为领取==。

（4）**无人领取，随案移送**。

查找不到被害人，或者通知被害人后，无人领取的，应当将有关财产及其孳息随案移送。

#### 5、**违禁品的处理**

（1）==与案件无关==：依照国家有关规定处理，一般是收缴或没收；

（2）==与案件有关==：需要作为证据使用的，应当在诉讼终结后处理。

## **六、查询、冻结**


::: note

行政案件中冻结是只针对==涉恐人员的财产==的。

而刑事案件冻结，针对所有案件的，不只是针对涉恐案件，针对所有的案件，只要是犯罪嫌疑人的存款。

:::

### （一）**查询冻结的范围**

1、犯罪嫌疑人的存款、汇款、证券交易结算资金、期货保证金，债券、股票、基金份额和其他证券，以及股权、保单权益和其他投资权益等财产，并可以要求有关单位和个人配合。

2、对于上述财产，==不得划转、转账或者以其他方式变相扣押==。

### （二）**查询的程序**

1、**呈批**：办案部门制作呈请查询财产报告书，报==县级以上公安机关负责人==批准；

2、**批准**：==县级以上公安机关负责人==批准后，办案部门制作协助查询财产通知书；

3、**实施查询**。侦查人员将协助查询财产通知书正本和回执联交金融机构等单位协助查询。

### （三）**冻结的程序**

1、**呈批**：办案部门制作呈请冻结财产报告书。

2、**批准**：

（1）**县级公安机关负责人**：一般的冻结；

（2）**设区的市一级以上公安机关负责人**：冻结股权、保单权益的；

（3）**省级以上公安机关负责人**：冻结==上市公司股权==的；

（4）批准后，办案部门制作==协助冻结财产通知书==。

::: note

行政案件当中，冻结股权是需要县级以上公安机关负责人批准。

:::

3、**实施**：

侦查人员将协助冻结财产通知书正本和回执联交金融机构等单位协助冻结。

（四）**冻结的期限**

1、存款、汇款、证券交易结算资金、期货保证金

（1）一般案件：冻结期限为==6个月==；

（2）重大复杂案件：冻结期限为==1年==。需要经过==设区的市一级以上公安机关负责人=={.caution}批准。

2、股权、保单权益或者投资==权益==：==期限为六个月==；

3、==债券股票==基金份额等证券：==期限为2年==。

::: note

- 金款类：6个月-1年
- 权益类：6个月
- 证券类：2年


:::
### （五）**冻结的续期**


1、**提前续期**：在冻结期限届满前办理续冻手续，按照原批准权限和程序。

2、**未续期后果**：逾期不办理续冻手续，视为自动解除冻结。

### （六）**冻结债券股票基金的出售**

1、**告知**：公安机关应当告知当事人或者其法定代理人、委托代理人有权申请出售。

2、**申请**：权利人提出书面申请，公安机关不得自行决定。

3、**审批**：==县级以上公安机关负责人==批准

（1）**汇票本票支票**：不影响国家、被害人、其他权利人利益+不影响诉讼正常进行+冻结的汇票本票支票的有效期即将届满；

（2）**股票基金债权**：不影响国家、被害人、其他权利人利益+不影响诉讼正常进行。

4、**保管**：通过出售或变现所得款项应当继续冻结在银行账户中，并及时告知当事人及其近亲属；没有对应银行账户的，所得价款由==公安机关在银行指定专门账户保管，并及时告知当事人或者其近亲属==。

### （七）**解除冻结的程序**

1、**前提**：不需要继续冻结犯罪嫌疑人的财产；

2、**审批**：应当经原批准冻结的公安机关负责人批准；

3、**实施**：制作协助解除冻结财产通知书，通知金融等单位协助办理。

（八）**其他**

1、犯罪嫌疑人的财产已被冻结的，不得重复冻结，但可以==轮候冻结==；

2、对冻结的财产，经查明确实与案件无关的，应当在==三日以内==通知金融机构等单位解除冻结，并通知被冻结财产的所有人。
