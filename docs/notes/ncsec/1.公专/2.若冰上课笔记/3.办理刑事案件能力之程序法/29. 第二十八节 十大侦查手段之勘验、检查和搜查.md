### **三、勘验、检查**

勘验的对象是==场所、物品和尸体==；检查的对象是==活人的身体==。

#### （一）**人身检查**

1、**目的**：为了确定被害人、犯罪嫌疑人的某些特征、伤害情况或者生理状态。

::: note

**某些特征**：如相貌、皮肤颜色、特殊痕迹、伤疤等。

**伤害情况**：是伤害的部位、程度、伤势形态等，这主要是对被害人进行的；

**生理状态**：是指有无生理缺陷，如智力发育情况、生理机能等。


:::

2、**手段**：人身检查；依法提取、采集肖像、指纹等人体生物识别信息，采集血液、 尿液等生物样本。

3、**强制检查、提取、采集**：只针对犯罪嫌疑人，由==办案部门负责人==批准。

4、**检查妇女的身体**：应当由==女工作人员或者医师==进行。

::: note

检查妇女的身体应当由女工作人员进行，一时找不到女工作人员的，可以由具有执业资格证的==医师==进行。

:::

5、**必须要有见证人**。

6、**制作检查笔录**，由==参加检查的侦查人员、检查人员、被检查人员和见证人==签名。

被检查人拒绝签名的，侦查人员应当在笔录中注明。

::: warning

办理强奸案件，==不准对被害人进行处女膜检查，也不准用检查处女膜的结论作为证据==。

:::


| 人身检查种类 | 审批                                                                        | 妇女身体       | 见证人 |
| ------ | ------------------------------------------------------------------------- | ---------- | --- |
| 行政     | 县级以上公安机关负责人，强制无需审批。                                                       | 女性工作人员     | 需要  |
| 治安     | **体表**<br>   • 办案部门负责人<br>**体内**（被侵害人体液、血液样本）<br>   • 办案部门负责人+被侵害人或其监护人同意 | 女性工作人员或者医师 | 需要  |
| 刑事     | 无需审批，强制需办案部门负责人审批                                                         | 女性工作人员或者医师 | 需要  |


#### （二）**尸体检验**

1、**目的**：为了确定死因。

2、**批准**：==县级以上公安机关负责人==。注意：==无需家属同意=={.danger}。

3、**通知**：应当通知死者的家属到场，让其在解剖尸体通知书上签名。死者家属无正当理由拒不到场或者拒绝签名，侦查人员应当在解剖尸体通知书上注明。对身份不明的尸体，无法通知死者家属的，应当在笔录中注明。

::: note

**解剖前的尸体保护**：
- 室外的尸体尽量保持原始状态，阳光照射时，可用洁净的物品加以遮挡，以延缓腐败；
- 遇有下雨、下雪等天气变化时，应用洁净的塑料布等材料加以遮盖，以防尸体上附着的毛发、血迹、精斑等痕迹、物证散失和被污染、破坏；
- 水中的尸体可以暂时不打捞上岸，水流过急时，应设法固定位置，无法固定的，在不破坏尸表特征的前提下，将尸体兜住打捞上岸。
- 火场中的尸体，遇有火势蔓延或建筑物即将倒塌时，应设法将尸体移出火场 。

:::

4、**主持**：==侦查人员==主持。


5、**检查人员**：勘验、检查有尸体的现场，应当有法医参加。

6、**解剖地点**：应当在==尸体解剖室==进行。确因情况紧急，或者受条件限制，需要在现场附近解剖的，==应当采取隔离、遮挡措施==。

7、**解剖尸体**：应当捺印尸体指纹和掌纹。必要时，提取血、尿、胃内容和有关组织、器官检材。

8、**照相、录像**。检验、解剖尸体时，应当录音、录像。

9、**制作尸体检验报告书**，存入诉讼卷。

10、**尸体处理**：对已经查明死因，没有继续保存必要的尸体，应当通知家属领回处理；对于无法通知或者通知后家属拒绝领回的，经县级以上公安机关负责人批准，可以及时处理。

11、**信息录入**。对于身份不明的尸体，应当按照有关规定，将有关的信息录入无名尸体信息库。

#### （三）**侦查实验**

1、**目的**：为了查明案情。

2、**批准**：==县级以上公安机关负责人==。

3、**侦查实验应当符合如下要求**

（1）**主持人**：侦查人员；

（2）**地点**：一般在案发地点进行；燃烧、爆炸等危险性实验，应当在其他能够确保安全的地点进行；

（3）**时间、环境**：应当与发案的时间、环境条件基本相同；

（4）**工具、材料**：应当与案发现场一致或者基本一致；必要时，可以使用不同类型的工具或者材料进行对照实验；

（5）**次数**：如条件许可，侦查实验应当进行2次以上；

（6）**评估实验结果**：应当考虑到客观环境、条件变化对实验的影响和可能出现的误差；

（7）**禁止**：足以造成危险、侮辱人格、有伤风化的行为。

::: note

**足以造成危险**：是指进行侦查实验所采取的==手段、方法==违背客观规律、违反操作规程、随时都可能危害人的生命，造成财产的损失。

**侮辱人格**：是指进行侦查实验所采取的的==方法、手段==损害了当事人及其他诉讼参与人的人格尊严和名誉等。

**有伤风化**：是指侦查实验破坏了当地的风俗、败坏了风气。

:::

4、**应当全程录音录像**。

5、**制作侦查实验笔录**：由==参加实验的人==签名。

::: warning

除听证笔录，辨认笔录剩下的笔录。==所有的参加人统统都要签名==。

:::

#### （四）**现场勘查**

##### 1、**现场勘查的一般规定**

（1）现场勘验、检查的**内容**包括：==现场保护、现场实地勘验检查、现场访问、现场搜索与追踪、侦查实验、现场分析、现场处理、现场复验与复查=={.info}等。

（2）**现场勘验的对象**：与犯罪有关的场所、物品、尸体；**检查的对象**：人身。

（3）**现场勘查的负责部门**：县级以上公安机关侦查部门组织实施。

##### **2、现场保护**

（1）发案地派出所、巡警等部门接到报警后，应当迅速派员赶赴现场，对于有犯罪现场的，妥善保护犯罪现场和证据，控制犯罪嫌疑人，并立即报告公安机关主管部门。

（2）负责保护现场的人民警察应当根据案件具体情况，划定保护范围，设置警戒线和告示牌，禁止无关人员进入现场。

（3）负责保护现场的人民警察==除抢救伤员、紧急排险等情况外==，不得进入现场，不得触动现场上的痕迹、物品和尸体；处理紧急情况时，==应当尽可能避免破坏现场上的痕迹、物品和尸体，对现场保护情况应当予以记录，对现场原始情况应当拍照或者录像==。

（4）负责保护现场的人民警察对现场可能受到自然、人为因素破坏的，应当对现场上的痕迹、物品和尸体等==采取相应的保护措施==。

（5）保护现场的时间，从==发现刑事案件现场==开始，至现场勘查结束。需要继续勘查或者需要保护现场的，应当对整个现场或者部分现场继续予以保护；

（6）负责现场保护的人民警察应当将现场保护情况及时报告==现场勘查指挥员==。

##### **3、现场勘验检查的参与人及步骤**

###### （1）**指挥人员**

现场勘验、检查的指挥人员由具有现场勘验、检查专业知识和组织指挥能力的人民警察担任。 一般案件的现场勘查，==由侦查部门负责人指定的人员现场指挥==；重大、特别重大案件的现场勘查==由侦查部门负责人现场指挥==；必要时，发案地公安机关负责人应当亲自到现场指挥。

###### （2）**指挥人员的职责**

现场勘验、检查的指挥员依法履行下列职责：

- 决定和组织实施现场勘验、检查的紧急措施；
- 制定和实施现场勘验、检查的工作方案；
- 对参加现场勘验、检查人员进行分工；
- 指挥、协调现场勘验、检查工作；
- ==确定现场勘验、检查见证人==；
- 审核现场勘验检查工作记录；
- 组织现场分析；
- 决定对现场的处理。

###### （3）**现场勘验人员**

应当具备现场勘验、检查的专门知识和专业技能，具有现场勘验、检查资格，佩带==刑事犯罪现场勘查证==。公安机关对刑事案件进行现场进行==勘验、检查的人员不得少于二人==。勘验检查==有尸体==的现场，应当==有法医==参加。


::: tip

有尸体有法医。

:::


###### （4）**现场勘验、检查人员职责**

- 实施现场紧急处置；
- 开展现场调查访问；
- 发现、固定和提取现场痕迹、物证等；
- 记录现场保护情况、现场原始情况和现场勘验、检查情况，制作《现场勘验检查工作记录》;
- ==参与现场分析==；
- 提出处理现场的意见；
- 将现场勘验信息录入“全国公安机关现场勘验信息系统”;
- ==利用现场信息串并案件==。

###### （5）**见证人**

勘验、检查现场时，应当邀请==一至二名与案件无关==的公民作见证人。==由于客观原因无法由符合条件的人员担任见证人的，应当在笔录材料中注明情况，并对相关活动进行录像=={.info}。

::: tip

==无关中立&明辨是非=={.danger}

:::

###### （6）**现场勘验、检查按照以下工作步骤**

- 巡视现场，==划==定勘验、检查==范围==；
- 按照 ==“先静后动，先下后上，先重点后一般，先固定后提取”=={.warning} 的原则，根据现场实际情况确==定==勘验、检查==流程==；
- ==初步==勘验、检查现场，固定和记录现场原始状况；
- ==详细==勘验、检查现场，发现、固定、记录和提取痕迹、物证；
- ==记录==现场勘验、检查情况。

###### （7）**无关人员不得进入**

勘验、检查现场时，==非勘验、检查人员不得进入现场==。确需进入现场的，==应当经指挥员同意，并按指定路线进出现场==。

**4、现场勘验的工作记录**

（1）现场勘验检查工作记录勘验、检查现场，应当==拍摄现场照片，绘制现场图，制作笔录==，由==参加勘查的人和见证人==签名。

（2）**现场图**

**种类**：现场勘验、检查人员可以制作现场方位图、现场平面示意图，并根据现场情况选择制作现场平面比例图、现场平面展开图、现场立体图和现场剖面图等。

**要求**：

- 标明案件名称，案件发现时间、案发地点；
- 完整反映现场的位置、范围；
- 准确反映与犯罪活动有关的主要物体，标明尸体、主要痕迹、主要物证、作案工具等具体位置；
- 文字说明简明、准确；
- 布局合理，重点突出，画面整洁，标识规范；
- 现场图注明==方向、图例==、==绘图单位、绘图日期和绘图人==。

（3）**现场照相和录像**

**种类**：包括==方位、概貌、重点部位和细目==四种。

**要求**：

- 影像清晰、主题突出、层次分明、色彩真实；

- 清晰、准确记录现场方位、周围环境及原始状态，记录痕迹、物证所在部位、形状、大小及其相互之间的关系；

- 细目照相、录像==应当放置比例尺==：  

- 现场照片需有文字说明。

**5、现场访问**

（1）现场勘验、检查人员应当向报案人、案件发现人，被害人及其亲属，其他知情人或者目击者了解、收集有关刑事案件现场的情况和线索。

（2）现场访问包括以下主要内容：

- 刑事案件发现和发生的时间、地点、详细经过，发现后采取的保护措施，现场情况，有无可疑人或者其他人在现场，现场有无反常情况，以及物品损失等情况；

- 现场可疑人或者作案人数、作案人性别、年龄、口音、身高、体态、相貌、衣着打扮、携带物品及特征，来去方向、路线等；

- 与刑事案件现场、被害人有关的其他情况。

- 现场访问应当制作询问笔录。

**6、现场的处理**

（1）现场勘验、检查结束后，==现场勘验、检查指挥员==决定是否保留现场。

- 对不需要保留的现场，应当及时通知有关单位和人员进行处理；

- 对需要保留的现场，应当及时通知有关单位和个人，==指定专人妥善保护==。

（2）对需要保留的现场，可以==整体保留或者局部保留==。

（3）现场勘验、检查结束后，==现场勘验、检查指挥员==决定是否保留尸体。

- 遇有死因未定、身份不明或者其他情况需要复验的，应当保存尸体；
- 对没有必要继续保存的尸体，经==县级以上公安机关负责人==批准，应当立即通知死者家属处理。对无法通知或者通知后家属拒绝领回的，经==县级以上公安机关负责人==批准，可以按照有关规定及时处理；
- 对没有必要继续保存的外国人尸体，经县级以上公安机关负责人批准，应当立即通知死者家属或者所属国驻华使、领馆的官员处理。对无法通知或者通知后外国人家属或者其所属国驻华使、领馆的官员拒绝领回的，经县级以上公安机关负责人批准，并书面通知外事部门后，可以按照有关规定及时处理。

**7、现场的复验、复查**

（1）遇有下列情形之一，应当对现场进行复验、复查：

①案情重大、现场情况复杂的；

②侦查工作需要从现场进一步收集信息、获取证据的；

③人民检察院审查案件时认为需要复验、复查的；

④当事人提出不同意见，公安机关==认为有必要复验、复查==的；

⑤其他需要复验、复查的。

（2）对人民检察院要求复验、复查的，公安机关==应当进行复验、复查==时，并可以通知人民检察院派员参加。

```markmap
# 勘验检查

## 现场保护
- **主体**：发案地派出所、巡警部门
- **行为**：
  - 划定保护范围，设置警戒线和告示牌，禁止无关人员进入
  - 负责保护现场的人民警察除抢救伤员、紧急排险外，不得进入现场、触碰痕迹等


## 现场勘查
- **主持人**：侦查人员
- **主体**：侦查人员不得少于`2人`
	- 持犯罪现场勘察证，除排险救人外，负责现场保护的警察不得进入现场
- **具体要求**：
  - 应当佩戴现场勘查证件
  - 制作现场勘查笔录，包括现场方位图、平面示意图等
  - 制作笔录（参加勘察的人和见证人签名）


## 人身检查
- **目的**：确定被检查人、犯罪嫌疑人某些特征、伤害情况或生理状态
- **提取采集**
	- 生物识别信息（肖像、指纹）
	- 生物样本（血液、尿液）
- **审批**：强制检查、提取、采集需==办案部门负责人==批准
- **特殊要求**：
  - 检查妇女身体：由女工作人员或医师进行
  - 必须有见证人在场
  - 制作检查笔录，
	  - 侦查人员、检查人员
	  - 被检查人员，拒绝签名，笔录注明
	  - 见证人签名

## 尸体检验
- **目的**：确定死因
- **审批**：==县级以上公安机关负责人==批准（无需家属同意）
- **应当**：通知家属到场，让其在解剖尸体通知书上签名
	- 不来或不签：在尸体解剖通知书上注明
	- 尸体身份不明，无法通知：在笔录中注明
- **尸体处理**：
  - 通知家属领回
	  - 拒绝或无法通知，经==县级以上公安机关负责人==批准后，可及时处理
- **细节**
	- 勘验检查有尸体的现场，应当有法医参加
	- **尸体保护**：
	  - 阳光照射：洁净物品加以遮挡
	  - 下雪下雨：洁净的塑料布
	  - 水中尸体：
		  - 缓：设法固定位置
		  - 急：不破坏尸体表面的前提将尸体兜住打捞上岸
	  - 火中尸体
		  - 火势蔓延或建筑物即将倒塌时，设法将尸体移出火场
	- **尸体的原为检查**
		- 移动现场尸体前，应当对尸体的原始状态及周围痕迹物品进行照相、录像，并提取相关痕迹物证
	- **尸体解剖地点**：尸体解剖室
		- 情况紧急或条件受限可在现场附近解剖，但应当采取隔离、遮挡措施
	- 解剖尸体应当捺印尸体的指纹和掌纹，应当==录音录像==
	- 不明身份的尸体应当录入无名尸体信息库

## 侦查实验
- **目的**：查明案情
- **审批**：==县级以上公安机关负责人==批准
- **要求**：
  - 符合法律规定，不得造成危险、侮辱人格或有伤风化
  - 全程录音录像
  - 制作侦查实验笔录，由参加实验人员签名
- **细节**
	- **地点**：一般在案发地点进行
	- **时间环境**：与案发时基本相同
	- **工具材料**：与案发时一致或基本一致
	- **次数**：条件许可下进行2次以上

## 复验、复查
- **条件**：案情重大、现场复杂，或需要进一步收集证据等
- **主体**：公安机关（检察院可要求复验复查）
- **要求**：复验复查时应通知原侦查人员参加
```


## **四、搜查**


### （一）**目的**

为了收集犯罪证据、查获犯罪嫌疑人。

### （二）**对象**

犯罪嫌疑人以及可能隐藏罪犯或犯罪证据的人的身体（==体外==）、物品、住所和其他有关的地方。

### （三）**审批**

==县级以上公安机关==负责人。

### （四）**搜查主体**

2名以上侦查人员。

### （五）**有证搜查和无证搜证**

1、进行搜查，必须向被搜查人出示警察证和搜查证。

2、执行==拘留、逮捕任务==的时候，遇到下列紧急情况之一，==不用搜查证也可以进行搜查==：

（1）可能随身携带凶器的；

（2）可以隐藏爆炸、剧毒等危险物品的；

（3）可能隐匿、毁弃、转移犯罪证据的；

（4）可能隐匿其他犯罪嫌疑人的；

（5）其他突然发生的紧急情况。

::: note

有刀有枪有人有证据。

:::

### （六）**搜查的要求**

1、**有人在场**。搜查时，应当有==被搜查人或者他的家属、邻居或者其他见证人==在场。

2、**配合义务**。公安机关可以要求有关单位和个人交出可以证明犯罪嫌疑人有罪或无罪的物证、书证、视听资料等证据。遇到阻碍搜查的，侦查人员可以强制搜查，==破坏性搜查=={.warning}时，应当经==办案部门负责人==批准。

::: note 强制搜查、破坏性搜查

强制检查不用签字，但强制搜查、破坏性搜查需要==办案部门负责人==批准。

强制搜查由侦查人员根据搜查现场的实际情况，自行判断采取，无需经过审批，一般应当在向被搜查人或者其家属说明阻碍搜查、妨碍公务应负的法律责任，经说服教育无果后行使。

来源《刑事程序规定释义与实务指南》 (2020年版)第540页。

:::

3、**对妇女保护**。搜查女性身体，应当由女工作人员进行，见证人也必须是女性。

4、对搜查中查获的犯罪证据及其放置地点，应当当场拍照后予以扣押，拍摄的照片应当加上文字说明附卷，必要的时候可以对搜查的过程录像。

（七）**搜查笔录的制作**

搜查的情况应当制作搜查笔录，由侦查人员和被搜查人或者他的家属、邻居或者其他见证人签名。

如果被搜查人拒绝签名，或者被搜查人在逃，他的家属拒绝签名或者不在场的，侦查人员应当在笔录中==注明==。


::: note

录音录像能够代替笔录的在行政案件当中有四种情况：
- 代替书面检查笔录
- 代替调解笔录
- 代替书面询问笔录（快速办理程序）
- 代替现场笔录（实施行政强制措施）



在刑事案件当中，录音录像都不能代替笔录，在刑事案件当中，录音录像代替的都是见证人。

:::
