## **二、取保候审**

### （一）**适用对象**

#### 1、**公、检、法机关对有下列情形之一的犯罪嫌疑人、被告人，==可以==取保候审**：

（1）可能判处==管制、拘役或者独立适用附加刑==的；

（2）可能判处有期徒刑以上刑罚，==采取取保候审不致发生社会危险性==的；

（3）患有==严重疾病、生活不能自理==，==怀孕或者正在哺乳自己婴儿的妇女=={.info}，==采取取保候审不致发生社会危险性=={.danger}的；

（4）羁押期限届满，==案件尚未办结，需要采取取保候审==的。

::: note

主要是指公安机关对于犯罪嫌疑人被刑事拘留、逮捕的案件，法定的侦查羁押期限已届满，但仍然不能结案，需要继续侦查的，可以将刑事拘留、逮捕变更为取保候审。

来源《刑事案件程序规定释义与实务指南》(2020年版) 第217条。

:::

（5）对拘留的犯罪嫌疑人，证据不符合逮捕条件，以及提请逮捕后，检察院不批准逮捕，==但需要继续侦查的，并且符合取保候审条件的，可以依法取保候审==。

#### 2、**不得适用的对象**：

（1）累犯;

::: note

对于累犯，不能适用取保候审、不能被判处缓刑、不能适用假释。

:::

（2）犯罪集团的主犯；

（3）==自伤、自残办法==逃避侦查的犯罪嫌疑人；

（4）严重暴力犯罪以及其他严重犯罪的犯罪嫌疑人等。


::: info 例外适用

（1）患有严重疾病、生活不能自理，怀孕或者正在哺乳自己婴儿的妇女，采取取保候审不致发生社会危险性的；

（2）羁押期限届满，案件尚未办结，需要采取取保候审的。

:::

### （二）**取保候审的审批和时限**

1、**依职权**。公、检、法机关根据案件具体情况，==可以直接主动地决定取保候审==。

2、**依申请**。被羁押的犯罪嫌疑人、被告人及其法定代理人、近亲属、辩护人、值班律师有权申请取保候审，公、检、法收到申请后，==应当在3日内作出决定==。

- **审批**：==县级以上公安机关负责人==批准；

- **期限**：==在公安机关侦查阶段不得超过12个月==，在此期间不得中断对案件的侦查。

::: note

在同一个诉讼阶段，多次适用取保候审的，应当连续计算取保候审期限；但是，从一个阶段进入后一个阶段，应当==重新计算取保候审的期限==。简言之，同一阶段连续计算，不同阶段重新计算。

:::


### （三）**提供保证人保证**

#### 1、**优先使用保证人保证的情形**

（1）对未成年人；

（2）年满75周岁的人。

::: tip

一老一小

:::
#### 2、**保证人的条件**

（1）与本案无牵连；

（2）==有能力==履行保证义务；

（3）享有政治权利，人身自由未受到限制；

（4）有固定的==住处和收入==。

#### 3、**保证人的数量**

（1）1-2名。

（2）应当==填写《取保候审保证书》==,并在保证书上==签名、捺指印==。

#### 4、**保证人的义务**：

（1）==监督==被保证人遵守相关规定；

（2）发现被保证人可能发生或者已经发生违反规定的行为，应当及时向执行机关==报告==；

#### 5、**保证人不愿继续担任担保或者丧失担保条件的处理**

（1）责令被取保候审人重新提出保证人或者缴纳保证金；

（2）作出变更强制措施的决定。

#### 6、**对保证人违规行为的处罚与救济**

  
（1）**处以罚款**：经==县级以上公安机关负责人==批准，对保证人处以==1千元-2万元==罚款；


::: tip 保证人123

行政暂缓行政拘留处罚3000元以下，取保候审1000元到20000元。

:::

::: info 

《六机关规定》第14条：对取保候审保证人是否履行了保证义务，由公安机关认定，对保证人的罚款决定，也由公安机关作出。

:::


（2）构成犯罪的，依法追究刑事责任；

（3）救济：对罚款不服，可以复议复核。3-57-57[+3-57-57]

**(四)提供保证金保证**

1、**保证金的数额**

::: note

在实践中，公安机关在确定某个案件的保证金数额时，应当考虑到本地区的经济发展水平和犯罪嫌疑人的经济状况，做到既能保证对犯罪嫌疑人的制约，使其不逃避、不妨碍侦查活动，又不影响被取保候审人及其家庭的基本生活。

来源《刑事案件程序规定释义与实务指南》(2020年版)第229页。

:::

（1）犯罪嫌疑人保证金==起点数额为一千元==；

（2）未成年的犯罪嫌疑人保证金==起点数额为五百元==。

::: warning

上不封顶。

:::

2、**保证金的交纳**

提供保证金的人，应当==一次性==将保证金存入公安机关取保候审保证金专门账户，保证金以==人民币==交纳 ；

3、**保证金的没收**

报==县级以上公安机关负责人==批准，制作没收保证金决定书。决定==没收5万元以上保证金=={.info}的，应当经==设区的市一级以上公安机关负责人=={.warning}批准 。

4、**没收保证金的救济**

可以复议复核。3-57-57 [+3-57-57]

::: note

没收保证金的决定，公安机关应当在三日以内向被取保候审人宣读，应当告知如果对没收保证金的决定不服，被取保候审人或者其法定代理人可以在五日以内向作出决定的公安机关申请复议，公安机关应当在收到复议申请后七日内作出决定。被取保候审人或者其法定代理人对复议决定不服的，可以在收到复议决定书五日以内向上一级公安机关申请复核一次。上一级公安机关应当在收到复核申请后七日以内作出决定。对上级公安机关撤销或者变更没收保证金决定的，下级公安机关应当执行。

:::

#### 5、**保证金的退还**

（1）没有违反取保候审期间规定，也没有重新故意犯罪的；

（2）具备撤案的相关情形的；

（3）制作退还保证金决定书，通知银行如数退还保证金。

#### 6、**涉嫌重新犯罪保证金的处理**

（1）在取保候审期间重新实施故意犯罪；

（2）负责执行的公安机关应当==暂扣==其交纳的保证金；

（3）待法院判决生效后，如果是故意犯罪，就没收保证金；如果是过失犯罪或不构成犯罪，退还保证金。


::: note

取保候审保证金由县级以上执行机关统一收取和管理。提供保证金的人应当将保证金存入执行机关指定银行的专门账户。保证金的没收、退还决定，应当由执行机关作出。

:::


### （五）**取保候审执行过程中的相关事项**

#### 1、**应遵守的义务**

::: note

应当制作《被取保候审人义务告知书》,一式三份，一份附卷，一份交给被取保候审人， 一份交执行机关。

:::

#### （1）**一般性义务**

::: note

一般义务是每个被取保候审的人都必须遵守的义务；

:::

①未经==执行机关==批准不得离开所居住的市、县；

::: note

注意和行政案件中的暂缓执行行政拘留期间应遵守的规定进行区分：行政案件是“==决定机关==”。

:::

②住址、工作单位和联系方式发生变动的，在==二十四小时内==向执行机关报告；

③在传讯的时候==及时==到案；

::: note

应当制作《传讯通知书》,由正本、副本和存根三联组成。

:::


④不得以任何形式干扰==证人==作证；

⑤不得毁灭、伪造==证据==或者串供。

#### （2）**特殊义务**

::: note

特殊义务是公安机关根据案件情况，责令特定被取保候审人遵守一项或多项规定。公安机关应当综合考虑案件的性质、情节、社会影响、犯罪嫌疑人的社会关系等因素，确定特定场所、特定人员和特定活动的范围。

:::

①不得进入与其犯罪活动等==相关联的特定场所==；


②不得与证人、被害人及其近亲属、同案犯以及与案件有关联的其他特定人员会见或者以任何方式通信；

③不得从事与其犯罪行为等相关联的特定活动；

④将护照等==出入境证件、驾驶证件==交执行机关保存。

::: info

应当制作《公安局保存证件清单》,一式三份，一份附卷，一份交证件持有人，一份交公安机关保管人员。

:::

#### 2、**执行机关**

（1）公安机关决定取保候审的，应当及时通知==被取保候审人居住地的派出所==执行；同时交付相关法律文书及相关材料。必要时，办案部门可以协助执行。

::: info 居住地

所谓居住地，既包括户籍所在地，也包括经常居住地。

:::

（2）人民法院、人民检察院决定取保候审的，负责执行的县级公安机关应当在收到法律文书和有关材料后==24小时以内==，指定被取保候审人居住地派出所核实情况后执行。

#### 3、**执行取保候审的派出所应当履行的职责**

（1）==告知==被取保候审人必须遵守的规定，以及违反规定或者在取保候审期间重新犯罪应当承担的法律后果；

（2）==监督、考察==被取保候审人遵守有关规定，及时掌握其活动、住址、工作单位、联系方式及变动情况；

（3）==监督==保证人履行保证义务；

（4）被取保候审人违反应当遵守的规定以及保证人未履行保证义务的，==应当及时制止、采取紧急措施==，同时==告知决定机关==。

::: warning

执行取保候审的派出所应当==定期==了解被取保候审人遵守取保候审规定的有关情况，并制作笔录。

:::

#### 4、**被取保候审人离开居住地的审批程序**

（1）被取保候审人有正当理由需要离开所居住的市、县的，应当==经负责执行的派出所负责人==批准；

（2）人民法院、检察院决定取保候审的，负责执行的派出所在批准被取保候审人离开所居住的市、县前，==应当征得决定取保候审的机关==同意。

#### 5、**对违规的被取保候审人的处理**

（1）交纳保证金的，根据情节，决定没收部分或全部保证金；

（2）情节较轻，不需要变更强制措施，允许再次取保候审的，责令其具结悔过、重新交纳保证金或者提出保证人；或者对其进行治安管理处罚;

::: info

①应当制作《公安局责令具结悔过决定书》,由==正本、副本和存根==三联组成。

②《治安管理处罚法》第60条第四项之规定，处==5日以上10日以下==拘留，并处==200元以上500元以下==罚款。

:::

（3）情节较重，不能继续适用取保候审，将其强制措施==变更为监视居住或逮捕==；对需要予以逮捕的，可以==对其先行拘留==。

### （六）**取保候审的解除程序**

1、**公安机关决定的取保候审**：办案部门呈请，应当经==县级以上公安机关负责人==批准，制作解除取保候审决定书、通知书，并及时通知负责执行的派出所、被取保候审人、保证人和有关单位。

2、**检法决定的取保候审**：检法作出解除取保候审决定，负责执行的公安机关根据决定书及时解除取保候审，并通知被取保候审人、保证人和有关单位。

3、**不再办理解除手续的情形**：

（1）变更取保候审为监视居住、拘留、逮捕的；`轻->重`

（2）移送审查起诉后人民检察院==继续取保候审或者变更保证方式==的；

（3）公安机关应当告知保证人解除保证义务或者退还保证金。

- **决定机关**：公、检、法
- **执行机关**：公安机关

## 不需要通知家属

## 对象
- **可以取保候审的对象**：
  - 可能判处管制、拘役或独立适用附加刑的
  - 可能判处有期徒刑以上，采取取保候审不致发生社会危险性的

  - 犯罪集团的主犯
  - 以自伤、自残办法逃避侦查的犯罪嫌疑人

- **申请**：
  - 犯罪嫌疑人、被告人及其法定代理人、近亲属和辩护人可以向公安机关、检察院或法院提出申请
  - 公安机关应当在收到申请后的3日内作出决定
- **审批**：
  - 县级以上公安机关负责人批准
- **期限**
  - 无次数限制
  - 在公安机关侦查阶段，不得超过12个月，在此期间不得中断对案件的侦查
  - 同一阶段连续计算，不同阶段重新计算

## 保证
- **保证人**：
  - 人数：1-2人
  - 条件：有固定住处和收入、享有政治权利、与本案无牵连、有能力履行保证义务
  - 责任：监督被保证人遵守规定，及时报告执行机关
  - 处罚：违反规定需承担法律责任，可能被罚款、拘留，构成犯罪的追究刑事责任
- **保证金**：
  - 金额：成年人1000元以上，未成年人500元以上
  - 管理：由县级以上执行机关（公安）统一收取、管理
  - 没收：违反规定，经告知后仍不改正的，没收保证金
  - 退还：遵守规定，取保候审期满后退还

## 遵守规定

- **一般性义务**
	- 未经批准不得离开市、县（擅自离开，逮捕，双批）
	- 住址、单位、联系方式变动，24小时内向执行机关报告
	- 传讯时及时到岸，情节严重或两次传讯不到，逮捕
	- 不得干扰证人作证
	- 不得毁灭、伪造证据或串供
- **特殊义务**
	- 场所
	- 活动
	- 人
	- 交证件（出入境证件、驾驶证）
- **离开居住地**
	- 公安决定：正当理由+执行机关及派出所负责人批准
	- 法检决定：正当理由+法/检同意+执行机关及派出所负责人批准


## 解除
- **撤销取保候审的情形**：
  - 不构成犯罪
  - 撤回起诉
  - 不起诉
  - 取保候审期限届满
  - 变更为监视居住、拘留、逮捕
- **程序**：法定情形出现后，执行机关应当及时解除取保候审，退还保证金，解除保证人义务，并通知被取保候审人

## 执行机关职责
- **执行机关**
	- 被取保候审人的居住地派出所
- **职责**
	- **告知规定**：告知被取保候审人应遵守的规定和违反规定的后果
	- **监督考察**：监督被取保候审人遵守规定，监督保证人履行保证义务
	- **制止违法行为**：发现被取保候审人或保证人违反规定，及时制止并处理
	- **定期了解**：定期了解被取保候审人的生活、工作等情况，并制作笔录
