## **八、辨认**

### （一）**目的**

为了查明案情。

### （二）**主持人**

不少于二名侦查人员。

### （三）**辨认**人

被害人、证人、犯罪嫌疑人。

### （四）**辨认对象**

犯罪嫌疑人、与犯罪有关的物品、文件、尸体、场所。

### （五）**辨认审批**

1、一般辨认：==民警决定==。

2、提解在押嫌疑人出所辨认：==县级以上公安机关主要负责人==批准。

### （六）**辨认过程**

1、**辨认前**：不得向辨认人展示辨认对象及其影像资料；

2、**个别辨认**：几名辨认人对同一辨认对象进行辨认时，应当由辨认人==个别==进行；

3、**混杂辨认**：量上： (包括辨认对象和陪衬)人不少于7人；物品不少于6件；照片不少于10张；质上：==特征要类似=={.warning}。

::: info 关联法条

公安机关组织辨认时，应当将辨认对象混杂在特征相类似的其他对象中，不得在辨认前向辨认人展示辨认对象及其影像资料，不得给辨认人任何暗示。

辨认犯罪嫌疑人时，被辨认的人数不得少于七人；对犯罪嫌疑人照片进行辨认的，不得少于十人的照片。

辨认物品时，混杂的同类物品不得少于五件；对物品的照片进行辨认的，不得少于十个物品的照片。

对场所、尸体等特定辨认对象进行辨认，或者辨认人能够准确描述物品独有特征的，陪衬物==不受数量的限制==。对场所、尸体等特定辨认对象进行辨认，或者辨认人能够准确描述物品独有特征的，陪衬物不受数量的限制。

:::


4、**秘密辨认**：对犯罪嫌疑人的辨认，辨认人不愿意公开进行时，可以在不暴露辨认人的情况下进行，并应当为其保守秘密；秘密辨认的结果只能==作为线索使用==，不可以作为证据使用。

### （七）**辨认笔录**

1、**辨认笔录**：对辨认经过和结果，应当制作辨认记录；

2、**签字**：由侦查人员、辨认人、见证人签名；

3、必要时，==应当对辨认过程进行录音录像==。


::: warning

办理行政案件过程中，辨认不需要见证人。

:::

## **九、技术侦查措施**

### （一）**技术侦查措施**

1、**阶段**：公安机关在立案后；

2、**审批**：==设区的市一级以上公安机关负责人==批准；

3、**实施**：==设区的市一级以上公安机关==负责技术侦查的部门；（刑技大队）

4、**对象**：犯罪嫌疑人、被告人以及与犯罪活动直接关联的人员；

5、**种类**：记录监控、行踪监控、通信监控、场所监控等措施；

6、**期限**：==3+3×N==;

7、**适用范围**——==国恐黑毒严逃=={.danger}。

（1）国、恐、黑、毒；

（2）严重暴力犯罪案件；

（3）集团性、系列性、跨区域性重大犯罪案件；

（4）利用电信、计算机网络、寄递渠道等重大犯罪案件，以及针对计算机网络实施的重大犯罪案件；

（5）其他可能判处七年以上有期徒刑以上的严重危害社会的犯罪案件；

（6）追捕被通缉或者批准、决定逮捕在逃的犯罪嫌疑人、被告人。

8、**技术侦查措施的解除**

（1）**有效期内**：

A. 办案部门认为需要解除的_——书面通知技术部门解除；

B. 技术部门认为需要解除的——报==设区的市一级公安机关负责人==批准——制作==解除技术侦查决定书==——及时通知办案部门。

（2）**有效期满**：技术部门应当立即解除。

9、**技术侦查措施的延长**

（1）**申请**：办案部门期满前提出申请；

（2）**审核**：技术部门审核；

（3）**批准**：==设区的市一级公安机关负责人==批准，制作延长技术侦查措施期限决定书。

10、**有效期内变更措施种类、适用对象**——重新审批(办案部门——设区的市一级公安机关批准)

11、**采用技术侦查收集材料的使用与管理**

（1）**用途特定**：侦查、起诉和审判。

（2）**管理**：无关要销毁；涉及三密要保密。

12、**采用技术侦查收集的材料作为证据使用**

（1）直接使用；

（2）决定书要附卷；（合法性）

（3）采取保护措施。 ( ==人+设备+方法== )

如果危及人身安全，或可能产生其他严重后果——不暴露身份和使用的技术设备、侦查方法等保护措施。

### （二）**控制下交付**

1、**目的**：为查明参与该项犯罪的人员和犯罪事实；

2、**审批**：==县级以上公安机关负责人==决定；

3、**案件范围**：涉及给付毒品等违禁品或者给付财物的犯罪活动。

4、**收集的材料可以作为证据使用**。如果可能产生危及人身安全，可以采取不暴露有关人员身份等保护措施。

### （三）**隐匿身份侦查**

1、**目的**：为了查明案情；

2、**审批**：必要时，==县级以上公安机关负责人==决定；

3、**谁去侦查**：侦查人员、公安机关指定的其他人员；

4、**方法底线**：不得诱使他人产生犯意、公共安全、重大人身危险；

5、**收集的材料可以作为证据使用**。如果可能产生危及人身安全，可以不暴露有关人员身份等保护措施。

## **十、通缉**

### （一）**通缉的对象**

1、应当逮捕而在逃①;

2、越狱逃跑的犯罪嫌疑人、被告人或罪犯②。

::: note

①**包括两种人**：即包括已经检察机关批准逮捕的，也包括公安机关经过调查取证，认为犯罪嫌疑人符合逮捕条件，应当予以逮捕，但尚未提请检察机关批准的。

来源《公安机关刑事案件法律文书制作指南与范例》(2020年版) 第369页。

②所谓越狱逃跑的犯罪嫌疑人、被告人，是指从羁押的看守所内脱逃出去的被拘留、被逮捕的犯罪嫌疑人或者被逮捕的被告人。所谓越狱逃跑的罪犯，是指从服刑的监狱、看守所、未成年犯管教所等监管场所脱逃出去的罪犯。 

来源《公安机关办理刑事案件程序规定释义与实务指南》(2020年版)第666页。

:::

### （二）**通缉令的发布权限和范围**

1、==县级以上公安机关==在自己管辖的范围内，可以直接发布。

2、超过管辖范围，报请有权决定的上级公安机关发布。如==跨县-市；跨市-省；跨省-公安部==。

3、发布范围，由==签发通缉令的公安机关负责人==决定。

### （三）**通缉令的内容**

1、个人基本信息；

2、口音、行为习惯；

3、附近期照片；

4、可以附指纹以及其他物证的照片(内部联);

5、除了保密外，应当写明发案时间、地点和简要案情；

6、必须加盖发布机关印章。

### （四）**通缉令的补发**

1、**前提**：通缉令发出后，发现了新的重要情况；

2、必须注明原通缉令的编号和日期。

### （五）**通缉令的效力和执行**

1、及时布置查缉。公安机关接到通缉令后，应当及时布置查缉。

2、抓获后依法羁押。抓获犯罪嫌疑人后，报经==县级以上公安机关负责人==批准，凭通缉令或者相关法律手续羁押。

3、==通知发布机关核实，办理交接手续==。

### （六）**通缉令的选配措施**

#### 1、**悬赏通告**

（1）**审批**：==县级以上公安机关负责人==批准，可以发布悬赏通告。

 (2) **内容**

①写明悬赏对象的基本情况。悬赏对象包括追缴的涉案财物、证据、查获犯罪嫌疑人。

②赏金的具体数额。不能笼统地写“必有重谢”“定有重赏”等。

#### 2、**边控措施**

（1）==县级以上公安机关负责人==审核，==层报省级公安机关==批准

（2）紧急情况下，县级公安机关先给边控部门出具公函，7日内补办手续。

### （七）**通缉令、悬赏通告、边控措施的撤销**

1、**人已到案**：自动投案和被抓获。

2、**人已死**：被击毙。

3、其他情形。

- **布置查辑**：应当及时布置

  - 凭通缉令或相关法律文书羁押

- **审批**：县级以上公安机关负责人

  - 不能写“必有重赏"1000-2000"等无明确表达的
- **审批流程**：县级以上公安机关审核报省级公安机关审批

## 边控措施
- **紧急情况下**：县级以上公安机关先出公函，边控部门先执行，但应在7日内按照规定程序办理
- **撤销措施**：被击毙、被抓获、自动投案、不需要等
