## **刑事强制措施总图**

**刑事诉讼法规定了五种**：拘传、取保候审、监视居住、拘留和逮捕。

**核心功能**：预防，即防止发生社会危害性。

**原则**：比例原则和实时变更原则。

- **比例原则**：根据犯罪嫌疑人、被告人的人身危险性高低，选择相应的强制措施。危险性低则适用较轻的措施，危险性高则适用较重的措施。
- **变更原则**：随着人身危险性的变化，可以变更强制措施。如被取保候审人违反规定，可转为监视居住或逮捕；反之，如危险性降低，可从逮捕变更为取保候审或监视居住。

## **一、拘传**

### （一）**决定主体**：公、检、法；

### （二）**执行主体**：公、检、法；

::: warning

作为拘传来说，公检法分别可以决定拘传。公检法自己决定自己执行：公安上决定的拘传公安机关自己执行；检察院决定的拘传检察院自己执行；法院决定的拘传法院自己执行。

==剩下强制措施取保候审，监视居住，拘留、逮捕执行主体只有公安机关=={.warning}。

:::

### （三）**适用对象**：未被羁押的犯罪嫌疑人、被告人；

### （四）**审批**：报==县级以上公安机关负责人==批准；（只有书面拘传）

### （五）**拘传地点**：==犯罪嫌疑人所在市、县公安机关执法办案场所==进行讯问；（唯一的地点）

### （六）**适用前提**

1、已立案侦查的犯罪嫌疑人、被告人；

2、对经传唤没有正当理由不到案的犯罪嫌疑人，也可以根据案件情况直接拘传犯罪嫌疑人。

### （七）**适用程序**

1、执行人员不得==少于2人==。

2、==应当出示拘传证=={.danger}，没有例外。

3、期限：（==12-24==）

刑事传唤、拘传持续的时间不得超过12小时，不得以连续传唤的形式变相拘禁犯罪嫌疑人；案情重大、复杂，需要采取拘留、逮捕措施的，传唤、拘传持续的时间不得超过24小时。拘传的时间从犯罪嫌疑人到案时开始计算。

::: note

《高检规则》第83条第二款： ……两次拘传间隔的时间一般不少于12小时，不得以连续拘传的方式变相拘禁犯罪嫌疑人。

:::

# 拘传

## 审批
- 县级以上公安机关负责人

## 决定主体
- 公、检、法

## 对象
- 犯罪嫌疑人、被告人

  - 根据案件情况需要拘传的嫌疑人→直接拘传
  - 无正当理由拒绝公安机关传唤的→间接拘传

## 执行主体
- 公、检、法
- 必须出具拘传证

- 犯罪嫌疑人所在市、县公安机关执法办案场所

## 签名
- 由犯罪嫌疑人在拘传证上填写到案时间、结束时间，并签名捺指印

## 时限
- 12小时
- 重大复杂+可能拘留逮捕的，24小时
- 从到案时间开始计算（次时）
- 拘传之间间隔不少于12小时（高检规则）
