## **五、逮捕**

### （一）**决定机关、批准机关和执行机关**

1、检察院 —— 批准和决定机关

2、人民法院 —— 决定机关

3、公安机关 —— 执行机关

| 机关类型 | 具体职责                                                                       |
| ---- | -------------------------------------------------------------------------- |
| 检察院  | 批准机关（审查公安机关提请的逮捕申请）、决定机关（可直接决定逮捕）                                          |
| 人民法院 | 决定机关（对符合条件的案件直接决定逮捕）（==5+8+转==）<br>  ·告诉才处理（5）<br>  ·轻微刑事案件（8）<br>  ·公诉转自诉 |
| 公安机关 | 执行机关（负责执行检察院批准或法院决定的逮捕程序）                                                  |


### （二）**适用对象**

#### 1、**一般逮捕**：

对有证据证明有犯罪事实，可能判处徒刑以上刑罚的犯罪嫌疑人，采取取保候审尚不足以防止发生下列社会危险性的，==应当提请逮捕==：

::: info 有证据证明有犯罪事实

有证据证明有犯罪事实，是指同时具备下列情形：

（一）有证据证明发生了犯罪事实；

（二）有证据证明该犯罪事实是犯罪嫌疑人实施的；

（三）证明犯罪嫌疑人实施犯罪行为的证据已有查证属实的。“犯罪事实”既可以是单一犯罪行为的事实，也可以是数个犯罪行为中任何一个犯罪行为的事实。

:::

①可能实施新的犯罪的；

②有危害国家安全、公共安全或者社会秩序的现实危险的；

③可能毁灭、伪造证据，干扰证人作证或者串供的；

④可能对被害人、举报人、控告人实施打击报复的；

⑤企图自杀或者逃跑的。

#### 2、**径行逮捕**

①对有证据证明有犯罪事实，==可能判处十年有期徒刑以上刑罚==的，应当提请逮捕；

②对有证据证明有犯罪事实，==可能判处徒刑以上刑罚，曾经故意犯罪或者身份不明的==，应当提请逮捕。

#### 3、**转化逮捕**

被取保候审、监视居住的犯罪嫌疑人、被告人违反取保候审、监视居住规定，==情节严重的==，可以予以逮捕。

（1）**违反取保候审规定转化逮捕情形**：

①涉嫌故意实施==新==的犯罪行为；

②有危害国家安全、公共安全或者社会秩序的现实==危险==的；

③实施毁灭、伪造证据或者干扰==证人==作证、串供行为，足以影响侦查工作正常进行的；

④对==被害人、举报人、控告人==实施打击报复的；

⑤企图自杀、逃跑，逃避侦查的；

⑥未经批准，擅自离开所居住的市、县，情节严重的；或者两次以上未经批准，擅自离开所居住的市、县的；

⑦经传讯无正当理由不到案，情节严重的，或者经两次以上传讯不到案的；

⑧违反规定进入特定场所、从事特定活动或者特定人员会见、通信两次以上的。


（2）**违反监视居住规定转化逮捕情形**：

①涉嫌故意实施新的犯罪行为；

②实施毁灭、伪造证据或者干扰证人作证、串供行为，足以影响侦查工作正常进行的；

③对被害人、举报人、控告人实施打击报复的；

④企图自杀、逃跑，逃避侦查的；

⑤未经批准，擅自离开执行监视居住的住所，情节严重的；或者两次以上未经批准，擅自离开执行监视居住的处所的；

⑥未经批准，擅自会见他人或者通信，情节严重的，或者两次以上未经批准，擅自会见他人或者通信的；

⑦经传讯无正当理由不到案，情节严重的，或者经两次以上传讯不到案的；


### （三）**审批程序**

#### 1、**提请逮捕**：

应当经县级以上公安机关负责人批准，制作提请批准逮捕书，连同案卷材料、证据，一并移送检察院审查批准；==犯罪嫌疑人自愿认罪认罚的，应当记录在案==，并在提请批准逮捕书中写明有关情况。

#### 2、**审查批准**——==7日内==

##### （1）**不批准逮捕**

①通知补充侦查，公安机关应当按照检察院的补查提纲补充侦查；补充侦查完毕，认为符合逮捕条件，应当重新提请批准逮捕；

②对于检察院不批准逮捕而未说明理由的，公安机关可以要求人民检察院说明理由。
 
::: info 不批准理由

**不批准的理由**通常有如下几个：一、不构成犯罪；二、虽构成犯罪，但依法不应当追究刑事责任；三、虽构成犯罪，但不可能判处徒刑以上刑罚；四、虽构成犯罪，但==采取取保候审或监视居住更合适==；五、证据不足。

:::

③对不批准逮捕的被拘留人释放

公安机关在收到不批准逮捕决定书后，==如果犯罪嫌疑人已被拘留，应当立即释放==，发给释放证明书，并在执行完毕后3日内将执行回执送达作出不批准逮捕决定的检察院。

④对不批准逮捕决定要求复议、提请复核的程序（==5-7-5-15=={.warning}）

**复议**：公安机关应当在收到不批准决定书后==五日内==制作要求复议意见书，报经县级以上公安机关负责人批准后，送交同级人民检察院复议，检察院收到复议意见书和案卷后==7日内==，作出是否变更的决定。

**复核**：公安机关应当在收到复议决定书后==五日内==制作提请复核意见书，报经县级公安机关负责人批准后，连同复议决定书一并提请上一级检察院复核，===上一级检察院===收到后==15日内==做出是否变更的决定。

##### （2）**批准逮捕**

1、==县级以上公安机关负责人==签发逮捕证，==立即执行==，并在执行完毕后==三日内==将执行回执送达检察院。如果未能执行，也应当将回执送达检察院，并写明未能执行的原因。

2、执行逮捕的人员==不得少于2人==，必须出示逮捕证；

3、**逮捕后三件事**

（1）应当立即将被逮捕人送看守所羁押； (==执行机关==)

（2）除无法通知（拘留后三件事多一个条件——==国恐+有碍侦查=={.warning}）的以外，应当在逮捕后==24小时以内=={.info}，通知被逮捕人的家属； (==决定机关==)

（3）在逮捕后的二十四小时以内进行讯问。在发现不应当逮捕的时候，必须立即释放，发给释放证明。(==决定机关==)

4、**逮捕后的羁押期限**（==2+1+2+2+X==）

（1）**同级检察院**： 一般不超过2个月

（2）**上一级检察院**：再延长1个月，条件是案情重大复杂、期限届满不能侦查终结的案件。

（3）**省级检察院**：再延长2个月，条件是==交==通十分不便的边远地区的重大复杂案件、重大的犯罪==集==团案件、==流==窜作案的重大复杂案件、犯罪涉及面==广==，取证困难的重大复杂案件。

（4）**省级检察院**：再延长2个月，条件是可能判处十年以上有期徒刑以上刑罚。

（5）**全人常**：再延长X个月，条件是特殊案件，最高检报请全人常批准延期审理。

（6）**期限的重新计算**：发现另有重要罪行。制作《重新计算侦查羁押期限通知书》重要罪行，是指与逮捕时的罪行不同种的重大犯罪以及同种犯罪并将影响罪名认定、量刑档次的重大犯罪。

（7）**期限的开始计算**：经==县级以上公安机关负责人==批准，==查清身份之日起==。对于犯罪事实清楚，证据确实、充分，确实无法查清其身份的，按其自报的姓名移送人民检察院审查起诉。

## **六、其他规定**

### （一）**公安机关采取强制措施不当的纠正程序**

公安机关发现对犯罪嫌疑人采取强制措施不当的，==应当及时撤销或者变更==。犯罪嫌疑人在押的，应当及时释放。公安机关释放被逮捕的人或者变更逮捕措施的，应当==通知==批准逮捕的人民检察院。

### （二）**对羁押必要性检察建议的处理**

犯罪嫌疑人被逮捕后，人民检察院经审查认为不需要继续羁押，==建议予以释放或者变更强制措施的，公安机关应当予以调查核实==。认为不需要继续羁押的，应当予以释放或者变更强制措施。认为需要继续羁押的，应当说明理由。公安机关应当在==十日内==将处理情况通知人民检察院。

（三）**申请变更强制措施**

犯罪嫌疑人及其法定代理人、近亲属或者辩护人有权申请变更强制措施。公安机关应当在收到申请后==三日以内==作出决定；不同意变更强制措施的，应当告知申请人，并说明理由。

（四）**强制措施变更的法律手续**

取保候审变更为监视居住的，取保候审、监视居住变更为拘留、逮捕的，==对原强制措施不再办理解除法律手续==。（轻->重）

（五）**移送审查起诉后强制措施的衔接**

案件在取保候审、监视居住期间移送审查起诉后，人民检察院决定重新取保候审、监视居住或者变更强制措施的，对原强制措施不再办理解除法律手续。
