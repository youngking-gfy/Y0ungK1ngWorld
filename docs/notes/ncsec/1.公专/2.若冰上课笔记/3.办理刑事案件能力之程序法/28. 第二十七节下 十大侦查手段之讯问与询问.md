### **一、讯问犯罪嫌疑人**

#### （一）**传唤的对象**

不需要拘留、逮捕的犯罪嫌疑人。

::: tip

所谓不需要拘留逮捕，既包括犯罪嫌疑人所犯罪行较轻，不需要拘留、逮捕，也包括犯罪嫌疑人的犯罪事实和证据尚未查清，暂时还不符合拘留、逮捕条件。

《公安机关办理刑事案件程序规定释义与实务指南》(2020年版) 第473页。

:::

#### （二）**传唤的审批——办案部门负责人**

#### （三）**传唤的方式**

1、**书面传唤**：出示==传唤证和警察证==一到案后，责令犯罪嫌疑人==在传唤证上填写到案时间，结束时，在传唤证上填写结束时间=={.warning}。==拒绝填写的，侦查人员在传唤证上注明=={.info}。

2、**口头传唤**：==现场==发现一出示警察证一在==讯问笔录==中注明犯罪嫌疑人的到案方式，并由犯罪嫌疑人注明到案时间和传唤结束时间。


::: danger

刑事无强制传唤，强制传唤是行政强制措施。

:::

3、**注意**：对自动投案或群众扭送到公安机关的犯罪嫌疑人，==可以==依法传唤。

#### （四）**传唤时间**

1、传唤持续时间==不得超过12小时==。

2、延长==传唤至24小时==：案件特别重大、复杂，需要采取拘留、逮捕措施的，经==办案部门负责人批准==。


| 传唤种类 | 审批              | 时限          | 备注      |
| ---- | --------------- | ----------- | ------- |
| 行政   | 无+口头或书面经办案部门负责人 | 8-24        | 通知家属    |
| 治安   | 无+口头或书面经办案部门负责人 | 8-==12==-24 | 通知家属    |
| 刑事   | 无+书面办案部门负责人     | 12-24       | 可以不通知家属 |


#### （五）**讯问地点**

1、**羁押期间**：==看守所==——讯问室；==拘留所、强戒所、监狱==——执行场所；

2、**非羁押期间**： (现、住、办、医)

（1）原则上在==公安机关办案场所的讯问室=={.warning}；

（2）特殊情况：==现场（情况紧急）=={.warning}、医院和住处（伤病、残疾、怀孕）;

（3）不需要拘留逮捕的犯罪嫌疑人——==办案部门负责人批准==——在执法办案场所或其住所。

#### （六）**讯问前的准备工作**

1、制定讯问计划；

2、应当通知合适的成年人到场

::: warning
- ==无大人必然排除==
- 只有法定代理人[+法定代理人]可以代为行使未成年犯罪嫌疑人的诉讼权利
:::

3、**翻译人员到场**：讯问聋、哑人，外国人，少数民族，语言不通时，都应当有翻译参加。要注明翻译人员的姓名、工作单位和职业。

::: warning

==无翻译必然排除==。

:::

4、讯问女性未成年犯罪嫌疑人，应当==有女工作人员==在场。

::: tip

行政案件没有要求。

:::

5、**准备录音、录像设备**：可能判无期、死刑或者其他重大犯罪案件，==应当录音录像==；

6、**进行安全检查**。对传唤、拘传的犯罪嫌疑人，应当进行安全检查，无须办理检查证。

7、**信息采集**。进行安全检查后，应当根据办案需要，按照操作规范对违法犯罪嫌疑人进行信息采集，对采集的信息应当及时录入信息库进行核查、比对，并按照规定妥善保管。

#### （七）**讯问过程注意事项**

1、**讯问主体**：==不少于二名==侦查人员。

2、**讯问规则**：个别进行。

3、**讯问内容**：犯罪嫌疑人的基本情况（个人 + 前科 + 政治面貌、工作单位 + 特殊身份 + ==家庭成员==，）+ 告知权利义务（如实陈述+无关问题可以拒绝回答 + 申请回避 + 聘请律师等，告知如实供述自己罪行可以从宽处理以及认罪认罚的法律规定。）+ 是否实施犯罪 + 听其陈述有罪的情节或无罪的辩解 + 继续追问。

::: warning 家庭成员

刑事案件是应当问，行政案件是必要时问。

:::

2020新增：==政治面貌、工作单位、认罪认罚==的法律规定。 

4、**人权保障**：传唤、拘传、讯问期间，==应当保证犯罪嫌疑人的饮食和必要的休息时间==，并记录在案；不得刑讯逼供或者使用威胁、引诱、欺骗以及其他非法的方法获取供述。

5、**讯问笔录的核对或宣读**、签字。交犯罪嫌疑人核对或者向他宣读一核对有误（有遗漏或差错）,应当允许其补充或更正、并捺指印；核对无误，==逐页签名捺指印==，并在末页写明“以上笔录我看过（或向我宣读），和我说的相符。”拒绝签名捺指印，侦查人员在笔录上注明。


::: tip 讯问笔录和询问笔录

讯问笔录：核对、宣读、逐页==签字且捺指印==，修改处==只捺指印=={.warning}。

==询问笔录=={.danger}：签字或捺指印，修改处只捺指印。

:::

6、**犯罪嫌疑人亲笔书写供词**。应当准许，必要时，侦查人员也可要求其亲自书写。犯罪嫌疑人应当在亲笔供词上==逐页签名、捺指印==。侦查人员收到后，应当在首页右上方写明“于某年某月某日收到”,并签名。

#### （八）**讯问结束后对供述的核查处理**

对犯罪嫌疑人供述的犯罪事实、无罪或者罪轻的事实、申辩和反证，以及犯罪嫌疑人提供的证明自己无罪、罪轻的证据，公安机关都应当认真核查；对有关证据，无论是否采信，都应当如实记录、妥善保管，并连同核查情况附卷。




### **二、询问证人、被害人**

#### （一）**询问主体**：==二名以上==侦查人员。

#### （二）**询问地点**

1、**现场询问**——==应当出示人民警察证==；

2、**所在单位、住处或其提出的地点**

（1）应当出示==询问通知书==——经==办案部门负责人==批准；

（2）应当==出示人民警察证==。

3、必要时，可以书面、电话或当场通知证人、被害人到公安机关提供证言。

#### （三）**询问前的准备工作**

1、应当了解证人、被害人的身份，证人、被害人、犯罪嫌疑人之间的关系。

2、通知合适成年人到场。

3、翻译人员到场。

4、必要时，询问过程录音录像。

#### （四）**询问过程注意事项**

1、个别进行。

2、问明个人基本情况。

3、告知权利义务。

4、询问案件情况。

5、侦查人员不得向其泄露案情、不得表示对案件的看法。

6、侦查人员严禁使用暴力、威胁等非法方法询问证人、被害人。

7、对涉及国家秘密、商业秘密和个人隐私的，应当保密。

8、对正在抢救的证人、被害人，应当重点问清作案人姓名、特征、作案经过。询问时，可以请医生、被害人的家属作为证人。

# 讯问犯罪嫌疑人

## 传唤
- **书面传唤**
  - 传唤证上由坏人注明到案和结束时间
- **口头传唤**
  - 在讯问笔录中注明到案方式，并由其（坏人）注明到案和结束时间
- **自动投案或扭送到案**：传唤

## 传唤时限
- **12小时**：办案部门负责人批准
- **24小时**：办案部门负责人批准
  - （重大复杂+需要采取拘留逮捕措施的）

## 讯问地点
- **羁押期间**
  - 看守所：讯问室
  - 拘留所、监狱、强制隔离戒毒所：执行场所
- **未羁押期间**
  - 一般：应当在公安机关执法办案场所的讯问室
  - 特殊：
	  - 现场（情况紧急）
      - 住处或医院
	      - 严重疾病、残疾、怀孕
  - 不需要拘留、逮捕
	  - 住处
	  - 执法办案场所

## 讯问前
- 制定讯问计划
- 讯问未成年人，应当通知合适成年人到场
  - 未到→绝对排除
- 翻译人员到场
- 准备录音录像
  - 应当：死刑、无期、重大犯罪案件
- 进行人身安全检查和信息采集

## 讯问中
- 告知权利义务
  - 认罪认罚的法律规定
- 个人基本信息
  - 政治面貌工作单位
- 是否有犯罪行为
  - 有罪的供述
  - 无罪的辩解
- 应保证饮食和必要的休息时间，并记录
- 严禁刑讯逼供，做好保密工作
- 不少于两名侦查人员

## 讯问后
- 核对、宣读
  - 有误或遗漏
    - 应当补充、更正，并捺指印
  - 无问题
    - ==逐页签名捺指印==
- 公安机关对其供述的核查：有罪、无罪、轻重。无论是否采信，都要如实记录妥善保管，并连同核查情况附卷

## 自行书写
- 犯罪嫌疑人自书（应当准许）
  - 嫌疑人逐页签名捺指印；侦查人员在首页右上方写明“于某年某月某日收到”并签名
- 侦查人员记录
