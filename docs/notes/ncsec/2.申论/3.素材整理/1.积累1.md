### **名言警句积累**

::: card title="为国也，观俗立法则治，察国事本则宜" icon="svg-spinners:12-dots-scale-rotate"

【例文】“为国也，观俗立法则治，察国事本则宜。”奋斗目标越是宏伟，越需要激发社会主义民主政治的新优势;改革发展的任务越是繁重，越需要把各项事业纳入法治化轨道。今天的内蒙古，正处于全面深化改革的攻坚阶段和全面建成小康社会的关键时刻，必须更加注重发挥法治的规范和引领作用，以法治谋求最大的社会共识，以法治凝聚改革发展的巨大力量。

【典故】出自战国商鞅著作汇编《商君书》，为国也，观俗立法则治，察国事本则宜。不观时俗，不察国本，则其法立而民乱，事剧而功寡。意思是，治理国家，在考察风俗民情的基础上立法，才能治理好，弄清国情、抓住根本，才能制定出适宜的政策。如果不考察当时的风俗，不弄清国家的情况，法令政策制定了民众也会混乱，政务再繁忙也是收效甚微。

【赏析】决胜全面小康，需要民主法治护航。从保障人民民主到发展社会主义市场经济，从改革开放到国家长治久安，从建设政治文明到构建和谐社会，法治既是全面建成小康社会的重要内容和目标，又是全面建成小康社会的制度动力和根本保障。我们要坚持党的领导、人民当家作主和依法治国的有机统一，积极探索推进民主法治建设制度化、规范化、程序化的新途径，使法律成为社会运行的普遍原则，让法治精神成为社会崇尚的普遍共识。


:::



::: card title="凡观物有疑，中心不定，则外物不清；吾虑不清，则未可定然否也。" icon="svg-spinners:12-dots-scale-rotate"


【例文】在补足精神之钙中把准政治方向。“凡观物有疑，中心不定则外物不清；吾虑不清，则未可定然否也。”政治上的坚定源于理论上的清醒。共产主义、社会主义的理论基础是马克思主义，丢掉了马克思主义的这个思想武器，党就会立场不稳、迷失方向。

【典故】出自《荀子·解蔽》，凡观物有疑，中心不定，则外物不清；吾虑不清，则未可定然否也。意思是，大凡观察事物有疑惑，内心不确定，就会对外界事物认识不清:自己的思想混乱不清，那就不能判断是非。

【赏析】方向决定道路，道路决定命运。政治方向是一个政党所确立的奋斗目标，集中反映了政党所代表阶级的根本利益和共同意志，引领着党的事业建设和发展。党员干部要进一步增强马克思主义理论武装的战斗力，进一步坚定理论自信，对举什么旗、走什么路时刻保持清醒头脑，在纷繁复杂的形势变化中把准政治方向不偏航。

:::


::: card title="立身百行，以学为基" icon="svg-spinners:12-dots-scale-rotate"


【例文】立身百行，以学为基。面对当今世界百年未有之大变局，面对错综复杂的国际环境和艰巨繁重的国内改革发展稳定任务，面对进行伟大斗争、伟大工程、伟大事业、伟大梦想的波澜壮阔实践，我们党要团结带领全国各族人民抓住和用好我国发展重要战略机遇期，坚持和发展中国特色社会主义，统筹推进“五位一体”总体布局、协调推进“四个全面”战略布局，实现党的奋斗目标，必须更加崇尚学习、积极改造学习、持续深化学习，不断增强适应新时代党和国家事业发展要求的能力。

【典故】出自元代许名奎的《劝忍百箴》，立身百行，以学为基。意思是，在安身立命的诸多本领中，学习是最为基本的。

【赏析】我们党依靠学习创造了历史，更要依靠学习走向未来。抓好全党大学习、千部大培训，全面增强执政本领，才能持续推动党和国家事业蓬勃发展，才能实现“两个一百年”奋斗目标，实现中华民族伟大复兴的中国梦。

【例文】“天下大势，浩浩汤汤，顺之者昌，逆之者亡。”中华民族伟大复兴，就是这样的浩荡大势;实现祖国完全统一，则是民族复兴的必然要求。携手推动民族复兴，实现和平统一目标;探索“两制”台湾方案，丰富和平统一实践;坚持一个中国原则，维护和平统一前景;深化两岸融合发展，夯实和平统一基础;实现同胞心灵契合，增进和平统一认同。

::: card title="河汉纵且横，北斗横复直" icon="svg-spinners:12-dots-scale-rotate"


【例文】“河汉纵且横，北斗横复直。”自古以来，北斗七星就是中国人辨明方向、把握时节的标志。如今，一颗颗北斗导航卫星闪耀天际，组网形成全球卫星导航系统，为人类提供一流的卫星导航服务，指引着人们追逐梦想、走向远方的脚步。

【典故】出自南朝沈约《夜夜曲》，河汉纵且横，北斗横复直。星汉空如此，宁知心有忆?孤灯暖不明，寒机晓犹织。零泪向谁道，鸡鸣徒叹息。意思是，银河纵横穿流、星斗横竖移动;银河与北斗星都是在无知无情的空自流转，又怎知我心中在想念一个人?空房之内，一盎孤灯半明不灭，不管天寒地冻，依然踏起织机，织起布来。泪流不止可又能向谁诉说呢?只能听着鸡鸣声发出一声声的叹息。

【赏析】不久前，伴随着长征三号乙运载火箭腾空而起，北斗三号最后一颗全球组网卫星在西昌卫星发射中心升空。北斗导航系统从无到有，从弱到强，充分彰显了中国智慧、中国速度、中国精度，为世界卫星导航的发展贡献了中国方案，更说明只要矢志创新，中国完全可以自主掌握核心技术。作为中国自主创新的结晶，北斗导航系统的发展历程浓缩着中国科技创新的不凡之路，写照着中国人向着星辰大海进发的不屈志气。

::: card title="执大象，天下往" icon="svg-spinners:12-dots-scale-rotate"

【例文】“执大象，天下往。”回首2013年金秋，习近平主席提出建设“丝绸之路经济带”和“21世纪海上丝绸之路”重大倡议。高瞻远瞩的构想，顺应时代潮流的倡议,“一带一路”一经提出，全球瞩目，应者云集。近6年来，被誉为21世纪伟大叙事的“一带一路”建设，以共商共建共享为原则，以和平合作、开放包容、互学互鉴、互利共赢的丝路精神为指引，以打造利益共同体、责任共同体、命运共同体为合作目标，展现出强大国际影响力、道义感召力、合作吸引力，汇聚起参与各国的力量，掀开了世界发展进程新的一页。

【典故】出自老子《道德经》，执大象，天下往。往而不害，安平太。乐与饵，过客止，道之出口，淡乎其无味，视之不足见，听之不足闻，用之不足既。意思是，哪里有“道”，天下的人便会向往哪里，大家都向“道”，天下便会安和太平。“道”犹如美妙的音乐和美食，能够使过路的人为之止步但要说出什么是“道”，它尝不出味道，看也看不见，听也听不见，而他的作用却是无穷无尽的!

【赏析】共建“一带一路”，承载着人类对文明交流的渴望、对和平安宁的期盼、对共同发展的追求、对美好生活的向往，是历史潮流的沿续，也是面向未来的正确抉择。从理念转化为行动，从愿景转变为现实，共建“一带一路”已完成总体布局，向着落地生根、持久发展的阶段迈进。在保持健康良性发展势头的基础上，积土成山、积水成渊，推动共建“一带一路”向高质量发展转变，我们就一定能更好造福各国人民，迎来更加美好的光明未来。

::: card title="天地与我并生，而万物与我为一" icon="svg-spinners:12-dots-scale-rotate"

【典故】出自庄子《齐物论》，夫天下莫大于秋豪之末，而太山为小;莫寿乎殇子，而彭祖为夭。天地与我并生，而万物与我为一。意思是，化自然于无为之中，顺应天命，不要刻意去追求“我”的欲求，而破坏自然之道。让我免除了物我之别，大小之分，体验“无往而非我之妙”

::: card title="筚路蓝缕，以启山林" icon="svg-spinners:12-dots-scale-rotate"

【例文】楚人“筚路蓝缕，以启山林”，才能“不鸣则已，一鸣惊人”各级领导干部要带头做“开山斧”，敢接最烫手的山芋、碰最硬的钉子、攻最难攻的碉堡，把科学精准防控和加快湖北重振抓实抓细抓落地。

【典故】出自《左传·宣公·宣公十二年》，昔我先王熊绎辟在荆山，筚路蓝蒌以处草莽，跋涉山林以事天子，唯是桃弧棘矢以共王事。意思是驾着简陋的车，穿着破烂的衣服去开辟山林。形容创业的艰苦。

【赏析】为民造福是我们最重要的政绩，也是我们工作最终的评价标准。无论什么时候，我们都要牢记初心使命，坚持人民至上，多做打基础、利长远、惠民生的实事。当前和今后一段时期，我们要慎终如始、再接再厉，在严格落实常态化疫情防控措施的前提下，加快推动经济运行回归常态、公众生活恢复正常。

::: card title="不谋全局者，不足谋一域" icon="svg-spinners:12-dots-scale-rotate"

【例文】“==不谋万世者，不足谋一时;不谋全局者，不足谋一域==。”面对变化，如果应对有方、化解有术,“失之东隅”后也能“收之桑榆”如果善于乘势而上、顺势而为，“山重水复”后也能“柳暗花明”。化危为机的本领不是与生俱来的，而是在困难、险境甚至绝境中摔打练出来的。要在复杂严峻的斗争中==经风雨、见世面、壮筋骨==，通过反复实践逐渐提升对势态的规律性认识和把握能力，做到“==任凭风浪起，稳坐钓鱼台==”。

【典故】出自清代陈澹然《寤言二·迁都建藩议》，不谋万世者，不足谋一时;不谋全局者，不足谋一域。意思是，从全局的角度考虑问题，即使治理好一方地区，也是微不足道的。不能制定长久的国家政策，一时的聪明也是微不足道的。

【赏析】习近平总书记强调，要坚持用全面、辩证、长远的眼光分析当前经济形势，努力在危机中育新机、于变局中开新局。当前，我们正面临百年未有之大变局，组工干部当有“春江水暖鸭先知”的敏锐，在复杂多变的国际国内环境中善感水温、知水情、顺水势，不断提高驾驭风险化危为机的本领。

::: card title="处大事贵乎明而能断" icon="svg-spinners:12-dots-scale-rotate"


【例文】“==处大事贵乎明而能断==。”在危机中育新机，于变局中开新局，推动高质量发展是根本要求，不迷失方向，莫自乱方寸。

【典故】出自明代薛瑄《从政录》，处大事贵乎明而能断，不明固无以知事之当断，然明而不断,亦不免于后艰矣。意思是，处理重要的大事情必须了解事情真相才能下结论，对事情的起因不明了不能了解具体情况而妄下论断。

【赏析】近日，习近平总书记在宁夏考察时指出，“要坚持不懈推动高质量发展，加快转变经济发展方式，加快产业转型升级，加快新旧动能转换，推动经济发展实现量的合理增长和质的稳步提升。”受新冠肺炎疫情影响，今年全球经济形势不容乐观，我国经济也面临较大下行压力。压力之下，更要保持清醒头脑，坚定信心决心，不被困难吓倒，不为形势所惑，一定要坚定不移走高质量发展之路，发挥创新驱动作用，推动产业向高端化、绿色化、智能化、融合化方向发展。

::: card title="骐骥一跃，不能十步；驽马十驾，功在不舍" icon="svg-spinners:12-dots-scale-rotate"


【例文】吃苦耐劳，永葆马不停蹄的毅力。“==骐骥一跃，不能十步;驽马十驾，功在不舍。==”蒙古马之所以跑得远源于耐力惊人。当前，我们取得了疫情防控阻击战的重大战略成果，但“鞍马犹未歇，战鼓又催征”党员干部要坚决摒弃歇歇脚、松口气的思想，永葆艰苦奋斗的政治本色，不怕疲劳、连续作战，让“在路上”始终成为常态。

【典故】出自荀子《劝学》，故不积跬步，无以至千里;不积小流无以成江海。骐骥一跃，不能十步;驽马十驾，功在不舍。锲而舍之，朽木不折;锲而不舍，金石可镂。意思是，以千里马的一跃，却还不到十步而老马走一步没多远，却不舍，相比之下，当然老马走的更远了。比喻作学问应该持之以恒。

【赏析】习近平总书记在参加全国两会内蒙古代表团审议时强调要大力弘扬“蒙古马精神”。“蒙古马精神”实质是一种吃苦耐劳、一往无前、不达目的绝不罢休的精神品质，在决胜全面建成小康社会、决战脱贫攻坚目标任务的关键时刻，广大党员干部要积极进取、奋发有为，做“蒙古马精神”的真正实践者。

::: card title="志行万里者，不中道而辍足" icon="svg-spinners:12-dots-scale-rotate"


【例文】志行万里者，不中道而辍足。落实我军建设发展“十三五”规划是一项宏大工程，任务艰巨繁重、工作千头万绪。全军要以“咬定青山不放松”的韧劲、“不破楼兰终不还”的拼劲，进一步加强统筹协调，加强重点突破，加强责任落实，以钉钉子的精神清“淤点”、通“堵点”、解“难点”。

【典故】出自晋代陈寿《三国志·吴书·陆逊传》，志行万里者，不中道而辍足;图四海者，匪怀细以害大。意思是，立志行万里的人，不会中途停步;想要统一天下的人，不会对小事耿耿于怀而危害大事。

【赏析】习近平总书记在出席十三届全国人大三次会议解放军和武警部队代表团全体会议时指出，“今年是我军建设发展'十三五’规划收官之年，要采取超常措施，克服疫情影响，集中力量打好规划落实攻坚战，力保重大任务完成、战略能力有大的提升。”总书记的重要讲话，从实现中国梦强军梦的高度，发出了打好我军建设规划落实攻坚战的动员令、任务书，必将进一步汇聚起全军官兵狠抓规划落实、开创强军事业新局面的磅礴力量。
