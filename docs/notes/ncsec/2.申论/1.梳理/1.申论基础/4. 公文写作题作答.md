# 申论公文写作题作答专题笔记

## 一、公文分类

### （一）固定模板类
- **报告**：向上级机关汇报工作、反映情况、答复询问。
- **请示**：向上级机关请求指示、批准。
- **通知**：传达要求下级机关执行或有关单位周知的事项。
- **意见**：对重要问题提出见解和处理办法。
- **函**：不相隶属机关之间商洽工作、询问和答复问题。

### （二）总结材料类
- **讲话稿（发言稿）**：在会议或集会上发表的讲话文稿。
- **演讲稿**：在公开场合发表的演讲文稿。
- **讲解稿**：对人物、画面、展品或旅游景观进行讲解的文稿。
- **简报**：简要报告工作、情况或动态。
- **编者按**：编辑对文章或消息的简短评语。
- **调研报告**：对调研结果的总结和分析。
- **新闻稿**：向新闻媒体发布的消息。
- **会议纪要**：记录会议主要情况和议定事项。
- **提纲**：讲话或文章的要点框架。

### （三）提出对策类
- **建议书**：提出解决问题的建议和方案。
- **方案**：具体的行动计划或操作步骤。

### （四）宣传说服类
- **倡议书**：号召大家共同做某事的书面文章。
- **宣传稿**：传播信息、理念或主张的文稿。
- **信（回信、公开信、感谢信、邀请信）**：用于沟通交流的书信形式。

### （五）发表评论类
- **短评**：对事例、看法或现象的简短评价。
- **时评**：对当前热点问题的评论。

## 二、公文的定义

公文，即公务文书，是党政机关、社会团体和企事业单位在行使管理职权、处理日常工作时使用的书面文字工具。它是各类社会组织用以表达意志、传达指令的方式和手段。

## 三、公文的格式

公文格式共18个要素，分为版头、主体、版记三部分及版心外要素。

### （一）版头（6个要素）
- **份号**：公文印制份数的顺序号。
- **密级和保密期限**：公文的保密等级和保密时间。
- **紧急程度**：公文送达和办理的时限要求。
- **发文机关标志**：发文机关的名称。
- **发文字号**：由发文机关代字、年份、发文顺序号组成。
- **签发人**：签发公文的机关负责人姓名。

### （二）主体（9个要素）
- **标题**：由发文机关名称、事由和文种组成。
- **主送机关**：公文的主要受理机关。
- **正文**：公文的主体内容。
- **附件说明**：公文附件的顺序号和名称。
- **发文机关署名**：发文机关的全称或规范化简称。
- **成文日期**：公文的生效时间。
- **印章**：发文机关的公章。
- **附注**：需要说明的事项。
- **附件**：公文的附属文件。

### （三）版记（3个要素）
- **抄送机关**：需要了解或协助办理公文的机关。
- **印发机关**：负责印制公文的机关。
- **印发日期**：公文的印制时间。

### （四）版心外要素
- **页码**：公文页面的顺序号。

## 四、公文的处理

### （一）公文写作原则
1. **符合法律法规和政策**：公文内容必须符合国家法律法规和党的路线方针政策。
2. **实事求是**：分析问题要客观，提出的措施要切实可行。
3. **简洁明了**：内容简洁，主题突出，观点鲜明，结构严谨，文字精炼。
4. **文种正确，格式规范**：选择正确的公文种类，格式符合规范。

## 五、公文写作实例

### （一）讲话稿
**标题**：在社区治理与服务经验交流座谈会上的发言  
**正文**：
```
尊敬的各位领导、亲爱的同仁们：

大家好！很荣幸能在此次“社区治理与服务经验交流座谈会”上发言。曾几何时，清河社区面临诸多难题，河水黑臭，严重影响居民生活与社区环境。但经过一系列努力，如今的清河社区已焕然一新，充满活力。我来自石板街道，今天想和大家分享我们辖区内清河社区的治理之道。

在河水污染治理方面，我们关停了沿岸“散乱污”小作坊，从源头减少污染。同时，积极创新治污方式，多方探索科学有效的治理手段，逐渐让清河恢复清澈。

对于清河直街的改造，社区主动与居民沟通，切实帮助群众解决难题。秉持保留历史积淀的理念，保留老字号店铺，留住老城记忆，同时吸引有文化气息的新商铺入驻，既传承文化，又为街区注入新活力。

考虑到社区老龄化问题，我们重点服务老人群体。不仅关注他们的日常需求，更注重引领其生活方式。划分功能区，开设丰富的兴趣班，聘请专业老师教学，让老人紧跟时代步伐，找到归属感。同时，就近增设卫生服务站并开通医保卡，为老人提供便捷、全面的基本医疗服务。

在社区管理中，我们借力科技引入智能管理系统。通过全天候监控重点区域，自动识别违规行为和不文明现象，并实时发送至后台，大大提高管理效率。

此外，我们积极构建共建共治共享格局。成立自治管理委员会，鼓励商家、社工等多元主体参与社区事务。比如在老旧小区改造过程中，充分收集群众意见，让改造更贴合居民需求。

当然，我们在社区治理与服务的道路上还有很长的路要走，未来也将继续探索创新。希望能和各位同仁多多交流，共同提升社区治理与服务水平，为居民创造更美好的生活环境。

谢谢大家！
```
