::: card title="不谋全局者，不足谋一域" icon="svg-spinners:12-dots-scale-rotate"

【例文】“==不谋万世者，不足谋一时;不谋全局者，不足谋一域==。”面对变化，如果应对有方、化解有术,“失之东隅”后也能“收之桑榆”如果善于乘势而上、顺势而为，“山重水复”后也能“柳暗花明”。化危为机的本领不是与生俱来的，而是在困难、险境甚至绝境中摔打练出来的。要在复杂严峻的斗争中==经风雨、见世面、壮筋骨==，通过反复实践逐渐提升对势态的规律性认识和把握能力，做到“==任凭风浪起，稳坐钓鱼台==”。

【典故】出自清代陈澹然《寤言二·迁都建藩议》，不谋万世者，不足谋一时;不谋全局者，不足谋一域。意思是，从全局的角度考虑问题，即使治理好一方地区，也是微不足道的。不能制定长久的国家政策，一时的聪明也是微不足道的。

【赏析】习近平总书记强调，要坚持用全面、辩证、长远的眼光分析当前经济形势，努力在危机中育新机、于变局中开新局。当前，我们正面临百年未有之大变局，组工干部当有“春江水暖鸭先知”的敏锐，在复杂多变的国际国内环境中善感水温、知水情、顺水势，不断提高驾驭风险化危为机的本领。


:::

::: card title="处大事贵乎明而能断" icon="svg-spinners:12-dots-scale-rotate"


【例文】“==处大事贵乎明而能断==。”在危机中育新机，于变局中开新局，推动高质量发展是根本要求，不迷失方向，莫自乱方寸。

【典故】出自明代薛瑄《从政录》，处大事贵乎明而能断，不明固无以知事之当断，然明而不断,亦不免于后艰矣。意思是，处理重要的大事情必须了解事情真相才能下结论，对事情的起因不明了不能了解具体情况而妄下论断。

【赏析】近日，习近平总书记在宁夏考察时指出，“要坚持不懈推动高质量发展，加快转变经济发展方式，加快产业转型升级，加快新旧动能转换，推动经济发展实现量的合理增长和质的稳步提升。”受新冠肺炎疫情影响，今年全球经济形势不容乐观，我国经济也面临较大下行压力。压力之下，更要保持清醒头脑，坚定信心决心，不被困难吓倒，不为形势所惑，一定要坚定不移走高质量发展之路，发挥创新驱动作用，推动产业向高端化、绿色化、智能化、融合化方向发展。

:::

::: card title="骐骥一跃，不能十步；驽马十驾，功在不舍" icon="svg-spinners:12-dots-scale-rotate"


【例文】吃苦耐劳，永葆马不停蹄的毅力。“==骐骥一跃，不能十步;驽马十驾，功在不舍。==”蒙古马之所以跑得远源于耐力惊人。当前，我们取得了疫情防控阻击战的重大战略成果，但“鞍马犹未歇，战鼓又催征”党员干部要坚决摒弃歇歇脚、松口气的思想，永葆艰苦奋斗的政治本色，不怕疲劳、连续作战，让“在路上”始终成为常态。

【典故】出自荀子《劝学》，故不积跬步，无以至千里;不积小流无以成江海。骐骥一跃，不能十步;驽马十驾，功在不舍。锲而舍之，朽木不折;锲而不舍，金石可镂。意思是，以千里马的一跃，却还不到十步而老马走一步没多远，却不舍，相比之下，当然老马走的更远了。比喻作学问应该持之以恒。

【赏析】习近平总书记在参加全国两会内蒙古代表团审议时强调要大力弘扬“蒙古马精神”。“蒙古马精神”实质是一种吃苦耐劳、一往无前、不达目的绝不罢休的精神品质，在决胜全面建成小康社会、决战脱贫攻坚目标任务的关键时刻，广大党员干部要积极进取、奋发有为，做“蒙古马精神”的真正实践者。
